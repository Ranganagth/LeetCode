# Intuition

Since commas are inserted after every three digits from the right, the number of commas in any given number depends solely on **how many digits it has**. Specifically, for a number with `d` digits:

```text
commas = floor((d - 1) / 3)
```

For example:
- `1-3` digits → `0` commas
- `4-6` digits → `1` comma
- `7-9` digits → `2` commas
- and so on...

So instead of manually formatting every number as a string and counting commas character by character, we can simply compute the digit count of each number and apply this formula directly — this is both simpler and faster.

---

# Approach

1. Iterate through every integer `i` from `1` to `n`.
2. For each `i`, determine its digit count `d` (e.g., using `i.toString().length` or a mathematical method).
3. Compute the comma contribution: `Math.floor((d - 1) / 3)`.
4. Sum up the contributions across all numbers from `1` to `n`.
5. Return the total sum.

Given the constraint `n ≤ 10^5`, a simple linear scan is efficient enough — no need for complex range-based batching, though that optimization is possible for much larger `n`.

---

# Complexity

- **Time complexity:** 
$$O(n)$$
We process each number once, and computing digit length takes constant time relative to the small fixed range of digit counts (at most 6 digits since $n ≤ 10^5$).

- **Space complexity:** 
$$O(1)$$
Only a running total is stored; no additional data structures are needed.

---

# Code

```typescript
function countCommas(n: number): number {
    let totalCommas = 0;

    for (let i = 1; i <= n; i++) {
        const digitCount = i.toString().length;
        totalCommas += Math.floor((digitCount - 1) / 3);
    }

    return totalCommas;
};

```

# Example Walkthrough

## Example 1

```text
n = 1002
```

Numbers with 4+ digits in range `[1, 1002]`: `1000, 1001, 1002` (each has 4 digits).

For each: `digitCount = 4` → `floor((4-1)/3) = floor(1) = 1` comma.

```text
Total = 1 + 1 + 1 = 3
```

Output: `3`

## Example 2

```text
n = 998
```

All numbers from `1` to `998` have at most 3 digits:

```text
floor((3-1)/3) = floor(0.67) = 0 commas for every number
```

```text
Total = 0
```

Output: `0`
