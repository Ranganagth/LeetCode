# Intuition

This is a classic **game theory** problem that can be solved using **dynamic programming**. The key insight is that a position is a winning position if there exists at least one move that leads to a losing position for the opponent.

**Key insight:** 
- A position is **winning** if we can make a move that puts the opponent in a **losing** position
- A position is **losing** if all possible moves lead to **winning** positions for the opponent
- Base case: 0 stones is a losing position (no moves available)

---

# Approach

1. **Use DP to track winning/losing positions:**
   - `dp[i]` = true if the current player wins with i stones remaining
   - `dp[0]` = false (no stones = no moves = lose)

2. **For each position i:**
   - Try removing all possible perfect squares (1, 4, 9, 16, ...)
   - If any move leads to a losing position for opponent (`dp[i - square] = false`), then current position is winning

3. **Optimization:**
   - Only check perfect squares ≤ i
   - Stop early if we find a winning move

---

# Complexity

- **Time complexity:** O(n × √n)
  - For each position i, we check up to √i perfect squares
- **Space complexity:** $O(n)$ for the DP array

# Code

## Solution 1: Dynamic Programming (Recommended)

```typescript
function winnerSquareGame(n: number): boolean {
    // dp[i] = true if current player wins with i stones
    const dp = new Array(n + 1).fill(false);
    
    // Base case: 0 stones = losing position
    dp[0] = false;
    
    // Fill DP table
    for (let i = 1; i <= n; i++) {
        // Try removing each perfect square
        for (let square = 1; square * square <= i; square++) {
            const remove = square * square;
            
            // If removing 'remove' stones leads to losing position for opponent
            // then current position is winning
            if (!dp[i - remove]) {
                dp[i] = true;
                break; // Found a winning move, no need to check more
            }
        }
    }
    
    return dp[n];
};

```

## Solution 2: With Detailed Comments

```typescript
function winnerSquareGame(n: number): boolean {
    // dp[i] represents whether the current player can win with i stones
    const dp = new Array(n + 1).fill(false);
    
    // Base case: with 0 stones, the current player has no moves and loses
    dp[0] = false;
    
    // Calculate for each number of stones from 1 to n
    for (let i = 1; i <= n; i++) {
        // Try all possible perfect square moves
        // We can remove 1, 4, 9, 16, ... stones (1², 2², 3², 4², ...)
        for (let k = 1; k * k <= i; k++) {
            const stonesToRemove = k * k;
            const remaining = i - stonesToRemove;
            
            // If after this move, the opponent is in a losing position,
            // then the current position is a winning position
            if (!dp[remaining]) {
                dp[i] = true;
                break; // Found a winning move, no need to check further
            }
        }
        
        // If dp[i] is still false, it means all moves lead to
        // winning positions for the opponent, so this is a losing position
    }
    
    return dp[n];
};

```

## Solution 3: Memoization (Top-Down)

```typescript
function winnerSquareGame(n: number): boolean {
    const memo = new Map<number, boolean>();
    
    function canWin(remaining: number): boolean {
        // Base case: no stones left, current player loses
        if (remaining === 0) return false;
        
        // Check memo
        if (memo.has(remaining)) {
            return memo.get(remaining)!;
        }
        
        // Try all perfect square moves
        for (let k = 1; k * k <= remaining; k++) {
            const remove = k * k;
            
            // If this move leads to opponent losing, we win
            if (!canWin(remaining - remove)) {
                memo.set(remaining, true);
                return true;
            }
        }
        
        // All moves lead to opponent winning, we lose
        memo.set(remaining, false);
        return false;
    }
    
    return canWin(n);
};

```

## Solution 4: Optimized with Early Break

```typescript
function winnerSquareGame(n: number): boolean {
    const dp = new Array(n + 1).fill(false);
    
    for (let i = 1; i <= n; i++) {
        // Calculate max square we can remove
        const maxSquare = Math.floor(Math.sqrt(i));
        
        for (let k = 1; k <= maxSquare; k++) {
            const remove = k * k;
            
            if (!dp[i - remove]) {
                dp[i] = true;
                break;
            }
        }
    }
    
    return dp[n];
};

```

# Key Insights

- **Game theory DP:** Position is winning if any move leads to losing position
- **Perfect squares:** Only moves available are removing 1, 4, 9, 16, ...
- **Optimal play:** Both players choose best moves
- **No pattern:** Unlike some game theory problems, this doesn't follow a simple mathematical pattern
- **Must compute:** Need to calculate all positions up to n

# Common Mistakes to Avoid

1. **Not breaking after finding winning move:**
   ```typescript
   // Wrong: continues checking even after finding win
   for (let k = 1; k * k <= i; k++) {
       if (!dp[i - k*k]) {
           dp[i] = true;
       }
   }
   
   // Correct: break early
   if (!dp[i - k*k]) {
       dp[i] = true;
       break;
   }
   ```

2. **Wrong base case:**
   ```typescript
   // Wrong: 0 stones is winning
   dp[0] = true;
   
   // Correct: 0 stones is losing (no moves)
   dp[0] = false;
   ```

3. **Not checking all perfect squares:**
   ```typescript
   // Wrong: only checking k=1
   if (!dp[i - 1]) dp[i] = true;
   
   // Correct: check all k where k² ≤ i
   for (let k = 1; k * k <= i; k++)
   ```

4. **Integer overflow in square calculation:**
   ```typescript
   // Wrong: might overflow for large k
   for (let k = 1; k <= n; k++) {
       if (k * k <= i) ...
   }
   
   // Correct: check condition first
   for (let k = 1; k * k <= i; k++)
   ```

- **Solution:** DP to find winning/losing positions
