# Intuition

At first glance, this seems like it requires checking many possible combinations, but a key mathematical observation simplifies everything: since subtraction preserves parity behavior in a predictable way, we can analyze this purely through **parity counting** (number of odd vs. even values), without needing to construct anything explicitly.

Specifically:
```text
parity(a - b) = parity(a) XOR parity(b)
```

This means for any index `i`, we can either:
- Keep its own parity (`nums1[i]`), or
- Flip it to the opposite parity, **but only if** there exists some other index `j ≠ i` with parity equal to the *needed* value.

---

# Approach

## Step 1: Count odd and even numbers

Let:
```text
oddCount = number of odd values in nums1
evenCount = n - oddCount
```

## Step 2: Case analysis

**Case A: All values already the same parity**
- If `oddCount == 0` → all even already → **true**
- If `oddCount == n` → all odd already → **true**

**Case B: Mixed parities (`0 < oddCount < n`)**

Choose target parity `T = odd`.

- Every index that is already odd satisfies `T` directly (keep itself).
- Every even index needs to flip to odd. To do so, it needs some `j ≠ i` where `nums1[j]` is odd.
  - Since `oddCount ≥ 1`, at least one odd index exists.
  - Since the current index `i` is even, that odd index is automatically different from `i`.
  - So **every even index can successfully flip to odd**.

This means: **whenever there is a mix of odd and even numbers, choosing "all odd" as the target always works.**

## Step 3: Conclusion

Combining both cases:
- If all same parity already → trivially true.
- If mixed → target "odd" always works.

**Therefore, the answer is always `true`** for any valid input satisfying the given constraints (`n ≥ 1`, distinct integers).

- **Time complexity:**
$$O(1)$$

- **Space complexity:** 
$$O(1)$$

# Code

```typescript
function uniformArray(nums1: number[]): boolean {
    const n = nums1.length;

    let oddCount = 0;
    for (const num of nums1) {
        if (num % 2 !== 0) {
            oddCount++;
        }
    }

    const evenCount = n - oddCount;

    // Case 1: All already even.
    if (oddCount === 0) {
        return true;
    }

    // Case 2: All already odd.
    if (evenCount === 0) {
        return true;
    }

    // Case 3: Mixed parities — target "odd" is always achievable,
    // since every even index can flip using any available odd index.
    return true;
};

```

# Example Walkthrough

## Example 1

```text
nums1 = [2, 3]
```

- `oddCount = 1`, `evenCount = 1` → mixed case.
- Target: all odd.
  - Index 0 (`2`, even) flips using index 1 (`3`, odd): `2 - 3 = -1` (odd)
  - Index 1 (`3`, odd) keeps itself: `3` (odd)
- Result: `nums2 = [-1, 3]`, all odd.

Output: `true`

## Example 2

```text
nums1 = [4, 6]
```

- `oddCount = 0` → all already even.
- Keep both as-is: `nums2 = [4, 6]`, all even.

Output: `true`

> **Key takeaway:** Due to the parity-flipping property of subtraction, this problem's answer is **always `true`** under the given constraints — no counterexample exists for `n ≥ 1` with distinct integers.
