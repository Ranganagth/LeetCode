# Intuition

We need to find the smallest number ≥ n where the product of its digits is divisible by t. A brute force approach works well given the small constraints (n ≤ 100, t ≤ 10).

**Key insight:** Simply iterate from n upward, calculate the digit product for each number, and return the first one divisible by t.

---

# Approach

1. **Start from n** and iterate upward

2. **For each number:**
   - Calculate the product of its digits
   - Check if the product is divisible by t
   - If yes, return this number

3. **Digit product calculation:**
   - Extract each digit by using modulo 10
   - Multiply all digits together

---

# Complexity

- **Time complexity:** $O(k × d)$ where k is the difference between result and n, d is number of digits
  - In worst case, k is small (at most a few iterations)
  - d ≤ 3 for n ≤ 1**00
- **Space** complexity:** $O(1)$ - only using variables

# Code

## Solution 1: Brute Force (Recommended)

```typescript
function smallestNumber(n: number, t: number): number {
    // Iterate from n upward
    for (let num = n; ; num++) {
        if (digitProduct(num) % t === 0) {
            return num;
        }
    }
}

function digitProduct(num: number): number {
    let product = 1;
    
    while (num > 0) {
        product *= num % 10;
        num = Math.floor(num / 10);
    }
    
    return product;
};

```

## Solution 3: Inline Digit Product

```typescript
function smallestNumber(n: number, t: number): number {
    for (let num = n; ; num++) {
        let product = 1;
        let temp = num;
        
        // Calculate digit product
        while (temp > 0) {
            product *= temp % 10;
            temp = Math.floor(temp / 10);
        }
        
        // Check divisibility
        if (product % t === 0) {
            return num;
        }
    }
};

```

## Solution 4: With Detailed Comments

```typescript
function smallestNumber(n: number, t: number): number {
    // Start from n and check each number
    for (let num = n; ; num++) {
        // Calculate the product of digits
        const product = getDigitProduct(num);
        
        // Check if product is divisible by t
        if (product % t === 0) {
            return num;
        }
    }
}

function getDigitProduct(num: number): number {
    let product = 1;
    
    // Extract each digit and multiply
    while (num > 0) {
        const digit = num % 10; // Get last digit
        product *= digit; // Multiply to product
        num = Math.floor(num / 10); // Remove last digit
    }
    
    return product;
};

```

# Key Insights

- **Brute force works:** Small constraints allow simple iteration
- **Digit product:** Extract digits using modulo and division
- **Zero handling:** Any number with 0 digit has product 0 (divisible by any t)
- **Quick convergence:** Answer is usually very close to n

# Common Mistakes to Avoid

1. **Not handling zero correctly:**
   ```typescript
   // Wrong: might skip numbers with 0
   if (product === 0) continue;
   
   // Correct: 0 is divisible by any number
   if (product % t === 0) return num;
   ```

2. **Integer division issues:**
   ```typescript
   // Wrong: might not work in all languages
   num = num / 10;
   
   // Correct: explicit floor division
   num = Math.floor(num / 10);
   ```

3. **Infinite loop without bound:**
   ```typescript
   // Wrong: no upper limit
   for (let num = n; ; num++)
   
   // Better: add reasonable upper bound
   for (let num = n; num <= 1000; num++)
   ```

4. **Not initializing product to 1:**
   ```typescript
   // Wrong: product starts at 0
   let product = 0;
   
   // Correct: product starts at 1
   let product = 1;
   ```
