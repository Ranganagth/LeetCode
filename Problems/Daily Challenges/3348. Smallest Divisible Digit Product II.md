# Intuition

We need to find the smallest zero-free number ≥ num where the product of its digits is divisible by t. The solution uses a **greedy approach** with three main strategies:

1. **Check impossibility:** If t has prime factors > 9, it's impossible
2. **Try to modify num:** Increment digits and fill remaining positions optimally
3. **Build from scratch:** If modification fails, construct the smallest valid number

**Key insight:** Use GCD to track remaining factors needed, and greedily place largest possible digits to minimize the number.

---

# Approach

1. **Validate t:**
   - Check if t only has prime factors ≤ 9 (2, 3, 5, 7)
   - If t has factors > 9, return "-1"

2. **Check if num already works:**
   - Track remaining factors needed as we scan left to right
   - If we can satisfy all factors without zeros, return num

3. **Try incrementing num:**
   - From the position where we failed (or found a zero), try incrementing
   - For each increment, greedily fill remaining positions with largest digits
   - Use GCD to track what factors are still needed

4. **Build new number:**
   - If incrementing doesn't work, build smallest number with required factors
   - Use digits 9, 8, 7, ... greedily to minimize length
   - Pad with 1s if needed to match or exceed original length

---

# Complexity

- **Time complexity:** $O(n × d × log t)$ where n is string length, d is digit range (9)
- **Space complexity:** $O(n)$ for arrays and result string

# Code

```typescript
function smallestNumber(num: string, t: number): string {
    // Step 1: Check if t is achievable (only has factors 2-9)
    let temp = t;
    for (let i = 2; i <= 9; i++) {
        while (temp % i === 0) {
            temp /= i;
        }
    }
    // If temp > 1, t has prime factors > 9 (impossible)
    if (temp > 1) {
        return "-1";
    }

    const n = num.length;
    const rem = new Array(n + 1); // rem[i] = remaining factors needed after position i
    rem[0] = t;
    let pos = n - 1; // Position where we need to start modifying

    const numArr = num.split("");
    
    // Step 2: Check if num already works (and find first zero if any)
    for (let i = 0; i < n; i++) {
        if (numArr[i] === "0") {
            pos = i; // Found a zero, must modify from here
            break;
        }
        // Update remaining factors: divide by GCD of current remainder and digit
        rem[i + 1] = Math.floor(rem[i] / gcd(rem[i], parseInt(numArr[i])));
    }

    // If all factors satisfied and no zeros, num works!
    if (rem[n] === 1) {
        return num;
    }

    // Step 3: Try incrementing from position pos
    for (let i = pos; i >= 0; i--) {
        while (true) {
            // Try next digit at position i
            numArr[i] = String.fromCharCode(numArr[i].charCodeAt(0) + 1);
            
            // If we exceeded '9', try previous position
            if (numArr[i] > "9") {
                break;
            }

            // Calculate remaining factors after this digit
            let tNow = Math.floor(rem[i] / gcd(rem[i], parseInt(numArr[i])));
            let k = 9;

            // Greedily fill remaining positions with largest possible digits
            for (let j = n - 1; j > i; j--) {
                // Find largest digit k that divides tNow
                while (tNow % k !== 0) {
                    k--;
                }
                tNow = Math.floor(tNow / k);
                numArr[j] = String.fromCharCode("0".charCodeAt(0) + k);
            }

            // If all factors satisfied, we found the answer!
            if (tNow === 1) {
                return numArr.join("");
            }
        }
    }

    // Step 4: Build new number from scratch (need extra digit)
    let ans: string[] = [];
    let originalT = t;
    
    // Greedily use largest digits (9, 8, 7, ...) to minimize length
    for (let i = 9; i > 1; i--) {
        while (originalT % i === 0) {
            ans.push(String.fromCharCode("0".charCodeAt(0) + i));
            originalT = Math.floor(originalT / i);
        }
    }

    // Pad with 1s to ensure length is at least n+1
    const padding = Math.max(n + 1 - ans.length, 0);
    for (let i = 0; i < padding; i++) {
        ans.push("1");
    }

    // Reverse to get smallest number (we built from largest digits)
    return ans.reverse().join("");
}

function gcd(a: number, b: number): number {
    while (b !== 0) {
        const temp = b;
        b = a % b;
        a = temp;
    }
    return a;
};

```

# Key Insights

- **GCD tracking:** Efficiently tracks remaining factors needed
- **Greedy filling:** Use largest digits to minimize number
- **Three-phase approach:** Check, modify, or build from scratch
- **Zero handling:** Must avoid zeros, triggers modification
- **Impossibility check:** Early return if t has large primes

# Common Mistakes to Avoid

1. **Not checking for zeros:**
   ```typescript
   // Wrong: might miss zeros
   if (rem[n] === 1) return num;
   
   // Correct: check zeros during scan
   if (numArr[i] === "0") {
       pos = i;
       break;
   }
   ```

2. **Wrong GCD usage:**
   ```typescript
   // Wrong: not reducing factors
   rem[i+1] = rem[i] - digit;
   
   // Correct: divide by GCD
   rem[i+1] = rem[i] / gcd(rem[i], digit);
   ```

3. **Not reversing final answer:**
   ```typescript
   // Wrong: largest digits first
   return ans.join("");
   
   // Correct: reverse for smallest number
   return ans.reverse().join("");
   ```
