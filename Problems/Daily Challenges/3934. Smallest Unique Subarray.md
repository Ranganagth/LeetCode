# Intuition

A brute-force check of every possible subarray length and every starting position would be too slow for `n <= 10^5` (`O(n³)` or worse with naive string comparisons). Instead, we rely on two key ideas:

1. **Monotonicity:** If a unique subarray of length `L` exists, then a unique subarray of length `L + 1` must also exist. This is because extending a *unique* subarray by one element (on whichever side has room) cannot suddenly make it non-unique - if two different positions produced the same extended subarray, their shared prefix of length `L` would also match, contradicting the original subarray's uniqueness. This lets us **binary search** on the answer length.

2. **Efficient equality checks:** To check all subarrays of a fixed length `L` for uniqueness quickly, we use **polynomial rolling hashing** (with two independent moduli to minimize collisions), allowing `O(1)` hash computation per subarray after `O(n)` preprocessing.

Combining binary search with rolling hash gives an overall `O(n log n)` solution.

---

# Approach

## 1. Precompute Rolling Hashes

Build prefix hash arrays using two different `(base, mod)` pairs to reduce the chance of hash collisions:

```text
prefix[i+1] = prefix[i] * base + (nums[i] + 1) mod M
```

Also precompute powers of the base up to `n` for quick substring hash extraction:

```text
hash(l, r) = (prefix[r+1] - prefix[l] * base^(r-l+1)) mod M
```

## 2. Check Function for a Given Length `L`

For a candidate length `L`, compute the combined (double) hash of every subarray `[i, i+L-1]`, and count occurrences using a `Map`. If **any** hash has a count of exactly `1`, a unique subarray of that length exists.

## 3. Binary Search on Length

Since uniqueness is monotonic in length (proven above), binary search for the smallest `L` where `check(L)` returns `true`:

```text
lo = 1, hi = n
while lo < hi:
    mid = (lo + hi) / 2
    if check(mid): hi = mid
    else: lo = mid + 1
return lo
```

The full array (`L = n`) always trivially satisfies uniqueness (only one subarray of that length exists), so the search space is well-defined and always has a valid answer.

---

# Complexity

- **Time complexity:** $O(n log n)$ - $O(log n)$ binary search iterations, each performing an $O(n)$ check using rolling hashes.
- **Space complexity:** $O(n)$ - for prefix hash arrays, power arrays, and the hash-count map used per check.

# Code

```typescript
function smallestUniqueSubarray(nums: number[]): number {
    const n = nums.length;
    if (n === 0) return 0;

    const MOD1 = 1_000_000_007n;
    const MOD2 = 998_244_353n;
    const BASE1 = 131542n;
    const BASE2 = 137511n;

    const prefix1 = new Array<bigint>(n + 1).fill(0n);
    const prefix2 = new Array<bigint>(n + 1).fill(0n);
    const pow1 = new Array<bigint>(n + 1).fill(1n);
    const pow2 = new Array<bigint>(n + 1).fill(1n);

    for (let i = 0; i < n; i++) {
        const v = BigInt(nums[i] + 1);
        prefix1[i + 1] = (prefix1[i] * BASE1 + v) % MOD1;
        prefix2[i + 1] = (prefix2[i] * BASE2 + v) % MOD2;
        pow1[i + 1] = (pow1[i] * BASE1) % MOD1;
        pow2[i + 1] = (pow2[i] * BASE2) % MOD2;
    }

    const getHash1 = (l: number, r: number): bigint => {
        const len = r - l + 1;
        let result = (prefix1[r + 1] - (prefix1[l] * pow1[len]) % MOD1) % MOD1;
        if (result < 0n) result += MOD1;
        return result;
    };

    const getHash2 = (l: number, r: number): bigint => {
        const len = r - l + 1;
        let result = (prefix2[r + 1] - (prefix2[l] * pow2[len]) % MOD2) % MOD2;
        if (result < 0n) result += MOD2;
        return result;
    };

    const check = (length: number): boolean => {
        const counts = new Map<string, number>();

        for (let i = 0; i + length - 1 < n; i++) {
            const key = getHash1(i, i + length - 1).toString() + '_' + getHash2(i, i + length - 1).toString();
            counts.set(key, (counts.get(key) ?? 0) + 1);
        }

        for (const count of counts.values()) {
            if (count === 1) return true;
        }

        return false;
    };

    let lo = 1;
    let hi = n;

    while (lo < hi) {
        const mid = (lo + hi) >> 1;

        if (check(mid)) {
            hi = mid;
        } else {
            lo = mid + 1;
        }
    }

    return lo;
};

```

# Example Walkthrough

## Example

```text
nums = [1, 1, 2, 2, 1]
```

**Binary search trace** (`lo=1, hi=5`):

- `mid = 3`: subarrays of length 3 → `[1,1,2], [1,2,2], [2,2,1]` - all distinct (each appears once) → `check(3) = true` → `hi = 3`
- `mid = 2`: subarrays of length 2 → `[1,1], [1,2], [2,2], [2,1]` - all distinct → `check(2) = true` → `hi = 2`
- `mid = 1`: subarrays of length 1 → `[1]` appears `3` times, `[2]` appears `2` times - no unique one → `check(1) = false` → `lo = 2`

Loop ends (`lo = hi = 2`).

Output: `2`

This matches the expected result - the smallest length at which a unique subarray exists is `2`.
