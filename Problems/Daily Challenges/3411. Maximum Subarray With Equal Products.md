# Intuition

Since `nums.length <= 100`, a straightforward **brute-force check of every subarray** is well within limits. For each subarray, we compute its product, GCD, and LCM, and check whether `product == lcm * gcd`. We track the longest subarray satisfying this condition.

---

# Approach

1. Iterate over every possible starting index `i`.
2. Iterate over every possible ending index `j >= i`, extending the subarray one element at a time.
3. Maintain running `product`, `gcd`, and `lcm` as the subarray grows:
   - `product *= nums[j]`
   - `gcd = gcd(gcd, nums[j])`
   - `lcm = lcm(lcm, nums[j])`
4. Check if `product === lcm * gcd`. If so, update the maximum length found so far.
5. Return the maximum length.

Since `nums[i] <= 10` and subarray length `<= 100`, the product can grow large (up to `10^100` in theory), but practically for product-equivalence to hold the values stay small - still, to be safe, we can bound the loop early if product exceeds a reasonable threshold (not strictly necessary given constraints, but helps avoid unnecessary huge number computations). In JavaScript/TypeScript, numbers remain safe for these small constraints without needing BigInt, since invalid (non-equivalent) subarrays will be filtered out and products naturally won't be used once they clearly can't satisfy the condition - but to keep it simple and correct, we just compute directly since `n <= 100` keeps total operations at `~10,000` iterations, trivially fast.

---

# Complexity

- **Time complexity:** $O(n²)$ - for each of the $O(n)$ starting points, we extend the subarray in $O(n)$, doing $O(1)$ work (gcd/lcm updates) at each step.
- **Space complexity:** $O(1)$ - only a few scalar variables are used per subarray.

---

# Code

```typescript
function maxLength(nums: number[]): number {
    const n = nums.length;

    const gcd = (a: number, b: number): number => {
        while (b !== 0) {
            [a, b] = [b, a % b];
        }
        return a;
    };

    const lcm = (a: number, b: number): number => {
        return (a / gcd(a, b)) * b;
    };

    let maxLen = 0;

    for (let i = 0; i < n; i++) {
        let product = 1;
        let currentGcd = 0;
        let currentLcm = 1;

        for (let j = i; j < n; j++) {
            product *= nums[j];
            currentGcd = gcd(currentGcd, nums[j]);
            currentLcm = lcm(currentLcm, nums[j]);

            if (product === currentLcm * currentGcd) {
                const length = j - i + 1;
                if (length > maxLen) {
                    maxLen = length;
                }
            }
        }
    }

    return maxLen;
};

```

# Example Walkthrough

## Example 1

```text
nums = [1, 2, 1, 2, 1, 1, 1]
```

Checking subarray starting at index `1`: `[2, 1, 2, 1, 1, 1]`... let's trace the one given in the explanation, `[1, 2, 1, 1, 1]` (indices `2` to `6`):

- `product = 1*2*1*1*1 = 2`
- `gcd = gcd(gcd(gcd(gcd(1,2),1),1),1) = 1`
- `lcm = lcm(lcm(lcm(lcm(1,2),1),1),1) = 2`
- Check: `product == lcm * gcd` → `2 == 2 * 1` → `2 == 2`

Length = `5`, which matches the expected output.

Output: `5`

## Example 2

```text
nums = [2, 3, 4, 5, 6]
```

Checking subarray `[3, 4, 5]` (indices `1` to `3`):

- `product = 3*4*5 = 60`
- `gcd = gcd(gcd(3,4),5) = 1`
- `lcm = lcm(lcm(3,4),5) = lcm(12,5) = 60`
- Check: `60 == 60 * 1` → Correct

Length = `3`, matching the expected output. Checking longer subarrays (e.g., including `2` or `6`) fails the equivalence condition due to shared factors inflating `gcd` or reducing `lcm` relative to the product.

Output: `3`

Checking subarray `[2, 3, 1, 4, 5]` (indices `1` to `5`):

Output: `5`
