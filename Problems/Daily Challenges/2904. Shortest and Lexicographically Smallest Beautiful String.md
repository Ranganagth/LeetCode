# Intuition

We need to find substrings with **exactly k ones**, determine the **minimum length** among all such substrings, then find the **lexicographically smallest** one among those with minimum length. Given the small constraint (n ≤ 100), a **sliding window** approach combined with checking all valid windows works efficiently.

---

# Approach

1. **Use a sliding window** to find all substrings with exactly `k` ones
2. **Track the minimum length** found so far
3. **Among substrings with minimum length**, keep the lexicographically smallest one
4. **Sliding window technique:** Expand right pointer to include more 1s, then shrink from left while maintaining exactly k ones (try to minimize window size)

---

# Complexity

- **Time Complexity:** $O(n²)$ worst case (or $O(n)$ with pure two-pointer, but comparing strings adds $O(n)$ per comparison)
- **Space Complexity:** $O(n)$ for storing result string

---

# Code

```typescript
function shortestBeautifulSubstring(s: string, k: number): string {
    const n = s.length;
    let minLen = Infinity;
    let result = "";
    
    let left = 0;
    let ones = 0;
    
    for (let right = 0; right < n; right++) {
        if (s[right] === '1') ones++;
        
        // Shrink from left while we have exactly k ones or more
        while (ones > k) {
            if (s[left] === '1') ones--;
            left++;
        }
        
        // Now check if we have exactly k ones, try to shrink further from left
        while (ones === k && s[left] === '0') {
            left++;
        }
        
        if (ones === k) {
            const len = right - left + 1;
            const candidate = s.slice(left, right + 1);
            
            if (len < minLen) {
                minLen = len;
                result = candidate;
            } else if (len === minLen && candidate < result) {
                result = candidate;
            }
        }
    }
    
    return result;
};

```

# Example Walkthrough

## Example 1: `s = "100011001", k = 3`

```
Sliding window finds various substrings with exactly 3 ones.
Shortest length found: 5
Among length-5 substrings with 3 ones, "11001" is lexicographically smallest.
```

**Output:** `"11001"` ✓

## Example 3: `s = "000", k = 1`

```
No '1's exist, so ones never reaches k=1
result remains ""
```

**Output:** `""` ✓

# Key Insight

The sliding window technique efficiently finds all valid windows with exactly `k` ones, and by tracking minimum length while comparing lexicographically, we get the optimal answer in a single pass with $O(n)$ window operations (string comparisons add minor overhead but are negligible given n ≤ 100). 🔍
