# Intuition

We need to find the **kth smallest value** among all numbers reachable by any single coin's multiples (union across all coins, but a number can only use **one** denomination, not combinations).

**Key insight:** This is a classic **"kth smallest in union of multiples"** problem. We can use **binary search on the answer** combined with **inclusion-exclusion principle** to count how many valid numbers are ≤ some value `x`.

**Counting formula:** For any candidate `x`, the count of numbers ≤ x that are multiples of *at least one* coin equals:
```
count(x) = Σ (for each non-empty subset S of coins) (-1)^(|S|+1) × floor(x / LCM(S))
```

This works because:
- Single coins contribute positively (their multiples)
- Pairs are subtracted (avoid double-counting overlaps)
- Triples are added back, and so on (standard inclusion-exclusion)

---

# Approach

1. **Precompute LCM for all subsets** of coins using bitmask DP (since coins.length ≤ 15, there are at most 2^15 = 32768 subsets)

2. **Binary search on the answer `x`:**
   - Lower bound: 1
   - Upper bound: `min(coins) × k` (worst case if only smallest coin contributes)

3. **For each candidate `x`, count how many valid numbers exist ≤ x** using inclusion-exclusion over all subsets

4. **Binary search converges** to the smallest `x` where `count(x) >= k`

---

# Complexity

**Time Complexity:** O(2ⁿ × log(maxValue))
- n ≤ 15, so 2ⁿ ≤ 32768
- Binary search range up to ~5×10¹⁰, giving log ≈ 36 iterations
- Total: ~32768 × 36 ≈ 1.2 million operations

**Space Complexity:** $O(2ⁿ)$
- Storing LCM for each subset

# Code

```typescript
function findKthSmallest(coins: number[], k: number): number {
    const n = coins.length;
    
    function gcd(a: number, b: number): number {
        while (b !== 0) {
            [a, b] = [b, a % b];
        }
        return a;
    }
    
    function lcmCapped(a: number, b: number, cap: number): number {
        const g = gcd(a, b);
        const result = (a / g) * b;
        return result > cap ? cap + 1 : result; // cap to avoid overflow
    }
    
    const upperBound = Math.min(...coins) * k;
    const CAP = upperBound + 1;
    
    // Precompute LCM for every subset using bitmask DP
    const lcms: number[] = new Array(1 << n).fill(1);
    for (let mask = 1; mask < (1 << n); mask++) {
        const lowBit = mask & (-mask);
        const idx = Math.round(Math.log2(lowBit));
        const prevMask = mask ^ lowBit;
        lcms[mask] = lcmCapped(lcms[prevMask], coins[idx], CAP);
    }
    
    function popcount(x: number): number {
        let c = 0;
        while (x) {
            c += x & 1;
            x >>= 1;
        }
        return c;
    }
    
    function countLE(x: number): number {
        let count = 0;
        
        for (let mask = 1; mask < (1 << n); mask++) {
            const l = lcms[mask];
            if (l > x) continue;
            
            const bits = popcount(mask);
            const term = Math.floor(x / l);
            
            if (bits % 2 === 1) {
                count += term;
            } else {
                count -= term;
            }
        }
        
        return count;
    }
    
    let lo = 1;
    let hi = upperBound;
    
    while (lo < hi) {
        const mid = Math.floor((lo + hi) / 2);
        
        if (countLE(mid) >= k) {
            hi = mid;
        } else {
            lo = mid + 1;
        }
    }
    
    return lo;
};

```

## Solution with Detailed Comments

```typescript
function findKthSmallest(coins: number[], k: number): number {
    const n = coins.length;
    
    // Standard GCD using Euclidean algorithm
    function gcd(a: number, b: number): number {
        while (b !== 0) {
            [a, b] = [b, a % b];
        }
        return a;
    }
    
    // LCM with overflow protection - cap at a maximum value
    function lcmCapped(a: number, b: number, cap: number): number {
        const g = gcd(a, b);
        const result = (a / g) * b;
        // If LCM exceeds our cap, we don't need exact value
        // since it won't contribute to counting anyway
        return result > cap ? cap + 1 : result;
    }
    
    // Upper bound: worst case is using only the smallest coin
    const upperBound = Math.min(...coins) * k;
    const CAP = upperBound + 1; // Values beyond this don't matter
    
    // Precompute LCM for all 2^n subsets using bitmask DP
    // lcms[mask] = LCM of all coins[i] where bit i is set in mask
    const lcms: number[] = new Array(1 << n).fill(1);
    
    for (let mask = 1; mask < (1 << n); mask++) {
        // Find the lowest set bit to determine which coin to add
        const lowBit = mask & (-mask);
        const idx = Math.round(Math.log2(lowBit));
        const prevMask = mask ^ lowBit; // Remove the lowest bit
        
        // LCM of current subset = LCM(previous subset's LCM, new coin)
        lcms[mask] = lcmCapped(lcms[prevMask], coins[idx], CAP);
    }
    
    // Count number of set bits (for inclusion-exclusion sign)
    function popcount(x: number): number {
        let c = 0;
        while (x) {
            c += x & 1;
            x >>= 1;
        }
        return c;
    }
    
    // Count how many numbers in [1, x] are multiples of at least one coin
    // Using inclusion-exclusion principle
    function countLE(x: number): number {
        let count = 0;
        
        for (let mask = 1; mask < (1 << n); mask++) {
            const l = lcms[mask];
            if (l > x) continue; // This subset's LCM exceeds x, contributes 0
            
            const bits = popcount(mask);
            const term = Math.floor(x / l);
            
            // Odd number of coins in subset: add (inclusion)
            // Even number of coins in subset: subtract (exclusion)
            if (bits % 2 === 1) {
                count += term;
            } else {
                count -= term;
            }
        }
        
        return count;
    }
    
    // Binary search for smallest x where countLE(x) >= k
    let lo = 1;
    let hi = upperBound;
    
    while (lo < hi) {
        const mid = Math.floor((lo + hi) / 2);
        
        if (countLE(mid) >= k) {
            // x = mid might be our answer, or answer is smaller
            hi = mid;
        } else {
            // x = mid doesn't have enough valid numbers, go higher
            lo = mid + 1;
        }
    }
    
    return lo;
};

```

## Example 1: `coins = [3,6,9], k = 3`

### Setup

```
n = 3 coins: [3, 6, 9]
upperBound = min(3,6,9) * 3 = 3 * 3 = 9

Precompute LCMs for all subsets:
  mask=001 (coin 3): lcm=3
  mask=010 (coin 6): lcm=6
  mask=011 (coins 3,6): lcm=lcm(3,6)=6
  mask=100 (coin 9): lcm=9
  mask=101 (coins 3,9): lcm=lcm(3,9)=9
  mask=110 (coins 6,9): lcm=lcm(6,9)=18
  mask=111 (coins 3,6,9): lcm=lcm(6,9)=18 (capped might apply if >9)
```

### Binary Search Process

```
lo=1, hi=9

Iteration 1: mid=5
  countLE(5):
    mask=001: lcm=3, term=floor(5/3)=1, bits=1(odd), count+=1 → count=1
    mask=010: lcm=6, 6>5, skip
    mask=011: lcm=6, 6>5, skip
    mask=100: lcm=9, 9>5, skip
    mask=101: lcm=9, 9>5, skip
    mask=110: lcm=18, 18>5, skip
    mask=111: lcm=18, 18>5, skip
    Total count = 1
  
  count(5)=1 >= k(3)? No
  lo = mid+1 = 6

Iteration 2: mid=7 (lo=6,hi=9)
  countLE(7):
    mask=001: lcm=3, term=floor(7/3)=2, count+=2 → count=2
    mask=010: lcm=6, term=floor(7/6)=1, count+=1 → count=3
    mask=011: lcm=6, term=floor(7/6)=1, bits=2(even), count-=1 → count=2
    mask=100: lcm=9, 9>7, skip
    ... (similar for others, all lcm>7)
    Total count = 2
  
  count(7)=2 >= k(3)? No
  lo = mid+1 = 8

Iteration 3: mid=8 (lo=8,hi=9)
  countLE(8):
    mask=001: lcm=3, term=floor(8/3)=2, count=2
    mask=010: lcm=6, term=floor(8/6)=1, count=3
    mask=011: lcm=6, term=1, bits=2, count-=1 → count=2
    mask=100: lcm=9, 9>8, skip
    Total count = 2
  
  count(8)=2 >= k(3)? No
  lo = mid+1 = 9

lo==hi==9, exit loop
```

### Result

```
Return 9
```

**Output:** `9` ✓

**Verification:** Numbers ≤ 9 that are multiples of 3, 6, or 9: {3, 6, 9} → 3 numbers, and 9 is the 3rd smallest ✓

## Example 2: `coins = [5,2], k = 7`

### Setup

```
upperBound = min(5,2) * 7 = 2 * 7 = 14

LCMs:
  mask=01 (coin 5): lcm=5
  mask=10 (coin 2): lcm=2
  mask=11 (coins 5,2): lcm=10
```

### Binary Search (abbreviated)

```
Testing various x values, eventually converging to x=12

countLE(12):
  mask=01: lcm=5, term=floor(12/5)=2, count=2
  mask=10: lcm=2, term=floor(12/2)=6, count=8
  mask=11: lcm=10, term=floor(12/10)=1, bits=2(even), count-=1 → count=7

```

### Verify Boundary

```
countLE(11):
  mask=01: term=floor(11/5)=2
  mask=10: term=floor(11/2)=5
  mask=11: term=floor(11/10)=1
  count = 2+5-1 = 6 < 7

Since count(11)=6 < 7 and count(12)=7 >= 7,
the answer is 12
```

**Output:** `12` ✓

# Visual Representation

## Inclusion-Exclusion Concept

```
For coins [5,2], counting multiples ≤ x:

Numbers divisible by 5: 5,10,15,20,...
Numbers divisible by 2: 2,4,6,8,10,12,14,...

Union (avoid double counting 10, which is divisible by both):
  |A ∪ B| = |A| + |B| - |A ∩ B|
  
Where A∩B = multiples of LCM(5,2) = multiples of 10
```

## Binary Search Convergence

```
Search space: [1, 14]

x=8: count=? (too few)
x=12: count=7 ✓ (exactly k)
x=11: count=6 (too few)

Binary search narrows down to x=12
```

# Key Insights

1. **Binary search on answer:** Instead of generating all numbers, we search for the value directly
2. **Inclusion-exclusion handles overlaps:** Numbers divisible by multiple coins are counted correctly
3. **Bitmask DP for LCM:** Efficiently computes LCM for all 2ⁿ subsets in $O(2ⁿ)$ time
4. **Overflow protection:** Capping LCM values prevents computation errors for large coin combinations
5. **Monotonic count function:** `countLE(x)` is non-decreasing as x increases, making binary search valid

# Edge Cases

| Case | Scenario | Handling |
|------|----------|----------|
| Single coin | `coins=[5]` | Simplifies to `5*k` directly |
| k is very large | k=2×10⁹ | Binary search handles large ranges efficiently |
| All coins coprime | No common factors | LCM grows quickly, inclusion-exclusion still works |
| Many coins (15) | Maximum subset count | 2^15=32768 subsets, still efficient |

---

# Common Mistakes to Avoid

1. **Not capping LCM values:**
   ```typescript
   // Wrong: may overflow for large coin combinations
   lcms[mask] = lcm(lcms[prevMask], coins[idx]);
   
   // Correct: cap to prevent overflow issues
   lcms[mask] = lcmCapped(lcms[prevMask], coins[idx], CAP);
   ```

2. **Incorrect inclusion-exclusion sign:**
   ```typescript
   // Wrong: always adding
   count += term;
   
   // Correct: alternate based on subset size parity
   if (bits % 2 === 1) count += term;
   else count -= term;
   ```

3. **Wrong upper bound for binary search:**
   ```typescript
   // Wrong: arbitrary large number
   let hi = 1e15;
   
   // Correct: tight bound based on smallest coin
   let hi = Math.min(...coins) * k;
   ```

# Recommended Solution

This binary search + inclusion-exclusion approach is optimal for:
- Handles k up to $2×10⁹$ efficiently
- $O(2ⁿ log(maxValue))$ time complexity
- Avoids generating and sorting all possible values
- Correctly handles overlapping multiples across different coins
- Production-ready with overflow protection

> This is the standard technique for "kth smallest in union of arithmetic progressions" problems!
