# Intuition

Each **primitive** component of the string starts at depth `0` and immediately opens with `'('` (bringing depth to `1`), eventually returning to depth `0` right before the next primitive begins. The **outermost** parentheses of each primitive are exactly the characters where the depth transitions **between `0` and `1`** — these are the ones we want to exclude from the output. Every other character (where depth is `≥ 2` at the time, or transitions among higher depths) belongs to the "inner" content we want to keep.

---

# Approach

1. Maintain a running `depth` counter, starting at `0`.
2. Iterate through each character of `s`:
   - If the character is `'('`:
     - If `depth > 0`, this is an **inner** opening parenthesis → include it in the result.
     - Increment `depth`.
   - If the character is `')'`:
     - Decrement `depth` **first**.
     - If `depth > 0` (after decrementing), this is an **inner** closing parenthesis → include it in the result.
3. Build the result string by appending only the "inner" characters as determined above.
4. Return the final result.

This single-pass approach naturally skips exactly the outermost `'('` of each primitive (when `depth` was `0` before incrementing to `1`) and the outermost `')'` of each primitive (when `depth` becomes `0` after decrementing).

---

# Complexity

- **Time complexity:** 
$$O(n)$$
Single pass through the string with constant-time work per character.

- **Space complexity:** 
$$O(n)$$
For building the output string (excluding the output itself, auxiliary space is `O(1)`).

---

# Code

```typescript
function removeOuterParentheses(s: string): string {
    let result = '';
    let depth = 0;

    for (const c of s) {
        if (c === '(') {
            if (depth > 0) {
                result += c;
            }
            depth++;
        } else {
            depth--;
            if (depth > 0) {
                result += c;
            }
        }
    }

    return result;
};

```
