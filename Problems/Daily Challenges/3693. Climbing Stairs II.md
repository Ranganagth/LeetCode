# Intuition

This is a straightforward **dynamic programming** problem on a line of steps. Since each step `i` can only be reached by jumping from `i-1`, `i-2`, or `i-3`, we can compute the minimum cost to reach each step incrementally, taking the best of these three possible incoming jumps.

---

# Approach

1. Define `dp[i]` as the **minimum total cost** to reach step `i`, starting from step `0` (`dp[0] = 0`).
2. For each step `j` from `1` to `n`, consider all valid previous steps `i` where `i = j - 1`, `j - 2`, or `j - 3` (and `i >= 0`):
   - The cost of jumping from `i` to `j` is:
     ```text
     costs[j - 1] + (j - i)^2
     ```
     (using `costs[j - 1]` since `costs` is effectively 1-indexed, representing cost of step `j`, but stored 0-indexed in the array).
   - Update `dp[j] = min(dp[j], dp[i] + costs[j - 1] + (j - i)^2)` for each valid `i`.
3. Return `dp[n]`.

Since each step only considers a constant number of predecessors (at most 3), the overall algorithm runs in **linear time**.

---

# Complexity

- **Time complexity:** $O(n)$ — each step performs a constant amount of work (checking up to 3 predecessors).
- **Space complexity:** $O(n)$ for the `dp` array (can be optimized to `O(1)` extra space using a sliding window of the last 3 values, but `O(n)` is simple and sufficient given constraints).

---

# Code

```typescript
function climbStairs(n: number, costs: number[]): number {
    // dp[i] = minimum cost to reach step i
    const dp = new Array<number>(n + 1).fill(Infinity);
    dp[0] = 0;

    for (let j = 1; j <= n; j++) {
        const stepCost = costs[j - 1];

        for (let step = 1; step <= 3; step++) {
            const i = j - step;

            if (i >= 0) {
                const jumpCost = stepCost + step * step;

                if (dp[i] + jumpCost < dp[j]) {
                    dp[j] = dp[i] + jumpCost;
                }
            }
        }
    }

    return dp[n];
};

```

# Example Walkthrough

## Example 1

```text
n = 4, costs = [1, 2, 3, 4]
```

- `dp[0] = 0`
- `dp[1]`: only `i=0` valid → `dp[0] + costs[0] + 1^2 = 0 + 1 + 1 = 2` → `dp[1] = 2`
- `dp[2]`: 
  - from `i=1`: `dp[1] + costs[1] + 1^2 = 2 + 2 + 1 = 5`
  - from `i=0`: `dp[0] + costs[1] + 2^2 = 0 + 2 + 4 = 6`
  - `dp[2] = 5`
- `dp[3]`:
  - from `i=2`: `dp[2] + costs[2] + 1^2 = 5 + 3 + 1 = 9`
  - from `i=1`: `dp[1] + costs[2] + 2^2 = 2 + 3 + 4 = 9`
  - from `i=0`: `dp[0] + costs[2] + 3^2 = 0 + 3 + 9 = 12`
  - `dp[3] = 9`
- `dp[4]`:
  - from `i=3`: `dp[3] + costs[3] + 1^2 = 9 + 4 + 1 = 14`
  - from `i=2`: `dp[2] + costs[3] + 2^2 = 5 + 4 + 4 = 13`
  - from `i=1`: `dp[1] + costs[3] + 3^2 = 2 + 4 + 9 = 15`
  - `dp[4] = 13`

Output: `13`

This matches the example path `0 → 1 → 2 → 4` with cost `2 + 3 + 8 = 13`.

## Example 3

```text
n = 3, costs = [9, 8, 3]
```

- `dp[0] = 0`
- `dp[1] = dp[0] + costs[0] + 1 = 0 + 9 + 1 = 10`
- `dp[2]`:
  - from `i=1`: `10 + 8 + 1 = 19`
  - from `i=0`: `0 + 8 + 4 = 12`
  - `dp[2] = 12`
- `dp[3]`:
  - from `i=2`: `12 + 3 + 1 = 16`
  - from `i=1`: `10 + 3 + 4 = 17`
  - from `i=0`: `0 + 3 + 9 = 12`
  - `dp[3] = 12`

Output: `12`

This matches the direct jump `0 → 3` with cost `3 + 9 = 12`.
