# Intuition

To sort the permutation, every index `i` where `nums[i] !== i` must eventually move its value. The values currently at these incorrect positions are the only values that matter.

For a swap to be allowed with value `k`, both swapped numbers must contain every bit set in `k`, because:

```text
a AND b = k
```

implies:

```text
k is a subset of both a and b
```

Therefore, every misplaced value must contain all bits of `k`. The largest possible such `k` is simply the **bitwise AND of all misplaced values**.

If the array is already sorted, there are no misplaced values; the required answer is `0`.

---

# Approach

1. Initialize `answer` to all bits set (`-1` in JavaScript bitwise arithmetic).
2. Traverse each index `i`.
3. If `nums[i] !== i`, this value must participate in sorting:
   - Update:
     ```typescript
     answer &= nums[i];
     ```
4. Return `answer`.

The AND of every misplaced value preserves only the bits common to all of them, giving the maximum valid `k`.

---

# Complexity

- **Time Coimplexity:** $$O(n)$$
- **Space Complexity:** $$O(1)$$

---

# Code

```typescript
function sortPermutation(nums: number[]): number {
    let k = 0;
    let found = false;

    for (let i = 0; i < nums.length; i++) {
        if (nums[i] !== i) {
            if (!found) {
                k = nums[i];
                found = true;
            } else {
                k &= nums[i];
            }
        }
    }

    return k;
};

```

# Example Walkthrough

## Example 1

```text
nums = [0, 3, 2, 1]
```

Incorrect positions:

| Index `i` | `nums[i]` |
|---:|---:|
| 1 | 3 |
| 3 | 1 |

Compute the AND:

```text
3 AND 1 = 1
```

So:

```text
k = 1
```

A valid allowed swap is:

```text
3 AND 1 = 1
```

Swap them:

```text
[0, 3, 2, 1] -> [0, 1, 2, 3]
```

Output: `1`

---

## Example 2

```text
nums = [0, 1, 3, 2]
```

Misplaced values are `3` and `2`:

```text
3 AND 2 = 2
```

So:

```text
k = 2
```

Swapping `3` and `2` is allowed because:

```text
3 AND 2 = 2
```

Output: `2`

---

## Example 3

```text
nums = [3, 2, 1, 0]
```

All positions are incorrect, so AND every value:

```text
3 AND 2 AND 1 AND 0 = 0
```

Output: `0`
