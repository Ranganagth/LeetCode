# Intuition

Since every `'('` requires **exactly two consecutive** `')'` to close it, we can track a single running counter `need` representing the **total number of `')'`** currently required to satisfy all the `'('` characters seen so far (each `'('` contributes `+2` to this requirement). As we encounter `')'` characters, we consume one unit of this requirement at a time.

Two tricky situations arise:
1. **Odd requirement interrupted by a new `'('`**: If `need` is **odd** when we see a new `'('`, it means there's a dangling single `')'` still owed from a previous `'('` (since pairs must be *consecutive*, this lone `')'` can never be completed later) — we must **insert** one `')'` right now to resolve it.
2. **More `')'` than can be matched**: If `need` goes **negative** when processing a `')'`, it means there's no `'('` at all to account for it — we must **insert** a `'('` to provide the missing match (which then requires one more `')'`, so we reset `need` to `1` after accounting for the one just consumed).

At the end, any leftover `need` (still-owed `')'` for unclosed `'('`) must also be inserted.

---

# Approach

1. Initialize `res = 0` (insertions counter) and `need = 0` (pending `')'` requirement).
2. Iterate through each character of `s`:
   - If `c === '('`:
     - Increase `need` by `2` (this `'('` now requires two `')'`).
     - If `need` is **odd**, it means a previous lone `')'` is dangling and can never pair up later — increment `res` by `1` and decrement `need` by `1` to resolve it (insert the missing `')'` now).
   - If `c === ')'`:
     - Decrease `need` by `1` (consuming one unit of requirement).
     - If `need < 0`, there was no open `'('` to match this `')'` at all — increment `res` by `1` (insert a `'('`), and reset `need = 1` (the inserted `'('` needs 2 total, minus the 1 just consumed by this `')'`).
3. After processing the whole string, add any remaining `need` to `res` (unclosed requirements must be fulfilled with insertions).
4. Return `res`.

---

# Complexity

- **Time complexity:** 
$$O(n)$$
Single pass through the string with constant-time work per character.

- **Space complexity:** 
$$O(1)$$
Only a few scalar counters are used.

---

# Code

```typescript
function minInsertions(s: string): number {
    let res = 0;
    let need = 0;

    for (const c of s) {
        if (c === '(') {
            need += 2;
            if (need % 2 === 1) {
                res += 1;
                need -= 1;
            }
        } else {
            need -= 1;
            if (need < 0) {
                res += 1;
                need = 1;
            }
        }
    }

    return res + need;
};

```

# Example Walkthrough

## Example 1

```text
s = "(()))"
```

| char | action | need | res |
|------|--------|------|-----|
| ( | need+=2 → 2 (even, ok) | 2 | 0 |
| ( | need+=2 → 4 (even, ok) | 4 | 0 |
| ) | need-=1 → 3 | 3 | 0 |
| ) | need-=1 → 2 | 2 | 0 |
| ) | need-=1 → 1 | 1 | 0 |

Final: `res + need = 0 + 1 = 1`

Output: `1`
