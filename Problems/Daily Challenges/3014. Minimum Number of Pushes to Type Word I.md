# Intuition

We have 8 keys (2-9) available to map letters. To minimize total pushes, we should:
- Assign the first 8 letters to different keys (1 push each)
- Assign the next 8 letters as second letters on keys (2 pushes each)
- Assign the next 8 letters as third letters on keys (3 pushes each)
- And so on...

**Key insight:** Since all letters are distinct, we just need to distribute them optimally across the 8 keys.

---

# Approach

1. **Distribute letters across 8 keys:**
   - Letters 0-7: position 1 on keys (1 push each)
   - Letters 8-15: position 2 on keys (2 pushes each)
   - Letters 16-23: position 3 on keys (3 pushes each)
   - Letters 24-25: position 4 on keys (4 pushes each)

2. **Calculate pushes for each letter:**
   - For letter at index `i`: pushes = `floor(i / 8) + 1`

3. **Sum all pushes**

---

# Complexity

- **Time complexity:** $O(n)$ where n is word length (max 26)
- **Space complexity:** $O(1)$

---

# Code Explanation

```typescript
function minimumPushes(word: string): number {
    const n = word.length;
    let ans = 0;
    
    // For each letter, calculate its push cost
    for (let i = 0; i < n; i++) {
        // Letters 0-7: floor(i/8) = 0, cost = 1
        // Letters 8-15: floor(i/8) = 1, cost = 2
        // Letters 16-23: floor(i/8) = 2, cost = 3
        // Letters 24-25: floor(i/8) = 3, cost = 4
        ans += Math.floor(i / 8) + 1;
    }
    
    return ans;
};

```

# Mathematical Formula

For n distinct letters:

```
Total pushes = Σ(floor(i/8) + 1) for i from 0 to n-1

Breaking it down:
- First 8 letters: 8 × 1 = 8
- Next 8 letters: 8 × 2 = 16
- Next 8 letters: 8 × 3 = 24
- Next 2 letters: 2 × 4 = 8

For n = 10:
- First 8: 8 × 1 = 8
- Next 2: 2 × 2 = 4
- Total: 8 + 4 = 12
```

# Key Insights

- **8 keys available:** We can assign up to 8 letters with 1 push each
- **Greedy assignment:** Assign letters sequentially to minimize pushes
- **Position cost:** Letter at position i costs `floor(i/8) + 1` pushes
- **No frequency needed:** Since all letters are distinct, order doesn't matter

# Why This Works

**Optimal strategy:**
1. We have 8 keys to distribute letters
2. To minimize total pushes, we want as many letters as possible in position 1 (1 push)
3. Then as many as possible in position 2 (2 pushes), and so on
4. Since all letters are distinct, we simply assign them in order

**Proof of optimality:**
- Any other assignment would move some letters to higher positions
- This would increase total pushes
- Therefore, sequential assignment is optimal
