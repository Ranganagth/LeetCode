# Intuition

To maximize `(nums[i]-1) * (nums[j]-1)`, we need to find the two largest values in the array. The product of `(largest-1) * (second_largest-1)` will give us the maximum result.

---

# Approach

## Solution 1: Find Two Largest Values (Optimal)

1. **Track two largest values** in a single pass
2. **Calculate product** using these two values
3. **Return result**

## Solution 2: Sort and Take Top Two

1. Sort the array in descending order
2. Take the first two elements
3. Calculate the product

## Solution 3: Brute Force

Check all pairs and find maximum (for comparison)

---

# Complexity

**Solution 1 (One Pass):**
- **Time complexity:** O(n) - single pass through array
- **Space complexity:** O(1) - only storing two variables

**Solution 2 (Sorting):**
- **Time complexity:** O(n log n) - sorting
- **Space complexity:** O(1) or O(n) depending on sort implementation

---

# Code

## Solution 1: One Pass - Two Largest (Optimal)

```typescript
function maxProduct(nums: number[]): number {
    let max1 = -Infinity;
    let max2 = -Infinity;
    
    for (const num of nums) {
        if (num > max1) {
            // New largest found, shift previous largest to second
            max2 = max1;
            max1 = num;
        } else if (num > max2) {
            // New second largest found
            max2 = num;
        }
    }
    
    return (max1 - 1) * (max2 - 1);
};

```

---

## Solution 2: Sorting Approach

```typescript
function maxProduct(nums: number[]): number {
    // Sort in descending order
    nums.sort((a, b) => b - a);
    
    // Take the two largest values
    return (nums[0] - 1) * (nums[1] - 1);
};

```

## Solution 3: Without Modifying Original Array

```typescript
function maxProduct(nums: number[]): number {
    let max1 = Math.max(nums[0], nums[1]);
    let max2 = Math.min(nums[0], nums[1]);
    
    for (let i = 2; i < nums.length; i++) {
        if (nums[i] > max1) {
            max2 = max1;
            max1 = nums[i];
        } else if (nums[i] > max2) {
            max2 = nums[i];
        }
    }
    
    return (max1 - 1) * (max2 - 1);
};

```

---

## Solution 4: Using Math.max (Concise)

```typescript
function maxProduct(nums: number[]): number {
    const sorted = [...nums].sort((a, b) => b - a);
    return (sorted[0] - 1) * (sorted[1] - 1);
};

```

---

## Solution 5: Brute Force (For Verification)

```typescript
function maxProduct(nums: number[]): number {
    let maxProd = 0;
    
    for (let i = 0; i < nums.length; i++) {
        for (let j = i + 1; j < nums.length; j++) {
            const prod = (nums[i] - 1) * (nums[j] - 1);
            maxProd = Math.max(maxProd, prod);
        }
    }
    
    return maxProd;
};

```

# Key Insights

- **Two largest values:** The product is maximized with the two largest numbers
- **Single pass:** Can find both values in O(n) time
- **Order matters:** Must update max2 before max1 when finding new largest
- **Edge case:** Works even when two largest are equal

---

# Edge Cases

| Case | Input | max1 | max2 | Output | Notes |
|------|-------|------|------|--------|-------|
| Two elements | [3,7] | 7 | 3 | 12 | Minimal case |
| All same | [5,5,5] | 5 | 5 | 16 | Equal values |
| Minimum values | [1,1] | 1 | 1 | 0 | (1-1)*(1-1)=0 |
| Large values | [1000,999] | 1000 | 999 | 998001 | Max constraint |
| Sorted ascending | [1,2,3,4,5] | 5 | 4 | 12 | Already sorted |
| Sorted descending | [5,4,3,2,1] | 5 | 4 | 12 | Reverse sorted |

---

# Common Mistakes to Avoid

1. **Wrong update order:** Must update max2 before max1
   ```typescript
   // Wrong:
   max1 = num;
   max2 = max1; // This makes max2 = num, not old max1
   
   // Correct:
   max2 = max1;
   max1 = num;
   ```

2. **Not handling equal values:** Algorithm works correctly even when max1 = max2

3. **Forgetting -1:** Must subtract 1 from each value before multiplying

4. **Index confusion:** We need values, not indices

# Why One Pass Works

**Mathematical proof:**

For any array, to maximize `(a-1) * (b-1)`:
- Both `a` and `b` should be as large as possible
- Since we're multiplying positive numbers (after -1), larger values give larger products
- Therefore, the two largest values always give the maximum product

**Example:**
```
Array: [3, 4, 5, 2]

Possible products:
(3-1)*(4-1) = 2*3 = 6
(3-1)*(5-1) = 2*4 = 8
(3-1)*(2-1) = 2*1 = 2
(4-1)*(5-1) = 3*4 = 12 <- Maximum
(4-1)*(2-1) = 3*1 = 3
(5-1)*(2-1) = 4*1 = 4
```
