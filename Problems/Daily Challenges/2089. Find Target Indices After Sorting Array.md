# Intuition

Since we just need the indices where `target` appears **after sorting**, the simplest approach is to **sort the array first**, then scan through it and collect all indices where the value matches `target`. Since sorting naturally groups equal values together in increasing order, the resulting indices will already be in increasing order.

---

# Approach

1. Create a sorted copy of `nums` in non-decreasing order.
2. Iterate through the sorted array, and for each index `i` where `sortedNums[i] === target`, add `i` to the result list.
3. Return the result list.

---

# Complexity

- **Time complexity:** 
$$O(n \log n)$$
Dominated by the sorting step; the scan afterward is `O(n)`.

- **Space complexity:**
$$O(n)$$
For the sorted copy and the result array.

---

# Code

```typescript
function targetIndices(nums: number[], target: number): number[] {
    const sorted = [...nums].sort((a, b) => a - b);
    const result: number[] = [];

    for (let i = 0; i < sorted.length; i++) {
        if (sorted[i] === target) {
            result.push(i);
        }
    }

    return result;
};

```

## Example 1

```text
nums = [1,2,5,2,3], target = 2
```

- Sorted: `[1,2,2,3,5]`
- Scan: index 1 → `2`, index 2 → `2`, others don't match.

Output: `[1, 2]`
