# Intuition

Since collecting all the litter items depends on **position**, **remaining energy**, and **which litter items have already been collected**, this becomes a classic **multi-dimensional BFS** problem.

Because every move costs exactly **1 unit of energy**, the shortest number of moves to reach any state is naturally found with **BFS**, where the state includes:

- Current row and column
- Current remaining energy
- Bitmask of collected litter items

Whenever the student steps onto an `'R'` cell, energy resets to full — this is simply a special transition rule in the BFS.

---

# Approach

## 1. Preprocessing

- Locate the start position `'S'`.
- Assign each `'L'` cell a unique bit index (since there are at most 10 litter cells, a bitmask fits in an integer).
- Compute `fullMask` representing "all litter collected".

If there is no litter, the answer is `0` immediately.

## 2. State Representation

Define a state as:

```text
(row, col, energy, mask)
```

Encode this into a single integer index for efficient array-based storage:

```text
index = ((row * n + col) * (energy + 1) + energyLeft) * (1 << litterCount) + mask
```

## 3. BFS Transition Rules

From state `(r, c, e, mask)`, for each of the four directions:

- Skip if the target cell is out of bounds or an obstacle `'X'`.
- If `e == 0`, the student cannot move (since not on an `'R'` before moving).
- Otherwise, moving consumes 1 energy:
  - If the destination is `'R'`, reset energy to the maximum capacity.
  - If the destination is `'L'` and not yet collected, update the mask.
- Push the new state into the BFS queue if not visited before.

## 4. Goal Condition

The first time `mask == fullMask` is reached, the BFS distance at that point is the **minimum number of moves** required.

If the queue empties without reaching `fullMask`, return `-1`.

---

# Complexity

- **Time complexity:**
$$O(m \times n \times energy \times 2^{L})$$
where `L` is the number of litter cells (≤ 10). Each state is processed once with constant-time transitions (4 directions).

- **Space complexity:**
$$O(m \times n \times energy \times 2^{L})$$
for storing visited/distance states and the BFS queue.

# Code

```typescript
function minMoves(classroom: string[], energy: number): number {
    const m = classroom.length;
    const n = classroom[0].length;

    let sr = -1, sc = -1;
    const litterIndex: number[][] = Array.from({ length: m }, () => new Array(n).fill(-1));
    let litterCount = 0;

    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            const ch = classroom[r][c];
            if (ch === 'S') {
                sr = r; sc = c;
            } else if (ch === 'L') {
                litterIndex[r][c] = litterCount++;
            }
        }
    }

    if (litterCount === 0) return 0;

    const fullMask = (1 << litterCount) - 1;
    const maskCount = 1 << litterCount;
    const eRange = energy + 1;

    const size = m * n * eRange * maskCount;
    const dist = new Int32Array(size).fill(-1);
    const queue = new Uint32Array(size);
    let head = 0, tail = 0;

    const encode = (r: number, c: number, e: number, mask: number): number => {
        return ((r * n + c) * eRange + e) * maskCount + mask;
    };

    const startIdx = encode(sr, sc, energy, 0);
    dist[startIdx] = 0;
    queue[tail++] = startIdx;

    const dr = [-1, 1, 0, 0];
    const dc = [0, 0, -1, 1];

    while (head < tail) {
        const cur = queue[head++];
        const curDist = dist[cur];

        // decode
        let mask = cur % maskCount;
        let temp = Math.floor(cur / maskCount);
        let e = temp % eRange;
        temp = Math.floor(temp / eRange);
        let c = temp % n;
        let r = Math.floor(temp / n);

        if (mask === fullMask) {
            return curDist;
        }

        if (e === 0) continue; // can't move further

        for (let dir = 0; dir < 4; dir++) {
            const nr = r + dr[dir];
            const nc = c + dc[dir];

            if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
            const cellType = classroom[nr][nc];
            if (cellType === 'X') continue;

            let ne = e - 1;
            let nm = mask;

            if (cellType === 'R') {
                ne = energy;
            } else if (cellType === 'L') {
                const bit = litterIndex[nr][nc];
                if (bit !== -1) {
                    nm = mask | (1 << bit);
                }
            }

            const nextIdx = encode(nr, nc, ne, nm);
            if (dist[nextIdx] === -1) {
                dist[nextIdx] = curDist + 1;
                queue[tail++] = nextIdx;
            }
        }
    }

    return -1;
};

```

# Example Walkthrough

## Example

```text
classroom = ["LS", "RL"]
energy = 4
```

- Start at `(0,1)` with full energy `4`
- Litter cells: `(0,0)` → bit 0, `(1,1)` → bit 1
- BFS explores:
  - `(0,1)->(0,0)`: collects litter bit 0, energy=3
  - `(0,0)->(1,0)`: lands on `'R'`, energy resets to 4
  - `(1,0)->(1,1)`: collects litter bit 1, mask becomes full

Total moves: `3`, matching the expected output.
