# Intuition

We need to identify all methods that are "suspicious" (method k and all methods it invokes directly or indirectly), then check if we can safely remove them. The key constraint is that we can only remove the suspicious group if **no non-suspicious method invokes any suspicious method**.

**Key insight:** 
1. Use **DFS/BFS** to find all methods reachable from k (suspicious methods)
2. Check if any non-suspicious method invokes a suspicious method
3. If yes, we can't remove anything; if no, remove all suspicious methods

---

# Approach

1. **Build adjacency list** from invocations (directed graph)

2. **Find all suspicious methods:**
   - Use DFS/BFS starting from k
   - Mark all reachable methods as suspicious

3. **Check if removal is safe:**
   - For each invocation [a, b]:
     - If a is NOT suspicious but b IS suspicious → can't remove
   
4. **Return result:**
   - If safe: return all non-suspicious methods
   - If not safe: return all methods [0, 1, ..., n-1]

---

# Complexity

- **Time complexity:** $O(n + m)$ where m is number of invocations
- **Space complexity:** $O(n + m)$ for graph and visited set

---

# Code

## Solution 1: DFS Approach (Recommended)

```typescript
function remainingMethods(n: number, k: number, invocations: number[][]): number[] {
    // Build adjacency list
    const graph = new Map<number, number[]>();
    for (let i = 0; i < n; i++) {
        graph.set(i, []);
    }
    
    for (const [a, b] of invocations) {
        graph.get(a)!.push(b);
    }
    
    // Find all suspicious methods (reachable from k)
    const suspicious = new Set<number>();
    
    function dfs(method: number) {
        if (suspicious.has(method)) return;
        suspicious.add(method);
        
        for (const next of graph.get(method)!) {
            dfs(next);
        }
    }
    
    dfs(k);
    
    // Check if we can safely remove suspicious methods
    // We can't remove if any non-suspicious method invokes a suspicious method
    for (const [a, b] of invocations) {
        if (!suspicious.has(a) && suspicious.has(b)) {
            // Non-suspicious method invokes suspicious method
            // Can't remove, return all methods
            return Array.from({ length: n }, (_, i) => i);
        }
    }
    
    // Safe to remove suspicious methods
    const result: number[] = [];
    for (let i = 0; i < n; i++) {
        if (!suspicious.has(i)) {
            result.push(i);
        }
    }
    
    return result;
};

```

## Solution 2: BFS Approach

```typescript
function remainingMethods(n: number, k: number, invocations: number[][]): number[] {
    // Build adjacency list
    const graph = new Map<number, number[]>();
    for (let i = 0; i < n; i++) {
        graph.set(i, []);
    }
    
    for (const [a, b] of invocations) {
        graph.get(a)!.push(b);
    }
    
    // BFS to find all suspicious methods
    const suspicious = new Set<number>();
    const queue: number[] = [k];
    suspicious.add(k);
    
    while (queue.length > 0) {
        const method = queue.shift()!;
        
        for (const next of graph.get(method)!) {
            if (!suspicious.has(next)) {
                suspicious.add(next);
                queue.push(next);
            }
        }
    }
    
    // Check if removal is safe
    for (const [a, b] of invocations) {
        if (!suspicious.has(a) && suspicious.has(b)) {
            return Array.from({ length: n }, (_, i) => i);
        }
    }
    
    // Return non-suspicious methods
    const result: number[] = [];
    for (let i = 0; i < n; i++) {
        if (!suspicious.has(i)) {
            result.push(i);
        }
    }
    
    return result;
};

```

## Solution 3: With Reverse Graph Check

```typescript
function remainingMethods(n: number, k: number, invocations: number[][]): number[] {
    // Build forward and reverse graphs
    const graph = new Map<number, number[]>();
    const reverseGraph = new Map<number, number[]>();
    
    for (let i = 0; i < n; i++) {
        graph.set(i, []);
        reverseGraph.set(i, []);
    }
    
    for (const [a, b] of invocations) {
        graph.get(a)!.push(b);
        reverseGraph.get(b)!.push(a);
    }
    
    // Find suspicious methods
    const suspicious = new Set<number>();
    
    function dfs(method: number) {
        if (suspicious.has(method)) return;
        suspicious.add(method);
        
        for (const next of graph.get(method)!) {
            dfs(next);
        }
    }
    
    dfs(k);
    
    // Check if any suspicious method is invoked by non-suspicious method
    for (const method of suspicious) {
        for (const caller of reverseGraph.get(method)!) {
            if (!suspicious.has(caller)) {
                // Can't remove
                return Array.from({ length: n }, (_, i) => i);
            }
        }
    }
    
    // Safe to remove
    return Array.from({ length: n }, (_, i) => i).filter(i => !suspicious.has(i));
};

```

## Example 1: `n = 4, k = 1, invocations = [[1,2],[0,1],[3,2]]`

```
Build graph:
0 → [1]
1 → [2]
2 → []
3 → [2]

Find suspicious methods (DFS from k=1):
Start: suspicious = {1}
Visit 1 → 2: suspicious = {1, 2}

Check if removal is safe:
[1,2]: 1 is suspicious, 2 is suspicious ✓
[0,1]: 0 is NOT suspicious, 1 IS suspicious ✗
       → Can't remove!
[3,2]: 3 is NOT suspicious, 2 IS suspicious ✗
       → Can't remove!

Result: Return all methods [0,1,2,3]
```

**Output:** `[0,1,2,3]`

# Key Insights

- **Graph traversal:** DFS/BFS to find all reachable methods
- **Directed graph:** Invocations are directional (a → b)
- **Safety check:** Critical to verify no external dependencies
- **All or nothing:** Either remove all suspicious or none
- **Cycles allowed:** Graph can have cycles (Example 3)

---

# Edge Cases

| Case | Description | Example | Output |
|------|-------------|---------|--------|
| k isolated | k has no invocations | k=0, invocations=[] | All except k |
| All suspicious | All methods reachable from k | Example 3 | [] |
| Can't remove | External dependencies | Example 1 | All methods |
| Disconnected | Multiple components | Example 2 | Non-suspicious |
| Self-loop | Method invokes itself | [[0,0]] | Depends on k |

---

# Common Mistakes to Avoid

1. **Not checking external invocations:**
   ```typescript
   // Wrong: only finding suspicious methods
   dfs(k);
   return non-suspicious methods;
   
   // Correct: check if safe to remove
   for (const [a, b] of invocations) {
       if (!suspicious.has(a) && suspicious.has(b)) {
           return all methods;
       }
   }
   ```

2. **Wrong graph direction:**
   ```typescript
   // Wrong: reverse direction
   for (const [a, b] of invocations) {
       graph.get(b)!.push(a);
   }
   
   // Correct: a invokes b
   graph.get(a)!.push(b);
   ```

3. **Not handling cycles:**
   ```typescript
   // Wrong: infinite loop on cycles
   function dfs(method) {
       for (const next of graph.get(method)!) {
           dfs(next);
       }
   }
   
   // Correct: check if visited
   if (suspicious.has(method)) return;
   suspicious.add(method);
   ```

4. **Returning wrong result when can't remove:**
   ```typescript
   // Wrong: returning empty array
   return [];
   
   // Correct: return all methods
   return Array.from({ length: n }, (_, i) => i);
   ```
