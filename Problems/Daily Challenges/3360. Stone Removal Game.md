# Intuition

This is a direct simulation problem. Each turn, the amount removed decreases by exactly `1` from the previous turn, starting at `10` for Alice. We simply simulate turns one by one until a player cannot remove the required number of stones (because fewer stones remain than needed) - that player loses.

---

# Approach

1. Start with `remove = 10` stones to take, and track whose turn it is (`Alice` first).
2. On each turn:
   - If the remaining stones `n < remove`, the current player **cannot move** and loses.
   - Otherwise, subtract `remove` from `n`, decrement `remove` by `1`, and switch turns.
3. Repeat until a player can't move.
4. Return `true` if **Bob** is the one who couldn't move (meaning Alice wins), otherwise `false`.

---

# Complexity

- **Time complexity:** $O(√n)$ - since the amount removed increases by $1$ each turn starting from $10$, the total stones removed after $k$ turns grows quadratically, so the simulation terminates in at most $O(√n)$ steps.
- **Space complexity:** $O(1)$ - only a few scalar variables are used.

---

# Code

```typescript
function canAliceWin(n: number): boolean {
    let remove = 10;
    let isAliceTurn = true;

    while (n >= remove) {
        n -= remove;
        remove--;
        isAliceTurn = !isAliceTurn;
    }

    // If it's Bob's turn and he can't move, Alice wins.
    return !isAliceTurn;
};

```

# Example Walkthrough

## Example 1

```text
n = 12
```

- Turn 1 (Alice): `remove = 10`, `n = 12 >= 10` → `n = 2`, `remove = 9`, turn switches to Bob.
- Turn 2 (Bob): `remove = 9`, `n = 2 < 9` → Bob **cannot move** → loop ends.

Since it's Bob's turn when the loop ends (`isAliceTurn = false`), Alice wins.

Output: `true`

## Example 2

```text
n = 1
```

- Turn 1 (Alice): `remove = 10`, `n = 1 < 10` → Alice **cannot move** → loop ends immediately.

Since it's Alice's turn when the loop ends (`isAliceTurn = true`), Alice loses.

Output: `false`
