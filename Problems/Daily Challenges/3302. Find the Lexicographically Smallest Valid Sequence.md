# Intuition

We need to find the lexicographically smallest sequence of indices from `word1` that forms a string "almost equal" to `word2` (at most 1 character difference). The solution uses a **greedy approach with suffix validation**.

**Key insight:** 
1. Precompute the rightmost positions where we can start matching each suffix of `word2`
2. Greedily select the smallest index at each step
3. Use our one allowed change only when it's safe (remaining suffix can still be matched)

---

# Approach

1. **Precompute suffix positions (`last` array):**
   - `last[j]` = the leftmost index in `word1` from which we can match `word2[j..]` exactly
   - Scan `word1` from right to left, matching characters with `word2` from right to left

2. **Greedy selection:**
   - For each position in `word2`, scan `word1` from left to right
   - Select the first index where:
     - Characters match exactly, OR
     - We haven't used our change yet AND remaining suffix can be matched (checked via `last` array)

3. **Validation:**
   - After processing, check if we matched all characters of `word2`
   - If not, return empty array

---

# Complexity

- **Time complexity:** $O(n + m)$ where n = word1.length, m = word2.length
- **Space complexity:** $O(m)$ for the `last` array

---

# Code

```typescript
function validSequence(word1: string, word2: string): number[] {
    const n = word1.length;
    const m = word2.length;
    
    // Step 1: Precompute suffix matching positions
    // last[j] = leftmost index in word1 where we can start matching word2[j..] exactly
    const last = new Array(m).fill(-1);
    let j = m - 1;
    
    // Scan word1 from right to left
    for (let i = n - 1; i >= 0; i--) {
        // If current char matches word2[j], record this position
        if (j >= 0 && word1[i] === word2[j]) {
            last[j] = i;
            j--;
        }
    }
    
    // Step 2: Greedy selection from left to right
    const res: number[] = [];
    let skip = 0; // Track if we've used our one allowed change
    j = 0; // Current position in word2
    
    for (let i = 0; i < n; i++) {
        // If we've matched all of word2, we're done
        if (j === m) break;
        
        // Check if we can use this index
        const isMatch = word1[i] === word2[j];
        const isLastChar = j === m - 1;
        const canMatchRemaining = isLastChar || i < last[j + 1];
        
        // We can use this index if:
        // 1. Characters match exactly, OR
        // 2. We haven't used our change yet AND remaining suffix can be matched
        if (isMatch || (skip === 0 && canMatchRemaining)) {
            // If not a match, we're using our one change
            skip += isMatch ? 0 : 1;
            res.push(i);
            j++;
        }
    }
    
    // Step 3: Validate - did we match all of word2?
    return j === m ? res : [];
};

```

# Key Insights

- **Suffix validation:** `last` array tells us if remaining can be matched
- **Greedy is optimal:** Always choose smallest valid index
- **One change tracking:** `skip` variable ensures we use at most one change
- **Early termination:** Stop when all of `word2` is matched
- **Lexicographically smallest:** Scanning left-to-right ensures this

# Edge Cases

| Case | Input | Output | Notes |
|------|-------|--------|-------|
| Exact match | "abc", "abc" | [0,1,2] | No change needed |
| One change needed | "vbc", "abc" | [0,1,2] | Change first |
| Impossible | "aaa", "abc" | [] | Need 2 changes |
| Shorter word2 | "abc", "ab" | [0,1] | Valid subsequence |
| All same chars | "aaaa", "aaa" | [0,1,2] | Multiple valid |

# Common Mistakes to Avoid

1. **Wrong suffix check:**
   ```typescript
   // Wrong: not checking if remaining can be matched
   if (word1[i] !== word2[j] && skip === 0) {
       skip = 1;
       res.push(i);
   }
   
   // Correct: check if remaining suffix can be matched
   if (skip === 0 && (j === m - 1 || i < last[j + 1])) {
       skip = 1;
       res.push(i);
   }
   ```

2. **Not validating final result:**
   ```typescript
   // Wrong: always return res
   return res;
   
   // Correct: check if we matched all of word2
   return j === m ? res : [];
   ```

3. **Wrong last array construction:**
   ```typescript
   // Wrong: scanning left to right
   for (let i = 0; i < n; i++) {
       if (word1[i] === word2[j]) {
           last[j] = i;
           j++;
       }
   }
   
   // Correct: scan right to left for leftmost positions
   for (let i = n - 1; i >= 0; i--) {
       if (j >= 0 && word1[i] === word2[j]) {
           last[j] = i;
           j--;
       }
   }
   ```
