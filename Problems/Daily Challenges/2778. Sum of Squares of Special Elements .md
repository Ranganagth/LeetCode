# Intuition

Since the array is **1-indexed** in this problem's context, we simply need to check each position `i` (from `1` to `n`) to see if it **divides** `n` evenly. Given the tiny constraints (`n ≤ 50`), a direct brute-force scan is more than sufficient.

---

# Approach

1. Let `n = nums.length`.
2. Iterate `i` from `1` to `n`.
3. For each `i`, check if `n % i === 0`.
4. If true, the element at 1-indexed position `i` (which is `nums[i - 1]` in 0-indexed terms) is **special** — add its square to a running sum.
5. Return the accumulated sum.

---

# Complexity

- **Time complexity:** 
$$O(n)$$
A single pass through indices `1` to `n`.

- **Space complexity:** 
$$O(1)$$
Only a running sum variable is used.

---

# Code

```typescript
function sumOfSquares(nums: number[]): number {
    const n = nums.length;
    let sum = 0;

    for (let i = 1; i <= n; i++) {
        if (n % i === 0) {
            const val = nums[i - 1];
            sum += val * val;
        }
    }

    return sum;
};

```

# Example Walkthrough

## Example 1

```text
nums = [1,2,3,4], n = 4
```

- `i=1`: `4 % 1 === 0` → special, `nums[0]=1` → add `1*1=1`
- `i=2`: `4 % 2 === 0` → special, `nums[1]=2` → add `2*2=4`
- `i=3`: `4 % 3 !== 0` → not special
- `i=4`: `4 % 4 === 0` → special, `nums[3]=4` → add `4*4=16`

Sum = `1 + 4 + 16 = 21`

Output: `21`

## Example 2

```text
nums = [2,7,1,19,18,3], n = 6
```

- `i=1`: `6%1=0` → special, `nums[0]=2` → `4`
- `i=2`: `6%2=0` → special, `nums[1]=7` → `49`
- `i=3`: `6%3=0` → special, `nums[2]=1` → `1`
- `i=4`: `6%4≠0` → not special
- `i=5`: `6%5≠0` → not special
- `i=6`: `6%6=0` → special, `nums[5]=3` → `9`

Sum = `4 + 49 + 1 + 9 = 63`

Output: `63`
