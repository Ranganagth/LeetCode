# Intuition

Incrementing `n - 1` elements by `1` is mathematically equivalent to **decreasing exactly one element by 1** relative to all the others (since raising everyone else is the same as lowering the one left behind, in terms of relative differences). So the problem reduces to: *how many total single-element decrements are needed to bring every element down to the minimum value?*

This means the answer is simply the **sum of differences between each element and the minimum element** in the array.

---

# Approach

1. Find the **minimum** value in `nums`.
2. For each element, compute `nums[i] - min` and sum these differences.
3. Return the total sum.

### Why this works
Each "move" (incrementing `n-1` elements) changes the **relative gap** between the one left-out element and the rest by exactly `1` (the left-out element's distance from the others effectively increases by 1, or equivalently, every other element's distance to it decreases by 1). To equalize all elements, every element must eventually "catch down" to the minimum — and the total number of such unit-reductions needed equals the sum of `(nums[i] - min)` across all elements. This is a classic reformulation trick for this type of problem.

---

# Complexity

- **Time complexity:**
$$O(n)$$
A single pass to find the minimum, and another pass to sum the differences.

- **Space complexity:**
$$O(1)$$
Only a few scalar variables are used.

---

# Code

```typescript
function minMoves(nums: number[]): number {
    let min = Infinity;

    for (const num of nums) {
        if (num < min) {
            min = num;
        }
    }

    let moves = 0;

    for (const num of nums) {
        moves += num - min;
    }

    return moves;
};

```

# Example Walkthrough

## Example 1

```text
nums = [1, 2, 3]
```

- `min = 1`
- Differences: `(1-1) + (2-1) + (3-1) = 0 + 1 + 2 = 3`

Output: `3`

This matches the given sequence of moves:
```text
[1,2,3] → [2,3,3] → [3,4,3] → [4,4,4]
```

## Example 2

```text
nums = [1, 1, 1]
```

- `min = 1`
- Differences: `0 + 0 + 0 = 0`

Output: `0`
