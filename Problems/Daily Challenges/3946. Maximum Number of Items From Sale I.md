# Intuition

Buying the **first copy** of an item type is special:

- It gives `1` purchased copy.
- It may also give several **free copies** of other items.
- Buying more copies of the same type gives only `1` purchased copy each—no extra free-item benefit.

For each item `i`, calculate:

```text
freeCopies[i] = number of items j (j != i)
                where factor[i] divides factor[j]
```

Then, purchasing the **first** copy of item `i` gives a value of:

```text
1 + freeCopies[i]
```

After deciding which item types to buy at least once, every remaining dollar should be spent on the **cheapest item**, since each additional purchased copy always contributes exactly `1` to the answer.

So we use **0/1 knapsack**:

- Choosing an item type once costs `price[i]`.
- It contributes `1 + freeCopies[i]`.
- Afterwards, use remaining budget to buy as many copies as possible of the cheapest item.

---

# Approach

## 1. Count free copies for each item

For item `i`, count how many factors in the list are multiples of `factor[i]`:

```text
freeCopies[i] = count(factor[j] % factor[i] === 0) - 1
```

We subtract `1` because an item cannot give itself a free copy.

Since factors are at most `1500`, we can calculate this efficiently using frequency counts and multiples.

## 2. 0/1 Knapsack for first purchases

Define:

```text
dp[c] = maximum number of copies obtained after spending exactly c
        on first-time purchases of distinct item types.
```

For item `i`:

```text
cost = price[i]
value = 1 + freeCopies[i]
```

Update the DP array backward so an item type is selected at most once.

## 3. Spend remaining budget on the cheapest item

For every reachable cost `spent`:

```text
extraCopies = floor((budget - spent) / cheapestPrice)
total = dp[spent] + extraCopies
```

Take the maximum total.

---

# Complexity

Let:

- `n = items.length`
- `B = budget`
- `F = 1500` (maximum factor)

- **Time complexity:** $O(F log F + n × B)$
  - Counting divisible factors: $O(F log F)$
  - Knapsack: $O(n × B)$

- **Space complexity:** $O(B + F)$

---

# Code

```typescript
function maximumSaleItems(items: number[][], budget: number): number {
    const MAX_FACTOR = 1500;

    // Count how many item types have each factor.
    const frequency = new Array<number>(MAX_FACTOR + 1).fill(0);

    let cheapestPrice = Infinity;

    for (const [factor, price] of items) {
        frequency[factor]++;
        cheapestPrice = Math.min(cheapestPrice, price);
    }

    /*
      divisibleCount[d] = number of items whose factor is divisible by d.
    */
    const divisibleCount = new Array<number>(MAX_FACTOR + 1).fill(0);

    for (let divisor = 1; divisor <= MAX_FACTOR; divisor++) {
        for (let multiple = divisor; multiple <= MAX_FACTOR; multiple += divisor) {
            divisibleCount[divisor] += frequency[multiple];
        }
    }

    /*
      dp[c] = maximum total copies gained by buying the first copy
      of some distinct item types with exact total price c.

      -Infinity means this cost is currently unreachable.
    */
    const dp = new Array<number>(budget + 1).fill(-Infinity);
    dp[0] = 0;

    for (const [factor, price] of items) {
        // All items with factors divisible by factor can be received for free,
        // except this item itself.
        const freeCopies = divisibleCount[factor] - 1;

        // First purchase gives one bought copy plus all its free copies.
        const firstPurchaseValue = 1 + freeCopies;

        // Go backward: each item type can activate its bonus only once.
        for (let spent = budget; spent >= price; spent--) {
            if (dp[spent - price] === -Infinity) continue;

            dp[spent] = Math.max(
                dp[spent],
                dp[spent - price] + firstPurchaseValue
            );
        }
    }

    let answer = 0;

    for (let spent = 1; spent <= budget; spent++) {
        if (dp[spent] === -Infinity) continue;

        // Further copies provide no new free-item rewards.
        const extraCopies = Math.floor((budget - spent) / cheapestPrice);

        answer = Math.max(answer, dp[spent] + extraCopies);
    }

    return answer;
};

```

# Example Walkthrough

## Example 1

```text
items = [[6,2], [2,6], [3,4]]
budget = 9
```

| Item | Factor | Price | Free items received | First-purchase value |
|---:|---:|---:|---|---:|
| 0 | `6` | `2` | none | `1` |
| 1 | `2` | `6` | item `0` (`2` divides `6`) | `2` |
| 2 | `3` | `4` | item `0` (`3` divides `6`) | `2` |

The cheapest item costs `2`.

A best choice is:

```text
Buy item 0 once: cost 2, copies gained = 1
Buy item 2 once: cost 4, copies gained = 2
```

So far:

```text
spent = 6
copies = 3
remaining budget = 3
```

Use the remaining budget to buy one extra copy of the cheapest item:

```text
extra copies = floor(3 / 2) = 1
```

Total:

```text
3 + 1 = 4
```

Output: `4`

## Example 2

```text
items = [[2,4], [3,2], [4,1], [6,4], [12,4]]
budget = 8
```

Choose:

```text
item 0: factor 2, price 4
item 1: factor 3, price 2
item 2: factor 4, price 1
```

First purchases cost:

```text
4 + 2 + 1 = 7
```

Free copies:

- Factor `2` divides `4`, `6`, and `12` → `3` free copies.
- Factor `3` divides `6` and `12` → `2` free copies.
- Factor `4` divides `12` → `1` free copy.

```text
Purchased copies = 3
Free copies = 3 + 2 + 1 = 6
Total = 9
```

There is `1` budget remaining, and the cheapest item costs `1`, so buy one additional copy:

```text
9 + 1 = 10
```

Output: `10`
