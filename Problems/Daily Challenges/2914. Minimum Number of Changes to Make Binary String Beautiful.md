# Intuition

Since every substring in a valid partition must have an **even length** and consist of identical characters, the simplest way to achieve this is to think of the string as a sequence of **consecutive pairs**: `(s[0], s[1])`, `(s[2], s[3])`, and so on.

If we make every pair internally consistent (both characters equal), then each pair alone already satisfies both conditions (length `2`, same character), and consecutive matching pairs can simply be merged into larger valid blocks if desired - but even without merging, treating every pair as its own block already produces a valid beautiful string.

So the problem reduces to: **for every non-overlapping pair of adjacent characters, how many pairs have mismatched characters?** Each mismatched pair requires exactly **one** change to make both characters equal (flip either character to match the other).

---

# Approach

1. Iterate through the string in steps of `2`, examining each pair `(s[i], s[i+1])`.
2. If the two characters differ, increment a counter - this pair needs exactly one change to become uniform.
3. If they already match, no change is needed for that pair.
4. Return the total count of mismatched pairs as the minimum number of changes.

### Why this is optimal
Any valid partition must respect **even-length monochromatic blocks**. The boundaries between pairs `(0,1), (2,3), ...` are the finest possible division respecting even length. Making each such pair monochromatic is both **necessary** (since any larger valid block is just a concatenation of adjacent same-character pairs) and **sufficient** to form a valid partition - so fixing mismatches at this granularity gives the true minimum.

---

# Complexity

- **Time complexity:** $O(n)$ - a single pass through the string, examining each pair once.
- **Space complexity:** $O(1)$ - only a counter variable is used.

---

# Code

```typescript
function minChanges(s: string): number {
    let changes = 0;
    const n = s.length;

    for (let i = 0; i < n; i += 2) {
        if (s[i] !== s[i + 1]) {
            changes++;
        }
    }

    return changes;
};

```

# Example Walkthrough

## Example 1

```text
s = "1001"
```

- Pair `(s[0], s[1]) = ('1', '0')` → mismatch → `changes = 1`
- Pair `(s[2], s[3]) = ('0', '1')` → mismatch → `changes = 2`

Output: `2`

This matches the expected explanation: changing `s[1]` to `'1'` and `s[3]` to `'0'` gives `"1100"`, which partitions as `"11|00"`.

## Example 2

```text
s = "10"
```

- Pair `(s[0], s[1]) = ('1', '0')` → mismatch → `changes = 1`

Output: `1`

Matches: change `s[1]` to `'1'` → `"11"`.

## Example 3

```text
s = "0000"
```

- Pair `(s[0], s[1]) = ('0', '0')` → match → `changes = 0`
- Pair `(s[2], s[3]) = ('0', '0')` → match → `changes = 0`

Output: `0`

The string is already beautiful (`"0000"` partitions as `"00|00"` or just `"0000"`).
