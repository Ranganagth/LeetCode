# Intuition

If every `'a'` must appear before every `'b'`, then once we encounter the first `'b'` in the string, **no `'a'` should appear afterward**. This means the string must look like a block of `'a'`s followed by a block of `'b'`s (either block can be empty).

---

# Approach

1. Scan through the string.
2. Once a `'b'` is found, set a flag indicating we've entered the "b section."
3. If an `'a'` is found **after** that flag is set, the condition is violated - return `false`.
4. If we finish scanning without violation, return `true`.

---

# Complexity

- **Time complexity:** $O(n)$ - single pass through the string.
- **Space complexity:** $O(1)$ - only a boolean flag is used.

---

# Code

```typescript
function checkString(s: string): boolean {
    let seenB = false;

    for (const char of s) {
        if (char === 'b') {
            seenB = true;
        } else if (seenB) {
            // Found an 'a' after a 'b' was already seen.
            return false;
        }
    }

    return true;
};

```

---

# Example Walkthrough

## Example 1

```text
s = "aaabbb"
```

- `'a'`, `'a'`, `'a'` → no `'b'` seen yet, fine.
- `'b'` → `seenB = true`
- `'b'`, `'b'` → fine, still `'b'`s

No violation found.

Output: `true`

## Example 2

```text
s = "abab"
```

- `'a'` → fine
- `'b'` → `seenB = true`
- `'a'` → violation! (`'a'` found after `'b'`)

Output: `false`

## Example 3

```text
s = "bbb"
```

- `'b'` → `seenB = true`
- `'b'`, `'b'` → fine, no `'a'`s at all

Output: `true`
