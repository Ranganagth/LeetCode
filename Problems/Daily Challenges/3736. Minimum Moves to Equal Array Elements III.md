# Intuition

Since moves can only **increase** an element's value (never decrease), every element must be raised up to meet the **largest** value in the array — nothing can come down to meet a smaller target. Therefore, the optimal target is simply `max(nums)`, and the total number of moves is the sum of how far each element falls short of that maximum.

---

# Approach

1. Find the **maximum** value in `nums`.
2. For each element, compute `max - nums[i]` (the number of increments needed to reach the max).
3. Sum these differences across all elements.
4. Return the total.

---

# Complexity

- **Time complexity:**
$$O(n)$$
One pass to find the max, another pass to sum the differences.

- **Space complexity:**
$$O(1)$$
Only a few scalar variables are used.

---

# Code

```typescript
function minMoves(nums: number[]): number {
    let max = -Infinity;

    for (const num of nums) {
        if (num > max) {
            max = num;
        }
    }

    let moves = 0;

    for (const num of nums) {
        moves += max - num;
    }

    return moves;
};

```

# Example Walkthrough

## Example 1

```text
nums = [2, 1, 3]
```

- `max = 3`
- Differences: `(3-2) + (3-1) + (3-3) = 1 + 2 + 0 = 3`

Output: `3`

## Example 2

```text
nums = [4, 4, 5]
```

- `max = 5`
- Differences: `(5-4) + (5-4) + (5-5) = 1 + 1 + 0 = 2`

Output: `2`
