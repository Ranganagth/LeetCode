# Intuition

For every node, we need to know two things about its subtree: the **sum** of all values and the **count** of nodes. With these, we can compute the subtree's average and compare it to the node's own value.

Since both the sum and count of a subtree depend on the sums/counts of its children, this is a natural fit for **post-order traversal** (process children first, then combine results at the parent).

---

# Approach

1. Perform a **post-order DFS** traversal starting from the root.
2. At each node:
   - Recursively compute `(sum, count)` for the left subtree.
   - Recursively compute `(sum, count)` for the right subtree.
   - Combine: 
     ```text
     totalSum = leftSum + rightSum + node.val
     totalCount = leftCount + rightCount + 1
     ```
   - Compute the average: `Math.floor(totalSum / totalCount)`.
   - If this average equals `node.val`, increment a global (or passed-by-reference) counter.
   - Return `(totalSum, totalCount)` up to the parent call.
3. If the tree is empty, return `0` immediately (though constraints guarantee at least one node).
4. Return the final counter value after the traversal completes.

---

# Complexity

- **Time complexity:** 
$$O(n)$$
Each node is visited exactly once during the post-order traversal.

- **Space complexity:** 
$$O(h)$$
where `h` is the height of the tree, due to the recursion call stack (worst case `O(n)` for a skewed tree).

# Code

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 * val: number
 * left: TreeNode | null
 * right: TreeNode | null
 * constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 * this.val = (val===undefined ? 0 : val)
 * this.left = (left===undefined ? null : left)
 * this.right = (right===undefined ? null : right)
 * }
 * }
 */

function averageOfSubtree(root: TreeNode | null): number {
    let count = 0;

    // Returns [sum, nodeCount] for the subtree rooted at `node`.
    const dfs = (node: TreeNode | null): [number, number] => {
        if (node === null) {
            return [0, 0];
        }

        const [leftSum, leftCount] = dfs(node.left);
        const [rightSum, rightCount] = dfs(node.right);

        const totalSum = leftSum + rightSum + node.val;
        const totalCount = leftCount + rightCount + 1;

        const average = Math.floor(totalSum / totalCount);
        if (average === node.val) {
            count++;
        }

        return [totalSum, totalCount];
    };

    dfs(root);

    return count;
};

```

# Example Walkthrough

## Example 1

```text
root = [4, 8, 5, 0, 1, null, 6]
```

Tree structure:

```text
        4
       / \
      8 5
     / \ \
    0 1 6
```

Post-order traversal computes:

- Node `0`: sum=0, count=1 → avg=0 → matches 
- Node `1`: sum=1, count=1 → avg=1 → matches 
- Node `8`: sum=0+1+8=9, count=3 → avg=3 → node.val=8 → no match
- Node `6`: sum=6, count=1 → avg=6 → matches 
- Node `5`: sum=5+6=11, count=2 → avg=5 → matches 
- Node `4`: sum=9+11+4=24, count=3+2+1=6 → avg=4 → matches 

Total matches: `5`

Output: `5`

## Example 2

```text
root = [1]
```

- Node `1`: sum=1, count=1 → avg=1 → matches 

Output: `1`
