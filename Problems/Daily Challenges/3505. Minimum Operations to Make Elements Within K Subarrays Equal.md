# Intuition

To make every element within a window of size `x` **equal** using the fewest increment/decrement operations, the optimal target is the **median** of that window - a well-known property that the median minimizes the sum of absolute deviations (whereas the mean minimizes squared deviations).

This naturally splits the problem into two independent parts:

1. **Compute the cost of equalizing every possible window of size `x`** - the minimum number of operations needed if that window becomes one uniform-value subarray, based on its median.
2. **Select `k` non-overlapping windows** from these precomputed costs that together minimize the **total** cost - a classic constrained interval-selection problem, solved with dynamic programming.

---

# Approach

## Part 1 - Sliding Window Median Cost (Two Heaps)

As the window of size `x` slides across `nums`, we continuously need:
- The current **median**.
- The **cost** to bring every element in the window to that median:

```text
cost = Σ |value - median|
```

To support both insertions (new element entering) and deletions (old element leaving) efficiently, maintain two heaps:

- `lowerHalf`: a **max-heap** storing the smaller half of the window's values.
- `upperHalf`: a **min-heap** storing the larger half.

Keep them balanced so that:

```text
lowerSize === upperSize OR lowerSize === upperSize + 1
```

The median is always `lowerHalf.top()`.

Since heaps don't natively support arbitrary-element deletion, we use **lazy deletion**:
- Mark a value as "to be removed" in a `deleted` map instead of searching for it.
- Whenever a heap's top happens to be a pending-deleted value, pop it for real via `cleanHeap`.

Running sums `lowerSum` and `upperSum` let us compute cost in `O(1)` once we know the median:

```text
costLeft = median * lowerSize - lowerSum // raising smaller values up to median
costRight = upperSum - median * upperSize // lowering larger values down to median
cost = costLeft + costRight
```

Each slide of the window performs one `deleteNumber` (old element) and one `insertNumber` (new element), each `O(log x)` amortized due to lazy cleanup.

This produces `costPerWindow[i]` for every starting index `i` from `0` to `n - x`.

## Part 2 - DP to Pick k Non-Overlapping Windows with Minimum Total Cost

Let `totalWindows = n - x + 1`. Define:

```text
dp[c][i] = minimum total cost using exactly c non-overlapping windows,
           where the c-th (last) chosen window starts at index i
```

**Base case** (`c = 1`):

```text
dp[1][i] = costPerWindow[i]
```

**Transition** (`c ≥ 2`): the previous window must end before this one begins, so its starting index must satisfy `≤ i - x` (ensuring no overlap). Rather than re-scanning for the best previous value every time, maintain a running minimum `minPreviousCost` as `i` increases from left to right - this keeps each DP row `O(totalWindows)`:

```text
dp[c][i] = minPreviousCost(over j <= i - x) + costPerWindow[i]
```

**Final Answer:**

```text
min(dp[k][i]) over all valid i
```

---

# Complexity

Let `n = nums.length`, `x` = window size, `k` = number of required subarrays.

- **Time complexity:**
  - Sliding window with two heaps: `O(n log x)` - insertion/deletion and lazy cleanup are `O(log x)` amortized each.
  - DP computation: `O(k × totalWindows) = O(k × n)`.
  - **Total:** $$O(n log x + k·n)$$

- **Space complexity:** $O(n)$ for `costPerWindow`, the heaps and their deletion maps, plus $O(k × n)$ for the DP table.

Given $k ≤ 15$ and $n ≤ 10^5$, this comfortably meets the constraints.

const minOperations = (nums: number[], windowSize: number, numSubarrays: number): number => {
    const arrayLength = nums.length;
    const totalWindows = arrayLength - windowSize + 1;

    const lowerHalf = new Heap<number>((a, b) => b - a); // max-heap
    const upperHalf = new Heap<number>((a, b) => a - b); // min-heap

    let lowerSum = 0;
    let upperSum = 0;
    let lowerSize = 0;
    let upperSize = 0;

    const lowerDeleted = new Map<number, number>();
    const upperDeleted = new Map<number, number>();

    const costPerWindow: number[] = [];

    const cleanHeap = (heap: Heap<number>, deleted: Map<number, number>) => {
        while (heap.size() > 0 && deleted.has(heap.top())) {
            const val = heap.pop();
            deleted.set(val, deleted.get(val)! - 1);
            if (deleted.get(val) === 0) deleted.delete(val);
        }
    };

    const rebalanceHeaps = () => {
        while (lowerSize > upperSize + 1) {
            cleanHeap(lowerHalf, lowerDeleted);
            const val = lowerHalf.pop();
            upperHalf.push(val);
            lowerSum -= val;
            upperSum += val;
            lowerSize--;
            upperSize++;
        }
        while (lowerSize < upperSize) {
            cleanHeap(upperHalf, upperDeleted);
            const val = upperHalf.pop();
            lowerHalf.push(val);
            upperSum -= val;
            lowerSum += val;
            upperSize--;
            lowerSize++;
        }
    };

    const insertNumber = (value: number) => {
        cleanHeap(lowerHalf, lowerDeleted);
        if (lowerSize === 0 || value <= lowerHalf.top()) {
            lowerHalf.push(value);
            lowerSum += value;
            lowerSize++;
        } else {
            upperHalf.push(value);
            upperSum += value;
            upperSize++;
        }
        rebalanceHeaps();
    };

    const deleteNumber = (value: number) => {
        cleanHeap(lowerHalf, lowerDeleted);
        if (value <= lowerHalf.top()) {
            lowerDeleted.set(value, (lowerDeleted.get(value) ?? 0) + 1);
            lowerSum -= value;
            lowerSize--;
        } else {
            upperDeleted.set(value, (upperDeleted.get(value) ?? 0) + 1);
            upperSum -= value;
            upperSize--;
        }
        rebalanceHeaps();
    };

    const calculateMedianCost = (): number => {
        cleanHeap(lowerHalf, lowerDeleted);
        const median = lowerHalf.top();
        const costLeft = median * lowerSize - lowerSum;
        const costRight = upperSum - median * upperSize;
        return costLeft + costRight;
    };

    for (let i = 0; i < windowSize; i++) {
        insertNumber(nums[i]);
    }
    costPerWindow.push(calculateMedianCost());

    for (let i = windowSize; i < arrayLength; i++) {
        deleteNumber(nums[i - windowSize]);
        insertNumber(nums[i]);
        costPerWindow.push(calculateMedianCost());
    }

    const dp: number[][] = Array.from({ length: numSubarrays + 1 }, () =>
        Array(totalWindows).fill(Infinity)
    );

    for (let windowIndex = 0; windowIndex < totalWindows; windowIndex++) {
        dp[1][windowIndex] = costPerWindow[windowIndex];
    }

    for (let subarrayCount = 2; subarrayCount <= numSubarrays; subarrayCount++) {
        let minPreviousCost = Infinity;

        for (let currentWindow = 0; currentWindow < totalWindows; currentWindow++) {
            const previousWindowEnd = currentWindow - windowSize;
            if (previousWindowEnd >= 0) {
                minPreviousCost = Math.min(minPreviousCost, dp[subarrayCount - 1][previousWindowEnd]);
            }

            if (minPreviousCost < Infinity) {
                dp[subarrayCount][currentWindow] = minPreviousCost + costPerWindow[currentWindow];
            }
        }
    }

    return Math.min(...dp[numSubarrays]);
};

# Example Walkthrough

## Example: `nums = [9, -2, -2, -2, 1, 5]`, `x = 2`, `k = 2`

### Step 1 - Compute `costPerWindow` (`windowSize = 2`)

| Window start | Elements | Median | Cost calculation | Cost |
|---|---|---|---|---|
| 0 | `[9, -2]` | `-2` | `|9-(-2)|` | `11` |
| 1 | `[-2, -2]` | `-2` | `0` | `0` |
| 2 | `[-2, -2]` | `-2` | `0` | `0` |
| 3 | `[-2, 1]` | `-2` | `|1-(-2)|` | `3` |
| 4 | `[1, 5]` | `1` | `|5-1|` | `4` |

```text
costPerWindow = [11, 0, 0, 3, 4]
```

**Heap trace for window at index 3 (`[-2, 1]`):**
- Remove `-2` (old `nums[1]`), insert `1` (new `nums[3]`).
- After rebalance, `lowerHalf.top() = -2`, so median = `-2`.
- `costLeft = -2 * 1 - (-2) = 0`, `costRight = 1 - (-2*1) = 3` → total `3`. matches table.

### Step 2 - DP Table Construction

**Base row (`c=1`):**

```text
dp[1] = [11, 0, 0, 3, 4]
```

**Row `c=2`** (`windowSize = 2`, so the previous window's start must be `≤ i - 2`):

- `i=0`: `previousWindowEnd = -2` → invalid → `Infinity`
- `i=1`: `previousWindowEnd = -1` → invalid → `Infinity`
- `i=2`: `previousWindowEnd = 0` → `minPreviousCost = dp[1][0] = 11` → `dp[2][2] = 11 + 0 = 11`
- `i=3`: `previousWindowEnd = 1` → `minPreviousCost = min(11, dp[1][1]=0) = 0` → `dp[2][3] = 0 + 3 = 3`
- `i=4`: `previousWindowEnd = 2` → `minPreviousCost = min(0, dp[1][2]=0) = 0` → `dp[2][4] = 0 + 4 = 4`

```text
dp[2] = [Infinity, Infinity, 11, 3, 4]
```

### Step 3 - Final Answer

```text
min(dp[2]) = 3
```

This corresponds to choosing:
- Window at index `1`: `[-2, -2]` - already equal, cost `0`.
- Window at index `3`: `[-2, 1]` - equalize to `-2` by subtracting `3` from `nums[4]`, cost `3`.

This matches the problem's expected explanation (subtract 3 from `nums[4]`, resulting in `[9, -2, -2, -2, -2, 5]`).

**Output: `3`**
