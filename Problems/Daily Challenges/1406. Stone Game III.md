# Intuition

This is a **game theory problem** with optimal play. Both players want to maximize their own score. We need to use **dynamic programming** to determine the best outcome for each player.

**Key insight:** At each position, a player can take 1, 2, or 3 stones. They will choose the option that maximizes their advantage over the opponent.

---

# Approach

1. **Define DP state:**
   - `dp[i]` = maximum score difference (current player - opponent) starting from position `i`

2. **Recurrence relation:**
   - At position `i`, the player can take 1, 2, or 3 stones
   - For each choice, calculate: `sum of taken stones - dp[i + stones_taken]`
   - The `-dp[i + stones_taken]` represents the opponent's best play from the remaining stones
   - Choose the maximum among these options

3. **Base case:**
   - `dp[n]` = 0 (no stones left, score difference is 0)

4. **Result:**
   - If `dp[0] > 0`: Alice wins
   - If `dp[0] < 0`: Bob wins
   - If `dp[0] == 0`: Tie

---

# Complexity

- **Time complexity:** $O(n)$ - compute dp for each position once
- **Space complexity:** $O(n)$ - dp array

---

# Code

```typescript
function stoneGameIII(stoneValue: number[]): string {
    const n = stoneValue.length;
    
    // dp[i] = max score difference (current player - opponent) from position i
    const dp = new Array(n + 1).fill(-Infinity);
    dp[n] = 0; // Base case: no stones left
    
    // Work backwards from the end
    for (let i = n - 1; i >= 0; i--) {
        let sum = 0;
        
        // Try taking 1, 2, or 3 stones
        for (let k = 0; k < 3 && i + k < n; k++) {
            sum += stoneValue[i + k];
            
            // Current player gets 'sum', opponent gets best from remaining
            // Score difference = sum - opponent's best difference
            dp[i] = Math.max(dp[i], sum - dp[i + k + 1]);
        }
    }
    
    // Determine winner based on Alice's advantage
    if (dp[0] > 0) return "Alice";
    if (dp[0] < 0) return "Bob";
    return "Tie";
};

```

# Alternative Solutions

## Solution 2: With Memoization (Top-Down)

```typescript
function stoneGameIII(stoneValue: number[]): string {
    const n = stoneValue.length;
    const memo = new Map<number, number>();
    
    function dp(i: number): number {
        if (i >= n) return 0;
        if (memo.has(i)) return memo.get(i)!;
        
        let maxDiff = -Infinity;
        let sum = 0;
        
        // Try taking 1, 2, or 3 stones
        for (let k = 0; k < 3 && i + k < n; k++) {
            sum += stoneValue[i + k];
            maxDiff = Math.max(maxDiff, sum - dp(i + k + 1));
        }
        
        memo.set(i, maxDiff);
        return maxDiff;
    }
    
    const aliceAdvantage = dp(0);
    
    if (aliceAdvantage > 0) return "Alice";
    if (aliceAdvantage < 0) return "Bob";
    return "Tie";
};

```

## Solution 3: Space Optimized

```typescript
function stoneGameIII(stoneValue: number[]): string {
    const n = stoneValue.length;
    
    // Only need last 3 values
    let dp0 = 0, dp1 = 0, dp2 = 0;
    
    for (let i = n - 1; i >= 0; i--) {
        let maxDiff = -Infinity;
        let sum = 0;
        
        // Try taking 1, 2, or 3 stones
        if (i < n) {
            sum += stoneValue[i];
            maxDiff = Math.max(maxDiff, sum - dp0);
        }
        if (i + 1 < n) {
            sum += stoneValue[i + 1];
            maxDiff = Math.max(maxDiff, sum - dp1);
        }
        if (i + 2 < n) {
            sum += stoneValue[i + 2];
            maxDiff = Math.max(maxDiff, sum - dp2);
        }
        
        // Shift values
        dp2 = dp1;
        dp1 = dp0;
        dp0 = maxDiff;
    }
    
    if (dp0 > 0) return "Alice";
    if (dp0 < 0) return "Bob";
    return "Tie";
};

```

# Example Walkthrough

## Example 1: `stoneValue = [1,2,3,7]`

```
Working backwards:

i=3 (last stone):
  Take 1: sum=7, diff = 7 - dp[4] = 7 - 0 = 7
  dp[3] = 7

i=2:
  Take 1: sum=3, diff = 3 - dp[3] = 3 - 7 = -4
  Take 2: sum=3+7=10, diff = 10 - dp[4] = 10 - 0 = 10
  dp[2] = max(-4, 10) = 10

i=1:
  Take 1: sum=2, diff = 2 - dp[2] = 2 - 10 = -8
  Take 2: sum=2+3=5, diff = 5 - dp[3] = 5 - 7 = -2
  Take 3: sum=2+3+7=12, diff = 12 - dp[4] = 12 - 0 = 12
  dp[1] = max(-8, -2, 12) = 12

i=0:
  Take 1: sum=1, diff = 1 - dp[1] = 1 - 12 = -11
  Take 2: sum=1+2=3, diff = 3 - dp[2] = 3 - 10 = -7
  Take 3: sum=1+2+3=6, diff = 6 - dp[3] = 6 - 7 = -1
  dp[0] = max(-11, -7, -1) = -1

dp[0] = -1 < 0, so Bob wins
```

**Output:** `"Bob"`

## Example 2: `stoneValue = [1,2,3,-9]`

```
i=3: dp[3] = -9 - 0 = -9

i=2:
  Take 1: 3 - (-9) = 12
  Take 2: 3+(-9)=-6, -6 - 0 = -6
  dp[2] = 12

i=1:
  Take 1: 2 - 12 = -10
  Take 2: 2+3=5, 5 - (-9) = 14
  Take 3: 2+3+(-9)=-4, -4 - 0 = -4
  dp[1] = 14

i=0:
  Take 1: 1 - 14 = -13
  Take 2: 1+2=3, 3 - 12 = -9
  Take 3: 1+2+3=6, 6 - (-9) = 15
  dp[0] = 15

dp[0] = 15 > 0, so Alice wins
```

**Output:** `"Alice"`

## Example 3: `stoneValue = [1,2,3,6]`

```
i=3: dp[3] = 6

i=2:
  Take 1: 3 - 6 = -3
  Take 2: 3+6=9, 9 - 0 = 9

i=1:

```

# Visual Representation

**DP state transition:**

```
Position: [1, 2, 3, 7]
           0 1 2 3

At position i, player can take:
- 1 stone: get stoneValue[i], opponent plays from i+1
- 2 stones: get sum(i, i+1), opponent plays from i+2
- 3 stones: get sum(i, i+1, i+2), opponent plays from i+3

Choose option that maximizes: (my gain) - (opponent's best)
```

# Key Insights

- **Score difference:** Track difference instead of absolute scores
- **Optimal play:** Each player maximizes their advantage
- **Backward DP:** Work from end to start
- **Minimax principle:** Maximize your gain while minimizing opponent's
- **Negative values:** Can make taking fewer stones optimal

---

# Why This Works

**Game theory principle:**

1. At each position, the current player wants to maximize their advantage
2. The advantage = (stones they take) - (opponent's best advantage from remaining)
3. The opponent will also play optimally, so we use their dp value
4. By working backwards, we know all future optimal plays

**Mathematical foundation:**
```
dp[i] = max over k in {1,2,3} of:
        (sum of k stones starting at i) - dp[i+k]
```

This represents the best score difference the current player can achieve.

---

# Common Mistakes to Avoid

1. **Not using score difference:**
   ```typescript
   // Wrong: tracking absolute scores
   dp[i] = max score from position i
   
   // Correct: tracking relative advantage
   dp[i] = max (my score - opponent's score) from position i
   ```

2. **Wrong sign in recurrence:**
   ```typescript
   // Wrong: adding opponent's advantage
   dp[i] = sum + dp[i+k]
   
   // Correct: subtracting opponent's advantage
   dp[i] = sum - dp[i+k]
   ```

3. **Not considering all options:**
   ```typescript
   // Wrong: only trying to take 1 stone
   dp[i] = stoneValue[i] - dp[i+1]
   
   // Correct: try 1, 2, and 3 stones
   for (let k = 0; k < 3; k++) { ... }
   ```
