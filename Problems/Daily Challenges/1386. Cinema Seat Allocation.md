# Intuition

Given `n` can be up to 10⁹, we **cannot iterate through every row** directly. However, only rows with reservations matter for reducing the seat count from the default maximum.

**Key insight:** In a row with **no reservations**, we can always fit **2 families** (using blocks [2-5] and [6-9], which don't overlap). Only rows that have at least one reserved seat need special calculation.

**Bitmask approach:** For each row with reservations, only seats 2-9 matter (since blocks only use these seats). We can represent reserved seats in this range as an 8-bit mask and check which blocks are available.

---

# Approach

## Step 1: Build a Reservation Map
Use a `Map<number, number>` where key is the row number and value is a **bitmask** representing reserved seats in that row (only seats 2-9 matter).

## Step 2: Define Seat Blocks as Bitmasks
Map seats 2-9 to bits 0-7:
- **Block A** (seats 2,3,4,5): bits 0-3 → mask = `0b00001111` = 15
- **Block B** (seats 4,5,6,7): bits 2-5 → mask = `0b00111100` = 60
- **Block C** (seats 6,7,8,9): bits 4-7 → mask = `0b11110000` = 240

## Step 3: Calculate Families Per Row
For each row with reservations:
- If **both** Block A and Block C fit (no overlap with reserved seats): **2 families**
- Else if **any single block** (A, B, or C) fits: **1 family**
- Else: **0 families**

## Step 4: Combine Results
- Rows **without** any reservations: 2 families each
- Rows **with** reservations: calculated value from bitmask check

**Total = 2 × (n - rowsWithReservations) + sum(families for reserved rows)**

---

# Complexity

**Time Complexity:** $O(R)$ where R = length of `reservedSeats`
- Building the map: $O(R)$
- Processing each unique row: $O(R)$ in worst case
- No dependency on `n` directly (crucial since n can be $10⁹$)

**Space Complexity:** $O(R)$
- Map stores at most R unique rows

---

# Code

```typescript
function maxNumberOfFamilies(n: number, reservedSeats: number[][]): number {
    const rowMasks = new Map<number, number>();
    
    // Build bitmask for each row (only seats 2-9 matter)
    for (const [row, seat] of reservedSeats) {
        if (seat >= 2 && seat <= 9) {
            const bit = seat - 2; // Map seat 2->bit0, seat3->bit1, ..., seat9->bit7
            const currentMask = rowMasks.get(row) || 0;
            rowMasks.set(row, currentMask | (1 << bit));
        }
        // Seats 1 and 10 don't affect any block, so we ignore them
    }
    
    const BLOCK_A = 0b00001111; // seats 2,3,4,5
    const BLOCK_B = 0b00111100; // seats 4,5,6,7
    const BLOCK_C = 0b11110000; // seats 6,7,8,9
    
    let totalFamilies = 0;
    
    // Process each row that has reservations
    for (const mask of rowMasks.values()) {
        if ((mask & BLOCK_A) === 0 && (mask & BLOCK_C) === 0) {
            // Both A and C blocks are free - can fit 2 families
            totalFamilies += 2;
        } else if (
            (mask & BLOCK_A) === 0 || 
            (mask & BLOCK_B) === 0 || 
            (mask & BLOCK_C) === 0
        ) {
            // At least one block is free - can fit 1 family
            totalFamilies += 1;
        }
        // Otherwise, no block fits - 0 families for this row
    }
    
    // Rows without any reservations get 2 families each
    const rowsWithReservations = rowMasks.size;
    const rowsWithoutReservations = n - rowsWithReservations;
    
    totalFamilies += rowsWithoutReservations * 2;
    
    return totalFamilies;
};

```

## Solution with Detailed Comments

```typescript
function maxNumberOfFamilies(n: number, reservedSeats: number[][]): number {
    // Map: row number -> bitmask of reserved seats (seats 2-9 only)
    const rowMasks = new Map<number, number>();
    
    // Process all reservations, building bitmasks
    for (const [row, seat] of reservedSeats) {
        // Only seats 2-9 are relevant since blocks only use these
        if (seat >= 2 && seat <= 9) {
            const bitPosition = seat - 2; // Normalize to 0-indexed bit position
            const existingMask = rowMasks.get(row) || 0;
            rowMasks.set(row, existingMask | (1 << bitPosition));
        }
        // Seats 1 and 10 are ignored as they don't block any seat group
    }
    
    // Define the three possible seat blocks as bitmasks
    const BLOCK_A = 0b00001111; // Represents seats 2,3,4,5
    const BLOCK_B = 0b00111100; // Represents seats 4,5,6,7
    const BLOCK_C = 0b11110000; // Represents seats 6,7,8,9
    
    let totalFamilies = 0;
    
    // Calculate families for each row that has at least one reservation
    for (const mask of rowMasks.values()) {
        const canFitA = (mask & BLOCK_A) === 0;
        const canFitB = (mask & BLOCK_B) === 0;
        const canFitC = (mask & BLOCK_C) === 0;
        
        if (canFitA && canFitC) {
            // Blocks A and C don't overlap, so both can be used together
            totalFamilies += 2;
        } else if (canFitA || canFitB || canFitC) {
            // At least one block is available
            totalFamilies += 1;
        }
        // If none fit, this row contributes 0 families
    }
    
    // Rows with no reservations automatically get 2 families
    // (since blocks A and C never overlap, both fit in an empty row)
    const emptyRows = n - rowMasks.size;
    totalFamilies += emptyRows * 2;
    
    return totalFamilies;
};

```

# Example Walkthrough

## Example 1: `n = 3, reservedSeats = [[1,2],[1,3],[1,8],[2,6],[3,1],[3,10]]`

### Step 1: Build Row Masks

```
Process [1,2]: seat=2, bit=0
  rowMasks[1] = 0 | (1<<0) = 1 (binary: 00000001)

Process [1,3]: seat=3, bit=1
  rowMasks[1] = 1 | (1<<1) = 3 (binary: 00000011)

Process [1,8]: seat=8, bit=6
  rowMasks[1] = 3 | (1<<6) = 67 (binary: 01000011)

Process [2,6]: seat=6, bit=4
  rowMasks[2] = 0 | (1<<4) = 16 (binary: 00010000)

Process [3,1]: seat=1, ignored (not in range 2-9)

Process [3,10]: seat=10, ignored (not in range 2-9)

Final rowMasks:
  Row 1: 67 (binary: 01000011) → seats 2,3,8 reserved
  Row 2: 16 (binary: 00010000) → seat 6 reserved
  Row 3: not in map (no relevant reservations)
```

### Step 2: Calculate Families for Reserved Rows

```
Row 1: mask = 67 (0b01000011)
  BLOCK_A = 0b00001111 = 15
  mask & BLOCK_A = 67 & 15 = 3 (not 0, blocked)
  
  BLOCK_B = 0b00111100 = 60
  mask & BLOCK_B = 67 & 60 = 0 (fits!)
  
  BLOCK_C = 0b11110000 = 240
  mask & BLOCK_C = 67 & 240 = 64 (not 0, blocked)
  
  canFitA = false, canFitB = true, canFitC = false
  Since not (canFitA && canFitC), check single block:
  canFitA || canFitB || canFitC = true
  Row 1 contributes: 1 family

Row 2: mask = 16 (0b00010000)
  mask & BLOCK_A = 16 & 15 = 0 (fits!)
  mask & BLOCK_C = 16 & 240 = 16 (not 0, blocked)
  
  canFitA = true, canFitC = false
  Not both fit, check single:
  canFitA || canFitB || canFitC = true
  Row 2 contributes: 1 family
```

### Step 3: Calculate Empty Rows

```
rowsWithReservations = 2 (rows 1 and 2)
emptyRows = n - rowsWithReservations = 3 - 2 = 1 (row 3)

Row 3 contributes: 2 families (empty row)
```

### Step 4: Sum Total

```
Total = 1 (row1) + 1 (row2) + 2 (row3, empty) = 4
```

**Output:** `4` ✓

# Key Insights

1. **Rows without reservations are trivial:** Always fit exactly 2 families using non-overlapping blocks A and C
2. **Bitmask enables O(1) block checking:** Simple AND operations determine if blocks are available
3. **Only process rows with reservations:** Since n can be up to 10⁹, we must avoid iterating all rows
4. **Two non-overlapping blocks maximize families:** A and C together give 2 families when both are free
5. **Seats 1 and 10 are irrelevant:** They don't belong to any of the three defined blocks

---

# Edge Cases

| Case | Scenario | Handling |
|------|----------|----------|
| No reservations | `reservedSeats = []` | All n rows get 2 families each |
| All seats reserved | Row fully blocked | 0 families for that row |
| Only seat 1 or 10 reserved | Doesn't affect blocks | Row still gets 2 families |
| Large n | $n = 10^9$ | Efficient due to map-based approach |
| Reservations in same row | Multiple entries per row | Correctly OR'd into single bitmask |

---

# Common Mistakes to Avoid

1. **Iterating through all n rows:**
   ```typescript
   // Wrong: will timeout for large n
   for (let row = 1; row <= n; row++) { ... }
   
   // Correct: only process rows with reservations
   for (const mask of rowMasks.values()) { ... }
   ```

2. **Including seats 1 and 10 in bitmask:**
   atManager
   ```typescript
   // Wrong: wastes bits on irrelevant seats
   const bit = seat - 1; // includes seat 1 and 10
   
   // Correct: only map seats 2-9
   if (seat >= 2 && seat <= 9) {
       const bit = seat - 2;
   }
   ```

3. **Incorrect block overlap check:**
   ```typescript
   // Wrong: checking if blocks overlap with each other instead of reservations
   if (BLOCK_A & BLOCK_C) { ... }
   
   // Correct: check if reservations block the seat group
   if ((mask & BLOCK_A) === 0) { ... }
   ```

4. **Not considering both A and C together:**
   ```typescript
   // Wrong: only checking single blocks
   if (canFitA) totalFamilies += 1;
   else if (canFitB) totalFamilies += 1;
   else if (canFitC) totalFamilies += 1;
   
   // Correct: check if both A and C fit for 2 families
   if (canFitA && canFitC) totalFamilies += 2;
   else if (canFitA || canFitB || canFitC) totalFamilies += 1;
   ```

# Performance Analysis

For $R = 10^4$ reservations, $n = 10^9$:

| Operation | Complexity | Notes |
|-----------|-----------|-------|
| Build row masks | $O(R)$ | Process each reservation once |
| Calculate families | $O(R)$ | At most R unique rows |
| **Total** | **$O(R)$** | **Independent of n!** |

This is crucial since n can be up to $10^9$ - we never iterate through all rows directly!

---

# Recommended Solution

This bitmask-based approach is optimal for:
- $O(R)$ time complexity, independent of n
- $O(R)$ space complexity
- Handles n up to $10^9$ efficiently
- Clean, elegant bitmask operations
- Correctly identifies all three seating scenarios (2 families, 1 family, 0 families)

> This is the standard and most efficient solution for this classic "seat allocation with sparse constraints" problem!
