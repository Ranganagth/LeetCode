# Intuition

Since the operation allows removing any prefix and any suffix (each possibly empty) while keeping the array non-empty, this is equivalent to choosing **any contiguous subarray** of `nums`. We need to count, for every possible product-mod-`k` value, how many subarrays produce that residue.

Since `k ≤ 5` is very small, we can efficiently track the distribution of **product residues mod k** for all subarrays **ending at the current index**, and update this distribution incrementally as we scan through the array.

---

# Approach

## Key Insight

If `dist[r]` represents the number of subarrays **ending at the previous index** whose product `≡ r (mod k)`, then when we move to the next index with value `a = nums[j] % k`:

- Each existing subarray extended by one more element gets its residue transformed: `newDist[(r * a) % k] += dist[r]`
- Additionally, a brand new subarray consisting of just `nums[j]` alone contributes: `newDist[a] += 1`

This gives us the residue distribution for all subarrays **ending exactly at index `j`**, in `O(k)` time per step.

## Algorithm

1. Initialize `result` array of size `k`, all zeros.
2. Initialize `dist` array of size `k`, all zeros (representing "no subarrays yet").
3. For each index `j` from `0` to `n-1`:
   - Compute `a = nums[j] % k`.
   - Build `newDist`:
     - For each residue `r` with `dist[r] > 0`, add `dist[r]` to `newDist[(r * a) % k]`.
     - Add `1` to `newDist[a]` for the new singleton subarray `[nums[j]]`.
   - Set `dist = newDist`.
   - Add `dist[r]` to `result[r]` for every `r` (accumulating all subarrays ending at this index into the global tally).
4. Return `result`.

Every subarray `[i, j]` is counted exactly once — as the subarray ending at `j` that started building up from index `i`.

---

# Complexity

- **Time complexity:** 
$$O(n \times k)$$
Since `k ≤ 5`, this is effectively linear in `n`.

- **Space complexity:** 
$$O(k)$$
Only the `dist`, `newDist`, and `result` arrays of fixed size `k` are used (no per-index storage needed).

# Code

```typescript
function resultArray(nums: number[], k: number): number[] {
    const n = nums.length;
    const result = new Array<number>(k).fill(0);
    let dist = new Array<number>(k).fill(0);

    for (let j = 0; j < n; j++) {
        const a = nums[j] % k;
        const newDist = new Array<number>(k).fill(0);

        for (let r = 0; r < k; r++) {
            if (dist[r] > 0) {
                const r2 = (r * a) % k;
                newDist[r2] += dist[r];
            }
        }

        newDist[a] += 1; // singleton subarray [nums[j]]

        dist = newDist;

        for (let r = 0; r < k; r++) {
            result[r] += dist[r];
        }
    }

    return result;
};

```

# Example Walkthrough

## Example 1

```text
nums = [1, 2, 3, 4, 5], k = 3
```

Step-by-step residues (`a = nums[j] % 3`): `1, 2, 0, 1, 2`

| j | a | dist before | newDist | result after |
|---|---|-------------|---------|----------------|
| 0 | 1 | {} | {1:1} | [0,1,0] |
| 1 | 2 | {1:1} | {2:2} | [0,1,2] |
| 2 | 0 | {2:2} | {0:3} | [3,1,2] |
| 3 | 1 | {0:3} | {0:3,1:1} | [6,2,2] |
| 4 | 2 | {0:3,1:1} | {0:3,2:2} | [9,2,4] |

Output: `[9, 2, 4]`

## Example 3

```text
nums = [1, 1, 2, 1, 1], k = 2
```

Residues mod 2: `1, 1, 0, 1, 1`

| j | a | dist before | newDist | result after |
|---|---|-------------|---------|----------------|
| 0 | 1 | {} | {1:1} | [0,1] |
| 1 | 1 | {1:1} | {1:2} | [0,3] |
| 2 | 0 | {1:2} | {0:3} | [3,3] |
| 3 | 1 | {0:3} | {0:3,1:1} | [6,4] |
| 4 | 1 | {0:3,1:1} | {0:3,1:4} | [9,8]... |

Wait, let's recompute step 4 carefully: `dist={0:3,1:1}`, `a=1`.
- r=0: `(0*1)%2=0` → newDist[0]+=3
- r=1: `(1*1)%2=1` → newDist[1]+=1
- singleton: newDist[1]+=1 → newDist[1]=2

newDist={0:3,1:2}. result becomes [6+3, 4+2] = [9,6]

Output: `[9, 6]`
