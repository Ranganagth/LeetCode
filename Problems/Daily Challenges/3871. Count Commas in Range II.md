# Intuition

A number with **d digits** has exactly:
$$
\text{commas}=\left\lfloor\frac{d-1}{3}\right\rfloor
$$
commas (since commas appear every 3 digits from the right).

So we just need to count how many integers in $[1,n]$ have each digit length $d$, then multiply by the commas-per-number for that $d$.

---

# Approach

1. For each possible digit length $d \in [1, \text{digits}(n)]$:
   - The range of $d$-digit numbers is:
     $$
     [10^{d-1},\, 10^d-1]
     $$
   - Count how many of them are $\le n$:
     $$
     cnt = \max(0,\; \min(n, 10^d-1) - 10^{d-1} + 1)
     $$
   - Add:
     $$
     cnt \times \left\lfloor\frac{d-1}{3}\right\rfloor
     $$
2. Sum over all digit lengths.

Use **BigInt** because $n$ can be up to $10^{15}$.

---

# Complexity

- **Time complexity:** $$O(\log_{10} n)$$ (at most ~16 digit lengths)
- **Space complexity:** $$O(1)$$

---

# Code

```typescript
function countCommas(n: number): number {
  const MOD = 1e9; // not needed, but keeps TS number ops safe
  let N = BigInt(n);

  const digitCountN = N.toString().length;

  let pow10 = 1n; // 10^(d-1)
  let ans = 0n;

  for (let d = 1; d <= digitCountN; d++) {
    const start = pow10; // 10^(d-1)
    const end = (pow10 * 10n) - 1n; // 10^d - 1

    const hi = end < N ? end : N;
    if (hi >= start) {
      const cnt = hi - start + 1n;
      const commasPer = BigInt(Math.floor((d - 1) / 3));
      ans += cnt * commasPer;
    }

    pow10 *= 10n;
  }

  return Number(ans);
};

```

# Example Walkthrough

## Example: `n = 1002`

Digit counts:
- 1–999 are 1 to 3 digits → commas per number = 0
- 1000–1002 are 4 digits → commas per number = floor((4-1)/3)=1

Count of 4-digit numbers up to 1002:
- `1000..1002` → 3 numbers

Total commas = `3 * 1 = 3`
