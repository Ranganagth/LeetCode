# Intuition

The problem naturally splits into two independent sub-problems:

1. **For any substring `s[i..j]`**, determine the minimum number of character changes needed to make it a **semi-palindrome** - trying every valid divisor `d` of its length and picking the cheapest one.
2. **Partition the whole string into exactly `k` substrings** such that the total cost (summed semi-palindrome costs) is minimized - a classic **interval partition DP**.

Since `s.length <= 200`, we can afford to precompute the cost for **every possible substring** (`O(n²)` substrings), and then use a straightforward DP over partitions.

---

# Approach

## Step 1 - Precompute `cost[i][j]`

`cost[i][j]` = minimum number of letter changes needed to make `s[i..j]` a semi-palindrome.

For a substring of length `len = j - i + 1`:

- Try every divisor `d` of `len` where `1 <= d < len`.
- For divisor `d`, split the substring into `d` groups, where group `g` consists of characters at positions `i+g, i+g+d, i+g+2d, ...`.
- For each group, compute the minimum changes needed to make it a **palindrome**: compare characters from both ends moving inward - each mismatched pair costs `1` change.
- Sum the costs of all `d` groups to get the total cost for this divisor.
- Take the **minimum** total cost over all valid divisors `d`.

If `len === 1`, there's no valid divisor per the problem's definition, but such a substring is trivially unchanged (cost `0`) - this only matters as a base case and won't typically appear in a final answer unless `k` allows very short pieces.

## Step 2 - Partition DP

Define:

```text
dp[i][p] = minimum total cost to partition s[i..n-1] into exactly p substrings
```

**Base case:**

```text
dp[n][0] = 0
```

**Transition:** Try every possible end index `j` for the current substring `s[i..j-1]`:

```text
dp[i][p] = min over j > i of (cost[i][j-1] + dp[j][p-1])
```

**Answer:**

```text
dp[0][k]
```

---

# Complexity

Let `n = s.length`.

- **Precomputing `cost[i][j]`:**
  For each of the `O(n²)` substrings, we iterate over its divisors (`O(√len)` divisors in general, but summing group-comparison work per divisor costs `O(len)`), giving roughly `O(n³)` in the worst case (bounded well for `n ≤ 200`, about `8 × 10⁶` operations).

- **Partition DP:**
  `O(n × k)` states, each with an `O(n)` transition → `O(n² × k)`.

Given `n ≤ 200` and `k ≤ n/2 ≤ 100`, both phases run comfortably within limits.

- **Space complexity:** `O(n²)` for the cost table, plus `O(n × k)` for the DP table.

# Code

```typescript
function minimumChanges(s: string, k: number): number {
    const n = s.length;
    const INF = Infinity;

    // cost[i][j] = minimum changes to make s[i..j] a semi-palindrome.
    const cost: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));

    for (let i = 0; i < n; i++) {
        for (let j = i; j < n; j++) {
            const len = j - i + 1;

            if (len === 1) {
                // A single character has no valid divisor,
                // so it can never be a semi-palindrome.
                cost[i][j] = INF;
                continue;
            }

            let best = Infinity;

            for (let d = 1; d < len; d++) {
                if (len % d !== 0) continue;

                let total = 0;

                for (let g = 0; g < d; g++) {
                    const indices: number[] = [];
                    for (let p = i + g; p <= j; p += d) {
                        indices.push(p);
                    }

                    let l = 0;
                    let r = indices.length - 1;

                    while (l < r) {
                        if (s[indices[l]] !== s[indices[r]]) {
                            total++;
                        }
                        l++;
                        r--;
                    }
                }

                if (total < best) {
                    best = total;
                }
            }

            cost[i][j] = best;
        }
    }

    // dp[i][p] = min cost to partition s[i..n-1] into p parts.
    const dp: number[][] = Array.from({ length: n + 1 }, () => new Array(k + 1).fill(INF));
    dp[n][0] = 0;

    for (let i = n - 1; i >= 0; i--) {
        for (let p = 1; p <= k; p++) {
            let best = INF;

            for (let j = i + 1; j <= n; j++) {
                if (dp[j][p - 1] === INF) continue;
                if (cost[i][j - 1] === INF) continue;

                const candidate = cost[i][j - 1] + dp[j][p - 1];

                if (candidate < best) {
                    best = candidate;
                }
            }

            dp[i][p] = best;
        }
    }

    return dp[0][k];
};

```

# Example Walkthrough

## Example 1

```text
s = "abcac", k = 2
```

### Step 1 - Compute relevant costs

**Substring `"ab"` (`i=0, j=1`):**
`len=2`, only divisor `d=1`.
Group: indices `[0,1]` → `"ab"`.
Compare `s[0]='a'` vs `s[1]='b'` → mismatch → cost `1`.
`cost[0][1] = 1`

**Substring `"cac"` (`i=2, j=4`):**
`len=3`, only divisor `d=1`.
Group: indices `[2,3,4]` → `"cac"`.
Compare ends: `s[2]='c'` vs `s[4]='c'` → match → cost `0`. (Middle character is unpaired, no cost.)
`cost[2][4] = 0`

### Step 2 - DP Partition

Splitting at `i=0, j=2` (first part `s[0..1]="ab"`, second part `s[2..4]="cac"`):

```text
cost[0][1] + cost[2][4] = 1 + 0 = 1
```

This matches the optimal partition described in the problem.

Output: `1`

## Example 2

```text
s = "aabbaa", k = 3
```

Partition into `"aa"`, `"bb"`, `"aa"`.

Each substring `"aa"` or `"bb"` has `len=2`, divisor `d=1`:
- Group `[0,1]` → compare the two identical characters → `0` cost.

So:

```text
cost("aa") = 0
cost("bb") = 0
cost("aa") = 0
```

Total cost: `0 + 0 + 0 = 0`.

Output: `0`
