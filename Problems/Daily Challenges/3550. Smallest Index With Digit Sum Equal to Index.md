# Intuition

Since we need the **smallest** index satisfying the condition, we can simply scan the array from left to right, checking each index in order, and return as soon as we find a match. Given the small constraints (`nums.length ≤ 100`), a straightforward digit-sum check per element is more than efficient enough.

---

# Approach

1. Iterate through the array from index `0` to `n-1`.
2. For each index `i`, compute the **digit sum** of `nums[i]`:
   - Repeatedly extract the last digit (`num % 10`) and add it to a running sum, then remove that digit (`num = Math.floor(num / 10)`), until `num` becomes `0`.
3. If the computed digit sum equals `i`, return `i` immediately (this guarantees the smallest valid index since we scan left to right).
4. If no index satisfies the condition after the full scan, return `-1`.

---

# Complexity

- **Time complexity:** 
$$O(n \cdot d)$$
where `n` is the array length and `d` is the maximum number of digits (at most 4, since `nums[i] ≤ 1000`). Effectively this is `O(n)`.

- **Space complexity:** 
$$O(1)$$
Only a few scalar variables are used.

---

# Code

```typescript
function smallestIndex(nums: number[]): number {
    const n = nums.length;

    for (let i = 0; i < n; i++) {
        let num = nums[i];
        let digitSum = 0;

        while (num > 0) {
            digitSum += num % 10;
            num = Math.floor(num / 10);
        }

        if (digitSum === i) {
            return i;
        }
    }

    return -1;
};

```

# Example Walkthrough

## Example 1

```text
nums = [1, 3, 2]
```

- `i=0`: `nums[0]=1`, digitSum=1, `1 !== 0` → no match
- `i=1`: `nums[1]=3`, digitSum=3, `3 !== 1` → no match
- `i=2`: `nums[2]=2`, digitSum=2, `2 === 2` → match!

Output: `2`

## Example 2

```text
nums = [1, 10, 11]
```

- `i=0`: `nums[0]=1`, digitSum=1, `1 !== 0` → no match
- `i=1`: `nums[1]=10`, digitSum=1+0=1, `1 === 1` → match!

Output: `1`

## Example 3

```text
nums = [1, 2, 3]
```

- `i=0`: digitSum=1, `1 !== 0` → no match
- `i=1`: digitSum=2, `2 !== 1` → no match
- `i=2`: digitSum=3, `3 !== 2` → no match

No match found.

Output: `-1`
