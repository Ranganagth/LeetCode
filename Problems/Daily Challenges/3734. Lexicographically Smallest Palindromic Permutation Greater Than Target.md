# Intuition

A palindrome is completely determined by:

- Its **left half**
- Its optional **middle character** (only when `n` is odd)
- The reverse of its left half

For example, if the left half is `"ab"` and the middle is `"c"`, the palindrome is:

```text
ab + c + ba = "abcba"
```

Therefore, lexicographic order among palindromic permutations is determined by the lexicographic order of their **left halves**.

So we only need to find the smallest valid permutation of the left-half characters that produces a palindrome strictly greater than `target`.

---

# Approach

## 1. Check whether a palindromic permutation is possible

A string can be rearranged into a palindrome only if at most one character has an odd frequency.

- More than one odd frequency → return `""`
- Otherwise:
  - `count[ch] / 2` characters go into the left half
  - The odd-frequency character, if any, becomes the middle character

## 2. Compare with `target` using its left half

Let:

```text
leftTarget = target[0 .. halfLength - 1]
```

There are two cases:

1. If `leftTarget` can be made using our available left-half character counts:
   - Build its palindrome.
   - If it is strictly greater than `target`, it is the answer.

2. Otherwise, or if that palindrome is not greater than `target`:
   - Find the smallest possible left half that is **strictly greater than** `leftTarget`.
   - Construct the corresponding palindrome.

To find this next left half efficiently:

- Traverse `leftTarget` from left to right.
- At every position, check whether we can replace the current character with a larger available character.
- Keep the **rightmost** such replacement, because changing a later character gives a smaller lexicographical result.
- Fill all remaining positions with the smallest available characters.

---

# Complexity

- **Time complexity:** $$O(n + 26) = O(n)$$

- **Space complexity:** $$O(n)$$ 
  The result palindrome and constructed left half require linear space.

---


# Code

```typescript
function lexPalindromicPermutation(s: string, target: string): string {
    const n = s.length;

    // Count frequencies in s.
    const freq = new Array<number>(26).fill(0);
    for (const ch of s) {
        freq[ch.charCodeAt(0) - 97]++;
    }

    // A palindrome can have at most one odd-frequency character.
    let oddCount = 0;
    let middle = "";

    for (let i = 0; i < 26; i++) {
        if (freq[i] % 2 === 1) {
            oddCount++;
            middle = String.fromCharCode(97 + i);
        }
    }

    if (oddCount > 1) {
        return "";
    }

    // Characters available for the left half.
    const halfCount = new Array<number>(26).fill(0);
    for (let i = 0; i < 26; i++) {
        halfCount[i] = Math.floor(freq[i] / 2);
    }

    const halfLength = Math.floor(n / 2);
    const targetLeft = target.slice(0, halfLength);

    // Builds a full palindrome from a left half.
    const buildPalindrome = (left: string): string => {
        const right = left.split("").reverse().join("");
        return left + middle + right;
    };

    // Check whether targetLeft can be formed exactly from halfCount.
    const remainingForExact = [...halfCount];
    let canUseTargetLeft = true;

    for (const ch of targetLeft) {
        const index = ch.charCodeAt(0) - 97;

        if (remainingForExact[index] === 0) {
            canUseTargetLeft = false;
            break;
        }

        remainingForExact[index]--;
    }

    // If using target's left half creates a palindrome greater than target,
    // it is the smallest possible answer.
    if (canUseTargetLeft) {
        const candidate = buildPalindrome(targetLeft);

        if (candidate > target) {
            return candidate;
        }
    }

    /*
     * Find the smallest multiset permutation of halfCount
     * that is strictly greater than targetLeft.
     */
    const remaining = [...halfCount];

    let bestPosition = -1;
    let bestChar = -1;

    for (let i = 0; i < halfLength; i++) {
        const current = targetLeft.charCodeAt(i) - 97;

        // Try replacing targetLeft[i] with the smallest larger available character.
        for (let next = current + 1; next < 26; next++) {
            if (remaining[next] > 0) {
                bestPosition = i;
                bestChar = next;
                break;
            }
        }

        // Continue matching targetLeft's prefix if possible.
        if (remaining[current] === 0) {
            break;
        }

        remaining[current]--;
    }

    // No left-half permutation can be greater than targetLeft.
    if (bestPosition === -1) {
        return "";
    }

    // Reconstruct the best left half:
    // targetLeft prefix + one larger character + smallest remaining characters.
    const counts = [...halfCount];
    let left = targetLeft.slice(0, bestPosition);

    // Remove characters used in the unchanged prefix.
    for (let i = 0; i < bestPosition; i++) {
        counts[targetLeft.charCodeAt(i) - 97]--;
    }

    // Use the selected larger character.
    left += String.fromCharCode(97 + bestChar);
    counts[bestChar]--;

    // Fill the suffix with the smallest available characters.
    for (let i = 0; i < 26; i++) {
        if (counts[i] > 0) {
            left += String.fromCharCode(97 + i).repeat(counts[i]);
        }
    }

    return buildPalindrome(left);
};

```

# Example Walkthrough

## Example 1

```text
s = "baba"
target = "abba"
```

Character frequencies:

```text
a -> 2
b -> 2
```

Left-half characters:

```text
a, b
```

Target left half:

```text
"ab"
```

Using `"ab"` creates:

```text
"ab" + "" + "ba" = "abba"
```

But `"abba"` is not strictly greater than the target.

Find the next valid left half after `"ab"`:

```text
"ba"
```

Build the palindrome:

```text
"ba" + "" + "ab" = "baab"
```

Answer:

```text
"baab"
```

## Example 4

```text
s = "aac"
target = "abb"
```

Frequencies:

```text
a -> 2
c -> 1
```

- Left half: `"a"`
- Middle character: `"c"`

Build the only palindrome:

```text
"a" + "c" + "a" = "aca"
```

Comparison:

```text
"aca" > "abb"
```

Answer:

```text
"aca"
```
