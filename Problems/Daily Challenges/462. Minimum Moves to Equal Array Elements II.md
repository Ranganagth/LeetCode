# Intuition

When each move allows incrementing **or** decrementing a single element by `1`, the total cost to make all elements equal to some target value `t` is the **sum of absolute differences** `Σ|nums[i] - t|`. This sum is minimized when `t` is chosen as the **median** of the array — a well-known property: the median minimizes the sum of absolute deviations (unlike the mean, which minimizes sum of squared deviations).

---

# Approach

1. **Sort** the array.
2. Identify the **median** element — for an array of size `n`, this is `nums[Math.floor(n/2)]` after sorting (works correctly for both even and odd lengths, since for even-length arrays any value between the two middle elements achieves the same minimal cost, and picking either middle element gives the same total sum).
3. Compute the sum of absolute differences between each element and the median.
4. Return that sum.

### Why the median works
If you consider moving the target value slightly, each element either "pulls" the cost up or down depending on whether it's above or below the target. The target value that balances the number of elements above and below it (the median) results in no beneficial single direction to shift further — this is the point where the total cost is minimized.

---

# Complexity

- **Time complexity:**
$$O(n \log n)$$
Dominated by the sorting step.

- **Space complexity:** 
$$O(1)$$
(or `O(n)` / `O(log n)` depending on the sort implementation's internal memory usage, but no extra data structures are needed beyond the input array itself).

---

# Code

```typescript
function minMoves2(nums: number[]): number {
    nums.sort((a, b) => a - b);

    const n = nums.length;
    const median = nums[Math.floor(n / 2)];

    let moves = 0;

    for (const num of nums) {
        moves += Math.abs(num - median);
    }

    return moves;
};

```

# Example Walkthrough

## Example 1

```text
nums = [1, 2, 3]
```

- Sorted: `[1, 2, 3]`
- `n = 3`, median index = `Math.floor(3/2) = 1` → `median = 2`
- Sum of absolute differences: `|1-2| + |2-2| + |3-2| = 1 + 0 + 1 = 2`

Output: `2`

This matches:
```text
[1,2,3] → [2,2,3] → [2,2,2]
```

## Example 2

```text
nums = [1, 10, 2, 9]
```

- Sorted: `[1, 2, 9, 10]`
- `n = 4`, median index = `Math.floor(4/2) = 2` → `median = 9`
- Sum of absolute differences: `|1-9| + |2-9| + |9-9| + |10-9| = 8 + 7 + 0 + 1 = 16`

Output: `16`

> Note: choosing `median = 2` — the other middle value — would give `|1-2|+|2-2|+|9-2|+|10-2| = 1+0+7+8 = 16`, the same total, confirming either middle element works for even-length arrays.
