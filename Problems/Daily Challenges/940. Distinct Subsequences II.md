# Intuition

At first glance, counting **distinct subsequences** seems tricky because duplicates arise naturally whenever a character repeats. The key insight is to process the string character by character while tracking how many *new* distinct subsequences each character contributes — and to correctly **subtract duplicates** created by repeated characters.

If we let `dp` represent the total count of distinct non-empty subsequences formed so far, then adding a new character `c` naturally **doubles** all previous subsequences (by appending `c` to each), plus adds one new subsequence — just `c` by itself. However, if `c` has appeared before, some of these newly formed subsequences will exactly duplicate ones we've already counted from `c`'s last occurrence, so we must subtract that overlap.

---

# Approach

1. Maintain a running total `dp`, representing the number of distinct non-empty subsequences formed using the string processed so far.
2. Maintain an array `last[26]`, where `last[c]` stores the value of `dp` **immediately after** the previous time character `c` was processed. This captures exactly the "duplicate contribution" that would otherwise be double-counted.
3. For each character `c` in `s`:
   - Compute the new total:
     ```text
     newDp = (2 * dp + 1) - last[c]
     ```
     - `2 * dp` accounts for: (a) keeping all old subsequences as-is, and (b) appending `c` to each old subsequence to form new ones.
     - `+1` accounts for the new subsequence consisting of just `c` alone.
     - `- last[c]` removes subsequences that would be exact duplicates of ones created the last time `c` appeared.
   - Update `last[c] = newDp` (store this new total for future duplicate-checking).
   - Update `dp = newDp`.
4. Apply modulo `10^9 + 7` at every step to keep numbers manageable, ensuring proper handling of negative values after subtraction.
5. Return `dp` as the final answer.

---

# Complexity

- **Time complexity:** 
$$O(n)$$
A single pass through the string, with constant-time work per character.

- **Space complexity:** 
$$O(1)$$
Only a fixed-size array of 26 elements (`last`) and a few scalar variables are used.

---

# Code

```typescript
function distinctSubseqII(s: string): number {
    const MOD = 1_000_000_007;
    const n = s.length;

    const last = new Array<number>(26).fill(0);
    let dp = 0;

    for (let i = 0; i < n; i++) {
        const idx = s.charCodeAt(i) - 97;

        let newDp = (2 * dp + 1) % MOD;
        newDp = (newDp - last[idx] + MOD) % MOD;

        last[idx] = newDp;
        dp = newDp;
    }

    return dp;
};

```

# Example Walkthrough

## Example 1

```text
s = "aba"
```

| Step | Char | dp before | newDp calculation | newDp | last['a'] | last['b'] |
|------|------|-----------|--------------------|-------|-----------|-----------|
| 1 | a | 0 | 2×0+1-0 = 1 | 1 | 1 | 0 |
| 2 | b | 1 | 2×1+1-0 = 3 | 3 | 1 | 3 |
| 3 | a | 3 | 2×3+1-1 = 6 | 6 | 6 | 3 |

Final `dp = 6`

Matches the expected subsequences: `"a", "b", "ab", "aa", "ba", "aba"`.
