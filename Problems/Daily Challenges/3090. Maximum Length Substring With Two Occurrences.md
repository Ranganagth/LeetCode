# Intuition

We need to find the longest substring where each character appears **at most 2 times**. This is a classic **sliding window** problem where we maintain a valid window and expand/contract it based on character frequencies.

**Key insight:** Use two pointers (left and right) to maintain a window. Expand the window by moving right, and contract it when any character count exceeds 2.

---

# Approach

**Sliding Window Strategy:**

1. Use a **frequency map** to track character counts in current window
2. **Expand window:** Move right pointer and add characters
3. **Contract window:** When any character count > 2, move left pointer until valid
4. **Track maximum:** Update max length at each valid window

**Why sliding window?**
- Each character is visited at most twice (once by right, once by left)
- $O(n)$ time complexity
- Efficiently maintains valid substring constraint

---

# Complexity

**Time Complexity:** $O(n)$
- Right pointer traverses string once: $O(n)$
- Left pointer moves at most n times total: $O(n)$
- Each character processed at most twice
- Total: $O(n)$

**Space Complexity:** $O(1)$
- Frequency map stores at most 26 characters (lowercase English letters)
- Constant space regardless of input size

# Code

## Solution 1: Sliding Window with Map

```typescript
function maximumLengthSubstring(s: string): number {
    const freq = new Map<string, number>();
    let left = 0;
    let maxLength = 0;
    
    for (let right = 0; right < s.length; right++) {
        const char = s[right];
        freq.set(char, (freq.get(char) || 0) + 1);
        
        // Contract window while any character appears more than 2 times
        while (freq.get(char)! > 2) {
            const leftChar = s[left];
            freq.set(leftChar, freq.get(leftChar)! - 1);
            if (freq.get(leftChar) === 0) {
                freq.delete(leftChar);
            }
            left++;
        }
        
        // Update maximum length
        maxLength = Math.max(maxLength, right - left + 1);
    }
    
    return maxLength;
};

```

## Solution 2: Using Array for Frequency (Faster)

```typescript
function maximumLengthSubstring(s: string): number {
    const freq = new Array(26).fill(0);
    let left = 0;
    let maxLength = 0;
    
    for (let right = 0; right < s.length; right++) {
        const charCode = s.charCodeAt(right) - 97; // 'a' = 97
        freq[charCode]++;
        
        // Contract window while current character appears more than 2 times
        while (freq[charCode] > 2) {
            const leftCharCode = s.charCodeAt(left) - 97;
            freq[leftCharCode]--;
            left++;
        }
        
        maxLength = Math.max(maxLength, right - left + 1);
    }
    
    return maxLength;
};

```

## Solution 3: With Detailed Comments

```typescript
function maximumLengthSubstring(s: string): number {
    // Frequency map to track character counts in current window
    const charCount = new Map<string, number>();
    
    // Two pointers for sliding window
    let left = 0;
    let maxLength = 0;
    
    // Expand window by moving right pointer
    for (let right = 0; right < s.length; right++) {
        const currentChar = s[right];
        
        // Add current character to window
        charCount.set(currentChar, (charCount.get(currentChar) || 0) + 1);
        
        // Contract window if constraint violated
        // Keep removing from left until currentChar count <= 2
        while (charCount.get(currentChar)! > 2) {
            const leftChar = s[left];
            
            // Remove leftmost character
            charCount.set(leftChar, charCount.get(leftChar)! - 1);
            
            // Clean up if count becomes 0
            if (charCount.get(leftChar) === 0) {
                charCount.delete(leftChar);
            }
            
            // Move left pointer
            left++;
        }
        
        // Current window [left, right] is valid
        // Update maximum length
        const currentLength = right - left + 1;
        maxLength = Math.max(maxLength, currentLength);
    }
    
    return maxLength;
};

```

## Solution 4: Compact Version

```typescript
function maximumLengthSubstring(s: string): number {
    const freq = new Array(26).fill(0);
    let left = 0;
    let max = 0;
    
    for (let right = 0; right < s.length; right++) {
        const idx = s.charCodeAt(right) - 97;
        freq[idx]++;
        
        while (freq[idx] > 2) {
            freq[s.charCodeAt(left++) - 97]--;
        }
        
        max = Math.max(max, right - left + 1);
    }
    
    return max;
};

```

## Solution 5: Alternative with Object

```typescript
function maximumLengthSubstring(s: string): number {
    const count: Record<string, number> = {};
    let left = 0;
    let result = 0;
    
    for (let right = 0; right < s.length; right++) {
        count[s[right]] = (count[s[right]] || 0) + 1;
        
        while (count[s[right]] > 2) {
            count[s[left]]--;
            left++;
        }
        
        result = Math.max(result, right - left + 1);
    }
    
    return result;
};
```

# Key Insights

1. **Sliding window maintains validity:** Only contracts when constraint violated
2. **Greedy expansion:** Always try to expand window to maximize length
3. **Efficient contraction:** Only remove from left until valid again
4. **Two-pointer technique:** Each element visited at most twice $(O(n))$
5. **Character frequency tracking:** Essential for checking constraint

# Edge Cases

| All different | "abcd" | 4 | Each appears once |
| Minimum length | "ab" | 2 | Entire string |
| Alternating | "ababab" | 4 | "abab" |
| Single repeat | "aabcd" | 5 | Entire string |

# Common Mistakes to Avoid

1. **Not contracting properly:**
   ```typescript
   // Wrong: only remove one character
   if (freq[char] > 2) {
       freq[s[left]]--;
       left++;
   }
   
   // Correct: keep removing until valid
   while (freq[char] > 2) {
       freq[s[left]]--;
       left++;
   }
   ```

2. **Updating max at wrong time:**
   ```typescript
   // Wrong: update before ensuring validity
   maxLength = Math.max(maxLength, right - left + 1);
   while (freq[char] > 2) { ... }
   
   // Correct: update after ensuring validity
   while (freq[char] > 2) { ... }
   maxLength = Math.max(maxLength, right - left + 1);
   ```

3. **Not handling frequency cleanup:**
   ```typescript
   // Good practice: remove from map when count is 0
   if (freq.get(leftChar) === 0) {
       freq.delete(leftChar);
   }
   ```

# Performance Comparison

| Implementation | Time | Space | Notes |
|----------------|------|-------|-------|
| Map | $O(n)$ | $O(26)$ | Clean, readable |
