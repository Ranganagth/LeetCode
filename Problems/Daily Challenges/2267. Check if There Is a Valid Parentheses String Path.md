# Intuition

A parentheses string is valid exactly when, scanning left to right, the running **balance** (`+1` for `(`, `-1` for `)`) **never goes negative** and **ends at exactly `0`**. Instead of tracking just the *range* of possible balances at each cell (which can miss gaps in reachability), we can track the **exact set of all achievable balances** at each cell using a **bitmask**, where bit `b` is set if balance `b` is reachable at that cell.

This bitmask approach is both elegant and efficient:
- Adding `(` (i.e., `+1` to balance) corresponds to a **left shift** of the bitmask by 1.
- Adding `)` (i.e., `-1` to balance) corresponds to a **right shift** of the bitmask by 1 — conveniently, this also **automatically discards** any balance that would go negative (bit 0 shifting right simply vanishes, rather than wrapping around), naturally enforcing the "balance never negative" rule.

We also get two quick early-exit checks: the starting cell must be `(` (otherwise balance goes negative immediately), and the ending cell must be `)` (otherwise the final balance can't return to `0`).

---

# Approach

## 1. Early Termination Checks

- If `(n + m - 1)` (the fixed path length) is **odd**, no valid parentheses string of odd length can ever balance — return `false`.
- If `grid[0][0] !== '('`, the very first character would make balance `-1` — invalid — return `false`.
- If `grid[n-1][m-1] !== ')'`, the last character can't bring balance back to `0` from a non-negative prior balance — return `false`.

## 2. Bitmask DP Definition

Let `dp[i][j]` be a `BigInt` bitmask where **bit `b` is set** if balance `b` is achievable by some valid path from `(0,0)` to `(i,j)`.

## 3. Base Case

```text
dp[0][0] = 1n << 1n // bit 1 set, since grid[0][0] is guaranteed '(' → balance = 1
```

## 4. Transition

For each cell `(i, j)`, determine `change = +1` if `grid[i][j] === '('`, else `change = -1`.

- From the top neighbor `(i-1, j)`:
  - If `change === +1`: `dp[i][j] |= dp[i-1][j] << 1n`
  - If `change === -1`: `dp[i][j] |= dp[i-1][j] >> 1n` (right shift naturally drops any balance that would become `-1`)
- From the left neighbor `(i, j-1)`: same logic, shifting `dp[i][j-1]`.

Combine both contributions with bitwise OR, since either direction of arrival is valid.

## 5. Final Answer

After filling the DP table, check whether **bit 0** is set in `dp[n-1][m-1]` — i.e., whether balance `0` is achievable at the destination:

```text
(dp[n-1][m-1] & 1n) !== 0n
```

---

# Complexity

- **Time complexity:**
$$O\left(n \cdot m \cdot \frac{n+m}{64}\right)$$
Each cell performs `BigInt` shift and OR operations on numbers with up to `O(n+m)` bits, and `BigInt` operations cost is proportional to the number of 64-bit words involved. Given `n, m ≤ 100`, this is extremely fast in practice.

- **Space complexity:**
$$O\left(n \cdot m \cdot \frac{n+m}{64}\right)$$
For storing the DP table of `BigInt` bitmasks, each potentially up to `O(n+m)` bits wide.

# Code

```typescript
function hasValidPath(grid: string[][]): boolean {
    const n = grid.length;
    const m = grid[0].length;
    const pathLen = n + m - 1;

    if (pathLen % 2 === 1) {
        return false;
    }
    if (grid[0][0] !== "(" || grid[n - 1][m - 1] !== ")") {
        return false;
    }

    const dp: bigint[][] = Array.from({ length: n }, () =>
        new Array(m).fill(0n),
    );

    dp[0][0] = 1n << 1n;

    for (let i = 0; i < n; ++i) {
        for (let j = 0; j < m; ++j) {
            if (i === 0 && j === 0) continue;

            const change = grid[i][j] === "(" ? 1 : -1;

            if (i > 0) {
                if (change === 1) {
                    dp[i][j] |= dp[i - 1][j] << 1n;
                } else {
                    dp[i][j] |= dp[i - 1][j] >> 1n;
                }
            }

            if (j > 0) {
                if (change === 1) {
                    dp[i][j] |= dp[i][j - 1] << 1n;
                } else {
                    dp[i][j] |= dp[i][j - 1] >> 1n;
                }
            }
        }
    }

    return (dp[n - 1][m - 1] & 1n) !== 0n;
};

```

grid = [[")", ")"], ["(", "("]]

## Example 1

```text
grid = [["(","(","("],[")","(",")"],["(","(",")"],["(","(",")"]]
```

- `n=4, m=3`, `pathLen = 6` (even).
- `grid[0][0] = '('`, `grid[3][2] = ')'` — passes early checks.

**Initialize:** `dp[0][0] = 0b10` (bit 1 set, balance = 1).

**Row 0:** all `'('`, so balances keep increasing moving right:
- `dp[0][1]`: from left, shift left by 1 → bit 2 set (balance 2)
- `dp[0][2]`: from left, shift left by 1 → bit 3 set (balance 3)

**Row 1:** `[')','(',')']`
- `dp[1][0]`: from top `(0,0)`, change=-1 → shift right → bit 0 set (balance 0)
- `dp[1][1]`: from top `(0,1)` (bits: {2}) change=+1 → shift left → {3}; from left `(1,0)` (bits: {0}) change=+1 → shift left → {1}. Combined: {1,3}
- `dp[1][2]`: from top `(0,2)` (bits:{3}) change=-1→shift right→{2}; from left `(1,1)` (bits:{1,3}) change=-1→shift right→{0,2}. Combined: {0,2}

**Row 2:** `['(','(',')']`
- `dp[2][0]`: from top `(1,0)` (bits:{0}) change=+1→shift left→{1}
- `dp[2][1]`: from top `(1,1)` (bits:{1,3}) change=+1→shift left→{2,4}; from left `(2,0)` (bits:{1}) change=+1→shift left→{2}. Combined: {2,4}
- `dp[2][2]`: from top `(1,2)` (bits:{0,2}) change=-1→shift right→{-1(drop),1}→{1}; from left `(2,1)` (bits:{2,4}) change=-1→shift right→{1,3}. Combined: {1,3}

**Row 3:** `['(','(',')']`
- `dp[3][0]`: from top `(2,0)` (bits:{1}) change=+1→shift left→{2}
- `dp[3][1]`: from top `(2,1)` (bits:{2,4}) change=+1→shift left→{3,5}; from left `(3,0)` (bits:{2}) change=+1→shift left→{3}. Combined: {3,5}
- `dp[3][2]`: from top `(2,2)` (bits:{1,3}) change=-1→shift right→{0,2}; from left `(3,1)` (bits:{3,5}) change=-1→shift right→{2,4}. Combined: {0,2,4}

`dp[3][2]` has **bit 0 set** → balance `0` is achievable at the destination.

Output: `true`
