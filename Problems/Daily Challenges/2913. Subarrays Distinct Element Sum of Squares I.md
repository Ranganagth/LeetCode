# Intuition

Given the small constraint (`n ≤ 100`), we can afford a straightforward **brute-force** approach: for each starting index `i`, extend the subarray one element at a time to the right, incrementally tracking the **distinct count** using a hash set. Each time we extend, we can immediately compute and accumulate the square of the current distinct count, avoiding redundant recomputation.

---

# Approach

1. Iterate over all possible starting indices `i` from `0` to `n-1`.
2. For each `i`, initialize an empty `Set<number>` to track distinct values seen so far in the current subarray starting at `i`.
3. Iterate `j` from `i` to `n-1`, extending the subarray one element at a time:
   - Add `nums[j]` to the set.
   - The size of the set gives the distinct count for subarray `nums[i..j]`.
   - Add `(distinctCount)²` to the running total.
4. Return the total sum after processing all `(i, j)` pairs.

This approach naturally covers **all** `O(n²)` subarrays, and maintaining the set incrementally as `j` increases avoids recomputation from scratch for each subarray.

---

# Complexity

- **Time complexity:** 
$$O(n^2)$$
For each of the `O(n)` starting points, we do `O(n)` work extending the subarray (set insertion is `O(1)` amortized).

- **Space complexity:** 
$$O(n)$$
For the hash set tracking distinct values in the current subarray (reset for each starting index).

---

# Code

```typescript
function sumCounts(nums: number[]): number {
    const n = nums.length;
    let total = 0;

    for (let i = 0; i < n; i++) {
        const seen = new Set<number>();
        for (let j = i; j < n; j++) {
            seen.add(nums[j]);
            const distinctCount = seen.size;
            total += distinctCount * distinctCount;
        }
    }

    return total;
};

```

# Example Walkthrough

## Example 1

```text
nums = [1, 2, 1]
```

**i=0:**
- j=0: seen={1}, count=1 → total += 1
- j=1: seen={1,2}, count=2 → total += 4 (total=5)
- j=2: seen={1,2}, count=2 → total += 4 (total=9)

**i=1:**
- j=1: seen={2}, count=1 → total += 1 (total=10)
- j=2: seen={2,1}, count=2 → total += 4 (total=14)

**i=2:**
- j=2: seen={1}, count=1 → total += 1 (total=15)

Output: `15`

## Example 2

```text
nums = [1, 1]
```

**i=0:**
- j=0: seen={1}, count=1 → total += 1
- j=1: seen={1}, count=1 → total += 1 (total=2)

**i=1:**
- j=1: seen={1}, count=1 → total += 1 (total=3)

Output: `3`
