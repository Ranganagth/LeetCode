# Intuition

Since XOR values are bounded by the grid values (`0 ≤ grid[i][j] ≤ 1023`, i.e., 10 bits), **any cumulative XOR along a path is also bounded within `[0, 1023]`**. This means that instead of tracking actual paths, we can track at each cell **the set of all possible XOR values achievable** when reaching that cell — since the universe of possible XOR values is small (just 1024 possibilities), this set-based DP is very efficient.

At each cell, the achievable XOR values are simply: *(any achievable XOR value from the cell above, XORed with the current cell's value)* **union** *(any achievable XOR value from the cell to the left, XORed with the current cell's value)*.

---

# Approach

1. Use a 2D DP structure `dp[i][j]`, where `dp[i][j]` is a boolean array of size `1024` — `dp[i][j][v] = true` means XOR value `v` is achievable when reaching cell `(i, j)`.
2. **Base case**: `dp[0][0][grid[0][0]] = true`.
3. **First row**: Each cell can only be reached from the left, so `dp[0][j][v] = true` iff `dp[0][j-1][v ^ grid[0][j]] = true` for some `v` (equivalently, take every achievable value from the left and XOR with current cell).
4. **First column**: Similarly, each cell can only be reached from above.
5. **General case**: For each achievable value `v` in `dp[i-1][j]` or `dp[i][j-1]`, mark `v ^ grid[i][j]` as achievable in `dp[i][j]`.
6. After filling the DP table, scan `dp[m-1][n-1]` for the smallest index `v` where the value is `true` — this is the minimum achievable XOR cost.

To optimize memory, we can use `Uint8Array` or plain boolean arrays of fixed size `1024`, and since `m*n ≤ 1000`, total space/time stays well within limits.

---

# Complexity

- **Time complexity:**
$$O(m \cdot n \cdot 1024)$$
Each cell requires `O(1024)` work to combine achievable sets from its predecessors.

- **Space complexity:**
$$O(m \cdot n \cdot 1024)$$
in the worst case if storing the full DP table, though this can be reduced to `O(n \cdot 1024)` using rolling rows.

---

# Code

```typescript
function minCost(grid: number[][]): number {
    const m = grid.length;
    const n = grid[0].length;
    const SIZE = 1024;

    // dp[j] represents achievable XOR values for the current row at column j
    let prevRow: boolean[][] = new Array(n);
    for (let j = 0; j < n; j++) {
        prevRow[j] = new Array(SIZE).fill(false);
    }

    prevRow[0][grid[0][0]] = true;

    for (let j = 1; j < n; j++) {
        for (let v = 0; v < SIZE; v++) {
            if (prevRow[j - 1][v]) {
                prevRow[j][v ^ grid[0][j]] = true;
            }
        }
    }

    for (let i = 1; i < m; i++) {
        const curRow: boolean[][] = new Array(n);
        for (let j = 0; j < n; j++) {
            curRow[j] = new Array(SIZE).fill(false);
        }

        // first column of this row: only from above
        for (let v = 0; v < SIZE; v++) {
            if (prevRow[0][v]) {
                curRow[0][v ^ grid[i][0]] = true;
            }
        }

        for (let j = 1; j < n; j++) {
            for (let v = 0; v < SIZE; v++) {
                if (prevRow[j][v] || curRow[j - 1][v]) {
                    curRow[j][v ^ grid[i][j]] = true;
                }
            }
        }

        prevRow = curRow;
    }

    const finalSet = prevRow[n - 1];
    for (let v = 0; v < SIZE; v++) {
        if (finalSet[v]) {
            return v;
        }
    }

    return 0; // unreachable in practice, grid always has at least one path
};

```

# Example Walkthrough

## Example 1

```text
grid = [[1,2],[3,4]]
```

**Row 0:**
- `prevRow[0][1] = true` (base case, value `1`)
- `j=1`: from `prevRow[0]` value `1`, compute `1 ^ 2 = 3` → `prevRow[1][3] = true`

**Row 1 (i=1):**
- First column: from `prevRow[0]` value `1`, compute `1 ^ 3 = 2` → `curRow[0][2] = true`
- `j=1`: check `prevRow[1]` (value `3`) and `curRow[0]` (value `2`):
  - From `prevRow[1]=3`: `3 ^ 4 = 7` → `curRow[1][7] = true`
  - From `curRow[0]=2`: `2 ^ 4 = 6` → `curRow[1][6] = true`

Final set at `(1,1)`: `{6, 7}`. Minimum value = `6`.

Output: `6`

## Example 2

```text
grid = [[2,7,5]]
```

Single row:
- `prevRow[0][2] = true`
- `j=1`: `2 ^ 7 = 5` → `prevRow[1][5] = true`
- `j=2`: `5 ^ 5 = 0` → `prevRow[2][0] = true`

Final set at `(0,2)`: `{0}`. Minimum = `0`.

Output: `0`
