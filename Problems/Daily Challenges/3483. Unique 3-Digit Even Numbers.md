# Intuition

Since the array size is very small (at most 10 digits), we can simply **try every possible combination of three distinct positions** (not values, since duplicate values can be reused up to their available count) and check whether the resulting number is valid. Using a `Set` to store valid numbers automatically handles distinctness — even if the same 3-digit number arises from different position combinations.

---

# Approach

1. Iterate over all ordered triples of **distinct indices** `(i, j, k)` from the `digits` array (where `i`, `j`, `k` are all different indices, not necessarily different values — this correctly allows reuse of a repeated digit value up to its actual count in the array).
2. For each triple:
   - The **hundreds digit** is `digits[i]` — it must not be `0` (no leading zero).
   - The **tens digit** is `digits[j]`.
   - The **units digit** is `digits[k]` — it must be even for the whole number to be even.
3. If both conditions hold, compute the number:
   $$
   num = digits[i] * 100 + digits[j] * 10 + digits[k]
   $$
4. Add `num` to a `Set` to automatically deduplicate identical numbers formed from different index combinations.
5. Return the size of the set.

Since `n ≤ 10`, the total number of index triples is at most `10 × 9 × 8 = 720`, which is trivially fast.

---

# Complexity

- **Time complexity:** 
$$O(n^3)$$
where `n` is the length of `digits` (at most 10), so this is effectively constant time in practice.

- **Space complexity:** 
$$O(n^3)$$
in the worst case for the set storing distinct valid numbers (bounded by at most 900 possible 3-digit even numbers anyway).

---

# Code

```typescript
function totalNumbers(digits: number[]): number {
    const n = digits.length;
    const validNumbers = new Set<number>();

    for (let i = 0; i < n; i++) {
        if (digits[i] === 0) continue; // no leading zero

        for (let j = 0; j < n; j++) {
            if (j === i) continue;

            for (let k = 0; k < n; k++) {
                if (k === i || k === j) continue;
                if (digits[k] % 2 !== 0) continue; // must be even

                const num = digits[i] * 100 + digits[j] * 10 + digits[k];
                validNumbers.add(num);
            }
        }
    }

    return validNumbers.size;
};

```

# Example Walkthrough

## Example 1

```text
digits = [0, 2, 2]
```

Indices: `0 -> value 0`, `1 -> value 2`, `2 -> value 2`

Valid triples (hundreds digit ≠ 0, units digit even):

- `i=1 (2), j=0 (0), k=2 (2)` → `202`
- `i=1 (2), j=2 (2), k=0 (0)` → `220`
- `i=2 (2), j=0 (0), k=1 (2)` → `202` (duplicate, set ignores)
- `i=2 (2), j=1 (2), k=0 (0)` → `220` (duplicate, set ignores)

Distinct valid numbers: `{202, 220}`

Output: `2`

## Example 2

```text
digits = [6, 6, 6]
```

All permutations give `666` since all digits are identical:

- Any `(i, j, k)` combination → `666`

Distinct valid numbers: `{666}`

Output: `1`

## Example 3

```text
digits = [1, 3, 5]
```

No digit is even, so no valid units digit exists for any triple.

Distinct valid numbers: `{}` (empty)

Output: `0`
