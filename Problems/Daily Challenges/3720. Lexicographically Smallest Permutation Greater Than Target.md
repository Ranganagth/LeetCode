# Intuition

To find the smallest permutation of `s` that's strictly greater than `target`, we want to **match target's prefix as long as possible**, then at the point where we diverge, place the **smallest character greater than target's character** at that position, and fill the rest with the smallest arrangement possible.

**Key insight:** Among all valid divergence points, choosing the **latest possible position** to diverge (with the smallest valid excess character) always gives the smallest result greater than target, because staying equal to target longer keeps our string "closer" to target from above.

---

# Approach

1. **Build frequency array** of characters in `s`
2. **Find maximum feasible prefix length `M`:** greedily match `target[0], target[1], ...` by subtracting from frequency counts, stopping when a character isn't available. Store frequency **snapshots** at each prefix length.
3. **Try positions from `M-1` (or `n-1`) down to `0`:** At each position `i`, check if there's a character greater than `target[i]` available in `snapshots[i]`
4. **When found:** Take `target[0..i-1]` as prefix, place the smallest valid character greater than `target[i]`, then append all remaining characters in **sorted ascending order** (smallest possible suffix)
5. **If no position works**, return `""`

---

# Complexity

- **Time Complexity:** $O(n × 26) = O(n)$ — for each position, we scan at most 26 letters
- **Space Complexity:** $O(n × 26)$ — storing frequency snapshots at each prefix length

---

# Code

```typescript
function lexGreaterPermutation(s: string, target: string): string {
    const n = s.length;
    const freq = new Array(26).fill(0);
    for (const ch of s) freq[ch.charCodeAt(0) - 97]++;
    
    // Build snapshots: snapshots[i] = frequency after matching target[0..i-1]
    const snapshots: number[][] = [freq.slice()];
    let M = n;
    
    for (let i = 0; i < n; i++) {
        const idx = target.charCodeAt(i) - 97;
        if (snapshots[i][idx] === 0) {
            M = i; // can't match beyond this point
            break;
        }
        const next = snapshots[i].slice();
        next[idx]--;
        snapshots.push(next);
    }
    
    const maxI = Math.min(M, n - 1);
    
    // Try diverging at the latest possible position first
    for (let i = maxI; i >= 0; i--) {
        const state = snapshots[i];
        const targetIdx = target.charCodeAt(i) - 97;
        
        let foundChar = -1;
        for (let c = targetIdx + 1; c < 26; c++) {
            if (state[c] > 0) {
                foundChar = c;
                break;
            }
        }
        
        if (foundChar !== -1) {
            const remaining = state.slice();
            remaining[foundChar]--;
            
            // Build smallest suffix from remaining characters
            let suffix = "";
            for (let c = 0; c < 26; c++) {
                if (remaining[c] > 0) {
                    suffix += String.fromCharCode(97 + c).repeat(remaining[c]);
                }
            }
            
            const prefix = target.slice(0, i);
            return prefix + String.fromCharCode(97 + foundChar) + suffix;
        }
    }
    
    return "";
};

```

# Example Walkthrough

## Example 1: `s = "abc", target = "bba"`

```
freq(s) = {a:1, b:1, c:1}

Matching prefix:
  i=0: target[0]='b', freq['b']=1>0, subtract → {a:1,b:0,c:1}
  i=1: target[1]='b', freq['b']=0, STOP. M=1

maxI = min(1,2) = 1

i=1: state={a:1,b:0,c:1}, target[1]='b'
     Find char > 'b': 'c' available (count=1)
     foundChar='c'
     remaining = {a:1,b:0,c:0}
     suffix = "a"
     prefix = target[0..0] = "b"
     result = "b" + "c" + "a" = "bca"
```

**Output:** `"bca"` ✓

# Key Insights

1. **Latest divergence = smallest result:** By matching target as long as possible before diverging, we minimize the "distance" our result has from target while still being strictly greater
2. **Snapshots avoid recomputation:** Storing frequency states at each prefix length lets us efficiently test each divergence point without rebuilding counts from scratch
3. **Sorted suffix guarantees minimality:** Once we've chosen our divergence character, the smallest possible completion is always the remaining characters in sorted order

> This greedy approach elegantly solves the "next permutation with multiset constraints" problem in efficient polynomial time!
