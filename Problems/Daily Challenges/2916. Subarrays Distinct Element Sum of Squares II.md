# Intuition

A direct `O(n²)` brute force won't scale to `n = 10^5`. Instead, we track — for every **starting index** `i` — the distinct count `F[i] = f(i, j)` of the subarray `nums[i..j]` as the **right endpoint `j`** grows one step at a time. The key insight is how `F[i]` changes when we extend `j` by one position:

- If `nums[j]` last appeared at index `p` (or never appeared, `p = -1`), then for every starting index `i` with `p < i < j` (i.e., `i` in `(p, j-1]`), the subarray `[i..j-1]` did **not** yet contain `nums[j]`, so extending it to `[i..j]` **increases** the distinct count by exactly `1`.
- For `i ≤ p`, `nums[j]` was already present in `[i..j-1]`, so the distinct count is **unchanged**.
- A brand new subarray `[j..j]` starts with distinct count `1`.

So each step requires a **range increment** operation (`+1` over a contiguous range of starting indices) and we need to track how the **sum of squares** of `F[i]` evolves — which can be derived from `(F[i]+1)² - F[i]² = 2·F[i] + 1`. This means we need the **sum of `F[i]`** over the affected range *before* applying the increment, which a **Fenwick tree supporting range update + range sum query** handles efficiently.

---

# Approach

## 1. Data Structure: Range-Update Range-Sum Fenwick Tree

We use the classic two-BIT technique to support:
- `rangeUpdate(l, r, v)`: add `v` to every element in `[l, r]`.
- `rangeSum(l, r)`: get the sum of elements in `[l, r]`.

Both operations run in `O(log n)`.

## 2. Maintain Distinct-Count Array Implicitly

We never materialize `F[i]` explicitly — it's represented inside the Fenwick tree, where `F[i] = f(i, j)` for the current `j` being processed.

## 3. Track Running Sum of Squares

Maintain `sumSquares` = `Σ F[i]² for i = 0..j` (mod `10^9+7`), updated incrementally:
- When incrementing a range `[l, r]` by `1`: query `S = rangeSum(l, r)` and `C = r - l + 1` **before** applying the update. The sum of squares changes by `2·S + C`.
- When adding the new element `F[j] = 1`: sum of squares increases by `1` (since `0² → 1²`).

## 4. Main Loop

For each `j` from `0` to `n-1`:
1. Find `p = lastOccurrence[nums[j]]` (or `-1` if unseen).
2. If `p + 1 ≤ j - 1`, compute the range `[p+1, j-1]`:
   - Query `S = rangeSum(p+1, j-1)`, `C = (j-1) - (p+1) + 1`.
   - Update `sumSquares += 2·S + C`.
   - Apply `rangeUpdate(p+1, j-1, +1)`.
3. Add the new subarray `[j..j]`: `rangeUpdate(j, j, +1)`, and `sumSquares += 1`.
4. Update `lastOccurrence[nums[j]] = j`.
5. Add `sumSquares` (current total for all subarrays ending at `j`) to the global `answer`.

## 5. Return `answer mod (10^9+7)`

---

# Complexity

- **Time complexity:** 
$$O(n \log n)$$
Each of the `n` steps performs a constant number of Fenwick tree operations, each `O(log n)`.

- **Space complexity:** 
$$O(n)$$
For the two Fenwick tree arrays and the last-occurrence map.

# Code

```typescript
function sumCounts(nums: number[]): number {
    const MOD = 1_000_000_007;
    const n = nums.length;

    // Range-update, range-sum Fenwick tree (1-indexed internally)
    const B1 = new Array<number>(n + 2).fill(0);
    const B2 = new Array<number>(n + 2).fill(0);

    const updateBIT = (BIT: number[], i: number, v: number) => {
        for (; i <= n + 1; i += i & (-i)) {
            BIT[i] += v;
        }
    };

    const queryBIT = (BIT: number[], i: number): number => {
        let s = 0;
        for (; i > 0; i -= i & (-i)) {
            s += BIT[i];
        }
        return s;
    };

    const rangeUpdate = (l: number, r: number, v: number) => {
        // 1-indexed inclusive [l, r]
        updateBIT(B1, l, v);
        updateBIT(B1, r + 1, -v);
        updateBIT(B2, l, v * (l - 1));
        updateBIT(B2, r + 1, -v * r);
    };

    const prefixSum = (i: number): number => {
        return i * queryBIT(B1, i) - queryBIT(B2, i);
    };

    const rangeSumQuery = (l: number, r: number): number => {
        if (l > r) return 0;
        return prefixSum(r) - prefixSum(l - 1);
    };

    const lastOcc = new Map<number, number>();
    let sumSquares = 0;
    let answer = 0;

    for (let j = 0; j < n; j++) {
        const p = lastOcc.has(nums[j]) ? lastOcc.get(nums[j])! : -1;

        const l0 = p + 1;
        const r0 = j - 1;

        if (l0 <= r0) {
            // convert to 1-indexed: positions l0+1 .. r0+1
            const S = rangeSumQuery(l0 + 1, r0 + 1);
            const C = r0 - l0 + 1;
            const delta = (2 * S + C) % MOD;
            sumSquares = (sumSquares + delta) % MOD;
            rangeUpdate(l0 + 1, r0 + 1, 1);
        }

        // new subarray [j..j]
        rangeUpdate(j + 1, j + 1, 1);
        sumSquares = (sumSquares + 1) % MOD;

        lastOcc.set(nums[j], j);

        answer = (answer + sumSquares) % MOD;
    }

    return answer;
};

```

# Example Walkthrough

## Example 1

```text
nums = [1, 2, 1]
```

**j=0** (`nums[0]=1`): `p=-1`, no range to update (`l0=0 > r0=-1`).
- Add new element at pos 1: `F[0]=1`, `sumSquares = 1`.
- `answer = 1`

**j=1** (`nums[1]=2`): `p=-1`, range `[l0=0, r0=0]` → 1-indexed `[1,1]`.
- `S = F[0] = 1`, `C = 1`, `delta = 2*1+1=3` → `sumSquares = 1+3=4`.
- Apply update: `F[0]` becomes `2`.
- Add new element at pos 2: `F[1]=1`, `sumSquares = 5`.
- `answer = 1+5 = 6`

**j=2** (`nums[2]=1`): `p=lastOcc[1]=0`, range `[l0=1, r0=1]` → 1-indexed `[2,2]`.
- `S = F[1] = 1`, `C=1`, `delta=2*1+1=3` → `sumSquares=5+3=8`.
- Apply update: `F[1]` becomes `2`.
- Add new element at pos 3: `F[2]=1`, `sumSquares=9`.
- `answer = 6+9=15`

Output: `15`

## Example 2

```text
nums = [2, 2]
```

**j=0**: `p=-1`, no range update.
- `F[0]=1`, `sumSquares=1`, `answer=1`.

**j=1**: `p=lastOcc[2]=0`, range `[l0=1, r0=0]` → `l0 > r0`, **skip** range update (no new distinct value introduced since `2` already present).
- Add new element at pos 2: `F[1]=1`, `sumSquares = 1+1=2`.
- `answer = 1+2=3`

Output: `3`
