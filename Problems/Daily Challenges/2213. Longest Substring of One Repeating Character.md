# Intuition

We need to track the longest substring of repeating characters after each update. The key challenge is efficiently updating and finding the maximum length after each character change.

**Key observations:**
1. When we change a character, it only affects **adjacent segments** of repeating characters
2. We need to track **segments** of consecutive identical characters
3. After each update, recalculate affected segments and find the maximum

---

# Approach: Segment Tree Approach

This is an **advanced solution using a Segment Tree** to efficiently handle range queries and updates. Let me break down how it works and provide alternative implementations.

---

# Understanding the Segment Tree Solution

## Key Concepts

**Segment Tree Properties:**
- Each node represents a range `[l, r]` of the string
- Stores metadata about the longest repeating substring in that range
- Updates and queries in **$O(log n)$** time

**Node Information:**
- `pre[u]`: Length of repeating prefix in range
- `suf[u]`: Length of repeating suffix in range
- `maxLen[u]`: Maximum repeating substring length in range
- `leftChar[u]`: First character in range
- `rightChar[u]`: Last character in range

# Code

```typescript
function longestRepeating(
    s: string,
    queryCharacters: string,
    queryIndices: number[],
): number[] {
    const n = s.length;
    
    // Segment tree arrays (4*n for complete binary tree)
    const pre: number[] = new Array(4 * n).fill(0); // Prefix length
    const suf: number[] = new Array(4 * n).fill(0); // Suffix length
    const maxLen: number[] = new Array(4 * n).fill(0); // Max in range
    const leftChar: string[] = new Array(4 * n).fill(""); // Left boundary char
    const rightChar: string[] = new Array(4 * n).fill(""); // Right boundary char

    // Merge information from child nodes
    const pushUp = (u: number, l: number, r: number): void => {
        const mid = (l + r) >> 1; // Bit shift for division by 2
        const leftLen = mid - l + 1;
        const rightLen = r - mid;
        const left = u << 1; // Left child: 2*u
        const right = (u << 1) | 1; // Right child: 2*u + 1
        
        // Set boundary characters
        leftChar[u] = leftChar[left];
        rightChar[u] = rightChar[right];
        
        // Calculate prefix length
        pre[u] = pre[left];
        if (pre[left] === leftLen && rightChar[left] === leftChar[right]) {
            // Prefix extends into right child
            pre[u] = pre[left] + pre[right];
        }
        
        // Calculate suffix length
        suf[u] = suf[right];
        if (suf[right] === rightLen && rightChar[left] === leftChar[right]) {
            // Suffix extends into left child
            suf[u] = suf[right] + suf[left];
        }
        
        // Calculate max length
        maxLen[u] = Math.max(maxLen[left], maxLen[right]);
        if (rightChar[left] === leftChar[right]) {
            // Can merge across boundary
            maxLen[u] = Math.max(maxLen[u], suf[left] + pre[right]);
        }
    };

    // Build initial segment tree
    const build = (u: number, l: number, r: number): void => {
        if (l === r) {
            // Leaf node
            pre[u] = 1;
            suf[u] = 1;
            maxLen[u] = 1;
            leftChar[u] = s[l];
            rightChar[u] = s[l];
            return;
        }
        const mid = (l + r) >> 1;
        build(u << 1, l, mid); // Build left subtree
        build((u << 1) | 1, mid + 1, r); // Build right subtree
        pushUp(u, l, r); // Merge information
    };

    // Update a single position
    const update = (
        u: number,
        l: number,
        r: number,
        pos: number,
        ch: string,
    ): void => {
        if (l === r) {
            // Found the leaf to update
            leftChar[u] = ch;
            rightChar[u] = ch;
            return;
        }
        const mid = (l + r) >> 1;
        if (pos <= mid) {
            update(u << 1, l, mid, pos, ch);
        } else {
            update((u << 1) | 1, mid + 1, r, pos, ch);
        }
        pushUp(u, l, r); // Recalculate after update
    };

    // Build tree and process queries
    build(1, 0, n - 1);
    const k = queryIndices.length;
    const ans: number[] = new Array(k);
    
    for (let i = 0; i < k; i++) {
        update(1, 0, n - 1, queryIndices[i], queryCharacters[i]);
        ans[i] = maxLen[1]; // Root contains answer for entire range
    }
    
    return ans;
};

```

# Alternative: Cleaner Segment Tree with Class

```typescript
class SegmentTreeNode {
    prefixLen: number = 0;
    suffixLen: number = 0;
    maxLen: number = 0;
    leftChar: string = '';
    rightChar: string = '';
}

function longestRepeating(
    s: string,
    queryCharacters: string,
    queryIndices: number[],
): number[] {
    const n = s.length;
    const tree: SegmentTreeNode[] = Array.from(
        { length: 4 * n },
        () => new SegmentTreeNode()
    );

    function merge(
        parent: SegmentTreeNode,
        left: SegmentTreeNode,
        right: SegmentTreeNode,
        leftLen: number,
        rightLen: number
    ): void {
        parent.leftChar = left.leftChar;
        parent.rightChar = right.rightChar;

        // Calculate prefix
        parent.prefixLen = left.prefixLen;
        if (left.prefixLen === leftLen && left.rightChar === right.leftChar) {
            parent.prefixLen += right.prefixLen;
        }

        // Calculate suffix
        parent.suffixLen = right.suffixLen;
        if (right.suffixLen === rightLen && left.rightChar === right.leftChar) {
            parent.suffixLen += left.suffixLen;
        }

        // Calculate max
        parent.maxLen = Math.max(left.maxLen, right.maxLen);
        if (left.rightChar === right.leftChar) {
            parent.maxLen = Math.max(
                parent.maxLen,
                left.suffixLen + right.prefixLen
            );
        }
    }

    function build(node: number, l: number, r: number): void {
        if (l === r) {
            tree[node].prefixLen = 1;
            tree[node].suffixLen = 1;
            tree[node].maxLen = 1;
            tree[node].leftChar = s[l];
            tree[node].rightChar = s[l];
            return;
        }

        const mid = Math.floor((l + r) / 2);
        const leftChild = 2 * node;
        const rightChild = 2 * node + 1;

        build(leftChild, l, mid);
        build(rightChild, mid + 1, r);

        merge(
            tree[node],
            tree[leftChild],
            tree[rightChild],
            mid - l + 1,
            r - mid
        );
    }

    function update(
        node: number,
        l: number,
        r: number,
        pos: number,
        ch: string
    ): void {
        if (l === r) {
            tree[node].leftChar = ch;
            tree[node].rightChar = ch;
            return;
        }

        const mid = Math.floor((l + r) / 2);
        const leftChild = 2 * node;
        const rightChild = 2 * node + 1;

        if (pos <= mid) {
            update(leftChild, l, mid, pos, ch);
        } else {
            update(rightChild, mid + 1, r, pos, ch);
        }

        merge(
            tree[node],
            tree[leftChild],
            tree[rightChild],
            mid - l + 1,
            r - mid
        );
    }

    build(1, 0, n - 1);

    const result: number[] = [];
    for (let i = 0; i < queryIndices.length; i++) {
        update(1, 0, n - 1, queryIndices[i], queryCharacters[i]);
        result.push(tree[1].maxLen);
    }

    return result;
};

```

# Complexity Analysis

| Operation | Time | Space |
|-----------|------|-------|
| Build tree | $O(n)$ | $O(n)$ |
| Single update | $O(log n)$ | - |
| k updates | $O(k log n)$ | - |
| **Total** | **$O(n + k log n)$** | **$O(n)$** |

---

# Key Insights

1. **Segment Tree Efficiency:**
   - Each update affects $O(log n)$ nodes
   - Much faster than $O(n)$ scan per query

2. **Merge Strategy:**
   - Track prefix/suffix to handle boundary merges
   - Max can be in left, right, or across boundary

3. **Space Optimization:**
   - 4n space is sufficient for complete binary tree
   - Implicit tree structure using array indices

---

# When to Use This Approach

**Use Segment Tree when:**
- Multiple range queries/updates
- Need $O(log n)$ per operation
- Large input size (n, k ≥ 10^5)

**Simpler approach when:**
- Small inputs
- One-time queries
- Interview time constraints
