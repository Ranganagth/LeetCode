# Intuition

We need to find the longest subarray where **no element appears more than k times**. This is a classic **sliding window** problem where we maintain a valid window and expand/shrink it based on frequency constraints.

**Key insight:** Use a sliding window with a frequency map. When an element's frequency exceeds k, shrink the window from the left until the constraint is satisfied.

---

# Approach

1. **Sliding window with two pointers:**
   - `left` and `right` pointers define the current window
   - Expand `right` to include new elements
   - Track frequency of each element

2. **Maintain validity:**
   - When frequency of any element exceeds k, shrink from left
   - Continue shrinking until all frequencies ≤ k

3. **Track maximum:**
   - Update maximum length whenever we have a valid window

---

# Complexity

- **Time complexity:** $O(n)$ - each element visited at most twice (once by right, once by left)
- **Space complexity:** $O(n)$ - for frequency map (worst case: all unique elements)

# Code

## Solution 1: Sliding Window (Recommended)

```typescript
function maxSubarrayLength(nums: number[], k: number): number {
    const freq = new Map<number, number>();
    let left = 0;
    let maxLength = 0;
    
    for (let right = 0; right < nums.length; right++) {
        // Add current element to window
        freq.set(nums[right], (freq.get(nums[right]) || 0) + 1);
        
        // Shrink window while any frequency exceeds k
        while (freq.get(nums[right])! > k) {
            freq.set(nums[left], freq.get(nums[left])! - 1);
            if (freq.get(nums[left]) === 0) {
                freq.delete(nums[left]);
            }
            left++;
        }
        
        // Update maximum length
        maxLength = Math.max(maxLength, right - left + 1);
    }
    
    return maxLength;
};

```

## Solution 2: With Detailed Comments

```typescript
function maxSubarrayLength(nums: number[], k: number): number {
    // Map to track frequency of each element in current window
    const frequency = new Map<number, number>();
    
    let left = 0; // Left pointer of sliding window
    let maxLength = 0; // Maximum valid subarray length found
    
    // Expand window by moving right pointer
    for (let right = 0; right < nums.length; right++) {
        const currentNum = nums[right];
        
        // Add current element to window and update its frequency
        frequency.set(currentNum, (frequency.get(currentNum) || 0) + 1);
        
        // Shrink window from left while constraint is violated
        // (any element appears more than k times)
        while (frequency.get(currentNum)! > k) {
            const leftNum = nums[left];
            
            // Remove leftmost element from window
            frequency.set(leftNum, frequency.get(leftNum)! - 1);
            
            // Clean up map if frequency becomes 0
            if (frequency.get(leftNum) === 0) {
                frequency.delete(leftNum);
            }
            
            left++; // Move left pointer
        }
        
        // Current window [left, right] is valid
        // Update maximum length
        const currentLength = right - left + 1;
        maxLength = Math.max(maxLength, currentLength);
    }
    
    return maxLength;
};

```

## Solution 3: Optimized with Early Cleanup

```typescript
function maxSubarrayLength(nums: number[], k: number): number {
    const freq = new Map<number, number>();
    let left = 0;
    let maxLen = 0;
    
    for (let right = 0; right < nums.length; right++) {
        // Increment frequency
        freq.set(nums[right], (freq.get(nums[right]) || 0) + 1);
        
        // If current element exceeds k, shrink window
        if (freq.get(nums[right])! > k) {
            // Shrink until nums[right] frequency becomes k
            while (freq.get(nums[right])! > k) {
                freq.set(nums[left], freq.get(nums[left])! - 1);
                left++;
            }
        }
        
        maxLen = Math.max(maxLen, right - left + 1);
    }
    
    return maxLen;
};

```

# Key Insights

- **Sliding window:** Expand right, shrink left when invalid
- **Frequency tracking:** Map to count occurrences
- **Two pointers:** Left and right define current window
- **Greedy approach:** Always try to maximize window size
- **Linear time:** Each element processed at most twice

---

# Why Sliding Window Works

**Properties:**
1. **Monotonicity:** If window [i, j] is invalid, [i, j+1] won't be valid either (without shrinking)
2. **Optimal substructure:** Longest valid window ending at j can be found by extending from j-1
3. **No backtracking needed:** Once left pointer moves, it never goes back

# Common Mistakes to Avoid

1. **Not shrinking enough:**
   ```typescript
   // Wrong: only shrink once
   if (freq.get(nums[right]) > k) {
       freq.set(nums[left], freq.get(nums[left]) - 1);
       left++;
   }
   
   // Correct: shrink until valid
   while (freq.get(nums[right]) > k) {
       freq.set(nums[left], freq.get(nums[left]) - 1);
       left++;
   }
   ```

2. **Updating maxLength before validation:**
   ```typescript
   // Wrong: update before checking validity
   maxLength = Math.max(maxLength, right - left + 1);
   while (freq.get(nums[right]) > k) { ... }
   
   // Correct: update after ensuring validity
   while (freq.get(nums[right]) > k) { ... }
   maxLength = Math.max(maxLength, right - left + 1);
   ```

3. **Not handling frequency cleanup:**
   ```typescript
   // Wrong: leaving 0 frequencies in map
   freq.set(nums[left], freq.get(nums[left]) - 1);
   
   // Better: clean up (optional but cleaner)
   freq.set(nums[left], freq.get(nums[left]) - 1);
   if (freq.get(nums[left]) === 0) {
       freq.delete(nums[left]);
   }
   ```

4. **Using nested loops incorrectly:**
   ```typescript
   // Wrong: O(n²) approach
   for (let i = 0; i < n; i++) {
       for (let j = i; j < n; j++) {
           // check subarray [i,j]
       }
   }
   
   // Correct: O(n) sliding window
   while (right < n) {
       // expand and shrink as needed
   }
   ```

# Performance Analysis

For n = 100,000:

| Operation | Time | Notes |
|-----------|------|-------|
| Expand right | $O(n)$ | Visit each element once |
| Shrink left | $O(n)$ | Each element removed at most once |
| Frequency ops | $O(1)$ | Map get/set |
| **Total** | **$O(n)$** | **Linear time** |

**Space:** O(min(n, unique elements))

---

# Comparison with Other Approaches

| Approach | Time | Space | Notes |
|----------|------|-------|-------|
| Brute force | $O(n²)$ | $O(n)$ | Check all subarrays |
| Sliding window | $O(n)$ | $O(n)$ | Optimal |
| Binary search + check | $O(n log n)$ | $O(n)$ | Overcomplicated |
