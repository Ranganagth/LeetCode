# Intuition

We simply need to check consecutive **multiples of k** (k, 2k, 3k, ...) and return the first one that's **not present** in the array.

---

# Approach

1. Convert `nums` to a `Set` for O(1) lookup
2. Start checking from `k`, `2k`, `3k`, ... 
3. Return the first multiple not found in the set

---

# Complexity

**Time Complexity:** $O(n + maxVal/k)$ - building the set plus checking multiples until we find a missing one

**Space Complexity:** $O(n)$ for the set

---

# Code

```typescript
function missingMultiple(nums: number[], k: number): number {
    const numSet = new Set(nums);
    
    let multiple = k;
    while (numSet.has(multiple)) {
        multiple += k;
    }
    
    return multiple;
};

```

# Example Walkthrough

## Example 1: `nums = [8,2,3,4,6], k = 2`

```
numSet = {8,2,3,4,6}

multiple=2: in set? Yes
multiple=4: in set? Yes
multiple=6: in set? Yes
multiple=8: in set? Yes
multiple=10: in set? No → return 10
```

**Output:** `10` ✓

---

```
numSet = {1,4,7,10,15}

multiple=5: in set? No → return 5
```

**Output:** `5` ✓
