# Intuition

We want to select the **maximum number of non-overlapping palindromic substrings**, each of length at least `k`. This is naturally a **dynamic programming** problem: process the string left to right, and at each position decide whether to end a valid palindrome there or simply carry forward the best result so far.

The key insight for efficiency: since `dp[i]` (best count using the first `i` characters) is **non-decreasing** as `i` increases, whenever multiple valid palindrome start positions exist for the same end position, we should always prefer the **latest possible start** (i.e., the shortest valid palindrome length), because that guarantees the largest possible `dp[j]` value to build upon.

---

# Approach

## 1. Precompute palindrome table

Build a 2D boolean table `isPal[i][j]` indicating whether `s[i..j]` is a palindrome, using the standard DP recurrence:

```text
isPal[i][j] = (s[i] == s[j]) && (j - i < 2 || isPal[i+1][j-1])
```

This is computed by increasing substring length, in `O(n²)` time and space.

## 2. Define the DP over prefixes

Let `dp[i]` represent the maximum number of valid substrings selectable using the first `i` characters of `s` (i.e., prefix `s[0..i-1]`).

- Base case: `dp[0] = 0`.
- Transition for each `i` from `1` to `n`:
  - Default: `dp[i] = dp[i-1]` (skip character at index `i-1`, don't end a substring here).
  - Try to end a palindrome exactly at index `i-1`: search for the **largest** `j` (i.e., shortest valid palindrome, length `≥ k`) such that `s[j..i-1]` is a palindrome and `i - j >= k`.
    - If found, update: `dp[i] = max(dp[i], dp[j] + 1)`.
    - Since we search `j` from `i-k` down to `0`, the **first match found** already gives the largest valid `j`, so we can `break` immediately — no need to check smaller `j` values, since `dp` is non-decreasing.

## 3. Final answer

Return `dp[n]`.

---

# Complexity

- **Time complexity:** 
$$O(n^2)$$
Building the palindrome table takes `O(n²)`, and the DP transition (with early break) also runs in `O(n²)` in the worst case.

- **Space complexity:** 
$$O(n^2)$$
For storing the palindrome table (feasible since `n ≤ 2000`, giving at most `4 × 10⁶` boolean entries).

# Code

```typescript
function maxPalindromes(s: string, k: number): number {
    const n = s.length;

    // isPal[i][j] = true if s[i..j] is a palindrome.
    const isPal: boolean[][] = Array.from({ length: n }, () => new Array(n).fill(false));

    for (let i = 0; i < n; i++) {
        isPal[i][i] = true;
    }
    for (let i = 0; i < n - 1; i++) {
        isPal[i][i + 1] = (s[i] === s[i + 1]);
    }

    for (let len = 3; len <= n; len++) {
        for (let i = 0; i + len - 1 < n; i++) {
            const j = i + len - 1;
            isPal[i][j] = (s[i] === s[j]) && isPal[i + 1][j - 1];
        }
    }

    // dp[i] = max substrings selectable using prefix s[0..i-1]
    const dp = new Array<number>(n + 1).fill(0);

    for (let i = 1; i <= n; i++) {
        dp[i] = dp[i - 1];

        for (let j = i - k; j >= 0; j--) {
            if (isPal[j][i - 1]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
                break; // largest valid j found; dp is non-decreasing, so this is optimal
            }
        }
    }

    return dp[n];
};

```

# Example Walkthrough

## Example 1

```text
s = "abaccdbbd", k = 3
```

- `isPal` table identifies palindromes like `"aba"` (indices 0-2) and `"dbbd"` (indices 5-8).
- Processing `dp`:
  - At `i = 3` (end of `"aba"`): `isPal[0][2] = true`, length `3 >= k` → `dp[3] = max(dp[2], dp[0]+1) = 1`
  - `dp` carries forward `1` until we reach `i = 9` (end of `"dbbd"`): `isPal[5][8] = true`, length `4 >= k` → `dp[9] = max(dp[8], dp[5]+1)`. Since `dp[5] = 1` (from `"aba"`), `dp[9] = 2`.

Output: `2`

## Example 2

```text
s = "adbcda", k = 2
```

No palindromic substring of length `≥ 2` exists (checking all pairs/triples confirms this), so no valid transition ever updates `dp` beyond `0`.

Output: `0`
