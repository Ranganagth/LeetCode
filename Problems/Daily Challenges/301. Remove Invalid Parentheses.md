# Intuition

To remove the **minimum** number of invalid parentheses, we can think of this as a **shortest path / BFS** problem: starting from the original string, each "move" removes exactly one character. We want to find the **first level** (fewest removals) at which **valid** parentheses strings appear — and collect **all** such valid strings found at that level, since BFS guarantees we explore strings level-by-level in order of increasing removals.

By processing level by level and stopping as soon as we find valid results, we guarantee minimality. Using a `visited` set prevents revisiting the same string multiple times (since many different removal sequences can produce identical substrings), keeping the search efficient.

---

# Approach

1. **Validity Check Helper** (`isValid`): Scan the string left to right, tracking a running `count` of unmatched `'('`. Increment on `'('`, decrement on `')'`. If `count` ever goes negative, the string is invalid at that point. At the end, valid only if `count === 0`.

2. **BFS Setup**:
   - Initialize a `queue` with the original string `s`.
   - Use a `visited` Set to avoid processing duplicate strings.
   - Maintain a `result` array to collect valid strings, and a `found` flag to mark once we've discovered the first level containing valid results.

3. **BFS Traversal**:
   - Dequeue the current string.
   - If it's valid, add it to `result` and set `found = true`.
   - **Important optimization**: if `found` is already `true`, skip generating further children from this string — we don't want to go to the *next* level (more removals) once we've already found valid results at the current level, since those would require unnecessary extra removals.
   - Otherwise, generate all possible "children" by removing **one character at a time** (only `'('` or `')'` characters — removing a letter would never help since letters are always valid).
   - Add any unvisited child to the queue and mark it visited.

4. **Final Return**:
   - If any valid strings were found, return `result`.
   - Otherwise (edge case, shouldn't typically happen since an empty string is always valid), return `[""]`.

This approach ensures we explore strings in increasing order of removals (breadth-first), so the **first level** where valid strings are found is guaranteed to have the **minimum number of removals**, and we collect **all distinct valid results** at that exact level.

---

# Complexity

- **Time complexity:**
$$O(2^n \cdot n)$$
In the worst case, BFS may generate an exponential number of substrings (each character either kept or removed), and validity checking plus string slicing takes `O(n)` per generated string. In practice, pruning via `visited` and early stopping once `found` significantly reduces actual work for typical inputs.

- **Space complexity:**
$$O(2^n \cdot n)$$
For storing visited strings and the BFS queue, each of length up to `n`.

# Code

```typescript
function removeInvalidParentheses(s: string): string[] {
    const isValid = (str: string): boolean => {
        let count = 0;
        for (const ch of str) {
            if (ch === '(') count++;
            else if (ch === ')') {
                count--;
                if (count < 0) return false;
            }
        }
        return count === 0;
    };

    const result: string[] = [];
    const visited = new Set<string>();
    const queue: string[] = [s];
    let found = false;

    while (queue.length > 0) {
        const current = queue.shift()!;
        if (isValid(current)) {
            result.push(current);
            found = true;
        }

        if (found) continue;

        for (let i = 0; i < current.length; i++) {
            if (current[i] !== '(' && current[i] !== ')') continue;

            const next = current.slice(0, i) + current.slice(i + 1);
            if (!visited.has(next)) {
                visited.add(next);
                queue.push(next);
            }
        }
    }

    return result.length > 0 ? result : [""];
};

```

- **Level 1** (5 chars, one removed): none of these are valid (still unbalanced).
