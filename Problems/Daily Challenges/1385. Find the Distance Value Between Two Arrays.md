# Intuition

For each element in `arr1`, we need to check whether **every** element in `arr2` is "too far away" (i.e., the absolute difference exceeds `d`). If no element in `arr2` falls within the allowed distance `d`, that element in `arr1` contributes to our answer.

Given the small constraints (`arr1.length, arr2.length <= 500`), a straightforward **brute-force comparison** is efficient enough.

---

# Approach

1. Iterate through each element `a` in `arr1`.
2. For each `a`, check every element `b` in `arr2`:
   - If `|a - b| <= d` for any `b`, this element `a` does **not** qualify — skip it.
3. If no such `b` exists (the element survives all checks), increment the result counter.
4. Return the final count.

---

# Complexity

- **Time complexity:** $O(n * m)$, where `n = arr1.length` and `m = arr2.length`. Given the constraints (`≤ 500` each), this is at most `250,000` operations — well within limits.
- **Space complexity:** $O(1)$, only a few scalar variables are used.

---

# Code

```typescript
function findTheDistanceValue(arr1: number[], arr2: number[], d: number): number {
    let count = 0;

    for (const a of arr1) {
        let isValid = true;

        for (const b of arr2) {
            if (Math.abs(a - b) <= d) {
                isValid = false;
                break;
            }
        }

        if (isValid) {
            count++;
        }
    }

    return count;
};

```

# Example Walkthrough

## Example 1

```text
arr1 = [4, 5, 8], arr2 = [10, 9, 1, 8], d = 2
```

- `a = 4`: differences with `arr2` are `6, 5, 3, 4` — all `> 2` → **valid**, count = `1`
- `a = 5`: differences are `5, 4, 4, 3` — all `> 2` → **valid**, count = `2`
- `a = 8`: differences are `2, 1, 7, 0` — `2 <= 2` found → **invalid**, skip

Output: `2`

## Example 2

```text
arr1 = [1, 4, 2, 3], arr2 = [-4, -3, 6, 10, 20, 30], d = 3
```

- `a = 1`: closest in `arr2` is `-3` (diff `4`) or `6` (diff `5`) — all `> 3` → **valid**
- `a = 4`: closest is `6` (diff `2`) → `<= 3` → **invalid**
- `a = 2`: closest is `-3` (diff `5`) or `6` (diff `4`) — all `> 3` → **valid**
- `a = 3`: closest is `6` (diff `3`) → `<= 3` → **invalid**

Valid elements: `1, 2` → count = `2`

Output: `2`

## Example 3

```text
arr1 = [2, 1, 100, 3], arr2 = [-5, -2, 10, -3, 7], d = 6
```

- `a = 2`: closest is `-2` (diff `4`) → `<= 6` → **invalid**
- `a = 1`: closest is `-2` (diff `3`) → `<= 6` → **invalid**
- `a = 100`: closest is `10` (diff `90`), `7` (diff `93`) — all `> 6` → **valid**
- `a = 3`: closest is `-2` (diff `5`) → `<= 6` → **invalid**

Valid elements: `100` → count = `1`

Output: `1`
