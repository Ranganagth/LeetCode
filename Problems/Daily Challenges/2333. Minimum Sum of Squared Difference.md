# Intuition

Since every unit of modification (whether applied to `nums1` or `nums2`) reduces the **absolute difference** `|nums1[i] - nums2[i]|` by exactly `1` (and both budgets `k1` and `k2` serve this same purpose), we can **combine them into a single pool** `k = k1 + k2` of "reduction operations" applied directly to the difference array.

To minimize the **sum of squares**, convexity tells us it's always best to **reduce the largest differences first** (reducing a large value by 1 decreases its square more than reducing a smaller value by 1). This leads to a classic **"water-filling" / greedy capping** strategy: find a threshold `V` such that capping all differences above `V` down to `V` uses as many operations as possible without exceeding `k`, then use any leftover operations to reduce some of the capped values by one more.

We can find this threshold efficiently via **binary search**.

---

# Approach

1. Compute the absolute difference array: `diffs[i] = |nums1[i] - nums2[i]|`.
2. Combine budgets: `k = k1 + k2`.
3. If `sum(diffs) <= k`, we can zero out everything — return `0`.
4. **Binary search** for the smallest value `V` such that:
   ```text
   cost(V) = sum(max(0, d - V) for d in diffs) <= k
   ```
   This `V` represents capping all differences greater than `V` down to `V`, using `cost(V)` operations.
5. Compute `remaining = k - cost(V)` — leftover operations after capping.
6. Apply the cap: `capped[i] = min(diffs[i], V)`.
7. Use the `remaining` operations to reduce `remaining` of the elements that equal `V` down to `V - 1` (since these are now the largest remaining values, further reduction here is optimal).
8. Return the sum of squares of the final `capped` array.

---

# Complexity

- **Time complexity:**
$$O(n \log(\max(diffs)))$$
Binary search runs `O(log(maxDiff))` iterations, each evaluating `cost(V)` in `O(n)`.

- **Space complexity:** 
$$O(n)$$
For storing the `diffs` and `capped` arrays.

# Code

```typescript
function minSumSquareDiff(nums1: number[], nums2: number[], k1: number, k2: number): number {
    const n = nums1.length;
    const diffs = new Array<number>(n);
    let total = 0;

    for (let i = 0; i < n; i++) {
        diffs[i] = Math.abs(nums1[i] - nums2[i]);
        total += diffs[i];
    }

    const k = k1 + k2;

    if (total <= k) {
        return 0;
    }

    let maxD = 0;
    for (const d of diffs) maxD = Math.max(maxD, d);

    const cost = (V: number): number => {
        let sum = 0;
        for (const d of diffs) {
            if (d > V) sum += d - V;
        }
        return sum;
    };

    let lo = 0;
    let hi = maxD;

    while (lo < hi) {
        const mid = Math.floor((lo + hi) / 2);
        if (cost(mid) <= k) {
            hi = mid;
        } else {
            lo = mid + 1;
        }
    }

    const V = lo;
    const used = cost(V);
    let remaining = k - used;

    const capped = new Array<number>(n);
    for (let i = 0; i < n; i++) {
        capped[i] = Math.min(diffs[i], V);
    }

    for (let i = 0; i < n && remaining > 0; i++) {
        if (capped[i] === V && V > 0) {
            capped[i] -= 1;
            remaining--;
        }
    }

    let result = 0;
    for (const v of capped) {
        result += v * v;
    }

    return result;
};

```

# Example Walkthrough

## Example 1

```text
nums1 = [1,4,10,12], nums2 = [5,8,6,9], k1 = 1, k2 = 1
```

- `diffs = [4, 4, 4, 3]`, `k = 2`
- `total = 15 > 2`, proceed.
- `maxD = 4`

**Binary search for minimal `V` with `cost(V) <= 2`:**
- `mid=2`: `cost(2) = 2+2+2+1 = 7 > 2` → `lo=3`
- `mid=3`: `cost(3) = 1+1+1+0 = 3 > 2` → `lo=4`
- `lo=hi=4` → `V=4`

- `used = cost(4) = 0`
- `remaining = 2 - 0 = 2`
- `capped = [4,4,4,3]` (capping at 4 changes nothing since max is already 4)

**Apply remaining reductions** to elements equal to `V=4`:
- `capped[0]=4→3` (remaining=1)
- `capped[1]=4→3` (remaining=0)

Final `capped = [3,3,4,3]`

```text
sum = 9 + 9 + 16 + 9 = 43
```

Output: `43`

## Example 1

```text
nums1 = [1,2,3,4], nums2 = [2,10,20,19], k1 = 0, k2 = 0
```

- `diffs = [1,8,17,15]`, `k = 0`
- `total = 41 > 0`, proceed.
- `maxD = 17`

**Binary search for minimal `V` with `cost(V) <= 0`:** Since `k=0`, no reduction is allowed, so `V` must equal `maxD = 17` (capping at max means `cost=0`).

- `used = 0`, `remaining = 0`
- `capped = [1,8,17,15]` (unchanged, since `V=17` equals the max)

sum = 1 + 64 + 289 + 225 = 579
