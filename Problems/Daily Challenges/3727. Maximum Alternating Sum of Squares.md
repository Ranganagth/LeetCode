# Intuition

Since we can **freely rearrange** the array, the alternating score simplifies to: choose which elements go into the "positive" (even-indexed) group and which go into the "negative" (odd-indexed) group, then compute `sum(positive²) - sum(negative²)`. The positions themselves don't matter beyond **how many** elements fall into each group — there must be `⌈n/2⌉` positive-group elements and `⌊n/2⌋` negative-group elements.

Since squaring removes sign information, what matters is each element's **absolute value**. To maximize the final score, we want the **largest absolute values** contributing positively (adding to the sum) and the **smallest absolute values** being forced into the negative group (subtracting the least possible amount).

---

# Approach

1. Compute `n = nums.length`.
2. Create an array of **absolute values** and **sort it in descending order**.
3. The first `⌈n/2⌉` elements (largest absolute values) go into the **positive group** — add their squares to the result.
4. The remaining `⌊n/2⌋` elements (smallest absolute values) go into the **negative group** — subtract their squares from the result.
5. Return the final computed score.

This greedy approach works because:
- Squaring is a monotonic function of absolute value, so larger `|x|` always contributes a larger square.
- To maximize `sum(positive²) - sum(negative²)`, we want the positive group to contain the overall largest magnitudes (maximizing the added term) and the negative group to contain the overall smallest magnitudes (minimizing the subtracted term) — this is achieved exactly by sorting all absolute values descending and splitting at the `⌈n/2⌉` boundary.

---

# Complexity

- **Time complexity:** 
$$O(n \log n)$$
Dominated by the sorting step.

- **Space complexity:** 
$$O(n)$$
For storing the array of absolute values (can be reduced to `O(1)` extra space if sorting in place, aside from input copy).

---

# Code

```typescript
function maxAlternatingSum(nums: number[]): number {
    const n = nums.length;
    const absVals = nums.map(x => Math.abs(x));
    absVals.sort((a, b) => b - a);

    const posCount = Math.ceil(n / 2);

    let score = 0;

    for (let i = 0; i < n; i++) {
        const sq = absVals[i] * absVals[i];
        if (i < posCount) {
            score += sq;
        } else {
            score -= sq;
        }
    }

    return score;
};

```

# Example Walkthrough

## Example 1

```text
nums = [1, 2, 3]
```

- `absVals sorted descending = [3, 2, 1]`
- `n = 3`, `posCount = ceil(3/2) = 2`

- i=0 (3): positive group → `+9`
- i=1 (2): positive group → `+4`
- i=2 (1): negative group → `-1`

```text
score = 9 + 4 - 1 = 12
```

Output: `12`

## Example 2

```text
nums = [1, -1, 2, -2, 3, -3]
```

- `absVals = [1,1,2,2,3,3]`, sorted descending = `[3,3,2,2,1,1]`
- `n = 6`, `posCount = ceil(6/2) = 3`

- i=0 (3): positive → `+9`
- i=1 (3): positive → `+9`
- i=2 (2): positive → `+4`
- i=3 (2): negative → `-4`
- i=4 (1): negative → `-1`
- i=5 (1): negative → `-1`

```text
score = 9+9+4-4-1-1 = 16
```

Output: `16`
