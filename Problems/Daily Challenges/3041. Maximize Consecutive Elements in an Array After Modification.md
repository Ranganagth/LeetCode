## Intuition

Each number `x` has only two possible final values:

```text
x // do not increase
x + 1 // increase by 1
```

After sorting `nums`, we want to build the longest sequence of consecutive values:

```text
..., v - 1, v, v + 1, ...
```

Maintain:

```text
dp[value] = maximum number of selected elements forming
            a consecutive sequence that ends at `value`
```

For each original number `x`, there are two choices:

1. Keep it as `x` 
   It can extend a sequence ending at `x - 1`.

   ```text
   dp[x] = dp[x - 1] + 1
   ```

2. Increase it to `x + 1` 
   It can extend a sequence ending at `x`.

   ```text
   dp[x + 1] = dp[x] + 1
   ```

Sorting ensures we process smaller values first, so any sequence we extend uses distinct valid elements.

---

## Approach

1. Sort `nums`.
2. Use a map where `dp.get(v)` represents the maximum length of a valid consecutive sequence ending at value `v`.
3. For every number `x`:
   - Compute the result if we keep it as `x`.
   - Compute the result if we increase it to `x + 1`.
   - Update both possible ending values.
4. Track the largest value in the DP map.

> ⚠️ Compute the transition for `x + 1` before updating `dp[x]` with the current element. Otherwise, the same element could accidentally be counted twice.

---

# Complexity

- **Time:** $O(n log n)$
  - Sorting costs `O(n log n)`.
  - Each DP update costs `O(1)` on average.

- **Space:** $O(n)$
  - The map can store up to roughly `2n` distinct values.

---

# Code

```typescript
function maxSelectedElements(nums: number[]): number {
    nums.sort((a, b) => a - b);

    /*
      dp[value] = longest consecutive sequence that ends at `value`.
    */
    const dp = new Map<number, number>();

    let answer = 0;

    for (const value of nums) {
        /*
          Save transitions before updating the map.

          Option 1: Increase value -> value + 1.
          It extends a sequence ending at value.
        */
        const makeValuePlusOne = (dp.get(value) ?? 0) + 1;

        /*
          Option 2: Keep value unchanged.
          It extends a sequence ending at value - 1.
        */
        const keepValue = (dp.get(value - 1) ?? 0) + 1;

        // Use this element as value + 1.
        dp.set(
            value + 1,
            Math.max(dp.get(value + 1) ?? 0, makeValuePlusOne)
        );

        // Use this element as value.
        dp.set(
            value,
            Math.max(dp.get(value) ?? 0, keepValue)
        );

        answer = Math.max(
            answer,
            dp.get(value)!,
            dp.get(value + 1)!
        );
    }

    return answer;
};

```

# Example Walkthrough

## Example 1

```text
nums = [2, 1, 5, 1, 1]
```

After sorting:

```text
nums = [1, 1, 1, 2, 5]
```

Initially:

```text
dp = {}
```

| Current value | Keep as | Increase to | Important DP states |
|---:|---:|---:|---|
| `1` | `1` → length `1` | `2` → length `1` | `dp[1] = 1`, `dp[2] = 1` |
| `1` | `1` → length `1` | `2` → extends `1`, length `2` | `dp[1] = 1`, `dp[2] = 2` |
| `1` | `1` → length `1` | `2` → length `2` | `dp[1] = 1`, `dp[2] = 2` |
| `2` | `2` → extends `1`, length `2` | `3` → extends `2`, length `3` | `dp[3] = 3` |
| `5` | `5` → length `1` | `6` → length `1` | unchanged best = `3` |

The best chain is:

```text
1, 2, 3
```

We can obtain it by using:

```text
1 -> 1
1 + 1 -> 2
2 + 1 -> 3
```

Output:

```text
3
```

## Example 2

```text
nums = [1, 4, 7, 10]
```

Even after increasing each number by at most `1`, the possible values are:

```text
1 or 2
4 or 5
7 or 8
10 or 11
```

No two selected values can form a longer consecutive chain.

Output:

```text
1
```
