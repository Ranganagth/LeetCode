# Intuition

To simulate this system efficiently, we need two capabilities:

1. **Quickly free up servers** whose jobs have finished by the time a new request arrives — this is naturally handled with a **min-heap** ordered by end time.
2. **Quickly find the next available server** starting from `i % k`, wrapping around if needed — this requires efficiently querying "the smallest available server index in a range." A **segment tree** storing counts of available servers supports this in `O(log k)`.

With `n, k ≤ 10^5`, a naive linear scan for each request (`O(k)` per request) could be `O(n·k)` in the worst case — too slow. Using a segment tree for range queries and a heap for expiration tracking brings the total complexity down to `O((n + k) log k)`.

---

# Approach

1. **Segment Tree** over servers `0` to `k-1`:
   - Each leaf stores `1` if the server is available, `0` if busy.
   - Internal nodes store the **count** of available servers in their range.
   - `queryFirst(l, r)`: returns the smallest available server index in `[l, r]`, or `-1` if none exists.
   - `update(idx, value)`: marks a server as available (`1`) or busy (`0`).

2. **Min-Heap** of busy servers, ordered by `endTime = arrival[i] + load[i]`.

3. **Processing each request `i`:**
   - **Free expired servers:** Pop all entries from the heap whose `endTime <= arrival[i]`, and mark those servers as available in the segment tree.
   - **Find a server:**
     - First try `queryFirst(i % k, k - 1)` (look from `i % k` to the end).
     - If none found, wrap around: `queryFirst(0, (i % k) - 1)`.
     - If still none found, **drop the request**.
   - **Assign the request:** Mark the chosen server busy, increment its request count, and push `(endTime, serverId)` onto the heap.

4. After processing all requests, find the **maximum count** among all servers, and collect every server ID achieving that maximum.

---

# Complexity

- **Time complexity:** $O((n + k) log k)$
  - Each segment tree update/query is `O(log k)`.
  - Each heap push/pop is `O(log n)`.
  - We process `n` requests and perform at most `k` initial updates.

- **Space complexity:** $O(k + n)$
  - `O(k)` for the segment tree and counts array.
  - `O(n)` for the heap (worst case, all servers busy simultaneously).

# Code

```typescript
function busiestServers(k: number, arrival: number[], load: number[]): number[] {
    const n = arrival.length;

    // Segment tree storing count of available servers in each range.
    const treeSize = 4 * k;
    const tree = new Int32Array(treeSize);

    const update = (node: number, start: number, end: number, idx: number, val: number): void => {
        if (start === end) {
            tree[node] = val;
            return;
        }

        const mid = (start + end) >> 1;

        if (idx <= mid) {
            update(2 * node, start, mid, idx, val);
        } else {
            update(2 * node + 1, mid + 1, end, idx, val);
        }

        tree[node] = tree[2 * node] + tree[2 * node + 1];
    };

    const queryFirst = (node: number, start: number, end: number, l: number, r: number): number => {
        if (r < start || end < l || tree[node] === 0) {
            return -1;
        }

        if (start === end) {
            return start;
        }

        const mid = (start + end) >> 1;
        const left = queryFirst(2 * node, start, mid, l, r);

        if (left !== -1) {
            return left;
        }

        return queryFirst(2 * node + 1, mid + 1, end, l, r);
    };

    // Initialize all servers as available.
    for (let i = 0; i < k; i++) {
        update(1, 0, k - 1, i, 1);
    }

    const findFirst = (l: number, r: number): number => {
        if (l > r) return -1;
        return queryFirst(1, 0, k - 1, l, r);
    };

    const setAvailable = (idx: number, val: number): void => {
        update(1, 0, k - 1, idx, val);
    };

    // Min-heap of [endTime, serverId], ordered by endTime.
    class MinHeap {
        private data: [number, number][] = [];

        size(): number {
            return this.data.length;
        }

        top(): [number, number] {
            return this.data[0];
        }

        push(item: [number, number]): void {
            this.data.push(item);
            let i = this.data.length - 1;

            while (i > 0) {
                const parent = (i - 1) >> 1;
                if (this.data[parent][0] <= this.data[i][0]) break;
                [this.data[parent], this.data[i]] = [this.data[i], this.data[parent]];
                i = parent;
            }
        }

        pop(): [number, number] {
            const top = this.data[0];
            const last = this.data.pop()!;

            if (this.data.length > 0) {
                this.data[0] = last;
                let i = 0;

                while (true) {
                    let smallest = i;
                    const left = 2 * i + 1;
                    const right = 2 * i + 2;

                    if (left < this.data.length && this.data[left][0] < this.data[smallest][0]) {
                        smallest = left;
                    }
                    if (right < this.data.length && this.data[right][0] < this.data[smallest][0]) {
                        smallest = right;
                    }
                    if (smallest === i) break;

                    [this.data[i], this.data[smallest]] = [this.data[smallest], this.data[i]];
                    i = smallest;
                }
            }

            return top;
        }
    }

    const busyHeap = new MinHeap();
    const counts = new Array<number>(k).fill(0);

    for (let i = 0; i < n; i++) {
        const currentArrival = arrival[i];

        // Free up servers that have finished before this request arrives.
        while (busyHeap.size() > 0 && busyHeap.top()[0] <= currentArrival) {
            const [, serverId] = busyHeap.pop();
            setAvailable(serverId, 1);
        }

        const start = i % k;
        let serverId = findFirst(start, k - 1);

        if (serverId === -1) {
            serverId = findFirst(0, start - 1);
        }

        if (serverId === -1) {
            // All servers are busy; drop this request.
            continue;
        }

        setAvailable(serverId, 0);
        counts[serverId]++;
        busyHeap.push([currentArrival + load[i], serverId]);
    }

    const maxCount = Math.max(...counts);
    const result: number[] = [];

    for (let i = 0; i < k; i++) {
        if (counts[i] === maxCount) {
            result.push(i);
        }
    }

    return result;
};

```

# Example Walkthrough

## Example 1

```text
k = 3, arrival = [1, 2, 3, 4, 5], load = [5, 2, 3, 3, 3]
```

**Request 0** (`arrival=1`): no busy servers to free. `start = 0 % 3 = 0`. Server `0` available → assign. `endTime = 1+5=6`. `counts = [1,0,0]`.

**Request 1** (`arrival=2`): nothing to free (`6 > 2`). `start = 1`. Server `1` available → assign. `endTime = 2+2=4`. `counts = [1,1,0]`.

**Request 2** (`arrival=3`): nothing to free. `start = 2`. Server `2` available → assign. `endTime = 3+3=6`. `counts = [1,1,1]`.

**Request 3** (`arrival=4`): free server `1` (`endTime=4 <= 4`). `start = 3 % 3 = 0`. Server `0` busy (`endTime=6`), search `[0,2]` → none available except after freeing server 1, so available = `{1}`. `findFirst(0,2)` finds server `1` → assign. `endTime = 4+3=7`. `counts = [1,2,1]`.

**Request 4** (`arrival=5`): no servers freed (`6,6,7` all `>5`). All servers busy → **dropped**.

Final counts: `[1, 2, 1]` → max = `2` at server `1`.

Output: `[1]`

## Example 2

```text
k = 3, arrival = [1, 2, 3], load = [10, 12, 11]
```

Each request arrives when all previous servers are still busy with long loads, so each goes to a fresh server:

- Request 0 → server 0
- Request 1 → server 1
- Request 2 → server 2

All counts equal `1` → all tied for busiest.

Output: `[0, 1, 2]`
