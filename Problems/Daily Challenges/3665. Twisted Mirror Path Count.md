# Intuition

At a free cell, the robot has up to two choices:

- Move **right**
- Move **down**

However, the next attempted cell may be a mirror, which can trigger a chain of reflections before the robot finally reaches:

- a free cell,
- or outside the grid.

Instead of simulating mirror chains every time, precompute where each attempted entry ends:

- `rightDest[r][c]`: where the robot ends if it tries to enter `(r, c)` while moving **right**.
- `downDest[r][c]`: where the robot ends if it tries to enter `(r, c)` while moving **down**.

Then use dynamic programming:

```text
dp[r][c] = number of ways to reach free cell (r, c)
```

From every reachable free cell, resolve its right/down move using the precomputed destinations.

---

# Approach

### 1. Precompute reflection destinations

For a **free cell**:

```text
rightDest[r][c] = (r, c)
downDest[r][c] = (r, c)
```

The robot enters and stops there.

For a **mirror cell**:

- Entering from the left means the robot was moving right.
  It turns downward, so its result is the same as entering the cell below it while moving down:

```text
rightDest[r][c] = downDest[r + 1][c]
```

- Entering from above means the robot was moving down.
  It turns right, so its result is the same as entering the cell to its right while moving right:

```text
downDest[r][c] = rightDest[r][c + 1]
```

If the reflection goes outside the grid, the destination is invalid.

Since reflections only move **right or down**, calculate these arrays from **bottom-right to top-left**.

---

### 2. Dynamic Programming

Let:

```text
dp[r][c] = number of valid ways to stand at free cell (r, c)
```

Initialize:

```text
dp[0][0] = 1
```

For every reachable free cell `(r, c)`:

- Attempt right:
  - Resolve the destination using `rightDest[r][c + 1]`.
- Attempt down:
  - Resolve the destination using `downDest[r + 1][c]`.

Add the current number of ways to each valid destination.

---

# Complexity

Let `m` be the number of rows and `n` the number of columns.

- **Time Complexity:** $$O(m × n)$$
- **Space Complexity:** $$O(m × n)$$

Each cell is processed a constant number of times.

---

## TypeScript Code

```typescript
function uniquePaths(grid: number[][]): number {
    const MOD = 1_000_000_007;
    const m = grid.length;
    const n = grid[0].length;
    const total = m * n;

    const id = (r: number, c: number): number => r * n + c;

    /*
      rightDest[cell]:
      destination when attempting to enter this cell while moving right.

      downDest[cell]:
      destination when attempting to enter this cell while moving down.

      Value is a flattened cell index.
      -1 means the reflection chain leaves the grid.
    */
    const rightDest = new Int32Array(total);
    const downDest = new Int32Array(total);

    rightDest.fill(-1);
    downDest.fill(-1);

    // Precompute reflection-chain destinations.
    for (let r = m - 1; r >= 0; r--) {
        for (let c = n - 1; c >= 0; c--) {
            const cur = id(r, c);

            if (grid[r][c] === 0) {
                // A free cell stops movement immediately.
                rightDest[cur] = cur;
                downDest[cur] = cur;
            } else {
                // Entered mirror while moving right -> turn down.
                if (r + 1 < m) {
                    rightDest[cur] = downDest[id(r + 1, c)];
                }

                // Entered mirror while moving down -> turn right.
                if (c + 1 < n) {
                    downDest[cur] = rightDest[id(r, c + 1)];
                }
            }
        }
    }

    // dp[cell] = number of ways to reach this free cell.
    const dp = new Float64Array(total);
    dp[0] = 1;

    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            const cur = id(r, c);

            // Mirrors cannot be stopping positions.
            if (grid[r][c] === 1 || dp[cur] === 0) {
                continue;
            }

            const ways = dp[cur];

            // Attempt to move right.
            if (c + 1 < n) {
                const next = rightDest[id(r, c + 1)];

                if (next !== -1) {
                    dp[next] += ways;
                    if (dp[next] >= MOD) {
                        dp[next] -= MOD;
                    }
                }
            }

            // Attempt to move down.
            if (r + 1 < m) {
                const next = downDest[id(r + 1, c)];

                if (next !== -1) {
                    dp[next] += ways;
                    if (dp[next] >= MOD) {
                        dp[next] -= MOD;
                    }
                }
            }
        }
    }

    return dp[total - 1];
};

```

# Example Walkthrough

## Example 1

```text
grid = [
  [0, 1, 0],
  [0, 0, 1],
  [1, 0, 0]
]
```

At `(0, 0)`, there are two choices:

1. Attempt right into `(0, 1)`, a mirror:
   - Turn down into `(1, 1)`.
2. Move down directly into `(1, 0)`.

From these cells, the robot continues making right/down choices. Some moves enter mirrors and redirect, but all reflection chains are resolved through `rightDest` and `downDest`.

The five valid paths are:

```text
1. (0,0) -> mirror (0,1) -> (1,1) -> mirror (1,2) -> (2,2)
2. (0,0) -> mirror (0,1) -> (1,1) -> (2,1) -> (2,2)
3. (0,0) -> (1,0) -> (1,1) -> mirror (1,2) -> (2,2)
4. (0,0) -> (1,0) -> (1,1) -> (2,1) -> (2,2)
5. (0,0) -> (1,0) -> mirror (2,0) -> (2,1) -> (2,2)
```

Result: `5`

---

## Example 2

```text
grid = [
  [0, 1, 1],
  [1, 1, 0]
]
```

The valid route is:

```text
(0,0)
-> attempt right into mirror (0,1)
-> reflect down into mirror (1,1)
-> reflect right into (1,2)
```

The alternative first move goes down into `(1,0)`, a mirror:

```text
(0,0)
-> mirror (1,0)
-> mirror (1,1)
-> outside the grid
```

So it is invalid.

Result: `1`
