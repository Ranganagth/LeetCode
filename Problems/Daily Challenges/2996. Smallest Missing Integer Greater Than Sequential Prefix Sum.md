# Intuition

We need to:
1. Find the longest **sequential prefix** (consecutive integers starting from `nums[0]`)
2. Calculate the **sum** of this prefix
3. Find the **smallest missing integer** ≥ this sum

**Key insight:** A sequential prefix means each element is exactly 1 more than the previous element.

---

# Approach

1. **Find longest sequential prefix:**
   - Start from `nums[0]`
   - Continue while `nums[i] = nums[i-1] + 1`
   - Calculate sum during this process

2. **Find smallest missing integer:**
   - Starting from the sum, check if each integer exists in `nums`
   - Return the first one that doesn't exist

---

# Complexity

- **Time complexity:** $O(n²)$ in worst case
  - $O(n)$ to find prefix sum
  - $O(n × k)$ to find missing integer, where k is the search range
  - With constraints (n ≤ 50, nums[i] ≤ 50), this is very fast
- **Space complexity:** $O(n)$ for the set

---

# Code

## Solution 1: Using Set (Recommended)

```typescript
function missingInteger(nums: number[]): number {
    // Step 1: Find the longest sequential prefix and its sum
    let sum = nums[0];
    let i = 1;
    
    while (i < nums.length && nums[i] === nums[i - 1] + 1) {
        sum += nums[i];
        i++;
    }
    
    // Step 2: Create a set for O(1) lookup
    const numSet = new Set(nums);
    
    // Step 3: Find the smallest missing integer >= sum
    let result = sum;
    while (numSet.has(result)) {
        result++;
    }
    
    return result;
};

```

## Solution 2: With Detailed Comments

```typescript
function missingInteger(nums: number[]): number {
    // Step 1: Find the longest sequential prefix
    // A sequential prefix means nums[i] = nums[i-1] + 1
    let prefixSum = nums[0];
    let index = 1;
    
    // Continue while elements are consecutive
    while (index < nums.length && nums[index] === nums[index - 1] + 1) {
        prefixSum += nums[index];
        index++;
    }
    
    // Step 2: Convert array to set for fast lookup
    const existingNumbers = new Set(nums);
    
    // Step 3: Find smallest missing integer >= prefixSum
    let candidate = prefixSum;
    
    // Keep incrementing until we find a number not in the array
    while (existingNumbers.has(candidate)) {
        candidate++;
    }
    
    return candidate;
};

```

## Solution 3: Without Set (Using Array Search)

```typescript
function missingInteger(nums: number[]): number {
    // Find sequential prefix sum
    let sum = nums[0];
    
    for (let i = 1; i < nums.length; i++) {
        if (nums[i] === nums[i - 1] + 1) {
            sum += nums[i];
        } else {
            break;
        }
    }
    
    // Find smallest missing integer >= sum
    let result = sum;
    
    while (nums.includes(result)) {
        result++;
    }
    
    return result;
};

```

## Solution 4: Optimized with Early Break

```typescript
function missingInteger(nums: number[]): number {
    // Calculate sequential prefix sum
    let sum = nums[0];
    let i = 1;
    
    while (i < nums.length && nums[i] === nums[i - 1] + 1) {
        sum += nums[i];
        i++;
    }
    
    // Create set for O(1) lookup
    const numSet = new Set(nums);
    
    // Find missing integer
    // With constraints, this loop is bounded
    for (let candidate = sum; candidate <= 2500; candidate++) {
        if (!numSet.has(candidate)) {
            return candidate;
        }
    }
    
    return sum; // Fallback (shouldn't reach here with valid input)
};

```

## Solution 5: One-Pass Approach

```typescript
function missingInteger(nums: number[]): number {
    const n = nums.length;
    
    // Find sequential prefix sum in one pass
    let sum = nums[0];
    let sequentialEnd = 0;
    
    for (let i = 1; i < n; i++) {
        if (nums[i] === nums[i - 1] + 1) {
            sum += nums[i];
            sequentialEnd = i;
        } else {
            break;
        }
    }
    
    // Build set of all numbers
    const numSet = new Set(nums);
    
    // Find smallest missing
    let answer = sum;
    while (numSet.has(answer)) {
        answer++;
    }
    
    return answer;
};

```

# Key Insights

- **Sequential prefix:** Must be consecutive integers (diff = 1)
- **Starts from nums[0]:** Prefix always begins at index 0
- **Sum calculation:** Can be done while finding prefix
- **Set for lookup:** O(1) existence check
- **Small constraints:** Makes brute force viable

# Common Mistakes to Avoid

1. **Wrong sequential check:**
   ```typescript
   // Wrong: checking if sorted
   if (nums[i] > nums[i-1])
   
   // Correct: checking if consecutive
   if (nums[i] === nums[i-1] + 1)
   ```

2. **Not starting from nums[0]:**
   ```typescript
   // Wrong: finding any sequential subsequence
   // Look for longest sequence anywhere
   
   // Correct: must start from index 0
   let sum = nums[0];
   let i = 1;
   while (i < nums.length && nums[i] === nums[i-1] + 1)
   ```

3. **Not using set for lookup:**
   ```typescript
   // Wrong: O(n) lookup each time
   while (nums.includes(result))
   
   // Correct: O(1) lookup with set
   const numSet = new Set(nums);
   while (numSet.has(result))
   ```

4. **Forgetting to include nums[0] in sum:**
   ```typescript
   // Wrong: starting sum at 0
   let sum = 0;
   for (let i = 0; i < n; i++)
   
   // Correct: initialize with nums[0]
   let sum = nums[0];
   for (let i = 1; i < n; i++)
   ```

# Alternative Approaches

**Why not use other methods?**

1. **Sorting:** Not needed, prefix must start at index 0
2. **DP:** Overkill for this simple problem
3. **Binary search:** No sorted property to exploit

**Use Solution 1 (Set-based)** for:

- $O(n)$ space complexity
- Clean and readable
- Efficient lookup
