# Intuition

To guarantee **exactly one** valid path, make only one route free and turn every other cell into an obstacle (`'#'`).

A simple valid route is:

1. Move **right** across the entire first row.
2. Then move **down** the entire last column.

Because all other cells are blocked, there is no opportunity to branch into another path.

---

# Approach

1. Initialize an `m × n` grid filled with `'#'`.
2. Set every cell in the first row to `'.'`.
3. Set every cell in the last column to `'.'`.
4. Convert each row into a string and return the grid.

The unique path is:

```text
(0, 0) → (0, 1) → ... → (0, n - 1)
                         ↓
                      (1, n - 1)
                         ↓
                      ...
                         ↓
                    (m - 1, n - 1)
```

---

# Complexity

- **Time Complexity:** $$O(m × n)$$ to construct the grid.

- **Space Complexity:** $$O(m × n)$$ for the returned grid.

---

# Code

```typescript
function createGrid(m: number, n: number): string[] {
    const grid: string[][] = Array.from(
        { length: m },
        () => new Array<string>(n).fill('#')
    );

    // Move right along the top row.
    for (let col = 0; col < n; col++) {
        grid[0][col] = '.';
    }

    // Move down along the last column.
    for (let row = 0; row < m; row++) {
        grid[row][n - 1] = '.';
    }

    return grid.map(row => row.join(''));
};

```

# Example Walkthrough

## `m = 3`, `n = 3`

Start with every cell blocked:

```text
###
###
###
```

Open the first row:

```text
...
###
###
```

Open the last column:

```text
..#
#.#
#.#
```

Returned grid:

```typescript
["...", "##.", "##."]
```

The only possible path is:

```text
(0,0) → (0,1) → (0,2) → (1,2) → (2,2)
```

There is exactly one valid right/down path.
