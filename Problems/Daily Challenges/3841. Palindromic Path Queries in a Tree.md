# Intuition

A string can be rearranged into a palindrome if **at most one character has an odd frequency**.

Instead of storing character counts, represent each node’s character with a **26-bit mask**:

```text
'a' -> 1 << 0
'b' -> 1 << 1
...
'z' -> 1 << 25
```

If we XOR all masks on a path:

- A bit is `1` if that character appears an **odd** number of times.
- A bit is `0` if it appears an **even** number of times.

Therefore, the path string can form a palindrome exactly when:

```text
mask has at most one set bit
```

We need support:

- **Point update:** change one node's character.
- **Path query:** XOR all masks on a tree path.

Use **Heavy-Light Decomposition (HLD)** to split each tree path into `O(log n)` contiguous ranges, and a **Fenwick Tree** that supports XOR range queries and point updates.

---

# Approach

1. Convert each character into a bitmask.
2. Build a Heavy-Light Decomposition:
   - `parent[node]`
   - `depth[node]`
   - `heavy[node]`: child with the largest subtree
   - `head[node]`: head of its heavy chain
   - `pos[node]`: flattened-array position
3. Store node masks in a Fenwick tree using XOR.
4. For an update:
   - Compute `delta = oldMask XOR newMask`.
   - Apply this delta at the node's flattened position.
5. For a query path `u -> v`:
   - Repeatedly move up the deeper heavy chain.
   - XOR each chain segment.
   - When both nodes are in the same chain, XOR the remaining segment.
6. Check whether the final XOR mask has at most one set bit:

```typescript
(mask & (mask - 1)) === 0
```

---

# Complexity

| Operation | Complexity |
|---|---:|
| Build HLD | `O(n)` |
| Fenwick initialization | `O(n log n)` |
| Update | `O(log n)` |
| Path query | `O(log² n)` |
| Space | `O(n)` |

With $n, queries.length <= 5 * 10^4$, this is efficient.

# Code

```typescript
function palindromePath(
    n: number,
    edges: number[][],
    s: string,
    queries: string[]
): boolean[] {
    const graph: number[][] = Array.from({ length: n }, () => []);

    for (const [u, v] of edges) {
        graph[u].push(v);
        graph[v].push(u);
    }

    // Fenwick Tree for XOR operations.
    class FenwickXor {
        private bit: number[];

        constructor(size: number) {
            this.bit = new Array(size + 1).fill(0);
        }

        update(index: number, value: number): void {
            for (let i = index; i < this.bit.length; i += i & -i) {
                this.bit[i] ^= value;
            }
        }

        prefixXor(index: number): number {
            let result = 0;

            for (let i = index; i > 0; i -= i & -i) {
                result ^= this.bit[i];
            }

            return result;
        }

        rangeXor(left: number, right: number): number {
            return this.prefixXor(right) ^ this.prefixXor(left - 1);
        }
    }

    const charMask = (ch: string): number => {
        return 1 << (ch.charCodeAt(0) - 97);
    };

    const parent = new Array<number>(n).fill(-1);
    const depth = new Array<number>(n).fill(0);
    const size = new Array<number>(n).fill(1);
    const heavy = new Array<number>(n).fill(-1);

    // Iterative DFS to determine parent/depth and traversal order.
    const order: number[] = [];
    const stack: number[] = [0];
    parent[0] = -2;

    while (stack.length > 0) {
        const node = stack.pop()!;
        order.push(node);

        for (const next of graph[node]) {
            if (next === parent[node]) continue;

            parent[next] = node;
            depth[next] = depth[node] + 1;
            stack.push(next);
        }
    }

    parent[0] = -1;

    // Process in reverse order to calculate subtree sizes and heavy children.
    for (let i = order.length - 1; i >= 0; i--) {
        const node = order[i];
        let largestChildSize = 0;

        for (const next of graph[node]) {
            if (next === parent[node]) continue;

            size[node] += size[next];

            if (size[next] > largestChildSize) {
                largestChildSize = size[next];
                heavy[node] = next;
            }
        }
    }

    // Heavy-Light Decomposition positions.
    const head = new Array<number>(n);
    const pos = new Array<number>(n);
    let currentPos = 1;

    // [starting node, chain head]
    const chainStack: [number, number][] = [[0, 0]];

    while (chainStack.length > 0) {
        const [startNode, chainHead] = chainStack.pop()!;

        let node = startNode;

        // Walk through the heavy chain.
        while (node !== -1) {
            head[node] = chainHead;
            pos[node] = currentPos++;

            // Light children begin their own chains.
            for (const next of graph[node]) {
                if (next === parent[node] || next === heavy[node]) continue;
                chainStack.push([next, next]);
            }

            node = heavy[node];
        }
    }

    const values = s.split('').map(charMask);
    const fenwick = new FenwickXor(n);

    for (let node = 0; node < n; node++) {
        fenwick.update(pos[node], values[node]);
    }

    const queryPathXor = (u: number, v: number): number => {
        let result = 0;

        while (head[u] !== head[v]) {
            // Ensure u belongs to the deeper chain.
            if (depth[head[u]] < depth[head[v]]) {
                [u, v] = [v, u];
            }

            result ^= fenwick.rangeXor(pos[head[u]], pos[u]);
            u = parent[head[u]];
        }

        // Both nodes are now in the same chain.
        if (depth[u] > depth[v]) {
            [u, v] = [v, u];
        }

        result ^= fenwick.rangeXor(pos[u], pos[v]);

        return result;
    };

    const answer: boolean[] = [];

    for (const query of queries) {
        const parts = query.split(' ');

        if (parts[0] === 'update') {
            const node = Number(parts[1]);
            const newMask = charMask(parts[2]);

            // XOR-ing old and new values replaces old with new.
            const delta = values[node] ^ newMask;
            fenwick.update(pos[node], delta);
            values[node] = newMask;
        } else {
            const u = Number(parts[1]);
            const v = Number(parts[2]);

            const mask = queryPathXor(u, v);

            // At most one odd-frequency character.
            answer.push((mask & (mask - 1)) === 0);
        }
    }

    return answer;
};

```

# Example Walkthrough

## Example 1:

### Input

```text
n = 3
edges = [[0,1], [1,2]]
s = "aac"

queries = [
  "query 0 2",
  "update 1 b",
  "query 0 2"
]
```

Initial masks:

```text
node 0: 'a' -> 001
node 1: 'a' -> 001
node 2: 'c' -> 100
```

### Query: `query 0 2`

Path characters:

```text
"aac"
```

XOR mask:

```text
001 XOR 001 XOR 100 = 100
```

Only one bit is set (`'c'` has odd frequency), so it can form a palindrome:

```text
"aca"
```

Result: `true`.

### Update: `update 1 b`

Now the path is:

```text
"a" + "b" + "c" = "abc"
```

Masks:

```text
001 XOR 010 XOR 100 = 111
```

Three bits are set, meaning three characters have odd frequency. It cannot form a palindrome.

Result: `false`.

```typescript
[true, false]
```
