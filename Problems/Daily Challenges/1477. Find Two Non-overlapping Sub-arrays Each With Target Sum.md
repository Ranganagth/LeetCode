# Intuition

We need two **non-overlapping** subarrays that each sum to `target`, minimizing the total length. The key idea is a **sliding window** to efficiently find all subarrays with sum equal to `target` (since all elements are positive, sums are monotonic, so a standard two-pointer window works). 

To handle the "non-overlapping" constraint efficiently, we maintain a running array `best[i]` = the length of the **shortest valid subarray found so far**, ending at or before index `i`. Then, whenever we find a new valid subarray ending at index `right` starting at `left`, we can combine it with the best subarray found entirely **before** `left` (i.e., `best[left - 1]`) to get a candidate answer.

---

# Approach

1. Use two pointers `left` and `right` to maintain a sliding window with `windowSum`.
2. Expand `right` one step at a time, adding `arr[right]` to `windowSum`.
3. Shrink from `left` while `windowSum > target` (safe since all values are positive).
4. Maintain an array `best`, where `best[i]` = the minimum length of any valid subarray fully contained within `arr[0..i]`.
   - `best[i] = best[i-1]` by default (carry forward the best found so far).
5. When `windowSum === target`:
   - Current subarray length: `currentLen = right - left + 1`.
   - If there exists a valid subarray ending before `left` (i.e., `best[left - 1]` is finite), update the answer:
     ```text
     ans = min(ans, currentLen + best[left - 1])
     ```
   - Update `best[right] = min(best[right], currentLen)`.
6. After processing the entire array, return `ans` if it was updated (finite), otherwise return `-1`.

This works in a single pass because the window only moves forward, and `best[i]` is built incrementally alongside it.

---

# Complexity

- **Time complexity:** 
$$O(n)$$
Both `left` and `right` pointers each traverse the array at most once (standard two-pointer amortized analysis).

- **Space complexity:** 
$$O(n)$$
For the `best` array tracking minimum subarray lengths up to each index.

---

# Code

```typescript
function minSumOfLengths(arr: number[], target: number): number {
    const n = arr.length;
    const INF = Infinity;

    const best = new Array<number>(n).fill(INF);
    let ans = INF;

    let left = 0;
    let windowSum = 0;

    for (let right = 0; right < n; right++) {
        windowSum += arr[right];

        while (windowSum > target) {
            windowSum -= arr[left];
            left++;
        }

        // Carry forward the best length found so far.
        best[right] = right > 0 ? best[right - 1] : INF;

        if (windowSum === target) {
            const currentLen = right - left + 1;

            if (left > 0 && best[left - 1] !== INF) {
                ans = Math.min(ans, currentLen + best[left - 1]);
            }

            best[right] = Math.min(best[right], currentLen);
        }
    }

    return ans === INF ? -1 : ans;
};

```

# Example Walkthrough

## Example 1

```text
arr = [3, 2, 2, 4, 3], target = 3
```

- `right=0`: window=[3], sum=3 → matches! `currentLen=1`. `left=0` so no prior best. `best[0]=1`.
- `right=1`: window=[3,2], sum=5 > 3 → shrink: remove 3, `left=1`, sum=2. Not equal to target. `best[1]=1`.
- `right=2`: window=[2,2], sum=4 > 3 → shrink: remove arr[1]=2, `left=2`, sum=2. Not equal. `best[2]=1`.
- `right=3`: window=[2,4], sum=6 > 3 → shrink: remove arr[2]=2, `left=3`, sum=4 > 3 → shrink again: remove arr[3]=4, `left=4`, sum=0. Not equal. `best[3]=1`.
- `right=4`: window=[3], sum=3 → matches! `currentLen=1`. `left=4>0`, `best[3]=1` (finite) → `ans = min(inf, 1+1) = 2`. `best[4]=1`.

Output: `2`

## Example 2

```text
arr = [4,3,2,6,2,3,4], target = 6
```

Only one subarray sums to `6`: `[6]` (index 3) or possibly `[4,2]`... let's trust the sliding window finds only one non-overlapping match position, so `ans` never gets updated (`best[left-1]` never available for a second match).

Output: `-1`
