# Intuition

Since the score depends on **nested** structure (doubling for each layer of nesting) and **sequential** structure (simple addition for concatenated parts), a natural fit is a **stack**-based simulation. Each time we open a new "layer" with `'('`, we push a placeholder to accumulate whatever score builds up inside it. When we close that layer with `')'`, we finalize its score - doubling it if it contained something, or treating it as the base case `1` if it was empty (`"()"`) - and add the result to the score of the enclosing layer.

---

# Approach

1. Initialize a **stack** with a single `0` representing the score accumulator at the top level.
2. Iterate through each character in `s`:
   - If `'('`: push a new `0` onto the stack - this starts accumulating the score for the new nested layer.
   - If `')'`: pop the top value `v` (the accumulated score inside this layer):
     - If `v === 0`, this was an empty pair `"()"`, so its score is `1`.
     - Otherwise, this was `(A)` for some non-trivial `A`, so its score is `2 * v`.
     - Add this computed score to the new top of the stack (the enclosing layer's accumulator).
3. After processing the entire string, the remaining single value on the stack is the final answer.

---

# Complexity

- **Time complexity:** 
$$O(n)$$
Single pass through the string, with constant-time stack operations per character.

- **Space complexity:** 
$$O(n)$$
In the worst case (e.g., all `'('` followed by all `')'`), the stack can grow to depth `O(n)`.

---

# Code

```typescript
function scoreOfParentheses(s: string): number {
    const stack: number[] = [0];

    for (const c of s) {
        if (c === '(') {
            stack.push(0);
        } else {
            const v = stack.pop()!;
            const score = v === 0 ? 1 : 2 * v;
            stack[stack.length - 1] += score;
        }
    }

    return stack[0];
};

```


| i | char | action | stack after |
|---|------|--------|-------------|
| - | - | init | [0] |
| 0 | ( | push 0 | [0, 0] |
| 1 | ( | push 0 | [0, 0, 0] |
| 2 | ) | pop 0 → score=1, add to top | [0, 1] |
| 3 | ) | pop 1 → score=2*1=2, add to top | [2] |
