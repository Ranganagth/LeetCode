# Intuition

Since islands are defined by **4-directionally connected positive integers** (with `0` treated as water/empty), we can find each island using a standard **flood fill** (BFS or DFS), summing up the values of all cells belonging to that island. Once we have the island's total sum, we simply check whether it's **divisible by `k`** and increment our counter accordingly.

---

# Approach

1. Create a `visited` matrix (or mark cells as visited by setting them to `0` in place) to avoid reprocessing cells.
2. Iterate over every cell `(i, j)` in the grid.
3. If `grid[i][j] > 0` and not yet visited, this marks the start of a **new island**:
   - Perform a flood fill (BFS/DFS) from `(i, j)`, visiting all 4-directionally connected positive cells.
   - Accumulate the **sum** of all cell values in this island.
   - Mark each visited cell to prevent revisiting.
4. After computing the island's total sum, check if `sum % k === 0`. If so, increment the `count`.
5. Return `count` after processing the entire grid.

---

# Complexity

- **Time complexity:**
$$O(m \cdot n)$$
Each cell is visited and processed exactly once across all flood-fill operations.

- **Space complexity:** 
$$O(m \cdot n)$$
For the BFS queue / DFS stack in the worst case (e.g., the entire grid is one large island).

---

# Code

```typescript
function countIslands(grid: number[][], k: number): number {
    const m = grid.length;
    const n = grid[0].length;
    const visited: boolean[][] = Array.from({ length: m }, () => new Array(n).fill(false));

    let count = 0;

    const bfs = (sr: number, sc: number): number => {
        let sum = 0;
        const queue: [number, number][] = [[sr, sc]];
        visited[sr][sc] = true;

        let head = 0;
        while (head < queue.length) {
            const [r, c] = queue[head++];
            sum += grid[r][c];

            const neighbors = [
                [r - 1, c],
                [r + 1, c],
                [r, c - 1],
                [r, c + 1],
            ];

            for (const [nr, nc] of neighbors) {
                if (
                    nr >= 0 && nr < m &&
                    nc >= 0 && nc < n &&
                    !visited[nr][nc] &&
                    grid[nr][nc] > 0
                ) {
                    visited[nr][nc] = true;
                    queue.push([nr, nc]);
                }
            }
        }

        return sum;
    };

    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            if (grid[i][j] > 0 && !visited[i][j]) {
                const sum = bfs(i, j);
                if (sum % k === 0) {
                    count++;
                }
            }
        }
    }

    return count;
};

```
