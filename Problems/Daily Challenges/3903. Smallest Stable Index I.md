# Intuition

The instability score at each index `i` depends on two independent quantities:

- The **maximum** of all elements to the left of and including `i`
- The **minimum** of all elements to the right of and including `i`

Since these are prefix and suffix aggregations, we can precompute them in a single pass each, then simply scan through all indices to find the first one satisfying the stability condition.

---

# Approach

1. **Precompute prefix maximums:**
   Create an array `prefixMax` where `prefixMax[i] = max(nums[0..i])`.

2. **Precompute suffix minimums:**
   Create an array `suffixMin` where `suffixMin[i] = min(nums[i..n-1])`.

3. **Scan for the first stable index:**
   For each index `i` from `0` to `n-1`, compute:
   ```text
   instability = prefixMax[i] - suffixMin[i]
   ```
   If `instability <= k`, return `i` immediately.

4. If no index satisfies the condition, return `-1`.

---

# Complexity

- **Time complexity:** 
$$O(n)$$
Three linear passes: one for prefix max, one for suffix min, and one for the final scan.

- **Space complexity:** 
$$O(n)$$
For storing the `prefixMax` and `suffixMin` arrays.

---

# Code

```typescript
function firstStableIndex(nums: number[], k: number): number {
    const n = nums.length;

    const prefixMax = new Array<number>(n);
    const suffixMin = new Array<number>(n);

    prefixMax[0] = nums[0];
    for (let i = 1; i < n; i++) {
        prefixMax[i] = Math.max(prefixMax[i - 1], nums[i]);
    }

    suffixMin[n - 1] = nums[n - 1];
    for (let i = n - 2; i >= 0; i--) {
        suffixMin[i] = Math.min(suffixMin[i + 1], nums[i]);
    }

    for (let i = 0; i < n; i++) {
        const instability = prefixMax[i] - suffixMin[i];
        if (instability <= k) {
            return i;
        }
    }

    return -1;
};

```

# Example Walkthrough

## Example 1

```text
nums = [5, 0, 1, 4], k = 3
```

- `prefixMax = [5, 5, 5, 5]`
- `suffixMin = [0, 0, 1, 4]`

Instability scores:
- `i=0`: `5 - 0 = 5` → not stable
- `i=1`: `5 - 0 = 5` → not stable
- `i=2`: `5 - 1 = 4` → not stable
- `i=3`: `5 - 4 = 1` → stable

Output: `3`

## Example 2

```text
nums = [3, 2, 1], k = 1
```

- `prefixMax = [3, 3, 3]`
- `suffixMin = [1, 1, 1]`

Instability scores at all indices: `3 - 1 = 2`, which exceeds `k = 1`.

Output: `-1`

## Example 3

```text
nums = [0], k = 0
```

- `prefixMax = [0]`
- `suffixMin = [0]`

Instability at `i=0`: `0 - 0 = 0 <= 0` → stable

Output: `0`
