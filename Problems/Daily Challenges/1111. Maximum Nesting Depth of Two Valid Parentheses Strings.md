# Intuition

The overall nesting depth of the original valid parentheses string can get quite large. But if we **split the parentheses at alternating depth levels** between the two groups `A` and `B`, we can effectively **halve the maximum depth** each group experiences. Specifically: put all characters at **odd depth levels** into one group, and all characters at **even depth levels** into the other. This way, neither group ever sees more than roughly half the original nesting depth.

---

# Approach

1. Traverse the string, maintaining a running `depth` counter:
   - On encountering `'('`: **increment** `depth` first, then assign this character based on the **new** depth.
   - On encountering `')'`: assign this character based on the **current** depth, then **decrement** `depth`.
2. Assign group membership based on whether the depth (at the time of assignment) is **odd** or **even**:
   - If `depth % 2 === 1` (odd depth) → assign to group `A` (`answer[i] = 0`)
   - If `depth % 2 === 0` (even depth) → assign to group `B` (`answer[i] = 1`)
3. This ensures that matching pairs of parentheses always end up in the **same group** (since a `'('` and its matching `')'` always occur at the same depth level relative to when they're processed), and the depth **within each group** never exceeds `⌈originalDepth / 2⌉`.

This greedy strategy is provably optimal: it's a well-known result that splitting by depth parity minimizes the maximum depth of either subsequence.

---

# Complexity

- **Time complexity:** 
$$O(n)$$
A single pass through the string with constant-time work per character.

- **Space complexity:** 
$$O(n)$$
For the output `answer` array (excluding the space required for the output itself, auxiliary space is `O(1)`).

---

# Code

```typescript
function maxDepthAfterSplit(seq: string): number[] {
    const n = seq.length;
    const answer = new Array<number>(n);

    let depth = 0;

    for (let i = 0; i < n; i++) {
        const c = seq[i];

        if (c === '(') {
            depth++;
            answer[i] = depth % 2 === 1 ? 0 : 1;
        } else {
            answer[i] = depth % 2 === 1 ? 0 : 1;
            depth--;
        }
    }

    return answer;
};

```

# Example Walkthrough

## Example 1

```text
seq = "(()())"
```

| i | char | action | depth (during assignment) | answer[i] |
|---|------|--------|------------------------------|-----------|
| 0 | ( | depth=1 | 1 (odd) | 0 |
| 1 | ( | depth=2 | 2 (even) | 1 |
| 2 | ) | assign at depth=2 | 2 (even) | 1 |
| | | then depth=1 | | |
| 3 | ( | depth=2 | 2 (even) | 1 |
| 4 | ) | assign at depth=2 | 2 (even) | 1 |
| | | then depth=1 | | |
| 5 | ) | assign at depth=1 | 1 (odd) | 0 |
| | | then depth=0 | | |

Result: `[0, 1, 1, 1, 1, 0]`

Matches expected output exactly.

## Example 2

```text
seq = "()(())()"
```

| i | char | depth after '(' or before ')' | answer[i] |
|---|------|-------------------------------|-----------|
| 0 | ( | depth=1 (odd) | 0 |
| 1 | ) | depth=1 (odd), then depth=0 | 0 |
| 2 | ( | depth=1 (odd) | 0 |
| 3 | ( | depth=2 (even) | 1 |
| 4 | ) | depth=2 (even), then depth=1 | 1 |
| 5 | ) | depth=1 (odd), then depth=0 | 0 |
| 6 | ( | depth=1 (odd) | 0 |
| 7 | ) | depth=1 (odd), then depth=0 | 0 |

Result: `[0, 0, 0, 1, 1, 0, 0, 0]`

This is a **valid alternative answer** (different from the sample output `[0,0,0,1,1,0,1,1]`), since the problem states multiple valid answers may exist. Both achieve the same minimized `max(depth(A), depth(B)) = 1`.
