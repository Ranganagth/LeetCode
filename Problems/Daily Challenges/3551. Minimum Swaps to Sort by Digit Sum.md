# Intuition

This is a classic **"minimum swaps to sort an array"** problem, generalized with a custom comparator (sort by digit sum, then by value). The key insight is that the minimum number of swaps needed to transform an array into a target permutation equals **`n - (number of cycles)`** in the permutation that maps current positions to target positions — equivalently, summing `(cycle length - 1)` over all cycles.

We can compute this efficiently by determining, for each element, its **target index** in the sorted order, then decomposing this index-mapping into cycles using a visited array.

---

# Approach

1. **Compute digit sums**: For each number in `nums`, calculate the sum of its digits.
2. **Determine target order**: Create an array of indices `[0, 1, ..., n-1]` and sort it based on `(digitSum[i], nums[i])` — this gives the indices in the order they should appear in the final sorted array.
3. **Build position mapping**: From the sorted indices, construct a mapping `pos[originalIndex] = targetIndex` — i.e., for each original index, determine where it should end up in the sorted array.
4. **Cycle Decomposition**: 
   - Use a `visited` boolean array of size `n`.
   - For each index `i` from `0` to `n-1`, if not yet visited, traverse the cycle starting at `i` by repeatedly following `pos[current]` until returning to `i`, marking each visited and counting the cycle length.
   - For a cycle of length `L`, it requires `L - 1` swaps to resolve.
5. **Sum up** `(cycleLength - 1)` across all cycles to get the total minimum swaps.
6. Return the total.

---

# Complexity

- **Time complexity:** 
$$O(n \log n)$$
Dominated by sorting the indices; cycle decomposition itself is `O(n)`.

- **Space complexity:**
$$O(n)$$
For storing digit sums, sorted indices, position mapping, and visited array.

# Code

```typescript
function minSwaps(nums: number[]): number {
    const n = nums.length;

    const digitSum = (num: number): number => {
        let s = 0;
        while (num > 0) {
            s += num % 10;
            num = Math.floor(num / 10);
        }
        return s;
    };

    const sums = new Array<number>(n);
    for (let i = 0; i < n; i++) {
        sums[i] = digitSum(nums[i]);
    }

    const indices = Array.from({ length: n }, (_, i) => i);

    indices.sort((a, b) => {
        if (sums[a] !== sums[b]) return sums[a] - sums[b];
        return nums[a] - nums[b];
    });

    // pos[originalIndex] = targetIndex
    const pos = new Array<number>(n);
    for (let targetIdx = 0; targetIdx < n; targetIdx++) {
        const originalIdx = indices[targetIdx];
        pos[originalIdx] = targetIdx;
    }

    const visited = new Array<boolean>(n).fill(false);
    let swaps = 0;

    for (let i = 0; i < n; i++) {
        if (visited[i]) continue;

        let cycleLen = 0;
        let cur = i;

        while (!visited[cur]) {
            visited[cur] = true;
            cur = pos[cur];
            cycleLen++;
        }

        if (cycleLen > 0) {
            swaps += cycleLen - 1;
        }
    }

    return swaps;
};

```

# Example Walkthrough

## Example 1

```text
nums = [37, 100]
```

- `sums = [10, 1]`
- `indices` sorted by `(sum, value)`: index 1 (sum=1) before index 0 (sum=10) → `indices = [1, 0]`
- `pos[originalIndex] = targetIndex`:
  - `pos[1] = 0` (original index 1 goes to target position 0)
  - `pos[0] = 1` (original index 0 goes to target position 1)

**Cycle decomposition:**
- `i=0`: not visited. cur=0→visited, cur=pos[0]=1, cycleLen=1; cur=1→visited, cur=pos[1]=0, cycleLen=2; cur=0 already visited → stop. Cycle length=2 → swaps += 1.
- `i=1`: already visited.

Total swaps = `1`

Output: `1`

## Example 2

```text
nums = [18, 43, 34, 16]
```

- `sums = [9, 7, 7, 7]`
- Sort indices by `(sum, value)`:
  - index 3: sum=7, value=16
  - index 2: sum=7, value=34
  - index 1: sum=7, value=43
  - index 0: sum=9, value=18
  - `indices = [3, 2, 1, 0]`

- `pos`:
  - `pos[3]=0, pos[2]=1, pos[1]=2, pos[0]=3`

**Cycle decomposition:**
- `i=0`: cur=0→visited, cur=pos[0]=3, len=1; cur=3→visited, cur=pos[3]=0, len=2; cur=0 visited→stop. Cycle length=2 → swaps += 1.
- `i=1`: cur=1→visited, cur=pos[1]=2, len=1; cur=2→visited, cur=pos[2]=1, len=2; cur=1 visited→stop. Cycle length=2 → swaps += 1.

Total swaps = `1 + 1 = 2`

Output: `2`

## Example 3

```text
nums = [22,14,33,7]
```

- `sums = [4,5,6,7]`, already sorted → `indices = [0,1,2,3]`
- `pos[i] = i` for all `i` → each element is its own cycle of length 1 → `0` swaps.

Output: `0`
