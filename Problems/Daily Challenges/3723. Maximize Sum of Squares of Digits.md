# Intuition

Given a fixed total digit sum distributed across a fixed number of digits (each between `0`-`9`), **convexity of the square function** tells us that to maximize the sum of squares, we should push digit values toward the **extremes** (`0` and `9`) rather than spreading the sum evenly. Concretely, using as many `9`s as possible, with at most one "remainder" digit absorbing the leftover, and filling the rest with `0`s, maximizes the sum of squares for a fixed total.

Once we know **which multiset of digits** achieves the maximum score, any arrangement of that same multiset gives the identical score (order doesn't affect sum of squares) — so to satisfy the secondary tie-breaking condition (**choose the maximum possible number**), we simply arrange these digits in **descending order**.

---

# Approach

1. **Feasibility Check**: 
   - A valid `num`-digit number has a leading digit `≥ 1`, so the minimum achievable digit sum is `1` and the maximum is `9 * num`.
   - If `sum < 1` or `sum > 9 * num`, no valid number exists → return `""`.

2. **Determine Optimal Digit Multiset**:
   - Let `k = Math.floor(sum / 9)` — the number of `9`s we can use.
   - Let `r = sum - 9 * k` — the leftover remainder digit (if nonzero).
   - This gives us `k` nines, optionally one digit `r` (if `r > 0`), and the rest filled with `0`s to reach exactly `num` digits total.

3. **Why This Maximizes Score**: 
   By convexity, pushing values to extremes (`9`s and a single leftover, rest `0`s) maximizes `Σd²` for a fixed `Σd` and fixed count — this is a classic majorization/extremal argument.

4. **Build the Result**:
   - Append `k` copies of `'9'`.
   - If `r > 0`, append the digit `r`.
   - Pad with `'0'` characters until the total length equals `num`.
   - This naturally produces digits in **descending order**, which also maximizes the numeric value among all arrangements achieving the same score (since leading `9`s come first, satisfying the nonzero leading digit requirement automatically whenever `k > 0`, and when `k = 0`, the nonzero remainder `r` leads instead).

5. Return the constructed string.

---

# Complexity

- **Time complexity:** 
$$O(num)$$
Building the result string takes linear time relative to the number of digits.

- **Space complexity:** 
$$O(num)$$
For storing the output digit array/string.

---

# Code

```typescript
function maxSumOfSquares(num: number, sum: number): string {
    if (sum < 1 || sum > 9 * num) {
        return "";
    }

    const k = Math.floor(sum / 9);
    const r = sum - 9 * k;

    const digits: string[] = [];

    for (let i = 0; i < k; i++) {
        digits.push('9');
    }

    if (r > 0) {
        digits.push(String(r));
    }

    while (digits.length < num) {
        digits.push('0');
    }

    return digits.join('');
};

```

# Example Walkthrough

## Example 1

```text
num = 2, sum = 3
```

- `sum=3` is within `[1, 18]` → feasible.
- `k = floor(3/9) = 0`, `r = 3 - 0 = 3`
- digits: `[]` (no nines) → push `r=3` → `["3"]` → pad with zeros to length 2 → `["3","0"]`

Output: `"30"`

## Example 2

```text
num = 2, sum = 17
```

- `sum=17` within `[1,18]` → feasible.
- `k = floor(17/9) = 1`, `r = 17 - 9 = 8`
- digits: push one `'9'` → `["9"]`, then push `r=8` → `["9","8"]`, already length 2, no padding needed.

Output: `"98"`

## Example 3

```text
num = 1, sum = 10
```

- `9 * num = 9`, and `sum = 10 > 9` → infeasible.

Output: `""`
