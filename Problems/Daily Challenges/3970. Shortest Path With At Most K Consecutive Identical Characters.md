# Intuition

The constraint "at most `k` consecutive identical characters" means we need to track **more than just the current node** while searching for the shortest path — we also need to know the **label of the last visited node** and **how many times in a row** that same label has repeated. This turns the problem into a **shortest path search over an expanded state space**: `(node, lastLabel, consecutiveCount)`.

Since all edge weights are positive, **Dijkstra's algorithm** naturally extends to this expanded state graph — we just need to define valid transitions between states based on whether the next node's label matches the current streak.

---

# Approach

1. **Build adjacency list**: For each edge `[u, v, w]`, store `(v, w)` in `graph[u]`.

2. **Define state**: A state is `(node, lastLabelCode, count)` where:
   - `lastLabelCode` is the character code (0-25) of the most recently visited node's label.
   - `count` is how many consecutive nodes (ending at `node`) share that same label.

3. **Encode state as a single number** for use in a `Map`-based distance table:
   ```text
   key = node * 26 * k + lastLabelCode * k + (count - 1)
   ```

4. **Initialize Dijkstra**:
   - Starting state: `(node=0, lastLabelCode=labelCode(labels[0]), count=1)` with distance `0`.
   - Use a min-heap (priority queue) keyed by accumulated weight.

5. **Process states**:
   - Pop the state with the smallest distance.
   - If `node === n - 1`, return the current distance — this is guaranteed minimal due to Dijkstra's greedy property.
   - Otherwise, for each outgoing edge `(v, w)`:
     - Compute `newLabel = labelCode(labels[v])`.
     - If `newLabel === lastLabelCode`: `newCount = count + 1`. **Skip this transition if `newCount > k`** (invalid, too many consecutive repeats).
     - Else: `newCount = 1`, `newLabel` becomes the new streak's label.
     - Relax the edge: if the new state offers a smaller distance than previously recorded, update and push it onto the heap.

6. **No valid path**: If the heap empties without reaching node `n-1`, return `-1`.

7. **Edge case**: If `n === 1`, the start and end are the same node — return `0` immediately.

---

# Complexity

- **Time complexity:**
$$O(E \cdot k \cdot \log(E \cdot k))$$
Each edge can generate up to `k` distinct transitions (one per possible previous streak count), and heap operations cost `O(log(\text{heap size}))`.

- **Space complexity:**
$$O(E \cdot k)$$
For the distance map and priority queue, bounded by the number of distinct reachable states.

# Code

```typescript
function shortestPath(n: number, edges: number[][], labels: string, k: number): number {
    if (n === 1) return 0;

    const graph: [number, number][][] = Array.from({ length: n }, () => []);
    for (const [u, v, w] of edges) {
        graph[u].push([v, w]);
    }

    const labelCode = (idx: number): number => labels.charCodeAt(idx) - 97;

    const stateKey = (node: number, lastLabel: number, count: number): number => {
        return node * 26 * k + lastLabel * k + (count - 1);
    };

    // Min-heap implementation: entries are [distance, node, lastLabel, count]
    class MinHeap {
        private heap: [number, number, number, number][] = [];

        push(item: [number, number, number, number]): void {
            this.heap.push(item);
            let i = this.heap.length - 1;
            while (i > 0) {
                const parent = (i - 1) >> 1;
                if (this.heap[parent][0] <= this.heap[i][0]) break;
                [this.heap[parent], this.heap[i]] = [this.heap[i], this.heap[parent]];
                i = parent;
            }
        }

        pop(): [number, number, number, number] | undefined {
            if (this.heap.length === 0) return undefined;
            const top = this.heap[0];
            const last = this.heap.pop()!;
            if (this.heap.length > 0) {
                this.heap[0] = last;
                let i = 0;
                const n = this.heap.length;
                while (true) {
                    let smallest = i;
                    const left = 2 * i + 1;
                    const right = 2 * i + 2;
                    if (left < n && this.heap[left][0] < this.heap[smallest][0]) smallest = left;
                    if (right < n && this.heap[right][0] < this.heap[smallest][0]) smallest = right;
                    if (smallest === i) break;
                    [this.heap[i], this.heap[smallest]] = [this.heap[smallest], this.heap[i]];
                    i = smallest;
                }
            }
            return top;
        }

        get size(): number {
            return this.heap.length;
        }
    }

    const dist = new Map<number, number>();
    const heap = new MinHeap();

    const startLabel = labelCode(0);
    const startKey = stateKey(0, startLabel, 1);
    dist.set(startKey, 0);
    heap.push([0, 0, startLabel, 1]);

    while (heap.size > 0) {
        const [d, node, lastLabel, count] = heap.pop()!;

        if (node === n - 1) {
            return d;
        }

        const key = stateKey(node, lastLabel, count);
        if (dist.has(key) && dist.get(key)! < d) continue;

        for (const [v, w] of graph[node]) {
            const newLabel = labelCode(v);
            let newCount: number;

            if (newLabel === lastLabel) {
                newCount = count + 1;
                if (newCount > k) continue;
            } else {
                newCount = 1;
            }

            const newDist = d + w;
            const newKey = stateKey(v, newLabel, newCount);

            if (!dist.has(newKey) || dist.get(newKey)! > newDist) {
                dist.set(newKey, newDist);
                heap.push([newDist, v, newLabel, newCount]);
            }
        }
    }

    return -1;
};

```

# Example Walkthrough

## Example 1

```text
n = 3, edges = [[0,1,1],[1,2,1],[0,2,3]], labels = "aab", k = 1
```

- Start state: `node=0, lastLabel='a', count=1, dist=0`.
- From `0`: 
  - edge to `1` (label 'a'): same label → `newCount=2 > k=1` → **skip**.
  - edge to `2` (label 'b'): different label → `newCount=1`, dist=3 → push `(3, 2, 'b', 1)`.
- Pop `(3, 2, 'b', 1)`: `node === n-1=2` → return `3`.

Output: `3`

## Example 2

```text
k = 2
```

- Start: `node=0, lastLabel='a', count=1, dist=0`.
- From `0→1` (label 'a'): same label → `newCount=2 ≤ k=2` → valid, dist=1 → push `(1, 1, 'a', 2)`.
- From `0→2` (label 'b'): different → `newCount=1`, dist=3 → push `(3, 2, 'b', 1)`.
- Pop smallest: `(1, 1, 'a', 2)`.
  - From `1→2` (label 'b'): different → `newCount=1`, dist=2 → push `(2, 2, 'b', 1)`.
- Pop `(2, 2, 'b', 1)`: `node === 2` → return `2`.

Output: `2`
