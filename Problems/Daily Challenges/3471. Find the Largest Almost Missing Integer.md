# Intuition

We need to find the **largest value** that appears in **exactly one subarray** of size `k`. The key insight is that "appears in a subarray" means the value is present **at least once** in that subarray (not counting multiple occurrences within the same subarray).

**Brute force approach:** For each distinct value in the array, count how many subarrays of size `k` contain that value at least once. Track the largest value where this count equals exactly 1.

Given the small constraints (n ≤ 50), a straightforward brute force solution is efficient enough.

---

# Approach

1. **Get all distinct values** from the array
2. **For each distinct value `v`:**
   - Slide through all possible subarrays of size `k`
   - Check if `v` exists in each subarray
   - Count how many subarrays contain `v`
3. **Track the answer:** If count equals exactly 1, update the answer with the maximum such value
4. **Return the result:** Largest value with count = 1, or -1 if none exists

---

# Complexity

**Time Complexity:** $O(n³)$ in the worst case
- $O(n)$ distinct values to check
- $O(n)$ subarrays of size k
- $O(k)$ to check if value exists in each subarray
- Total: O(n × n × k) ≈ $O(n³)$ for small n

**Space Complexity:** $O(n)$
- Storing distinct values in a Set

For n ≤ 50, worst case operations ≈ 125,000, which is very fast.

# Code

## Solution 1: Brute Force (Clean and Simple)

```typescript
function largestInteger(nums: number[], k: number): number {
    const n = nums.length;
    const distinctValues = Array.from(new Set(nums));
    let answer = -1;
    
    for (const value of distinctValues) {
        let count = 0;
        
        // Check all subarrays of size k
        for (let i = 0; i + k <= n; i++) {
            let found = false;
            
            // Check if value exists in this subarray
            for (let j = i; j < i + k; j++) {
                if (nums[j] === value) {
                    found = true;
                    break;
                }
            }
            
            if (found) {
                count++;
            }
        }
        
        // If value appears in exactly one subarray, update answer
        if (count === 1) {
            answer = Math.max(answer, value);
        }
    }
    
    return answer;
};

```

## Solution 2: With Detailed Comments

```typescript
function largestInteger(nums: number[], k: number): number {
    const n = nums.length;
    
    // Get all unique values from the array
    const distinctValues = Array.from(new Set(nums));
    
    let answer = -1;
    
    // Check each distinct value
    for (const value of distinctValues) {
        let subarrayCount = 0;
        
        // Slide through all subarrays of size k
        for (let start = 0; start + k <= n; start++) {
            const end = start + k;
            let valueExists = false;
            
            // Check if current value exists in this subarray
            for (let idx = start; idx < end; idx++) {
                if (nums[idx] === value) {
                    valueExists = true;
                    break; // No need to check further
                }
            }
            
            if (valueExists) {
                subarrayCount++;
            }
        }
        
        // Value is "almost missing" if it appears in exactly 1 subarray
        if (subarrayCount === 1) {
            answer = Math.max(answer, value);
        }
    }
    
    return answer;
};

```

## Solution 3: Optimized with Set for Subarray Check

```typescript
function largestInteger(nums: number[], k: number): number {
    const n = nums.length;
    const distinctValues = Array.from(new Set(nums));
    let answer = -1;
    
    for (const value of distinctValues) {
        let count = 0;
        
        for (let i = 0; i + k <= n; i++) {
            const subarraySet = new Set(nums.slice(i, i + k));
            
            if (subarraySet.has(value)) {
                count++;
            }
        }
        
        if (count === 1) {
            answer = Math.max(answer, value);
        }
    }
    
    return answer;
};

```

## Solution 4: Compact Version

function largestInteger(nums: number[], k: number): number {
    const n = nums.length;
    let answer = -1;
    
    for (const value of new Set(nums)) {
        let count = 0;
        
        for (let i = 0; i + k <= n; i++) {
            if (nums.slice(i, i + k).includes(value)) {
                count++;
            }
        }
        
        if (count === 1) {
            answer = Math.max(answer, value);
        }
    }
    
    return answer;
};

# Visual Representation

## Sliding Window Concept

```
nums = [3, 9, 2, 1, 7], k = 3

Window 1: [3, 9, 2] | 1, 7
Window 2: 3, [9, 2, 1], 7
Window 3: 3, 9, [2, 1, 7]

For each value, count how many windows contain it:
  Value 3: window 1 only → count=1
  Value 7: window 3 only → count=1
  
These are "almost missing" - appear in exactly 1 window
```

## Why This Works

```
"Almost missing" means:
  - Not completely missing (appears at least once)
  - Not common (doesn't appear in many subarrays)
  - Appears in EXACTLY one subarray

This typically happens for values at the "edges" of the array,
since edge elements are covered by fewer subarrays
```

---

# Key Insights

1. **Position matters more than frequency:** A value's subarray count depends on its position(s) in the array
2. **Edge elements are naturally "almost missing":** Elements near array boundaries appear in fewer subarrays
3. **Distinct values only:** We check each unique value once, not each occurrence
4. **Union of ranges:** If a value appears multiple times, we count subarrays containing ANY occurrence
5. **Greedy selection:** Among all "almost missing" values, pick the largest one

---

# Edge Cases

| Case | Input | Output | Explanation |
|------|-------|--------|-------------|
| k = n | Single subarray | Any value | Every value appears in exactly 1 subarray |
| k = 1 | Each element is its own subarray | Depends | Value appears once only if it's unique |
| All same value | `[5,5,5]` | -1 or 5 | Depends on how many subarrays contain it |
| No valid answer | Duplicates everywhere | -1 | No value has count exactly 1 |
| Single element | `[5]`, k=1 | 5 | Trivially appears in 1 subarray |

# Common Mistakes to Avoid

1. **Counting occurrences instead of subarrays:**
   ```typescript
   // Wrong: counts every occurrence in a subarray
   for (let j = i; j < i + k; j++) {
       if (nums[j] === value) count++; // Wrong!
   }
   
   // Correct: count subarray only once if value exists
   let found = false;
   for (let j = i; j < i + k; j++) {
       if (nums[j] === value) { found = true; break; }
   }
   if (found) count++;
   ```

2. **Not checking all distinct values:**
   ```typescript
   // Wrong: only checking values in first subarray
   for (const value of nums.slice(0, k)) { ... }
   
   // Correct: check all distinct values in entire array
   for (const value of new Set(nums)) { ... }
   ```

3. **Wrong tie-breaking:**
   ```typescript
   // Wrong: using < instead of tracking max properly
   if (count === 1 && value > answer) answer = value;
   
   // Correct: use Math.max for clarity
   if (count === 1) answer = Math.max(answer, value);
   ```

| Component | Complexity | Operations |
|-----------|-----------|------------|
| Distinct values | $O(n)$ | ≤50 |

| **Total** | **O(n²k)** | **≤125,000** |

Very fast for the given constraints!
