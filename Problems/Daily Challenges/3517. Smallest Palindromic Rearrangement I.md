# Intuition

Since the input string is already a palindrome, we need to rearrange it to get the lexicographically smallest palindrome.

**Key insights:**
1. A palindrome reads the same forwards and backwards
2. For lexicographically smallest, we want smaller characters at the beginning
3. We can count character frequencies and build the palindrome from outside to inside
4. Place characters in sorted order on the left half, mirror them on the right, and handle the middle character (if odd length)

---

# Approach

1. **Count character frequencies** using a frequency map or array

2. **Build left half** by placing characters in sorted order:
   - For each character, use half of its occurrences
   - Place them in alphabetical order

3. **Handle middle character** (if string length is odd):
   - Find the character with odd count (if any)
   - Place it in the middle

4. **Build right half** by mirroring the left half

5. **Combine:** left + middle + right

---

# Complexity

- **Time complexity:** O(n) - counting frequencies and building result
- **Space complexity:** O(1) - fixed size array for 26 lowercase letters

# Code

## Solution 1: Frequency Count with Array

```typescript
function smallestPalindrome(s: string): string {
    const n = s.length;
    
    // Count frequency of each character
    const freq = new Array(26).fill(0);
    for (const char of s) {
        freq[char.charCodeAt(0) - 'a'.charCodeAt(0)]++;
    }
    
    // Build left half (use half of each character's frequency)
    let left = '';
    for (let i = 0; i < 26; i++) {
        const count = Math.floor(freq[i] / 2);
        if (count > 0) {
            left += String.fromCharCode('a'.charCodeAt(0) + i).repeat(count);
        }
    }
    
    // Find middle character (character with odd frequency, if any)
    let middle = '';
    for (let i = 0; i < 26; i++) {
        if (freq[i] % 2 === 1) {
            middle = String.fromCharCode('a'.charCodeAt(0) + i);
            break; // Only one character can have odd frequency in a palindrome
        }
    }
    
    // Build right half (reverse of left)
    const right = left.split('').reverse().join('');
    
    return left + middle + right;
};

```

## Solution 2: Using Map for Clarity

```typescript
function smallestPalindrome(s: string): string {
    // Count character frequencies
    const freqMap = new Map<string, number>();
    for (const char of s) {
        freqMap.set(char, (freqMap.get(char) || 0) + 1);
    }
    
    // Get sorted characters
    const sortedChars = Array.from(freqMap.keys()).sort();
    
    // Build left half
    let left = '';
    for (const char of sortedChars) {
        const count = Math.floor(freqMap.get(char)! / 2);
        left += char.repeat(count);
    }
    
    // Find middle character (odd frequency)
    let middle = '';
    for (const char of sortedChars) {
        if (freqMap.get(char)! % 2 === 1) {
            middle = char;
            break;
        }
    }
    
    // Build palindrome
    const right = left.split('').reverse().join('');
    return left + middle + right;
};

```

## Solution 3: Optimized with Single Loop

```typescript
function smallestPalindrome(s: string): string {
    const freq = new Array(26).fill(0);
    
    // Count frequencies
    for (const char of s) {
        freq[char.charCodeAt(0) - 97]++;
    }
    
    let result = '';
    let middle = '';
    
    // Build left half and find middle
    for (let i = 0; i < 26; i++) {
        const char = String.fromCharCode(97 + i);
        const halfCount = Math.floor(freq[i] / 2);
        
        // Add to left half
        result += char.repeat(halfCount);
        
        // Check for middle character
        if (freq[i] % 2 === 1 && middle === '') {
            middle = char;
        }
    }
    
    // Build complete palindrome
    return result + middle + result.split('').reverse().join('');
};

```

## Solution 4: With Detailed Comments

```typescript
function smallestPalindrome(s: string): string {
    const n = s.length;
    
    // Step 1: Count frequency of each character (a-z)
    const charCount = new Array(26).fill(0);
    for (let i = 0; i < n; i++) {
        const index = s.charCodeAt(i) - 'a'.charCodeAt(0);
        charCount[index]++;
    }
    
    // Step 2: Build the left half of palindrome
    // Use half of each character's count, in alphabetical order
    const leftHalf: string[] = [];
    for (let i = 0; i < 26; i++) {
        const halfCount = Math.floor(charCount[i] / 2);
        const char = String.fromCharCode('a'.charCodeAt(0) + i);
        
        for (let j = 0; j < halfCount; j++) {
            leftHalf.push(char);
        }
    }
    
    // Step 3: Find middle character (if string length is odd)
    // Only one character can have odd frequency in a palindrome
    let middleChar = '';
    for (let i = 0; i < 26; i++) {
        if (charCount[i] % 2 === 1) {
            middleChar = String.fromCharCode('a'.charCodeAt(0) + i);
            break;
        }
    }
    
    // Step 4: Build the complete palindrome
    // Left half + middle + reversed left half
    const rightHalf = [...leftHalf].reverse();
    
    return leftHalf.join('') + middleChar + rightHalf.join('');
};

```

# Key Insights

- **Lexicographically smallest:** Place characters in alphabetical order from outside to inside
- **Palindrome property:** Left half mirrors right half
- **Odd length handling:** At most one character can have odd frequency
- **Frequency division:** Use floor(count/2) for each half
- **Sorting advantage:** Processing characters in alphabetical order ensures smallest result

| Long palindrome | "aabbccddee" | "abcdeedcba" | Multiple chars |

# Why This Works

**Mathematical reasoning:**

1. **Palindrome structure:** For a string to be a palindrome, characters must appear in pairs (except possibly one middle character)

2. **Lexicographic order:** To get the smallest palindrome:
   - Place smallest characters first (leftmost positions)
   - Mirror them on the right
   - Put any odd-count character in the middle

3. **Frequency guarantee:** Since input is already a palindrome, we know:
   - At most one character has odd frequency
   - All other characters have even frequency

---

# Common Mistakes to Avoid

1. **Not sorting characters:** Must process in alphabetical order
2. **Wrong middle character:** Should be the smallest character with odd count
3. **Incorrect frequency division:** Use floor division for left half
4. **Forgetting to reverse:** Right half must be reverse of left half
