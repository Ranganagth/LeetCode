# Intuition

To classify edges, we compare the **MST weight in three scenarios** for each edge:
1. **Baseline:** Normal MST weight using all edges
2. **Excluding the edge:** Build MST without this edge - if the resulting weight increases (or MST becomes impossible), the edge is **critical** (essential for minimum weight)
3. **Forcing the edge:** Build MST with this edge pre-included - if the resulting weight equals the baseline, the edge is **pseudo-critical** (can be part of an MST, but isn't required)

**Key insight:** An edge is critical if removing it makes the MST worse. An edge is pseudo-critical if it's not critical but including it still achieves the optimal MST weight.

---

# Approach

1. **Compute baseline MST weight** using Kruskal's algorithm with Union-Find

2. **For each edge `i`:**
   - **Test exclusion:** Run Kruskal's algorithm skipping edge `i`. If the resulting MST weight is greater than baseline (or disconnected), mark edge `i` as **critical**
   - **Test inclusion:** If not critical, run Kruskal's algorithm with edge `i` pre-added to the Union-Find structure. If the resulting MST weight equals baseline, mark edge `i` as **pseudo-critical**

3. **Sort edges by weight** first (required for Kruskal's algorithm to work correctly)

---

# Complexity

**Time Complexity:** $O(E² × α(V))$
- E = number of edges (≤ 200)
- For each edge, we run Kruskal's algorithm twice: $O(E α(V))$
- Total: $O(E) × O(E α(V)) = O(E² α(V))$

**Space Complexity:** $O(V + E)$
- Union-Find structure and edge storage

For E ≤ 200, this gives at most 200² = 40,000 operations, very efficient.

```typescript
function findCriticalAndPseudoCriticalEdges(n: number, edges: number[][]): number[][] {
    const m = edges.length;
    
    // Add original index to each edge for tracking
    const indexedEdges = edges.map((edge, idx) => [...edge, idx]);
    
    // Sort by weight for Kruskal's algorithm
    indexedEdges.sort((a, b) => a[2] - b[2]);
    
    class UnionFind {
        parent: number[];
        rank: number[];
        components: number;
        
        constructor(size: number) {
            this.parent = Array.from({ length: size }, (_, i) => i);
            this.rank = new Array(size).fill(0);
            this.components = size;
        }
        
        find(x: number): number {
            if (this.parent[x] !== x) {
                this.parent[x] = this.find(this.parent[x]);
            }
            return this.parent[x];
        }
        
        union(x: number, y: number): boolean {
            const rootX = this.find(x);
            const rootY = this.find(y);
            
            if (rootX === rootY) return false;
            
            if (this.rank[rootX] < this.rank[rootY]) {
                this.parent[rootX] = rootY;
            } else if (this.rank[rootX] > this.rank[rootY]) {
                this.parent[rootY] = rootX;
            } else {
                this.parent[rootY] = rootX;
                this.rank[rootX]++;
            }
            
            this.components--;
            return true;
        }
    }
    
    // Compute MST weight, optionally skipping one edge and/or forcing another
    function computeMST(skipIdx: number, forceIdx: number): number {
        const uf = new UnionFind(n);
        let weight = 0;
        let edgeCount = 0;
        
        // Force include a specific edge first
        if (forceIdx !== -1) {
            const [a, b, w] = indexedEdges[forceIdx];
            uf.union(a, b);
            weight += w;
            edgeCount++;
        }
        
        for (let i = 0; i < m; i++) {
            if (i === skipIdx || i === forceIdx) continue;
            
            const [a, b, w] = indexedEdges[i];
            if (uf.union(a, b)) {
                weight += w;
                edgeCount++;
            }
        }
        
        // Return -1 if MST is not fully connected
        return edgeCount === n - 1 ? weight : Infinity;
    }
    
    // Compute baseline MST weight
    const baselineWeight = computeMST(-1, -1);
    
    const critical: number[] = [];
    const pseudoCritical: number[] = [];
    
    for (let i = 0; i < m; i++) {
        const originalIdx = indexedEdges[i][3];
        
        // Test exclusion: does removing this edge increase MST weight?
        const weightWithoutEdge = computeMST(i, -1);
        
        if (weightWithoutEdge > baselineWeight) {
            critical.push(originalIdx);
        } else {
            // Test inclusion: does forcing this edge still achieve baseline weight?
            const weightWithEdge = computeMST(-1, i);
            
            if (weightWithEdge === baselineWeight) {
                pseudoCritical.push(originalIdx);
            }
        }
    }
    
    return [critical, pseudoCritical];
};

```

## Solution with Detailed Comments

```typescript
function findCriticalAndPseudoCriticalEdges(n: number, edges: number[][]): number[][] {
    const m = edges.length;
    
    // Attach original index to each edge before sorting
    // Format: [a, b, weight, originalIndex]
    const indexedEdges = edges.map((edge, idx) => [...edge, idx]);
    
    // Sort by weight - required for Kruskal's algorithm
    indexedEdges.sort((a, b) => a[2] - b[2]);
    
    // Union-Find (Disjoint Set Union) data structure
    class UnionFind {
        parent: number[];
        rank: number[];
        components: number;
        
        constructor(size: number) {
            this.parent = Array.from({ length: size }, (_, i) => i);
            this.rank = new Array(size).fill(0);
            this.components = size;
        }
        
        find(x: number): number {
            // Path compression for efficiency
            if (this.parent[x] !== x) {
                this.parent[x] = this.find(this.parent[x]);
            }
            return this.parent[x];
        }
        
        union(x: number, y: number): boolean {
            const rootX = this.find(x);
            const rootY = this.find(y);
            
            if (rootX === rootY) return false; // Already connected
            
            // Union by rank for balanced tree
            if (this.rank[rootX] < this.rank[rootY]) {
                this.parent[rootX] = rootY;
            } else if (this.rank[rootX] > this.rank[rootY]) {
                this.parent[rootY] = rootX;
            } else {
                this.parent[rootY] = rootX;
                this.rank[rootX]++;
            }
            
            this.components--;
            return true;
        }
    }
    
    // Compute MST weight with optional constraints:
    // skipIdx: edge to exclude from consideration
    // forceIdx: edge to include first (forced into MST)
    function computeMST(skipIdx: number, forceIdx: number): number {
        const uf = new UnionFind(n);
        let totalWeight = 0;
        let edgesUsed = 0;
        
        // If forcing an edge, add it first regardless of Kruskal's order
        if (forceIdx !== -1) {
            const [a, b, w] = indexedEdges[forceIdx];
            uf.union(a, b);
            totalWeight += w;
            edgesUsed++;
        }
        
        // Standard Kruskal's algorithm on remaining edges
        for (let i = 0; i < m; i++) {
            if (i === skipIdx || i === forceIdx) continue;
            
            const [a, b, w] = indexedEdges[i];
            
            if (uf.union(a, b)) {
                totalWeight += w;
                edgesUsed++;
            }
        }
        
        // Valid MST requires exactly n-1 edges connecting all nodes
        return edgesUsed === n - 1 ? totalWeight : Infinity;
    }
    
    // Step 1: Calculate the baseline (normal) MST weight
    const baselineWeight = computeMST(-1, -1);
    
    const criticalEdges: number[] = [];
    const pseudoCriticalEdges: number[] = [];
    
    // Step 2: Test each edge for critical/pseudo-critical status
    for (let i = 0; i < m; i++) {
        const originalIndex = indexedEdges[i][3];
        
        // Test 1: Exclude this edge - does MST weight increase?
        const weightExcluding = computeMST(i, -1);
        
        if (weightExcluding > baselineWeight) {
            // Removing this edge makes MST worse (or impossible)
            // This edge is ESSENTIAL - mark as critical
            criticalEdges.push(originalIndex);
        } else {
            // Test 2: Force include this edge - can we still achieve baseline weight?
            const weightIncluding = computeMST(-1, i);
            
            if (weightIncluding === baselineWeight) {
                // This edge CAN be part of an optimal MST, but isn't required
                pseudoCriticalEdges.push(originalIndex);
            }
            // If weightIncluding > baseline, this edge can never be in an optimal MST
        }
    }
    
    return [criticalEdges, pseudoCriticalEdges];
};

```

## Example 1: `n = 5, edges = [[0,1,1],[1,2,1],[2,3,2],[0,3,2],[0,4,3],[3,4,3],[1,4,6]]`

### Step 1: Sort Edges by Weight

```
Original edges with indices:
  0: [0,1,1]
  1: [1,2,1]
  2: [2,3,2]
  3: [0,3,2]
  4: [0,4,3]
  5: [3,4,3]
  6: [1,4,6]

After sorting by weight (already sorted in this case):
  Sorted order: [0,1,1,idx=0], [1,2,1,idx=1], [2,3,2,idx=2], 
                [0,3,2,idx=3], [0,4,3,idx=4], [3,4,3,idx=5], [1,4,6,idx=6]
```

### Step 2: Compute Baseline MST

```
Kruskal's algorithm:
  Edge [0,1,1]: Union(0,1) → success, weight=1, edges=1
  Edge [1,2,1]: Union(1,2) → success, weight=2, edges=2
  Edge [2,3,2]: Union(2,3) → success, weight=4, edges=3
  Edge [0,3,2]: Union(0,3) → 0 and 3 already connected, skip
  Edge [0,4,3]: Union(0,4) → success, weight=7, edges=4
  Edge [3,4,3]: Union(3,4) → already connected, skip
  Edge [1,4,6]: Union(1,4) → already connected, skip

Total edges used = 4 = n-1 ✓
Baseline MST weight = 7
```

### Step 3: Test Each Edge

**Edge 0: [0,1,1]**

```
Test exclusion (skip edge 0):
  Edge [1,2,1]: Union(1,2) → success, weight=1
  Edge [2,3,2]: Union(2,3) → success, weight=3
  Edge [0,3,2]: Union(0,3) → success (0 and 3 not yet connected), weight=5
  Edge [0,4,3]: Union(0,4) → success, weight=8
  Edge [3,4,3]: already connected, skip
  Edge [1,4,6]: already connected, skip
  
  Edges used = 4, weight = 8

weightExcluding(8) > baseline(7)? Yes!
→ Edge 0 is CRITICAL
```

**Edge 1: [1,2,1]**

```
Test exclusion (skip edge 1):
  Edge [0,1,1]: Union(0,1) → success, weight=1
  Edge [2,3,2]: Union(2,3) → success, weight=3
  Edge [0,3,2]: Union(0,3) → 0,3 not connected via 2, success? 
    Wait, 0-1 connected, 2-3 connected, these are separate components
    Union(0,3): success, weight=5, now {0,1,3,2} connected
  Edge [0,4,3]: Union(0,4) → success, weight=8
  
  Edges used = 4, weight = 8

weightExcluding(8) > baseline(7)? Yes!
→ Edge 1 is CRITICAL
```

**Edge 2: [2,3,2]**

```
Test exclusion (skip edge 2):
  Edge [0,1,1]: success, weight=1
  Edge [1,2,1]: success, weight=2
  Edge [0,3,2]: Union(0,3) → success (3 not yet connected), weight=4
  Edge [0,4,3]: success, weight=7
  
  Edges used = 4, weight = 7

weightExcluding(7) > baseline(7)? No (equal)
→ Test inclusion instead

Test inclusion (force edge 2):
  Force [2,3,2]: weight=2, edges=1
  Edge [0,1,1]: success, weight=3
  Edge [1,2,1]: success (1 connects to 2,3), weight=4
  Edge [0,3,2]: already connected, skip
  Edge [0,4,3]: success, weight=7
  
  Edges used = 4, weight = 7

weightIncluding(7) === baseline(7)? Yes!
→ Edge 2 is PSEUDO-CRITICAL
```

**Edge 3: [0,3,2]** (similar analysis)

```
Test exclusion: Can still achieve weight=7 using edge 2 instead
→ Not critical

Test inclusion: Force edge 3, still achieves weight=7
→ PSEUDO-CRITICAL
```

**Edge 4: [0,4,3]**

```
Test exclusion (skip edge 4):
  Using edges 0,1,2: weight=4, connects {0,1,2,3}
  Edge [3,4,3]: Union(3,4) → success, weight=7
  
  Edges used = 4, weight = 7

weightExcluding(7) > baseline(7)? No
→ Test inclusion

Test inclusion (force edge 4):
  Similar path, achieves weight=7
→ PSEUDO-CRITICAL
```

**Edge 5: [3,4,3]** (symmetric to edge 4)

```
→ PSEUDO-CRITICAL
```

**Edge 6: [1,4,6]**

```
Test exclusion: MST unaffected since this edge wasn't used
weightExcluding = 7 = baseline
→ Test inclusion

Test inclusion (force edge 6):
  Force [1,4,6]: weight=6
  Then need to connect remaining nodes optimally
  Edge [0,1,1]: success, weight=7
  Edge [1,2,1]: success, weight=8
  Edge [2,3,2]: success, weight=10
  
  Edges used=4, weight=10

weightIncluding(10) === baseline(7)? No
→ Edge 6 is NEITHER critical nor pseudo-critical
```

### Final Classification

```
Critical: [0, 1]
Pseudo-critical: [2, 3, 4, 5]
Neither: [6]
```

**Output:** `[[0,1],[2,3,4,5]]` ✓

## Example 2: `n = 4, edges = [[0,1,1],[1,2,1],[2,3,1],[0,3,1]]`

### All edges have equal weight

```
Baseline MST weight: Using any 3 of the 4 edges gives weight=3

(since the remaining 3 edges can still connect all 4 nodes)

For each edge, including it also achieves the same weight
```

### Result

```
No edge is critical (all can be excluded without weight increase)
All edges are pseudo-critical (all can be included in some optimal MST)
```

# Visual Representation

## Critical vs Pseudo-Critical Concept

```
Critical Edge:
  Without it: MST weight increases
  ┌─────┐
  │ MST │ = weight W
  └─────┘
  Remove edge → weight > W (MUST use this edge)

Pseudo-Critical Edge:
  Without it: MST weight stays the same (alternative path exists)
  With it forced: MST weight stays the same (valid alternative)
  → Edge is OPTIONAL but still optimal
```

## Testing Process Flowchart

```
For each edge e:
  
  1. Remove e, compute MST
     ↓
  Weight increased? 
     ├─ Yes → CRITICAL
     └─ No → Continue to step 2
  
  2. Force e, compute MST
     ↓
  Weight same as baseline?
     ├─ Yes → PSEUDO-CRITICAL
     └─ No → Neither (edge never useful)
```

# Key Insights

1. **Two-test approach:** Testing both exclusion and forced inclusion definitively classifies every edge
2. **Kruskal's algorithm foundation:** The greedy nature of Kruskal's makes it perfect for this incremental testing
3. **Baseline comparison is key:** All decisions are relative to the baseline MST weight
4. **Order matters for forced edges:** Forcing an edge first, then continuing with sorted order, correctly simulates "this edge must be used"
5. **$O(E)$ tests, each $O(E α(V))$:** Efficient enough for the given constraints

# Edge Cases

| Case | Scenario | Handling |
|------|----------|----------|
| All equal weights | Every edge is interchangeable | All edges pseudo-critical, none critical |
| Single valid MST | Only one way to form MST | All MST edges critical |
| Disconnected without edge | Edge is bridge | Correctly identified as critical |
| Edge never in any MST | Too heavy/redundant | Correctly excluded from both lists |
| Minimum edges (tree) | n-1 edges exactly | All edges critical (no redundancy) |

# Common Mistakes to Avoid

1. **Not sorting edges before Kruskal's:**
   ```typescript
   // Wrong: Kruskal's requires sorted edges
   for (const edge of edges) { ... }
   
   // Correct: sort by weight first
   indexedEdges.sort((a, b) => a[2] - b[2]);
   ```

2. **Forgetting to check full connectivity:**
   ```typescript
   // Wrong: not verifying n-1 edges achieved
   return totalWeight;
   
   // Correct: check for complete spanning tree
   return edgesUsed === n - 1 ? totalWeight : Infinity;
   ```

3. **Incorrect force-edge implementation:**
   ```typescript
   // Wrong: forcing edge doesn't respect Kruskal's greedy order
   // Just adding weight without using Union-Find properly
   
   // Correct: actually union the nodes for forced edge
   uf.union(a, b);
   weight += w;
   ```

4. **Not preserving original indices:**
   ```typescript
   // Wrong: losing track of original edge position after sorting
   edges.sort((a, b) => a[2] - b[2]);
   
   // Correct: attach original index before sorting
   const indexed = edges.map((e, i) => [...e, i]);
   indexed.sort((a, b) => a[2] - b[2]);
   ```

This dual-testing approach with Kruskal's algorithm is optimal for:
- Correctly identifies both critical and pseudo-critical edges
- $O(E² α(V))$ time complexity - efficient for E ≤ 200
- Clean separation of concerns (exclusion test vs inclusion test)
- Handles all edge cases including disconnected scenarios
- Industry-standard technique for MST edge classification problems
