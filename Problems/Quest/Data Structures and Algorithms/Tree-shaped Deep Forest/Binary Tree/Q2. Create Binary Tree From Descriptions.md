# Intuition

We need to construct a binary tree from a list of parent-child relationships. The key challenges are:
1. **Creating nodes** for each unique value
2. **Linking them** correctly as left/right children
3. **Finding the root** - the node that never appears as a child

**Key insight:** Use a **HashMap** to store all nodes by their value, then link them according to descriptions. The root is the only node that appears as a parent but never as a child.

---

# Approach

1. **Create a map** to store `value -> TreeNode` for all nodes
2. **Track children** using a Set to identify which nodes are children
3. **Process each description:**
   - Create parent node if it doesn't exist
   - Create child node if it doesn't exist
   - Link child to parent (left or right based on `isLeft`)
   - Mark child value as "has parent"
4. **Find the root:** The parent value that never appears in the children set
5. **Return the root node**

---

# Complexity

- **Time Complexity:** $O(n)$ where n is the length of descriptions array
  - Single pass through descriptions to build the tree
  - $O(1)$ map operations (get/set)
  
- **Space Complexity:** $O(n)$
  - HashMap stores all unique nodes
  - Set stores all child values

# Code

## Solution 1: Using Map and Set (Recommended)

```typescript
function createBinaryTree(descriptions: number[][]): TreeNode | null {
    const nodeMap = new Map<number, TreeNode>();
    const childrenSet = new Set<number>();
    
    // Helper function to get or create a node
    function getNode(val: number): TreeNode {
        if (!nodeMap.has(val)) {
            nodeMap.set(val, new TreeNode(val));
        }
        return nodeMap.get(val)!;
    }
    
    // Process all descriptions
    for (const [parentVal, childVal, isLeft] of descriptions) {
        const parentNode = getNode(parentVal);
        const childNode = getNode(childVal);
        
        if (isLeft === 1) {
            parentNode.left = childNode;
        } else {
            parentNode.right = childNode;
        }
        
        childrenSet.add(childVal);
    }
    
    // Find root: a parent value that is never a child
    for (const [parentVal] of descriptions) {
        if (!childrenSet.has(parentVal)) {
            return nodeMap.get(parentVal)!;
        }
    }
    
    return null;
};

```

## Solution 2: With Detailed Comments

```typescript
function createBinaryTree(descriptions: number[][]): TreeNode | null {
    // Map to store value -> TreeNode mapping
    const nodeMap = new Map<number, TreeNode>();
    
    // Set to track which values are children (have a parent)
    const childrenSet = new Set<number>();
    
    // Helper function to retrieve existing node or create new one
    function getOrCreateNode(val: number): TreeNode {
        if (!nodeMap.has(val)) {
            nodeMap.set(val, new TreeNode(val));
        }
        return nodeMap.get(val)!;
    }
    
    // Step 1: Build the tree structure
    for (const [parentVal, childVal, isLeft] of descriptions) {
        // Get or create parent and child nodes
        const parentNode = getOrCreateNode(parentVal);
        const childNode = getOrCreateNode(childVal);
        
        // Link child to parent based on isLeft flag
        if (isLeft === 1) {
            parentNode.left = childNode;
        } else {
            parentNode.right = childNode;
        }
        
        // Mark this child value as having a parent
        childrenSet.add(childVal);
    }
    
    // Step 2: Find the root
    // The root is a value that appears as parent but never as child
    for (const [parentVal] of descriptions) {
        if (!childrenSet.has(parentVal)) {
            return nodeMap.get(parentVal)!;
        }
    }
    
    return null;
};
```

## Solution 4: Single Pass with Root Tracking

```typescript
function createBinaryTree(descriptions: number[][]): TreeNode | null {
    const nodeMap = new Map<number, TreeNode>();
    const hasParent = new Set<number>();
    let root: number = -1;
    
    for (const [parentVal, childVal, isLeft] of descriptions) {
        if (!nodeMap.has(parentVal)) {
            nodeMap.set(parentVal, new TreeNode(parentVal));
        }
        if (!nodeMap.has(childVal)) {
            nodeMap.set(childVal, new TreeNode(childVal));
        }
        
        const parentNode = nodeMap.get(parentVal)!;
        const childNode = nodeMap.get(childVal)!;
        
        if (isLeft === 1) {
            parentNode.left = childNode;
        } else {
            parentNode.right = childNode;
        }
        
        hasParent.add(childVal);
    }
    
    // Find the root by checking all node values
    for (const val of nodeMap.keys()) {
        if (!hasParent.has(val)) {
            root = val;
            break;
        }
    }
    
    return root !== -1 ? nodeMap.get(root)! : null;
};

```

# Visual Representation

## Building Process

```
Step 1: Create nodes as needed
  Map: {} → {20: Node(20)} → {20: Node(20), 15: Node(15)}

Step 2: Link nodes based on isLeft
  node20.left = node15
  
Step 3: Track children
  childrenSet: {} → {15} → {15, 17} → ...

Step 4: Find root
  Root = parent value NOT in childrenSet
```

## Why This Approach Works

```
Every node except root appears as a child exactly once
Root never appears as a child (it's the topmost node)

By tracking all children in a Set,
we can identify the root by elimination:
  Root = any parent value NOT in the children set
```

# Key Insights

1. **Map for $O(1)$ access:** Efficiently create/retrieve nodes by value
2. **Set for children tracking:** Quickly check if a value has a parent
3. **Root identification:** The value that's never a child is the root
4. **Single pass construction:** Build entire tree structure in one iteration
5. **Lazy node creation:** Only create nodes when first encountered

# Edge Cases

| Case | Description | Handling |
|------|-------------|----------|
| Single edge | One parent-child pair | Works correctly |
| Deep tree | Long chain of nodes | No issues, iterative approach |
| Multiple children | Parent with left and right | Handled by separate descriptions |
| Large values | Values up to $10^5$ | Map handles any number range |

---

# Common Mistakes to Avoid

1. **Not creating nodes before linking:**
   ```typescript
   // Wrong: might reference undefined node
   parentNode.left = nodeMap.get(childVal);
   
   // Correct: ensure node exists first
   const childNode = getOrCreateNode(childVal);
   parentNode.left = childNode;
   ```

2. **Incorrect root-finding logic:**
   ```typescript
   // Wrong: checking child appears in parent list
   for (const [p, c] of descriptions) {
       if (childrenSet.has(p)) return nodeMap.get(p);
   }
   
   // Correct: find parent NOT in children set
   if (!childrenSet.has(parentVal)) {
       return nodeMap.get(parentVal);
   }
   ```

3. **Forgetting to handle duplicate node creation:**
   ```typescript
   // Wrong: always creates new node
   nodeMap.set(val, new TreeNode(val));
   
   // Correct: check existence first
   if (!nodeMap.has(val)) {
       nodeMap.set(val, new TreeNode(val));
   }
   ```
