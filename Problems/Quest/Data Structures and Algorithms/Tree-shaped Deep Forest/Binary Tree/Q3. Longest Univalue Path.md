# Intuition

We need to find the longest path where all nodes have the **same value**. The path can go through any node and doesn't need to pass through the root, but it must follow parent-child edges (it can go down-left then down-right through a common ancestor).

**Key insight:** For each node, calculate the longest "arm" (single direction path) extending downward with the same value. The longest path through a node is the sum of its left and right arms (if they match the node's value).

**Approach:** Use **DFS (post-order traversal)** to compute the longest univalue path ending at each node, and track the global maximum by combining left and right arms at each node.

---

# Approach

1. **DFS traversal:** For each node, recursively find the longest univalue arm length from left and right children
2. **Check value match:** Only extend the arm if child's value equals current node's value
3. **Calculate path through node:** Combine left arm + right arm (if both match current node's value)
4. **Update global maximum:** Track the maximum path length seen so far
5. **Return arm length:** Return the longer of left/right arm (that matches current value) to parent, plus 1

**Formula for each node:**
- `leftArm` = left child's arm length + 1 (if left child's value == node's value, else 0)
- `rightArm` = right child's arm length + 1 (if right child's value == node's value, else 0)
- **Path through this node** = `leftArm + rightArm`
- **Arm returned to parent** = `max(leftArm, rightArm)`

---

# Complexity

**Time Complexity:** $O(n)$
- Visit each node exactly once in DFS traversal

**Space Complexity:** $O(h)$
- h is the height of the tree (recursion stack)
- Worst case $O(n)$ for skewed tree, $O(log n)$ for balanced tree

# Code

## Solution 1: DFS with Global Variable (Recommended)

```typescript
function longestUnivaluePath(root: TreeNode | null): number {
    let maxLength = 0;
    
    function dfs(node: TreeNode | null): number {
        if (!node) return 0;
        
        // Get arm lengths from left and right subtrees
        const leftArm = dfs(node.left);
        const rightArm = dfs(node.right);
        
        // Calculate actual arm lengths based on value match
        let leftPath = 0;
        let rightPath = 0;
        
        if (node.left && node.left.val === node.val) {
            leftPath = leftArm + 1;
        }
        
        if (node.right && node.right.val === node.val) {
            rightPath = rightArm + 1;
        }
        
        // Update global maximum (path through this node)
        maxLength = Math.max(maxLength, leftPath + rightPath);
        
        // Return longer arm to parent
        return Math.max(leftPath, rightPath);
    }
    
    dfs(root);
    return maxLength;
};

```

## Solution 2: With Detailed Comments

```typescript
function longestUnivaluePath(root: TreeNode | null): number {
    // Track the maximum path length found so far
    let maxLength = 0;
    
    // DFS function returns the longest arm (single direction path)
    // extending from this node with the same value as this node
    function dfs(node: TreeNode | null): number {
        // Base case: null node has arm length 0
        if (!node) {
            return 0;
        }
        
        // Recursively get arm lengths from children
        const leftArmLength = dfs(node.left);
        const rightArmLength = dfs(node.right);
        
        // Calculate extended arm length only if values match
        let leftPath = 0;
        if (node.left !== null && node.left.val === node.val) {
            leftPath = leftArmLength + 1;
        }
        
        let rightPath = 0;
        if (node.right !== null && node.right.val === node.val) {
            rightPath = rightArmLength + 1;
        }
        
        // The path through current node combines both arms
        // This represents a path that goes left-down then right-down
        const pathThroughNode = leftPath + rightPath;
        maxLength = Math.max(maxLength, pathThroughNode);
        
        // Return the longer single arm to parent
        // (parent can only extend one direction, not both)
        return Math.max(leftPath, rightPath);
    }
    
    dfs(root);
    return maxLength;
};

```

```typescript
function longestUnivaluePath(root: TreeNode | null): number {

        if (!node) return 0;
        
        const leftArm = dfs(node.left);

        return Math.max(leftPath, rightPath);
    }
    
    dfs(root);
    return result.maxLength;
};

```

## Solution 4: Compact Version

```typescript
function longestUnivaluePath(root: TreeNode | null): number {
    let max = 0;
    
    const dfs = (node: TreeNode | null): number => {
        if (!node) return 0;
        
        const left = dfs(node.left);
        const right = dfs(node.right);
        
        const l = node.left?.val === node.val ? left + 1 : 0;
        const r = node.right?.val === node.val ? right + 1 : 0;
        
        max = Math.max(max, l + r);
        
        return Math.max(l, r);
    };
    
    dfs(root);
    return max;
};

```

# Example Walkthrough

## Example 1: `root = [5,4,5,1,1,null,5]`

### Tree Structure

```
            5
           / \
          4 5
         / \ \
        1 1 5
```

### DFS Traversal (Post-order: process children before parent)

```
Step 1: Process leftmost leaf (node with val=1, left child of 4)
  dfs(node=1, leftmost)
    left = dfs(null) = 0
    right = dfs(null) = 0
    leftPath = 0 (no left child)
    rightPath = 0 (no right child)
    maxLength = max(0, 0+0) = 0
    return max(0, 0) = 0

Step 2: Process second leaf (node with val=1, right child of 4)
  dfs(node=1, second)
    Similarly returns 0
    maxLength remains 0

Step 3: Process node with val=4 (left child of root)
  dfs(node=4)
    leftArm = dfs(left child, val=1) = 0
    rightArm = dfs(right child, val=1) = 0
    
    Check left: node.left.val(1) === node.val(4)? No
    leftPath = 0
    
    Check right: node.right.val(1) === node.val(4)? No
    rightPath = 0
    
    maxLength = max(0, 0+0) = 0
    return max(0, 0) = 0

Step 4: Process rightmost leaf (node with val=5, right child of right 5)
  dfs(node=5, rightmost)
    left = dfs(null) = 0
    right = dfs(null) = 0
    leftPath = 0
    rightPath = 0
    maxLength remains 0
    return 0

Step 5: Process node with val=5 (right child of root)
  dfs(node=5, right subtree)
    leftArm = dfs(null) = 0 (no left child)
    rightArm = dfs(rightmost 5) = 0
    
    leftPath = 0 (no left child)
    
    Check right: node.right.val(5) === node.val(5)? Yes!
    rightPath = rightArm + 1 = 0 + 1 = 1
    
    maxLength = max(0, 0+1) = 1
    return max(0, 1) = 1

Step 6: Process root (val=5)
  dfs(root, val=5)
    leftArm = dfs(node=4) = 0 (from step 3)
    rightArm = dfs(node=5, right subtree) = 1 (from step 5)
    
    Check left: node.left.val(4) === node.val(5)? No
    leftPath = 0
    
    Check right: node.right.val(5) === node.val(5)? Yes!
    rightPath = rightArm + 1 = 1 + 1 = 2
    
    maxLength = max(1, 0+2) = 2
    return max(0, 2) = 2

Final maxLength = 2
```

**Visual representation of the path:**
```
            5
             \
              5
               \
                5

Path: 5 → 5 → 5 (using right subtree)
Length: 2 edges
```

**Output:** `2`

# Visual Representation

## DFS Arm Calculation Concept

```
For each node, calculate:

        node(val=X)
         / \
    left(Y) right(Z)

If Y === X: leftPath = leftArm + 1
If Z === X: rightPath = rightArm + 1

Path through node = leftPath + rightPath
Arm returned to parent = max(leftPath, rightPath)
```

## Why We Track Both Path-Through and Arm-Length

```
Path through node (for global max):
  Represents a path like: left-subtree → node → right-subtree
  This is a "peak" path that can't be extended further up

Arm length (returned to parent):
  Represents only ONE direction extension
  Parent can only continue in one direction (either through
  this node's left or right, not both, since parent-node-child
  is a single path direction)
```

---

# Key Insights

1. **Two different values tracked:** Path through node (for answer) vs arm length (for recursion)
2. **Value matching required:** Arm only extends if child value matches current node value
3. **Post-order traversal:** Must process children before parent to get their arm lengths
4. **Global maximum tracking:** Path through any node could be the answer, not just root
5. **Return value is asymmetric:** Return single arm (max of left/right) but calculate answer using sum

# Edge Cases

| Case | Input | Output | Explanation |
|------|-------|--------|-------------|
| Empty tree | `null` | 0 | No nodes, no path |
| Single node | `[5]` | 0 | No edges possible |
| All same value | `[5,5,5,5]` | Varies | Entire tree matches |
| No matching values | `[1,2,3]` | 0 | No two adjacent nodes match |
| Path through root | `[5,5,5]` | 2 | Root connects two matching children |

# Common Mistakes to Avoid

1. **Not checking null before accessing value:**
   ```typescript
   // Wrong: might throw error on null
   if (node.left.val === node.val) { ... }
   
   // Correct: check null first
   if (node.left && node.left.val === node.val) { ... }
   ```

2. **Confusing path-through-node with arm-length:**
   ```typescript
   // Wrong: returning sum instead of max
   return leftPath + rightPath;
   
   // Correct: return max (single direction)
   return Math.max(leftPath, rightPath);
   ```

3. **Not updating global max at every node:**
   ```typescript
   // Wrong: only checking at root
   if (node === root) {
       maxLength = leftPath + rightPath;
   }
   
   // Correct: check at every node
   maxLength = Math.max(maxLength, leftPath + rightPath);
   ```

4. **Resetting arm length incorrectly:**
   ```typescript
   // Wrong: always adding 1 regardless of value match
   const leftPath = leftArm + 1;
   
   // Correct: only add 1 if values match
   const leftPath = (node.left && node.left.val === node.val) 
                     ? leftArm + 1 : 0;
   ```
