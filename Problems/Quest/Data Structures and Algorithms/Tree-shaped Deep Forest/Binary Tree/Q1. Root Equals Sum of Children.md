# Intuition

This is a straightforward problem where we need to check if the **root's value equals the sum of its two children's values**. Since the tree is guaranteed to have exactly 3 nodes (root, left child, right child), we simply need to compare `root.val` with `root.left.val + root.right.val`.

---

# Approach

1. Access the root's value
2. Access the left child's value
3. Access the right child's value
4. Check if root value equals sum of children values
5. Return the boolean result

---

# Complexity

- **Time Complexity:** $O(1)$ - constant time, just accessing 3 values and comparing
- **Space Complexity:** $O(1)$ - no additional space needed

---

# Code

## Solution 1: Simple One-Liner

```typescript
function checkTree(root: TreeNode | null): boolean {
    return root!.val === root!.left!.val + root!.right!.val;
};

```

---

## Solution 2: With Explicit Null Checks (Safer)

```typescript
function checkTree(root: TreeNode | null): boolean {
    if (!root || !root.left || !root.right) {
        return false;
    }
    
    return root.val === root.left.val + root.right.val;
};

```

---

## Solution 3: With Detailed Comments

```typescript
function checkTree(root: TreeNode | null): boolean {
    // Since the tree always has exactly 3 nodes (root, left, right)
    // we can safely access these properties
    
    const rootValue = root!.val;
    const leftValue = root!.left!.val;
    const rightValue = root!.right!.val;
    
    // Check if root equals sum of children
    return rootValue === leftValue + rightValue;
};

```

# Key Insights

- **Guaranteed structure:** Since the tree always has exactly 3 nodes, we can safely use non-null assertions (`!`) or add simple checks
- **Simple comparison:** No traversal needed, just direct value comparison
- **Edge case handling:** Values can be negative (-100 to 100), but the comparison logic remains the same

---

# Recommended Solution

**Use Solution 2 (With Null Checks)** for production code as it's safer and handles edge cases gracefully, even though the problem guarantees the tree structure.

**Use Solution 1** if you're confident about the input constraints and want the most concise code (common in competitive programming).
