# Intuition

We need to support two operations efficiently: **point updates** (changing a single value) and **range sum queries** (getting sum between two indices). A naive approach would use $O(n)$ for either update or query, but we need something better for large inputs with many queries.

**Key insight:** Use a **Binary Indexed Tree (Fenwick Tree)** or **Segment Tree** to achieve $O(log n)$ time complexity for both operations, making the solution efficient even with 3×10⁴ queries.

---

# Approach

## Binary Indexed Tree (Fenwick Tree) Strategy

1. **Build the tree:** Initialize a BIT array of size `n+1` and add each element using the update operation
2. **Update operation:** When updating index `i` to value `val`:
   - Calculate the difference: `diff = val - nums[i]`
   - Propagate this difference through the BIT using the "add" operation
   - Update the original array to reflect new value
3. **Range sum query:** Use prefix sum technique:
   - `sumRange(left, right) = prefixSum(right) - prefixSum(left - 1)`
   - Calculate prefix sum using BIT's query operation

**Why BIT works:**
- Each index in BIT represents a range based on its binary representation
- Update propagates changes to all ranges containing that index: $O(log n)$
- Query aggregates from an index down to 0: $O(log n)$

---

# Complexity

**Time Complexity:**
- **Constructor:** O(n log n) - building the tree with n updates
- **update:** $O(log n)$ - single update operation
- **sumRange:** $O(log n)$ - two prefix sum queries

**Space Complexity:** $O(n)$
- BIT array of size n+1
- Original array to track current values

# Code

## Solution 1: Binary Indexed Tree (Fenwick Tree) - Recommended

```typescript
class NumArray {
    private nums: number[];
    private tree: number[];
    private n: number;

    constructor(nums: number[]) {
        this.n = nums.length;
        this.nums = new Array(this.n).fill(0);
        this.tree = new Array(this.n + 1).fill(0);
        
        for (let i = 0; i < this.n; i++) {
            this.update(i, nums[i]);
        }
    }

    update(index: number, val: number): void {
        const diff = val - this.nums[index];
        this.nums[index] = val;
        
        // Update BIT: propagate difference to all relevant ranges
        for (let i = index + 1; i <= this.n; i += i & (-i)) {
            this.tree[i] += diff;
        }
    }

    private prefixSum(index: number): number {
        let sum = 0;
        
        // Traverse BIT from index down to 0
        for (let i = index + 1; i > 0; i -= i & (-i)) {
            sum += this.tree[i];
        }
        
        return sum;
    }

    sumRange(left: number, right: number): number {
        return this.prefixSum(right) - this.prefixSum(left - 1);
    }
};

```

## Solution 2: With Detailed Comments

```typescript
class NumArray {
    private nums: number[]; // Store current values
    private tree: number[]; // Binary Indexed Tree (1-indexed)
    private n: number;

    constructor(nums: number[]) {
        this.n = nums.length;
        this.nums = new Array(this.n).fill(0);
        this.tree = new Array(this.n + 1).fill(0);
        
        // Build the tree by updating each element
        for (let i = 0; i < this.n; i++) {
            this.update(i, nums[i]);
        }
    }

    update(index: number, val: number): void {
        // Calculate the difference to propagate
        const diff = val - this.nums[index];
        this.nums[index] = val;
        
        // Update BIT: add diff to all ranges that include this index
        // Convert to 1-indexed for BIT operations
        let i = index + 1;
        
        while (i <= this.n) {
            this.tree[i] += diff;
            // Move to next range using lowbit trick
            i += i & (-i);
        }
    }

    private prefixSum(index: number): number {
        // Calculate sum from index 0 to index (inclusive)
        let sum = 0;
        let i = index + 1; // Convert to 1-indexed
        
        while (i > 0) {
            sum += this.tree[i];
            // Move to parent range using lowbit trick
            i -= i & (-i);
        }
        
        return sum;
    }

    sumRange(left: number, right: number): number {
        // Range sum = prefixSum(right) - prefixSum(left-1)
        return this.prefixSum(right) - this.prefixSum(left - 1);
    }
};

```

## Solution 3: Segment Tree Alternative

```typescript
class NumArray {
    private tree: number[];
    private n: number;

    constructor(nums: number[]) {
        this.n = nums.length;
        this.tree = new Array(2 * this.n).fill(0);
        
        // Build tree: leaves are at [n, 2n-1]
        for (let i = 0; i < this.n; i++) {
            this.tree[this.n + i] = nums[i];
        }
        
        // Build internal nodes
        for (let i = this.n - 1; i > 0; i--) {
            this.tree[i] = this.tree[2 * i] + this.tree[2 * i + 1];
        }
    }

    update(index: number, val: number): void {
        let pos = index + this.n;
        this.tree[pos] = val;
        
        // Update ancestors
        while (pos > 1) {
            pos = Math.floor(pos / 2);
            this.tree[pos] = this.tree[2 * pos] + this.tree[2 * pos + 1];
        }
    }

    sumRange(left: number, right: number): number {
        let l = left + this.n;
        let r = right + this.n + 1;
        let sum = 0;
        
        while (l < r) {
            if (l % 2 === 1) {
                sum += this.tree[l];
                l++;
            }
            if (r % 2 === 1) {
                r--;
                sum += this.tree[r];
            }
            l = Math.floor(l / 2);
            r = Math.floor(r / 2);
        }
        
        return sum;
    }
};

```

## Solution 4: Compact BIT Version

```typescript
class NumArray {
    private nums: number[];
    private tree: number[];
    private n: number;

    constructor(nums: number[]) {
        this.n = nums.length;
        this.nums = new Array(this.n).fill(0);
        this.tree = new Array(this.n + 1).fill(0);
        nums.forEach((val, i) => this.update(i, val));
    }

    update(index: number, val: number): void {
        const diff = val - this.nums[index];
        this.nums[index] = val;
        for (let i = index + 1; i <= this.n; i += i & (-i)) {
            this.tree[i] += diff;
        }
    }

    sumRange(left: number, right: number): number {
        const query = (idx: number): number => {
            let sum = 0;
            for (let i = idx + 1; i > 0; i -= i & (-i)) sum += this.tree[i];
            return sum;
        };
        return query(right) - query(left - 1);
    }
};

```

# Example Walkthrough

## Example 1: `nums = [1, 3, 5]`

### Constructor: Build BIT

```
n = 3
Initial tree = [0, 0, 0, 0] (1-indexed, size n+1=4)
Initial nums = [0, 0, 0]

Update(0, 1): Set nums[0] = 1
  diff = 1 - 0 = 1
  nums[0] = 1
  
  BIT update: i = 0 + 1 = 1
    tree[1] += 1 → tree[1] = 1
    i += (1 & -1) = 1 + 1 = 2
    tree[2] += 1 → tree[2] = 1
    i += (2 & -2) = 2 + 2 = 4
    i > n(3), stop
  
  tree = [0, 1, 1, 0]

Update(1, 3): Set nums[1] = 3
  diff = 3 - 0 = 3
  nums[1] = 3
  
  BIT update: i = 1 + 1 = 2
    tree[2] += 3 → tree[2] = 4
    i += (2 & -2) = 2 + 2 = 4
    i > n(3), stop
  
  tree = [0, 1, 4, 0]

Update(2, 5): Set nums[2] = 5
  diff = 5 - 0 = 5
  nums[2] = 5
  
  BIT update: i = 2 + 1 = 3
    tree[3] += 5 → tree[3] = 5
    i += (3 & -3) = 3 + 1 = 4
    i > n(3), stop
  
  tree = [0, 1, 4, 5]

Final state:
  nums = [1, 3, 5]
  tree = [0, 1, 4, 5]
```

### Visual BIT Structure

```
tree[1] = nums[0] = 1
tree[2] = nums[0] + nums[1] = 1 + 3 = 4
tree[3] = nums[2] = 5

Tree represents:
  Index 1: covers range [0,0]
  Index 2: covers range [0,1]
  Index 3: covers range [2,2]
```

### Query 1: `sumRange(0, 2)`

```
sumRange(0, 2) = prefixSum(2) - prefixSum(-1)

prefixSum(2):
  i = 2 + 1 = 3
  sum = 0
  
  Iteration 1: i=3
    sum += tree[3] = 5
    sum = 5
    i -= (3 & -3) = 3 - 1 = 2
  
  Iteration 2: i=2
    sum += tree[2] = 4
    sum = 9
    i -= (2 & -2) = 2 - 2 = 0
  
  i = 0, stop
  Return sum = 9

prefixSum(-1):
  i = -1 + 1 = 0
  i = 0, loop doesn't execute
  Return sum = 0

sumRange(0, 2) = 9 - 0 = 9
```

**Output:** `9` ✓ (1 + 3 + 5 = 9)

---

### Operation: `update(1, 2)`

```
Update index 1 to value 2

diff = 2 - nums[1] = 2 - 3 = -1
nums[1] = 2

BIT update: i = 1 + 1 = 2
  tree[2] += (-1) → tree[2] = 4 + (-1) = 3
  i += (2 & -2) = 2 + 2 = 4
  i > n(3), stop

Updated tree = [0, 1, 3, 5]
Updated nums = [1, 2, 5]
```

---

### Query 2: `sumRange(0, 2)` (after update)

```
sumRange(0, 2) = prefixSum(2) - prefixSum(-1)

prefixSum(2):
  i = 3
  sum = 0
  
  Iteration 1: i=3
    sum += tree[3] = 5
    sum = 5
    i = 2
  
  Iteration 2: i=2
    sum += tree[2] = 3
    sum = 8
    i = 0
  
  Return sum = 8

prefixSum(-1) = 0 (as before)

sumRange(0, 2) = 8 - 0 = 8
```

**Output:** `8` ✓ (1 + 2 + 5 = 8)

# Visual Representation

## Binary Indexed Tree Structure

```
Array: [1, 2, 5] (after update)
Index: 0 1 2

BIT (1-indexed):
  tree[1] = nums[0]
  tree[2] = nums[0] + nums[1]
  tree[3] = nums[2]

Visual tree:
       tree[2]
      /
  tree[1]
  
  tree[3] (separate branch)

This allows $O(log n)$ updates and queries by
following the binary representation of indices
```

## Update Operation (Lowbit Trick)

```
To update index i (1-indexed), we add to:
  i, i + lowbit(i), i + lowbit(i) + lowbit(next), ...

Where lowbit(x) = x & (-x) [isolates rightmost set bit]

Example: Update index 1
  i=1: tree[1] += diff
  i=1+1=2: tree[2] += diff
  i=2+2=4: stop (exceeds n)
```

## Query Operation (Lowbit Trick)

```
To get prefix sum up to index i (1-indexed):
  i, i - lowbit(i), i - lowbit(i) - lowbit(next), ...

Example: Query prefix sum up to index 3
  i=3: sum += tree[3]
  i=3-1=2: sum += tree[2]
  i=2-2=0: stop
```

# Key Insights

1. **BIT enables $O(log n)$ operations:** Both update and query use the binary representation trick
2. **Lowbit trick is essential:** `i & (-i)` isolates the rightmost set bit, determining range size
3. **1-indexed internally:** BIT typically uses 1-indexing to simplify bit operations
4. **Difference-based updates:** Track the change (diff) rather than absolute value for efficient propagation
5. **Prefix sum technique:** Range sum = prefixSum(right) - prefixSum(left-1)

# Edge Cases

| Case | Scenario | Handling |
|------|----------|----------|
| Single element | `nums = [5]` | BIT with size 2, works correctly |
| Update same value | `update(i, nums[i])` | diff = 0, no actual change needed |
| Query entire array | `sumRange(0, n-1)` | Standard prefix sum calculation |
| Query single element | `sumRange(i, i)` | prefixSum(i) - prefixSum(i-1) |
| Negative values | `val = -100` | BIT handles negative numbers correctly |

# Common Mistakes to Avoid

1. **Forgetting to update nums array:**
   ```typescript
   // Wrong: only updating BIT, not tracking current value
   update(index, val) {
       const diff = val - oldValue; // oldValue unknown!
   }
   
   // Correct: maintain nums array
   const diff = val - this.nums[index];
   this.nums[index] = val;
   ```

2. **Incorrect lowbit calculation:**
   ```typescript
   // Wrong: incorrect bit manipulation
   i += i & i; // This doesn't isolate lowest bit
   
   // Correct: use two's complement trick
   i += i & (-i);
   ```

3. **Off-by-one indexing errors:**
   ```typescript
   // Wrong: forgetting to convert to 1-indexed
   for (let i = index; i <= n; i += i & (-i)) { ... }
   
   // Correct: convert 0-indexed to 1-indexed
   for (let i = index + 1; i <= n; i += i & (-i)) { ... }
   ```

4. **Not handling left=0 case in sumRange:**
   ```typescript
   // Wrong: might access negative index incorrectly
   return prefixSum(right) - prefixSum(left - 1);
   // When left=0, prefixSum(-1) should return 0
   
   // Correct: prefixSum(-1) naturally returns 0 due to loop condition
   // i = -1 + 1 = 0, loop "i > 0" doesn't execute
   ```
