# Intuition

We need to allow **double bookings** but prevent **triple bookings**. The key insight is to track **overlapping intervals** where a double-booking already exists. If a new event would overlap with an existing double-booked region, it would create a triple booking, so we must reject it.

**Strategy:** Maintain two lists:
1. **All booked events** (single or double bookings)
2. **Double-booked regions** (overlaps between any two existing events)

When adding a new event, check if it overlaps with any double-booked region. If yes, reject it. Otherwise, add it and update the double-booked regions with any new overlaps created.

---

# Approach

1. **Maintain two arrays:**
   - `bookings`: All events added so far
   - `overlaps`: Regions where two events already overlap (double-booked)

2. **For each new booking request `[start, end]`:**
   - **Check against overlaps:** If `[start, end]` intersects with any existing double-booked region, return `false` (would cause triple booking)
   - **If safe:** Calculate new overlaps between this event and all existing bookings, add these to `overlaps`
   - **Add the event** to `bookings`
   - Return `true`

3. **Overlap calculation:** Two intervals `[s1, e1]` and `[s2, e2]` overlap if `max(s1, s2) < min(e1, e2)`, and the overlap region is `[max(s1, s2), min(e1, e2))`

---

# Complexity

**Time Complexity:** $O(n)$ per booking call
- Checking against overlaps: $O(n)$
- Checking against bookings to find new overlaps: $O(n)$
- Overall: $O(n)$ per call, $O(n²)$ for n total calls

**Space Complexity:** $O(n)$
- Storing bookings and overlaps

For n ≤ 1000, this gives $O(n²) = 10^6$ operations, which is very efficient.

# Code

## Solution 1: Track Bookings and Overlaps (Recommended)

```typescript
class MyCalendarTwo {
    private bookings: number[][];
    private overlaps: number[][];

    constructor() {
        this.bookings = [];
        this.overlaps = [];
    }

    book(startTime: number, endTime: number): boolean {
        // Check if this would cause a triple booking
        for (const [oStart, oEnd] of this.overlaps) {
            if (startTime < oEnd && oStart < endTime) {
                return false;
            }
        }
        
        // Find new overlaps with existing bookings
        for (const [bStart, bEnd] of this.bookings) {
            const overlapStart = Math.max(startTime, bStart);
            const overlapEnd = Math.min(endTime, bEnd);
            
            if (overlapStart < overlapEnd) {
                this.overlaps.push([overlapStart, overlapEnd]);
            }
        }
        
        // Add the new booking
        this.bookings.push([startTime, endTime]);
        
        return true;
    }
};

```

## Solution 2: With Detailed Comments

```typescript
class MyCalendarTwo {
    private bookings: number[][]; // All events (single or double booked)
    private overlaps: number[][]; // Regions that are already double-booked

    constructor() {
        this.bookings = [];
        this.overlaps = [];
    }

    book(startTime: number, endTime: number): boolean {
        // Step 1: Check if adding this event would cause a triple booking
        // This happens if the new event overlaps with any existing 
        // double-booked region
        for (const [overlapStart, overlapEnd] of this.overlaps) {
            // Two intervals overlap if start of one is before end of other
            if (startTime < overlapEnd && overlapStart < endTime) {
                // Would create a triple booking, reject
                return false;
            }
        }
        
        // Step 2: Safe to add - find new double-booking overlaps
        // Check against all existing single/double bookings
        for (const [existingStart, existingEnd] of this.bookings) {
            const newOverlapStart = Math.max(startTime, existingStart);
            const newOverlapEnd = Math.min(endTime, existingEnd);
            
            // If there's a valid overlap (non-empty intersection)
            if (newOverlapStart < newOverlapEnd) {
                // This region will now be double-booked
                this.overlaps.push([newOverlapStart, newOverlapEnd]);
            }
        }
        
        // Step 3: Add the new event to bookings
        this.bookings.push([startTime, endTime]);
        
        return true;
    }
};

```

## Solution 3: Using Difference Array / Sweep Line (Alternative)

```typescript
class MyCalendarTwo {
    private events: Map<number, number>;

    constructor() {
        this.events = new Map();
    }

    book(startTime: number, endTime: number): boolean {
        // Increment at start, decrement at end
        this.events.set(startTime, (this.events.get(startTime) || 0) + 1);
        this.events.set(endTime, (this.events.get(endTime) || 0) - 1);
        
        // Check if any point has count > 2
        let count = 0;
        const sortedKeys = Array.from(this.events.keys()).sort((a, b) => a - b);
        
        for (const key of sortedKeys) {
            count += this.events.get(key)!;
            if (count > 2) {
                // Rollback the changes
                this.events.set(startTime, this.events.get(startTime)! - 1);
                this.events.set(endTime, this.events.get(endTime)! + 1);
                return false;
            }
        }
        
        return true;
    }
};

```

## Solution 4: Compact Version

```typescript
class MyCalendarTwo {
    private bookings: number[][] = [];
    private overlaps: number[][] = [];

    book(startTime: number, endTime: number): boolean {
        for (const [s, e] of this.overlaps) {
            if (startTime < e && s < endTime) return false;
        }
        
        for (const [s, e] of this.bookings) {
            const os = Math.max(startTime, s);
            const oe = Math.min(endTime, e);
            if (os < oe) this.overlaps.push([os, oe]);
        }
        
        this.bookings.push([startTime, endTime]);
        return true;
    }
};

```

## Overlap Detection Logic

```
Two intervals [s1,e1) and [s2,e2) overlap if:
  max(s1,s2) < min(e1,e2)

This means there's a non-empty intersection region:
  [max(s1,s2), min(e1,e2))
```

# Key Insights

1. **Track double-bookings explicitly:** By maintaining an `overlaps` array, we can quickly check if a new event would create a triple booking
2. **Half-open intervals matter:** Using `<` instead of `<=` correctly handles boundary cases (e.g., [5,10) and [10,20) don't overlap)
3. **Incremental overlap calculation:** Each new booking only needs to check against existing bookings to find new overlaps, not recalculate everything
4. **Two-phase approach:** First check for conflicts, then safely add and update overlap tracking

# Edge Cases

| Case | Example | Result | Explanation |
|------|---------|--------|-------------|
| No overlap | `[0,5]` then `[10,15]` | Both true | Completely separate |
| Exact boundary | `[5,10]` then `[10,15]` | Both true | Half-open interval, no overlap |
| Full overlap | `[0,10]` then `[0,10]` | Both true (double) | Same interval, creates double-booking |
| Triple booking attempt | Three overlapping same region | Third rejected | Prevents triple booking |
| Partial overlaps | Various overlapping patterns | Depends | Only rejects if triple booking would occur |

# Common Mistakes to Avoid

1. **Using <= instead of < for overlap check:**
   ```typescript
   // Wrong: incorrectly treats touching intervals as overlapping
   if (startTime <= oEnd && oStart <= endTime) { ... }
   
   // Correct: half-open intervals use strict inequality
   if (startTime < oEnd && oStart < endTime) { ... }
   ```

2. **Not checking overlaps before adding new overlaps:**
   ```typescript
   // Wrong: adding overlaps before checking for triple booking
   // This could add invalid overlaps that shouldn't exist
   
   // Correct: check first, then add if safe
   ```

3. **Forgetting to calculate overlap region correctly:**
   ```typescript
   // Wrong: incorrect overlap calculation
   const overlap = [startTime, bEnd]; // Not necessarily correct
   
   // Correct: use max/min to get actual overlap region
   const overlapStart = Math.max(startTime, bStart);
   const overlapEnd = Math.min(endTime, bEnd);
   ```
