# Intuition

We need to insert a new value into a **Binary Search Tree (BST)** while maintaining its BST property. Since we're guaranteed the value doesn't already exist, we simply need to find the correct **leaf position** where the new node should be placed.

**Key insight:** Using the BST property (left < root < right), we can navigate to find the correct empty spot. When we reach a null position where the new value should go, we simply create a new node there.

---

# Approach

1. **Base case:** If `root` is null, create and return a new `TreeNode` with the given value (this is our insertion point)
2. **Compare values:**
   - If `val < root.val`: recursively insert into the **left subtree**
   - If `val > root.val`: recursively insert into the **right subtree**
3. **Update pointers:** Assign the result of recursive call back to `root.left` or `root.right`
4. **Return root:** Return the (possibly unchanged) root node

This can be implemented either **recursively** or **iteratively**.

---

# Complexity

**Time Complexity:** $O(H)$
- $H$ is the height of the tree
- $O(log n)$ for balanced BST
- $O(n)$ for skewed BST (worst case)

**Space Complexity:**
- **Recursive:** $O(H)$ for recursion stack
- **Iterative:** $O(1)$ - no extra space needed

# Code

## Solution 1: Recursive Approach (Clean and Intuitive)

```typescript
function insertIntoBST(root: TreeNode | null, val: number): TreeNode | null {
    if (root === null) {
        return new TreeNode(val);
    }
    
    if (val < root.val) {
        root.left = insertIntoBST(root.left, val);
    } else {
        root.right = insertIntoBST(root.right, val);
    }
    
    return root;
};

```

## Solution 2: Iterative Approach ($O(1)$ Space)

```typescript
function insertIntoBST(root: TreeNode | null, val: number): TreeNode | null {
    const newNode = new TreeNode(val);
    
    if (root === null) {
        return newNode;
    }
    
    let current = root;
    
    while (true) {
        if (val < current.val) {
            if (current.left === null) {
                current.left = newNode;
                break;
            }
            current = current.left;
        } else {
            if (current.right === null) {
                current.right = newNode;
                break;
            }
            current = current.right;
        }
    }
    
    return root;
};

```

---

## Solution 3: With Detailed Comments

```typescript
function insertIntoBST(root: TreeNode | null, val: number): TreeNode | null {
    // Base case: found the position to insert (empty spot)
    if (root === null) {
        return new TreeNode(val);
    }
    
    // BST property: if val is smaller, go left
    if (val < root.val) {
        // Recursively insert into left subtree
        // and update the left pointer with the result
        root.left = insertIntoBST(root.left, val);
    } 
    // If val is larger, go right
    else {
        // Recursively insert into right subtree
        // and update the right pointer with the result
        root.right = insertIntoBST(root.right, val);
    }
    
    // Return the root (unchanged reference, but subtree may have changed)
    return root;
};

```

## Solution 4: Compact Ternary Version

```typescript
function insertIntoBST(root: TreeNode | null, val: number): TreeNode | null {
    if (!root) return new TreeNode(val);
    
    if (val < root.val) {
        root.left = insertIntoBST(root.left, val);
    } else {
        root.right = insertIntoBST(root.right, val);
    }
    
    return root;
};

```

# Example Walkthrough

## Example 1: `root = [4,2,7,1,3], val = 5`

### Initial Tree Structure

```
        4
       / \
      2 7
     / \
    1 3
```

### Recursive Insertion Process

```
Call: insertIntoBST(node=4, val=5)
  root = 4, not null
  val(5) < root.val(4)? No
  Go right: root.right = insertIntoBST(node=7, val=5)

  Call: insertIntoBST(node=7, val=5)
    root = 7, not null
    val(5) < root.val(7)? Yes
    Go left: root.left = insertIntoBST(node=null, val=5)

    Call: insertIntoBST(node=null, val=5)
      root === null
      Create new TreeNode(5)
      Return TreeNode(5)

    Back in node=7 call:
    root.left = TreeNode(5)
    Return node=7 (now with left child = 5)

  Back in node=4 call:
  root.right = node=7 (updated)
  Return node=4 (root, now with right subtree updated)
```

### Final Tree Structure

```
        4
       / \
      2 7
     / \ /
    1 3 5

New node 5 inserted as left child of 7
```

**Output:** `[4,2,7,1,3,5]`

## Example 2: `root = [40,20,60,10,30,50,70], val = 25`

### Initial Tree Structure

```
              40
             / \
           20 60
          / \ / \
        10 30 50 70
```

### Iterative Insertion Process

```
newNode = TreeNode(25)
current = root (40)

Iteration 1:
  val(25) < current.val(40)? Yes
  current.left (20) is not null
  current = current.left = node(20)

Iteration 2:
  val(25) < current.val(20)? No
  current.right (30) is not null
  current = current.right = node(30)

Iteration 3:
  val(25) < current.val(30)? Yes
  current.left is null!
  current.left = newNode(25)
  Break loop
```

### Final Tree Structure

```
              40
             / \
           20 60
          / \ / \
        10 30 50 70
           /
          25

New node 25 inserted as left child of 30
```

**Output:** `[40,20,60,10,30,50,70,null,null,25]`

# Key Insights

1. **BST property guides insertion:** Compare with current node to decide left or right
2. **Null indicates insertion point:** When we reach null, that's where the new node belongs
3. **Recursive elegance:** Each recursive call returns the (possibly modified) subtree
4. **Pointer reassignment:** `root.left = insertIntoBST(...)` handles both insertion and connection
5. **Always insert as leaf:** New node always becomes a leaf node (no existing children)

---

# Edge Cases

| Case | Input | Output | Explanation |
|------|-------|--------|-------------|
| Empty tree | `root = null` | New single node | Root becomes the new node |
| Insert smaller than all | `val < min` | Leftmost position | Traverses left repeatedly |
| Insert larger than all | `val > max` | Rightmost position | Traverses right repeatedly |
| Insert in middle | `val` between existing | Correct BST position | Standard insertion logic |
| Single node tree | `root = [5], val = 3` | `[5,3]` | Simple left insertion |

---

# Common Mistakes to Avoid

1. **Not returning root properly:**
   ```typescript
   // Wrong: doesn't maintain tree structure
   function insertIntoBST(root, val) {
       if (val < root.val) {
           insertIntoBST(root.left, val); // Missing assignment!
       }
   }
   
   // Correct: assign result back to maintain structure
   root.left = insertIntoBST(root.left, val);
   ```

2. **Forgetting base case:**
   ```typescript
   // Wrong: will cause null reference error
   if (val < root.val) { ... }
   
   // Correct: check for null first
   if (root === null) return new TreeNode(val);
   if (val < root.val) { ... }
   ```

3. **Creating new node incorrectly:**
   ```typescript
   // Wrong: forgetting to set value
   return new TreeNode();
   
   // Correct: pass value to constructor
   return new TreeNode(val);
   ```

# Recommended Solution

**Use Solution 1 (Recursive)** for:
- Clean, intuitive code
- Easy to understand and maintain
- Naturally handles the insertion logic
- Preferred for interviews due to simplicity

**Use Solution 2 (Iterative)** for:
- $O(1)$ space complexity (no recursion stack)
- Better performance for very deep/skewed trees
- Avoids potential stack overflow for large inputs

> Both solutions are correct and efficient - the recursive approach is generally preferred for its clarity and elegance in solving BST problems!
