# Intuition

Deleting a node from a BST requires handling **three distinct cases** based on the node's children:
1. **No children (leaf node):** Simply remove it
2. **One child:** Replace the node with its child
3. **Two children:** Replace the node's value with its **in-order successor** (smallest value in right subtree) or **in-order predecessor** (largest value in left subtree), then delete that successor/predecessor

**Key insight:** We first **search** for the node using BST property, then **delete** it while maintaining the BST structure using the appropriate case.

---

# Approach

1. **Search phase:** Navigate using BST property (compare `key` with `root.val`)
   - If `key < root.val`: search left subtree
   - If `key > root.val`: search right subtree
   - If `key === root.val`: found the node to delete

2. **Deletion phase:** Once found, handle three cases:
   - **Case 1 - No children:** Return `null`
   - **Case 2 - One child:** Return the non-null child
   - **Case 3 - Two children:** 
     - Find the **in-order successor** (minimum value in right subtree)
     - Replace current node's value with successor's value
     - Recursively delete the successor from the right subtree

3. **Update pointers:** Assign the result back to maintain tree structure

---

# Complexity

**Time Complexity:** $O(H)$
- $H$ is the height of the tree
- $O(log n)$ for balanced BST
- $O(n)$ for skewed BST (worst case)
- Finding successor also takes $O(H)$ in the worst case, but overall still $O(H)$

**Space Complexity:** $O(H)$
- Recursion stack depth equals tree height

# Code

## Solution 1: Recursive with In-order Successor (Recommended)

```typescript
function deleteNode(root: TreeNode | null, key: number): TreeNode | null {
    if (root === null) {
        return null;
    }
    
    if (key < root.val) {
        root.left = deleteNode(root.left, key);
    } else if (key > root.val) {
        root.right = deleteNode(root.right, key);
    } else {
        // Found the node to delete
        
        // Case 1: No children (leaf node)
        if (root.left === null && root.right === null) {
            return null;
        }
        
        // Case 2: One child
        if (root.left === null) {
            return root.right;
        }
        if (root.right === null) {
            return root.left;
        }
        
        // Case 3: Two children
        // Find in-order successor (minimum value in right subtree)
        let successor = root.right;
        while (successor.left !== null) {
            successor = successor.left;
        }
        
        // Replace current node's value with successor's value
        root.val = successor.val;
        
        // Delete the successor from right subtree
        root.right = deleteNode(root.right, successor.val);
    }
    
    return root;
};

```

## Solution 2: With Detailed Comments

```typescript
function deleteNode(root: TreeNode | null, key: number): TreeNode | null {
    // Base case: node not found
    if (root === null) {
        return null;
    }
    
    // Search phase: use BST property to navigate
    if (key < root.val) {
        // Key is smaller, search left subtree
        root.left = deleteNode(root.left, key);
    } else if (key > root.val) {
        // Key is larger, search right subtree
        root.right = deleteNode(root.right, key);
    } else {
        // Found the node with matching key - now delete it
        
        // Case 1: Leaf node (no children)
        if (root.left === null && root.right === null) {
            return null;
        }
        
        // Case 2: Only right child exists
        if (root.left === null) {
            return root.right;
        }
        
        // Case 2: Only left child exists
        if (root.right === null) {
            return root.left;
        }
        
        // Case 3: Two children exist
        // Strategy: Find in-order successor (smallest in right subtree)
        // This maintains BST property when we replace the node
        let successor = root.right;
        while (successor.left !== null) {
            successor = successor.left;
        }
        
        // Copy successor's value to current node
        root.val = successor.val;
        
        // Now delete the successor (which has at most one child - right child)
        // from the right subtree
        root.right = deleteNode(root.right, successor.val);
    }
    
    return root;
};

```

## Solution 3: Using In-order Predecessor (Alternative)

```typescript
function deleteNode(root: TreeNode | null, key: number): TreeNode | null {
    if (root === null) return null;
    
    if (key < root.val) {
        root.left = deleteNode(root.left, key);
    } else if (key > root.val) {
        root.right = deleteNode(root.right, key);
    } else {
        if (root.left === null) return root.right;
        if (root.right === null) return root.left;
        
        // Find in-order predecessor (maximum value in left subtree)
        let predecessor = root.left;
        while (predecessor.right !== null) {
            predecessor = predecessor.right;
        }
        
        root.val = predecessor.val;
        root.left = deleteNode(root.left, predecessor.val);
    }
    
    return root;
};

```

## Solution 4: Compact Version

```typescript
function deleteNode(root: TreeNode | null, key: number): TreeNode | null {
    if (!root) return null;
    
    if (key < root.val) {
        root.left = deleteNode(root.left, key);
    } else if (key > root.val) {
        root.right = deleteNode(root.right, key);
    } else {
        if (!root.left) return root.right;
        if (!root.right) return root.left;
        
        let successor = root.right;
        while (successor.left) successor = successor.left;
        
        root.val = successor.val;
        root.right = deleteNode(root.right, successor.val);
    }
    
    return root;
};

```

# Example Walkthrough

## Example 1: `root = [5,3,6,2,4,null,7], key = 3`

### Initial Tree Structure

```
            5
           / \
          3 6
         / \ \
        2 4 7
```

### Deletion Process

```
Call: deleteNode(node=5, key=3)
  key(3) < root.val(5)? Yes
  root.left = deleteNode(node=3, key=3)

  Call: deleteNode(node=3, key=3)
    key(3) === root.val(3)? Yes! Found node to delete
    
    Check children:
      root.left = node(2), not null
      root.right = node(4), not null
      Both children exist → Case 3
    
    Find in-order successor:
      successor = root.right = node(4)
      successor.left === null? Yes
      successor = node(4) (no further left traversal needed)
    
    Replace value:
      root.val = successor.val = 4
      Node(3) becomes Node(4) with same children
    
    Delete successor from right subtree:
      root.right = deleteNode(node=4, key=4)
      
      Call: deleteNode(node=4, key=4)
        key(4) === root.val(4)? Yes! Found node to delete
        
        Check children:
          root.left === null? Yes
          root.right === null? Yes
          Case 1: Leaf node
        
        Return null
      
      root.right = null
    
    Return updated node (now has val=4, left=2, right=null)

  root.left = node(4) [previously node(3), now updated]

Return root (val=5)
```

### Final Tree Structure

```
            5
           / \
          4 6
         / \
        2 7

Node with value 3 replaced by value 4 (its in-order successor)
```

**Output:** `[5,4,6,2,null,null,7]`

## Example 2: `root = [5,3,6,2,4,null,7], key = 0`

### Search Process

```
Call: deleteNode(node=5, key=0)
  key(0) < root.val(5)? Yes
  root.left = deleteNode(node=3, key=0)

  Call: deleteNode(node=3, key=0)
    key(0) < root.val(3)? Yes
    root.left = deleteNode(node=2, key=0)

    Call: deleteNode(node=2, key=0)
      key(0) < root.val(2)? Yes
      root.left = deleteNode(null, key=0)

      Call: deleteNode(null, key=0)
        root === null
        Return null

      root.left = null (unchanged, was already null)
      Return node(2) (unchanged)

    root.left = node(2) (unchanged)
    Return node(3) (unchanged)

  root.left = node(3) (unchanged)
  Return node(5) (unchanged, root)
```

### Final Tree Structure

```
Tree remains unchanged since key=0 doesn't exist:

            5
           / \
          3 6
         / \ \
        2 4 7
```

**Output:** `[5,3,6,2,4,null,7]`

# Visual Representation

## Three Deletion Cases

```
Case 1: No children (Leaf)
    Before: After:
      X (removed)
                     
    Simply return null

Case 2: One child
    Before: After:
      X Y (child replaces X)
       \
        Y

    Return the single child

Case 3: Two children
    Before: After:
      X Y (successor's value)
     / \ / \
    L R L R'
       / /
      Y (successor) (Y removed from here)
    
    1. Find successor (min value in right subtree)
    2. Copy successor's value to X
    3. Delete successor from right subtree
```

## In-order Successor Finding

```
To find in-order successor of node with two children:
  Go to right child once
  Then keep going left until no more left children

Example:
      4 (root.right)
       \
        7
       /
      5 ← This is the successor (leftmost in right subtree)
```

# Key Insights

1. **BST property enables efficient search:** $O(H)$ time to locate the node
2. **Successor maintains BST property:** Using in-order successor ensures tree remains valid BST
3. **Successor always has ≤1 child:** Since it's the leftmost node, it can't have a left child
4. **Recursive deletion simplifies logic:** After replacing value, recursively delete the duplicate
5. **Either successor or predecessor works:** Both maintain BST property; choice is arbitrary

---

# Edge Cases

| Case | Input | Output | Explanation |
|------|-------|--------|-------------|
| Empty tree | `root = null` | `null` | Nothing to delete |
| Key not found | Key doesn't exist | Unchanged tree | Search completes without deletion |
| Delete leaf | Node has no children | Node removed | Simple removal |
| Delete root (leaf) | `root = [5], key = 5` | `null` | Entire tree becomes empty |
| Delete with one child | Node has only left/right | Child replaces node | Direct replacement |
| Delete with two children | Node has both children | Value replaced by successor | Complex case handled |

# Common Mistakes to Avoid

1. **Not handling all three cases:**
   ```typescript
   // Wrong: only handling leaf case
   if (root.left === null && root.right === null) {
       return null;
   }
   // Missing one-child and two-children cases!
   
   // Correct: handle all cases
   if (root.left === null) return root.right;
   if (root.right === null) return root.left;
   // Then handle two children case
   ```

2. **Incorrect successor finding:**
   ```typescript
   // Wrong: not going all the way left
   let successor = root.right;
   // Missing while loop!
   
   // Correct: traverse to leftmost node
   let successor = root.right;
   while (successor.left !== null) {
       successor = successor.left;
   }
   ```

3. **Forgetting to delete the successor:**
   ```typescript
   // Wrong: only copying value, not removing duplicate
   root.val = successor.val;
   // Missing deletion step!
   
   // Correct: delete successor after copying value
   root.val = successor.val;
   root.right = deleteNode(root.right, successor.val);
   ```

4. **Not updating pointers correctly:**
   ```typescript
   // Wrong: not assigning result back
   deleteNode(root.left, key);
   
   // Correct: assign back to maintain structure
   root.left = deleteNode(root.left, key);
   ```

# Performance Analysis

For $n = 10^4$ nodes:

| Tree Type | Height | Time Complexity |
|-----------|--------|------------------|
| Balanced BST | $O(log n) ≈ 14$ | Very fast |
| Skewed BST | $O(n) = 10,000$ | Still meets $O(H)$ requirement |

**Follow-up requirement met:** $O(H)$ time complexity achieved through:
- $O(H)$ to search for the node
- $O(H)$ to find successor (in worst case)
- Total: $O(H) + O(H) = O(H)$
