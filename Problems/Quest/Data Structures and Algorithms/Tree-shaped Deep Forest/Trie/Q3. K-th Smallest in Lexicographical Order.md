# Intuition

The lexicographical order of numbers from 1 to n forms a structure similar to a **10-ary tree** (like a trie), where:
- Root level contains digits 1-9
- Each number's "children" are formed by appending digits 0-9 to it

For example, node `1` has children `10, 11, 12, ..., 19`, and node `12` has children `120, 121, ..., 129`.

**Key insight:** We can navigate this tree structure to find the kth number by counting how many numbers exist in each "subtree" (prefix range) without generating them all, using a mathematical formula.

---

# Approach

1. **Start at `curr = 1`** (smallest lexicographic number) and decrement `k` by 1 (since we've already "visited" curr)

2. **For each step, calculate `steps`:** the count of numbers in range `[1, n]` that have `curr` as a prefix (i.e., numbers between `curr` and `curr+1` when compared as prefixes)

3. **Decision:**
   - If `steps <= k`: The kth number is **not** in this subtree. Move to the next sibling: `curr++`, and subtract `steps` from `k`
   - If `steps > k`: The kth number **is** in this subtree. Move to first child: `curr *= 10`, and decrement `k` by 1

4. **Repeat until `k == 0`**, then return `curr`

## Counting Steps Formula

To count how many numbers with prefix `curr` exist in `[1, n]`:
```
steps = 0
prefix1 = curr, prefix2 = curr + 1

while prefix1 <= n:
    steps += min(n + 1, prefix2) - prefix1
    prefix1 *= 10
    prefix2 *= 10

return steps
```

This works by checking each "level" of the subtree (curr, curr0-curr9, curr00-curr99, etc.) and counting how many fall within `[1, n]`.

---

# Complexity

**Time Complexity:** $O((log n)²)$
- Outer loop runs at most $O(log n)$ times (since curr grows by factor of 10 or increments)
- Inner countSteps loop runs $O(log n)$ times per call

**Space Complexity:** $O(1)$
- Only using a few variables, no extra data structures

---

# Code

```typescript
function findKthNumber(n: number, k: number): number {
    function countSteps(n: number, prefix1: number, prefix2: number): number {
        let steps = 0;
        
        while (prefix1 <= n) {
            steps += Math.min(n + 1, prefix2) - prefix1;
            prefix1 *= 10;
            prefix2 *= 10;
        }
        
        return steps;
    }
    
    let curr = 1;
    k--; // We start counting from curr=1, so decrement k
    
    while (k > 0) {
        const steps = countSteps(n, curr, curr + 1);
        
        if (steps <= k) {
            // kth number is not in this subtree, move to next sibling
            curr++;
            k -= steps;
        } else {
            // kth number is in this subtree, move to first child
            curr *= 10;
            k--;
        }
    }
    
    return curr;
};

```

## Solution with Detailed Comments

```typescript
function findKthNumber(n: number, k: number): number {
    // Count how many numbers with prefix in [prefix1, prefix2) exist in range [1, n]
    function countSteps(n: number, prefix1: number, prefix2: number): number {
        let steps = 0;
        
        // Check each level of the subtree (single digit, two digits, etc.)
        while (prefix1 <= n) {
            // Add numbers in current level, capped by n
            steps += Math.min(n + 1, prefix2) - prefix1;
            
            // Move to next level (append a digit: multiply by 10)
            prefix1 *= 10;
            prefix2 *= 10;
        }
        
        return steps;
    }
    
    let curr = 1; // Start at the lexicographically smallest number
    k--; // curr=1 is already the 1st number, so we need k-1 more steps
    
    while (k > 0) {
        // Count how many numbers exist in the subtree rooted at 'curr'
        const steps = countSteps(n, curr, curr + 1);
        
        if (steps <= k) {
            // The entire subtree doesn't contain our answer
            // Move to the next number at the same level (sibling)
            curr++;
            k -= steps; // Skip all numbers in this subtree
        } else {
            // Our answer is within this subtree
            // Move to the first child (append a 0)
            curr *= 10;
            k--; // We've moved one step closer
        }
    }
    
    return curr;
};

```

### Initial Setup

```

```

### Iteration 1

```

  countSteps(13, 1, 2):

      steps += min(14, 2) - 1 = 2 - 1 = 1
      prefix1 = 10, prefix2 = 20
    
    Level 2: prefix1(10) <= n(13)? Yes
      steps += min(14, 20) - 10 = 14 - 10 = 4
      prefix1 = 100, prefix2 = 200
    
    Level 3: prefix1(100) <= n(13)? No, stop
    
    Return steps = 1 + 4 = 5

steps = 5, k = 1
steps(5) <= k(1)? No
→ Move to first child: curr = 1 * 10 = 10
→ k = k - 1 = 0
```

```
Return curr = 10
```

# Key Insights

1. **Tree traversal without generation:** We navigate the lexicographic tree structure mathematically, avoiding generating all n numbers (crucial since n can be up to 10^9)

2. **Steps calculation is prefix-based:** By comparing `prefix1` to `prefix2` at each digit level, we count exactly how many valid numbers share that prefix

3. **Two movement types:**
   - **Sibling movement** (`curr++`): Skip entire subtree, moving to next number at same level
   - **Child movement** (`curr *= 10`): Dive deeper into current number's subtree

4. **Efficient for large n:** Since we work with digit-based prefixes, the algorithm runs in $O((log n)²)$ time regardless of how large n is

| k = n | Any n | Last number | The very last number in lex order |

| Large n | $n=10^9$ | Varies | Algorithm handles efficiently |
| n = 1 | n=1, k=1 | 1 | Only one number exists |

# Common Mistakes to Avoid

1. **Not handling overflow correctly:**
   ```typescript
   // Wrong: doesn't cap at n properly
   steps += prefix2 - prefix1;
   
   // Correct: cap using min with n+1
   steps += Math.min(n + 1, prefix2) - prefix1;
   ```

2. **Forgetting to decrement k initially:**
   ```typescript
   // Wrong: doesn't account for curr=1 as first number
   let k_remaining = k;
   
   // Correct: decrement since curr=1 is already counted
   k--;
   ```

3. **Incorrect step counting for multiple levels:**
   ```typescript
   // Wrong: only checks single level
   const steps = Math.min(n+1, curr+1) - curr;
   
   // Correct: check all levels using while loop
   while (prefix1 <= n) {
       steps += Math.min(n+1, prefix2) - prefix1;
       prefix1 *= 10;
       prefix2 *= 10;
   }
   ```

# Performance Analysis

For $n = 10^9$, $k = 10^9$:

| Component | Complexity | Notes |
|-----------|-----------|-------|
| Outer loop | $O(log n)$ | curr grows by factor 10 or increments |
| countSteps per call | $O(log n)$ | Checks each digit level |
| **Total** | **$O((log n)²)$** | ~100 operations for $n=10^9$ |

Extremely efficient even for the maximum constraint values!

# Recommended Solution

This digit-by-digit tree traversal approach is optimal for:
- $O((log n)²)$ time complexity - handles n up to 10^9 efficiently
- $O(1)$ space complexity
- Avoids generating and sorting all numbers (which would be $O(n log n)$)
- Elegant mathematical solution to a seemingly complex ordering problem

> This is the standard and most efficient solution for finding the kth lexicographically smallest number in a range!
