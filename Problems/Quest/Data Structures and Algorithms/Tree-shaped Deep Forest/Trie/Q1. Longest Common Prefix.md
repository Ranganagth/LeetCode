# Intuition

We need to find the **longest common prefix** shared by all strings. A simple approach: take the first string as a reference, then compare character by character with all other strings, shrinking the prefix whenever a mismatch is found.

---

# Approach

1. Start with the first string as the initial prefix guess
2. Compare this prefix against every other string
3. If the current prefix isn't found at the start of some string, shorten the prefix by removing the last character
4. Repeat until the prefix matches all strings or becomes empty

---

# Complexity

- **Time Complexity:** O(S) where S is the sum of all characters in all strings (worst case)
- **Space Complexity:** O(1) extra space (excluding output)

---

# Code

## Solution 1: Horizontal Scanning (Recommended)

```typescript
function longestCommonPrefix(strs: string[]): string {
    if (strs.length === 0) return "";
    
    let prefix = strs[0];
    
    for (let i = 1; i < strs.length; i++) {
        while (strs[i].indexOf(prefix) !== 0) {
            prefix = prefix.slice(0, -1);
            if (prefix === "") return "";
        }
    }
    
    return prefix;
};

```

---

## Solution 2: Vertical Scanning (Character by Character)

```typescript
function longestCommonPrefix(strs: string[]): string {
    if (strs.length === 0) return "";
    
    for (let i = 0; i < strs[0].length; i++) {
        const char = strs[0][i];
        
        for (let j = 1; j < strs.length; j++) {
            if (i >= strs[j].length || strs[j][i] !== char) {
                return strs[0].slice(0, i);
            }
        }
    }
    
    return strs[0];
};

```

# Example Walkthrough

## Example 1: `strs = ["flower","flow","flight"]`

```
prefix = "flower"

Compare with "flow":
  "flow".indexOf("flower") !== 0, shrink prefix
  prefix = "flowe" → "flow" → matches "flow".indexOf("flow") === 0 ✓

Compare with "flight":
  "flight".indexOf("flow") !== 0, shrink prefix
  prefix = "flo" → "fl" → matches "flight".indexOf("fl") === 0 ✓

Final prefix = "fl"
```

**Output:** `"fl"`

---

## Example 2: `strs = ["dog","racecar","car"]`

```
prefix = "dog"

Compare with "racecar":
  "racecar".indexOf("dog") !== 0, shrink
  prefix = "do" → "d" → "" 
  prefix is empty, return ""
```

**Output:** `""`

---

# Key Insights

- **Early termination:** If prefix becomes empty, immediately return `""`
- **First string as baseline:** Using the first string as initial guess is efficient since the answer can't be longer than it
- **Vertical scanning advantage:** Can terminate early per character position, often faster in practice for strings with early mismatches
