# Intuition

We need to find **all paths** from node 0 to node n-1 in a directed acyclic graph (DAG). This is a classic **backtracking/DFS** problem where we explore all possible paths and collect those that reach the target.

**Key insights:**
1. DAG guarantees no cycles (no infinite loops)
2. Start from node 0, end at node n-1
3. Need to explore all possible paths (not just one)
4. Backtracking naturally handles path exploration

---

# Approach

1. **DFS with backtracking:**
   - Start from node 0 with empty path
   - For each node, try all neighbors
   - When reaching target (n-1), save the path
   - Backtrack to explore other paths

2. **Path tracking:**
   - Maintain current path during traversal
   - Add node when visiting
   - Remove node when backtracking

3. **Base case:**
   - When current node equals target, add path to results

---

# Complexity

- **Time complexity:** O(2^n × n) 
  - In worst case (complete graph), exponential paths
  - Each path can have up to n nodes
- **Space complexity:** O(n) for recursion stack and current path

# Code

## Solution 1: DFS with Backtracking (Recommended)

```typescript
function allPathsSourceTarget(graph: number[][]): number[][] {
    const n = graph.length;
    const target = n - 1;
    const result: number[][] = [];
    const currentPath: number[] = [];
    
    function dfs(node: number) {
        // Add current node to path
        currentPath.push(node);
        
        // If we reached the target, save this path
        if (node === target) {
            result.push([...currentPath]); // Make a copy
        } else {
            // Explore all neighbors
            for (const neighbor of graph[node]) {
                dfs(neighbor);
            }
        }
        
        // Backtrack: remove current node from path
        currentPath.pop();
    }
    
    dfs(0);
    return result;
};

```

## Solution 2: With Detailed Comments

```typescript
function allPathsSourceTarget(graph: number[][]): number[][] {
    const n = graph.length;
    const target = n - 1;
    const allPaths: number[][] = [];
    const currentPath: number[] = [];
    
    function dfs(currentNode: number) {
        // Step 1: Add current node to the path
        currentPath.push(currentNode);
        
        // Step 2: Check if we've reached the target
        if (currentNode === target) {
            // Found a complete path! Save it
            // Important: make a copy because currentPath will be modified
            allPaths.push([...currentPath]);
        } else {
            // Step 3: Not at target yet, explore all neighbors
            for (const neighbor of graph[currentNode]) {
                dfs(neighbor);
            }
        }
        
        // Step 4: Backtrack - remove current node from path
        // This allows us to explore other paths
        currentPath.pop();
    }
    
    // Start DFS from node 0
    dfs(0);
    
    return allPaths;
};

```

## Solution 3: Iterative with Stack

```typescript
function allPathsSourceTarget(graph: number[][]): number[][] {
    const n = graph.length;
    const target = n - 1;
    const result: number[][] = [];
    
    // Stack stores [currentNode, currentPath]
    const stack: [number, number[]][] = [[0, [0]]];
    
    while (stack.length > 0) {
        const [node, path] = stack.pop()!;
        
        if (node === target) {
            result.push(path);
            continue;
        }
        
        for (const neighbor of graph[node]) {
            stack.push([neighbor, [...path, neighbor]]);
        }
    }
    
    return result;
};

```

## Solution 4: BFS Approach

```typescript
function allPathsSourceTarget(graph: number[][]): number[][] {
    const n = graph.length;
    const target = n - 1;
    const result: number[][] = [];
    
    // Queue stores paths (each path is an array of nodes)
    const queue: number[][] = [[0]];
    
    while (queue.length > 0) {
        const path = queue.shift()!;
        const node = path[path.length - 1];
        
        if (node === target) {
            result.push(path);
            continue;
        }
        
        for (const neighbor of graph[node]) {
            queue.push([...path, neighbor]);
        }
    }
    
    return result;
};

```

## Solution 5: Optimized with Path Building

```typescript
function allPathsSourceTarget(graph: number[][]): number[][] {
    const target = graph.length - 1;
    const result: number[][] = [];
    
    function dfs(node: number, path: number[]) {
        if (node === target) {
            result.push([...path, node]);
            return;
        }
        
        for (const neighbor of graph[node]) {
            dfs(neighbor, [...path, node]);
        }
    }
    
    dfs(0, []);
    return result;
};

```

# Key Insights

- **Backtracking essential:** Need to explore all paths, not just one
- **Path copying:** Must copy path when saving (array is mutable)
- **DAG property:** No cycles means guaranteed termination
- **No visited set needed:** DAG ensures no revisiting
- **Multiple solutions:** Unlike shortest path, we want ALL paths

---

# Why Backtracking Works

**Path exploration:**
```
Current path: [0, 1]

Explore neighbor 3:
  path = [0, 1, 3] → save if target
  
Backtrack (pop 3):
  path = [0, 1]
  
Explore neighbor 4:
  path = [0, 1, 4] → save if target
  
Backtrack (pop 4):
  path = [0, 1]
```

This allows exploring all branches from each node.

# Common Mistakes to Avoid

1. **Not copying path when saving:**
   ```typescript
   // Wrong: saves reference (will be modified)
   if (node === target) {
       result.push(currentPath);
   }
   
   // Correct: save copy
   if (node === target) {
       result.push([...currentPath]);
   }
   ```

2. **Forgetting to backtrack:**
   ```typescript
   // Wrong: path keeps growing
   currentPath.push(node);
   dfs(neighbor);
   // Missing: currentPath.pop();
   
   // Correct: backtrack
   currentPath.push(node);
   dfs(neighbor);
   currentPath.pop();
   ```

3. **Using visited set (not needed for DAG):**
   ```typescript
   // Wrong: prevents finding all paths
   const visited = new Set();
   if (visited.has(node)) return;
   visited.add(node);
   
   // Correct: no visited set needed
   // DAG has no cycles
   ```

4. **Not handling target correctly:**
   ```typescript
   // Wrong: continue exploring after target
   if (node === target) {
       result.push([...currentPath]);
   }
   for (const neighbor of graph[node]) {
       dfs(neighbor);
   }
   
   // Correct: use else to stop exploring
   if (node === target) {
       result.push([...currentPath]);
   } else {
       for (const neighbor of graph[node]) {
           dfs(neighbor);
       }
   }
   ```

| Approach | Pros | Cons |
|----------|------|------|

| Iterative Stack | No recursion limit | More complex |
| BFS | Level-order | More memory |
