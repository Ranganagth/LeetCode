# Intuition

To find the perimeter of an island, we need to count the **edges** of land cells that are exposed to water or the boundary. Each land cell contributes to the perimeter based on how many of its 4 sides are exposed (not adjacent to another land cell).

**Key insight:** 
- Each land cell can contribute 0-4 to the perimeter
- For each land cell, count sides that touch water or boundary
- Alternatively: count all land cells × 4, then subtract shared edges × 2

---

# Approach

## Method 1: Count Exposed Sides
- For each land cell, check all 4 directions
- Add 1 to perimeter for each side that's water or out of bounds

## Method 2: Count Land and Neighbors
- Count total land cells × 4 (max perimeter)
- Subtract 2 for each shared edge between land cells

---

# Complexity

- **Time complexity:** $O(rows × cols)$ - visit each cell once
- **Space complexity:** $O(1)$ - only using variables

---

# Code

## Solution 1: Count Exposed Sides (Recommended)

```typescript
function islandPerimeter(grid: number[][]): number {
    const rows = grid.length;
    const cols = grid[0].length;
    let perimeter = 0;
    
    for (let i = 0; i < rows; i++) {
        for (let j = 0; j < cols; j++) {
            if (grid[i][j] === 1) {
                // Check all 4 directions
                // Add 1 for each side that's water or boundary
                
                // Top
                if (i === 0 || grid[i - 1][j] === 0) {
                    perimeter++;
                }
                
                // Bottom
                if (i === rows - 1 || grid[i + 1][j] === 0) {
                    perimeter++;
                }
                
                // Left
                if (j === 0 || grid[i][j - 1] === 0) {
                    perimeter++;
                }
                
                // Right
                if (j === cols - 1 || grid[i][j + 1] === 0) {
                    perimeter++;
                }
            }
        }
    }
    
    return perimeter;
};

```

## Solution 2: Count Land and Subtract Neighbors

```typescript
function islandPerimeter(grid: number[][]): number {
    const rows = grid.length;
    const cols = grid[0].length;
    let landCells = 0;
    let neighbors = 0;
    
    for (let i = 0; i < rows; i++) {
        for (let j = 0; j < cols; j++) {
            if (grid[i][j] === 1) {
                landCells++;
                
                // Count neighbors (only check right and down to avoid double counting)
                if (i < rows - 1 && grid[i + 1][j] === 1) {
                    neighbors++;
                }
                if (j < cols - 1 && grid[i][j + 1] === 1) {
                    neighbors++;
                }
            }
        }
    }
    
    // Each land cell contributes 4 sides
    // Each neighbor pair shares 2 sides (subtract 2 per neighbor)
    return landCells * 4 - neighbors * 2;
};

```

## Solution 3: Using Directions Array

```typescript
function islandPerimeter(grid: number[][]): number {
    const rows = grid.length;
    const cols = grid[0].length;
    const directions = [[-1, 0], [1, 0], [0, -1], [0, 1]]; // up, down, left, right
    let perimeter = 0;
    
    for (let i = 0; i < rows; i++) {
        for (let j = 0; j < cols; j++) {
            if (grid[i][j] === 1) {
                // Check all 4 directions
                for (const [di, dj] of directions) {
                    const ni = i + di;
                    const nj = j + dj;
                    
                    // Add 1 if out of bounds or water
                    if (ni < 0 || ni >= rows || nj < 0 || nj >= cols || grid[ni][nj] === 0) {
                        perimeter++;
                    }
                }
            }
        }
    }
    
    return perimeter;
};

```

## Solution 5: Compact Version

```typescript
function islandPerimeter(grid: number[][]): number {
    let perimeter = 0;
    
    for (let i = 0; i < grid.length; i++) {
        for (let j = 0; j < grid[0].length; j++) {
            if (grid[i][j] === 1) {
                perimeter += 4; // Start with 4 sides
                
                // Subtract 1 for each adjacent land cell
                if (i > 0 && grid[i - 1][j] === 1) perimeter--;
                if (i < grid.length - 1 && grid[i + 1][j] === 1) perimeter--;
                if (j > 0 && grid[i][j - 1] === 1) perimeter--;
                if (j < grid[0].length - 1 && grid[i][j + 1] === 1) perimeter--;
            }
        }
    }
    
    return perimeter;
};

```

# Key Insights

- **Exposed sides:** Only count sides touching water or boundary
- **Shared edges:** Don't contribute to perimeter
- **No diagonal:** Only 4 directions matter
- **Simple iteration:** Just check each cell once
- **Two approaches:** Count exposed OR count all minus shared

---

# Mathematical Formula

**Method 2 formula:**
```
Perimeter = (Land cells × 4) - (Shared edges × 2)

Why × 2?
Each shared edge is counted twice (once from each cell)
```

# Common Mistakes to Avoid

1. **Counting shared edges twice:**
   ```typescript
   // Wrong: counting each shared edge from both sides
   if (grid[i][j] === 1 && grid[i][j+1] === 1) {
       perimeter -= 1; // Should be -= 2 or count once
   }
   
   // Correct: subtract 2 or count only once
   if (j < cols - 1 && grid[i][j+1] === 1) {
       neighbors++; // Count once, subtract 2 later
   }
   ```

2. **Not checking boundaries:**
   ```typescript
   // Wrong: array out of bounds
   if (grid[i-1][j] === 0) perimeter++;
   
   // Correct: check boundary first
   if (i === 0 || grid[i-1][j] === 0) perimeter++;
   ```

3. **Checking diagonals:**
   ```typescript
   // Wrong: checking diagonal neighbors
   if (grid[i-1][j-1] === 1) ...
   
   // Correct: only check 4 directions (up, down, left, right)
   ```

4. **Processing water cells:**
   ```typescript
   // Wrong: processing all cells
   for each cell:
       check neighbors
   
   // Correct: only process land cells
   if (grid[i][j] === 1) {
       check neighbors
   }
   ```

| Check neighbors | $O(1)$ per cell | 4 checks |

# Comparison of Approaches

| Approach | Pros | Cons |
|----------|------|------|
| Count exposed | Intuitive, direct | More conditions |
| Count & subtract | Mathematical, elegant | Less obvious |
| Directions array | Clean, extensible | Slightly more code |

# Recommended Solution

**Use Solution 1 (Count Exposed Sides)** for:
- $O(rows × cols)$ time
- $O(1)$ space
- Most intuitive
- Easy to understand
- Interview-friendly

**Use Solution 2 (Count & Subtract)** for:
- More elegant
- Mathematical approach
- Fewer conditions

Both are excellent choices!
