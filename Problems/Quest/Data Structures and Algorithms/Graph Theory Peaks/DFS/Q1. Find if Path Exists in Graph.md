# Intuition

We need to determine if there's a path between two nodes in an undirected graph. This is a classic **graph connectivity** problem that can be solved using:
1. **DFS/BFS** - Graph traversal
2. **Union-Find** - Check if nodes are in the same connected component

**Key insight:** If source and destination are in the same connected component, a path exists.

---

# Approach

## Method 1: DFS/BFS
- Build adjacency list from edges
- Start traversal from source
- Return true if we reach destination

## Method 2: Union-Find (Optimal)
- Union all connected nodes
- Check if source and destination have the same root

---

# Complexity

**DFS/BFS:**
- **Time:** $O(n + e)$ where e is number of edges
- **Space:** $O(n + e)$ for graph and visited set

**Union-Find:**
- **Time:** $O(e × α(n)) ≈ O(e)$ where α is inverse Ackermann
- **Space:** $O(n)$ for parent array

# Code

## Solution 1: BFS (Recommended for Interviews)

```typescript
function validPath(n: number, edges: number[][], source: number, destination: number): boolean {
    // Edge case: source equals destination
    if (source === destination) return true;
    
    // Build adjacency list
    const graph = new Map<number, number[]>();
    for (let i = 0; i < n; i++) {
        graph.set(i, []);
    }
    
    for (const [u, v] of edges) {
        graph.get(u)!.push(v);
        graph.get(v)!.push(u);
    }
    
    // BFS
    const visited = new Set<number>();
    const queue: number[] = [source];
    visited.add(source);
    
    while (queue.length > 0) {
        const node = queue.shift()!;
        
        // Check if we reached destination
        if (node === destination) {
            return true;
        }
        
        // Visit all neighbors
        for (const neighbor of graph.get(node)!) {
            if (!visited.has(neighbor)) {
                visited.add(neighbor);
                queue.push(neighbor);
            }
        }
    }
    
    return false;
};

```

## Solution 2: DFS (Recursive)

```typescript
function validPath(n: number, edges: number[][], source: number, destination: number): boolean {
    if (source === destination) return true;
    
    // Build adjacency list
    const graph = new Map<number, number[]>();
    for (let i = 0; i < n; i++) {
        graph.set(i, []);
    }
    
    for (const [u, v] of edges) {
        graph.get(u)!.push(v);
        graph.get(v)!.push(u);
    }
    
    // DFS
    const visited = new Set<number>();
    
    function dfs(node: number): boolean {
        if (node === destination) return true;
        
        visited.add(node);
        
        for (const neighbor of graph.get(node)!) {
            if (!visited.has(neighbor)) {
                if (dfs(neighbor)) {
                    return true;
                }
            }
        }
        
        return false;
    }
    
    return dfs(source);
};

```

## Solution 3: Union-Find (Most Efficient)

```typescript
function validPath(n: number, edges: number[][], source: number, destination: number): boolean {
    // Union-Find data structure
    const parent = Array.from({ length: n }, (_, i) => i);
    
    function find(x: number): number {
        if (parent[x] !== x) {
            parent[x] = find(parent[x]); // Path compression
        }
        return parent[x];
    }
    
    function union(x: number, y: number): void {
        const rootX = find(x);
        const rootY = find(y);
        
        if (rootX !== rootY) {
            parent[rootX] = rootY;
        }
    }
    
    // Union all edges
    for (const [u, v] of edges) {
        union(u, v);
    }
    
    // Check if source and destination are in same component
    return find(source) === find(destination);
};

```

## Solution 4: Union-Find with Rank Optimization

```typescript
function validPath(n: number, edges: number[][], source: number, destination: number): boolean {
    const parent = Array.from({ length: n }, (_, i) => i);
    const rank = new Array(n).fill(0);
    
    function find(x: number): number {
        if (parent[x] !== x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    function union(x: number, y: number): void {
        const rootX = find(x);
        const rootY = find(y);
        
        if (rootX === rootY) return;
        
        // Union by rank
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
    }
    
    for (const [u, v] of edges) {
        union(u, v);
    }
    
    return find(source) === find(destination);
};

```

## Solution 5: Optimized BFS (Early Termination)

```typescript
function validPath(n: number, edges: number[][], source: number, destination: number): boolean {
    if (source === destination) return true;
    
    // Build adjacency list
    const graph = new Map<number, number[]>();
    for (const [u, v] of edges) {
        if (!graph.has(u)) graph.set(u, []);
        if (!graph.has(v)) graph.set(v, []);
        graph.get(u)!.push(v);
        graph.get(v)!.push(u);
    }
    
    // If source or destination not in graph
    if (!graph.has(source) || !graph.has(destination)) {
        return source === destination;
    }
    
    const visited = new Set<number>([source]);
    const queue = [source];
    
    while (queue.length > 0) {
        const node = queue.shift()!;
        
        for (const neighbor of graph.get(node) || []) {
            if (neighbor === destination) return true; // Early termination
            
            if (!visited.has(neighbor)) {
                visited.add(neighbor);
                queue.push(neighbor);
            }
        }
    }
    
    return false;
};

```

# Example Walkthrough

## Example 1: `n = 3, edges = [[0,1],[1,2],[2,0]], source = 0, destination = 2`

### BFS Approach:
```
Graph:
  0 -- 1
  | |
  +----2

BFS from 0:
  Queue: [0], Visited: {0}
  
  Process 0:
    Neighbors: [1, 2]
    Add 1: Queue: [1], Visited: {0, 1}
    Add 2: Queue: [1, 2], Visited: {0, 1, 2}
  
  Process 1:
    node = 1 ≠ destination
    Neighbors: [0, 2] (both visited)
  
  Process 2:
    node = 2 = destination ✓
    Return true
```

### Union-Find Approach:
```
Initial: parent = [0, 1, 2]

Union(0, 1): parent = [1, 1, 2]
Union(1, 2): parent = [1, 2, 2]
Union(2, 0): parent = [1, 2, 2]

After path compression:
find(0) = 2
find(2) = 2

find(0) === find(2) ✓
Return true
```

**Output:** `true`

## Example 2: `n = 6, edges = [[0,1],[0,2],[3,5],[5,4],[4,3]], source = 0, destination = 5`

```
Graph (two components):
  Component 1: 0 -- 1
               |
               2
  
  Component 2: 3 -- 5
               | |
               +----4

BFS from 0:
  Can reach: {0, 1, 2}
  Cannot reach: {3, 4, 5}
  
  5 not in reachable set
  Return false

Union-Find:
  Component 1: {0, 1, 2}
  Component 2: {3, 4, 5}
  
  find(0) ≠ find(5)
  Return false
```

**Output:** `false`

# Key Insights

- **Graph connectivity:** Core problem is checking if nodes are connected
- **Multiple approaches:** BFS, DFS, Union-Find all work
- **Union-Find advantage:** No need to build full graph, just process edges
- **Early termination:** Can stop as soon as destination is found
- **Edge case:** Source equals destination (always true)

---

# Performance Comparison

| Approach | Time | Space | Best For |
|----------|------|-------|----------|
| BFS | $O(n + e)$ | $O(n + e)$ | Finding shortest path too |
| DFS | $O(n + e)$ | $O(n + e)$ | Simple implementation |
| Union-Find | $O(e × α(n))$ | $O(n)$ | Multiple queries |
| UF + Rank | $O(e × α(n))$ | $O(n)$ | Best overall |

---

# Edge Cases

| Case | Input | Output | Notes |
|------|-------|--------|-------|
| Same node | source=0, dest=0 | true | Trivial path |
| No edges | edges=[] | false | Unless source=dest |
| Single edge | edges=[[0,1]] | true/false | Depends on nodes |
| Disconnected | Two components | false | If in different |
| Complete graph | All connected | true | Always path |

# Common Mistakes to Avoid

1. **Not handling source = destination:**
   ```typescript
   // Wrong: might do unnecessary work
   // Build graph and search...
   
   // Correct: check first
   if (source === destination) return true;
   ```

2. **Building graph incorrectly:**
   ```typescript
   // Wrong: only one direction
   graph.get(u)!.push(v);
   
   // Correct: bidirectional
   graph.get(u)!.push(v);
   graph.get(v)!.push(u);
   ```

3. **Not marking visited in BFS:**
   ```typescript
   // Wrong: might revisit nodes
   queue.push(neighbor);
   
   // Correct: mark before adding
   visited.add(neighbor);
   queue.push(neighbor);
   ```

4. **Union-Find without path compression:**
   ```typescript
   // Wrong: slow find
   function find(x) {
       while (parent[x] !== x) {
           x = parent[x];
       }
       return x;
   }
   
   // Correct: with compression
   function find(x) {
       if (parent[x] !== x) {
           parent[x] = find(parent[x]);
       }
       return parent[x];
   }
   ```

# When to Use Each Approach

**Use BFS when:**
- Need shortest path
- Want level-order traversal
- Interview setting (most intuitive)

**Use DFS when:**
- Simpler recursion preferred
- Memory constrained (can be iterative)

**Use Union-Find when:**
- Multiple connectivity queries
- Building connected components
- Most efficient for this problem

---

# Recommended Solution

**For interviews: Use Solution 1 (BFS)**
- $O(n + e)$ time
- Easy to explain
- Intuitive
- Can extend to shortest path

**For production: Use Solution 4 (Union-Find with Rank)**
- Most efficient
- Handles multiple queries well
- Clean implementation

> Both are excellent choices depending on context!
