# Intuition

The key insight is that we can **visit the same road multiple times** and **revisit cities**. This means if cities 1 and n are in the same connected component, we can use ANY edge in that component by traveling back and forth.

**Key observation:** The answer is the minimum edge weight in the connected component containing both city 1 and city n.

---

# Approach

1. **Find the connected component** containing city 1 (and city n)
2. **Track the minimum edge weight** in that component
3. Since we can revisit roads, we can always access the minimum edge

**Methods:**
- **BFS/DFS:** Explore from city 1, track minimum edge
- **Union-Find:** Find component, then find minimum edge in it

---

# Complexity

- **Time complexity:** $O(n + e)$ where e is number of roads
- **Space complexity:** $O(n + e)$ for graph representation

# Code

## Solution 1: BFS (Recommended)

```typescript
function minScore(n: number, roads: number[][]): number {
    // Build adjacency list with edge weights
    const graph = new Map<number, Array<[number, number]>>();
    
    for (let i = 1; i <= n; i++) {
        graph.set(i, []);
    }
    
    for (const [a, b, distance] of roads) {
        graph.get(a)!.push([b, distance]);
        graph.get(b)!.push([a, distance]);
    }
    
    // BFS from city 1 to find all reachable cities
    const visited = new Set<number>();
    const queue: number[] = [1];
    visited.add(1);
    
    let minScore = Infinity;
    
    while (queue.length > 0) {
        const city = queue.shift()!;
        
        // Check all roads from this city
        for (const [neighbor, distance] of graph.get(city)!) {
            // Update minimum score
            minScore = Math.min(minScore, distance);
            
            // Visit neighbor if not visited
            if (!visited.has(neighbor)) {
                visited.add(neighbor);
                queue.push(neighbor);
            }
        }
    }
    
    return minScore;
};

```

## Solution 2: DFS (Recursive)

```typescript
function minScore(n: number, roads: number[][]): number {
    // Build graph
    const graph = new Map<number, Array<[number, number]>>();
    
    for (let i = 1; i <= n; i++) {
        graph.set(i, []);
    }
    
    for (const [a, b, distance] of roads) {
        graph.get(a)!.push([b, distance]);
        graph.get(b)!.push([a, distance]);
    }
    
    const visited = new Set<number>();
    let minScore = Infinity;
    
    function dfs(city: number) {
        visited.add(city);
        
        for (const [neighbor, distance] of graph.get(city)!) {
            minScore = Math.min(minScore, distance);
            
            if (!visited.has(neighbor)) {
                dfs(neighbor);
            }
        }
    }
    
    dfs(1);
    return minScore;
};

```

## Solution 3: Union-Find

```typescript
function minScore(n: number, roads: number[][]): number {
    const parent = Array.from({ length: n + 1 }, (_, i) => i);
    
    function find(x: number): number {
        if (parent[x] !== x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    function union(x: number, y: number): void {
        const rootX = find(x);
        const rootY = find(y);
        if (rootX !== rootY) {
            parent[rootX] = rootY;
        }
    }
    
    // Union all connected cities
    for (const [a, b, _] of roads) {
        union(a, b);
    }
    
    // Find the component containing city 1
    const component1 = find(1);
    
    // Find minimum edge in that component
    let minScore = Infinity;
    for (const [a, b, distance] of roads) {
        if (find(a) === component1) {
            minScore = Math.min(minScore, distance);
        }
    }
    
    return minScore;
};

```

## Solution 4: Optimized BFS with Early Minimum Tracking

```typescript
function minScore(n: number, roads: number[][]): number {
    // Build adjacency list
    const graph = new Map<number, Array<[number, number]>>();
    
    for (const [a, b, distance] of roads) {
        if (!graph.has(a)) graph.set(a, []);
        if (!graph.has(b)) graph.set(b, []);
        graph.get(a)!.push([b, distance]);
        graph.get(b)!.push([a, distance]);
    }
    
    // BFS to explore connected component
    const visited = new Set<number>([1]);
    const queue = [1];
    let minDistance = Infinity;
    
    while (queue.length > 0) {
        const current = queue.shift()!;
        
        for (const [next, dist] of graph.get(current) || []) {
            minDistance = Math.min(minDistance, dist);
            
            if (!visited.has(next)) {
                visited.add(next);
                queue.push(next);
            }
        }
    }
    
    return minDistance;
};

```

## Solution 5: With Detailed Comments

```typescript
function minScore(n: number, roads: number[][]): number {
    // Step 1: Build adjacency list representation of the graph
    // Each city maps to array of [neighbor, distance] pairs
    const graph = new Map<number, Array<[number, number]>>();
    
    for (let i = 1; i <= n; i++) {
        graph.set(i, []);
    }
    
    for (const [a, b, distance] of roads) {
        // Bidirectional road
        graph.get(a)!.push([b, distance]);
        graph.get(b)!.push([a, distance]);
    }
    
    // Step 2: BFS to find all cities in the same component as city 1
    const visited = new Set<number>();
    const queue: number[] = [1];
    visited.add(1);
    
    // Track the minimum edge weight in the component
    let minScore = Infinity;
    
    while (queue.length > 0) {
        const city = queue.shift()!;
        
        // Explore all roads from current city
        for (const [neighbor, distance] of graph.get(city)!) {
            // Update minimum score with this edge
            // Key insight: we can use ANY edge in the component
            // by traveling back and forth
            minScore = Math.min(minScore, distance);
            
            // Visit neighbor if not already visited
            if (!visited.has(neighbor)) {
                visited.add(neighbor);
                queue.push(neighbor);
            }
        }
    }
    
    // Step 3: Return the minimum edge weight found
    return minScore;
};

```

# Visual Representation

**Why we can use any edge in the component:**

```
Path from 1 to n with minimum edge:

If minimum edge is between cities A and B:
  1 → ... → A → B → ... → n
  
But we can also go:
  1 → ... → A → B → A → B → ... → n
  
By going back and forth on edge (A,B),
we can make its weight the minimum of our path!

This is why we just need to find the
minimum edge in the connected component.
```

# Key Insights

- **Can revisit roads:** Makes any edge in component accessible
- **Minimum in component:** Answer is minimum edge weight in component
- **No shortest path needed:** Not finding shortest path, just minimum edge
- **Connected component:** Only edges in same component as 1 and n matter
- **Simple BFS/DFS:** Just explore component and track minimum

---

# Why This Works

**Proof:**
1. Cities 1 and n are in same component (given)
2. We can visit any edge in the component by traveling to it
3. We can use that edge multiple times by going back and forth
4. The path score is the minimum edge used
5. Therefore, we can achieve a score equal to the minimum edge in the component

# Edge Cases

| Case | Description | Example | Notes |
|------|-------------|---------|-------|
| Direct edge | 1 and n connected | [[1,n,5]] | Return that edge |
| Single component | All connected | Complete graph | Min of all edges |
| Multiple paths | Many routes | Example 1 | Still min edge |
| Long path | Many hops | Linear chain | Can still use min |

# Common Mistakes to Avoid

1. **Trying to find shortest path:**
   ```typescript
   // Wrong: using Dijkstra (not needed)
   // We don't need shortest path, just minimum edge
   
   // Correct: just explore component
   while (queue.length > 0) {
       minScore = Math.min(minScore, distance);
   }
   ```

2. **Not considering all edges in component:**
   ```typescript
   // Wrong: only checking edges on path to n
   if (neighbor === n) {
       minScore = Math.min(minScore, distance);
   }
   
   // Correct: check ALL edges in component
   for (const [neighbor, distance] of graph.get(city)!) {
       minScore = Math.min(minScore, distance);
   }
   ```

3. **Forgetting bidirectional edges:**
   ```typescript
   // Wrong: only one direction
   graph.get(a)!.push([b, distance]);
   
   // Correct: both directions
   graph.get(a)!.push([b, distance]);
   graph.get(b)!.push([a, distance]);
   ```

4. **Not initializing minScore properly:**
   ```typescript
   // Wrong: starting at 0
   let minScore = 0;
   
   // Correct: starting at Infinity
   let minScore = Infinity;
   ```
