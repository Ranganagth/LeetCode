# Intuition

This problem is essentially asking for the **distance from each land cell to the nearest water cell**. Water cells have height 0, and each step away from water increases height by 1 (due to the constraint that adjacent cells differ by at most 1).

**Key insight:** This is a **multi-source BFS** problem where all water cells are starting points, and we propagate outward to assign heights.

---

# Approach

1. **Initialize:**
   - Create result matrix with all cells set to -1 (unvisited)
   - Set all water cells to height 0
   - Add all water cells to a queue

2. **Multi-source BFS:**
   - Process cells level by level
   - For each cell, assign height = parent's height + 1
   - Only visit unvisited cells (height = -1)

3. **Result:**
   - The BFS naturally maximizes heights while respecting constraints
   - Cells farther from water get higher values

---

# Complexity

- **Time complexity:** $O(m × n)$ - visit each cell once
- **Space complexity:** $O(m × n)$ - for queue and result matrix

---

# Code

## Using Deque for Optimization

```typescript
function highestPeak(isWater: number[][]): number[][] {
    const m = isWater.length;
    const n = isWater[0].length;
    const height = Array.from({ length: m }, () => Array(n).fill(-1));
    const queue: [number, number][] = [];
    
    // Initialize water cells
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            if (isWater[i][j] === 1) {
                height[i][j] = 0;
                queue.push([i, j]);
            }
        }
    }
    
    const dirs = [[-1, 0], [1, 0], [0, -1], [0, 1]];
    let queueIndex = 0; // Use index instead of shift() for better performance
    
    while (queueIndex < queue.length) {
        const [r, c] = queue[queueIndex++];
        
        for (const [dr, dc] of dirs) {
            const nr = r + dr;
            const nc = c + dc;
            
            if (nr >= 0 && nr < m && nc >= 0 && nc < n && height[nr][nc] === -1) {
                height[nr][nc] = height[r][c] + 1;
                queue.push([nr, nc]);
            }
        }
    }
    
    return height;
};

```

function highestPeak(isWater: number[][]): number[][] {
    const m = isWater.length, n = isWater[0].length;
    const h = Array.from({ length: m }, () => Array(n).fill(-1));
    const q: [number, number][] = [];
    
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            if (isWater[i][j]) {
                h[i][j] = 0;
                q.push([i, j]);
            }
        }
    }
    
    const d = [[-1,0],[1,0],[0,-1],[0,1]];
    
    for (let i = 0; i < q.length; i++) {
        const [r, c] = q[i];
        for (const [dr, dc] of d) {
            const nr = r + dr, nc = c + dc;
            if (nr >= 0 && nr < m && nc >= 0 && nc < n && h[nr][nc] === -1) {
                h[nr][nc] = h[r][c] + 1;
                q.push([nr, nc]);
            }
        }
    }
    
    return h;
};

# Key Insights

- **Multi-source BFS:** Start from all water cells simultaneously
- **Distance interpretation:** Height = distance from nearest water
- **Level-by-level:** BFS naturally processes cells in order of distance
- **Maximized heights:** Cells farthest from water get highest values
- **Constraint satisfaction:** Adjacent cells differ by exactly 1 (BFS property)

---

# Why This Works

**Correctness proof:**
1. **Water cells = 0:** Explicitly set in initialization ✓
2. **Non-negative:** All heights ≥ 0 ✓
3. **Adjacent difference ≤ 1:** BFS ensures each cell is exactly 1 more than parent ✓
4. **Maximized:** BFS finds shortest path = minimum height, but since all paths from water increase by 1 per step, this is also the maximum valid height ✓

# Common Mistakes to Avoid

1. **Using single-source BFS:**
   ```typescript
   // Wrong: only starting from one water cell
   queue.push([firstWaterCell]);
   
   // Correct: start from ALL water cells
   for (let i = 0; i < m; i++) {
       for (let j = 0; j < n; j++) {
           if (isWater[i][j] === 1) {
               queue.push([i, j]);
           }
       }
   }
   ```

2. **Not marking visited cells:**
   ```typescript
   // Wrong: might revisit cells
   if (inBounds(nr, nc)) {
       queue.push([nr, nc]);
   }
   
   // Correct: check if unvisited
   if (inBounds(nr, nc) && height[nr][nc] === -1) {
       height[nr][nc] = height[r][c] + 1;
       queue.push([nr, nc]);
   }
   ```

3. **Using DFS instead of BFS:**
   ```typescript
   // Wrong: DFS doesn't guarantee shortest distance
   function dfs(r, c, h) {
       height[r][c] = h;
       for (neighbor of neighbors) {
           dfs(neighbor, h + 1);
       }
   }
   
   // Correct: BFS for level-by-level processing
   ```

4. **Forgetting to initialize water cells:**
   ```typescript
   // Wrong: water cells not set to 0
   const height = Array(m).fill(Array(n).fill(-1));
   
   // Correct: set water cells to 0 before BFS
   if (isWater[i][j] === 1) {
       height[i][j] = 0;
   }
   ```

# Optimization Tips

1. **Use index instead of shift():**
   ```typescript
   // Slower: O(n) per operation
   const cell = queue.shift();
   
   // Faster: O(1) per operation
   let index = 0;
   while (index < queue.length) {
       const cell = queue[index++];
   }
   ```

2. **Pre-allocate arrays:**
   ```typescript
   // Better memory management
   const height = Array.from({ length: m }, () => Array(n).fill(-1));
   ```
