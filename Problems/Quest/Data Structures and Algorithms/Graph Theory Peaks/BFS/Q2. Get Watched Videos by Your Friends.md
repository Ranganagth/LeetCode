# Intuition

This problem combines **BFS (to find people at a specific level)** with **frequency counting and sorting**. We need to:
1. Find all people at exactly distance `level` from person `id` using BFS
2. Collect all videos watched by those people
3. Sort by frequency (ascending), then alphabetically

**Key insight:** Use BFS to traverse the friend network level by level, stopping at the target level.

---

# Approach

1. **BFS to find people at target level:**
   - Start from person `id`
   - Traverse friend network level by level
   - Track visited people to avoid cycles
   - Stop when reaching the target level

2. **Collect and count videos:**
   - For all people at target level, collect their watched videos
   - Count frequency of each video

3. **Sort results:**
   - Sort by frequency (ascending)
   - For same frequency, sort alphabetically

---

# Complexity

- **Time complexity:** $O(n + e + v log v)$ where:
  - n = number of people
  - e = number of friendships
  - v = number of unique videos
- **Space complexity:** $O(n + v)$ for visited set, queue, and frequency map

# Code

## Solution 1: BFS with Frequency Counting (Recommended)

```typescript
function watchedVideosByFriends(
    watchedVideos: string[][], 
    friends: number[][], 
    id: number, 
    level: number
): string[] {
    // Step 1: BFS to find all people at the target level
    const visited = new Set<number>([id]);
    let queue: number[] = [id];
    let currentLevel = 0;
    
    while (currentLevel < level) {
        const nextQueue: number[] = [];
        
        for (const person of queue) {
            for (const friend of friends[person]) {
                if (!visited.has(friend)) {
                    visited.add(friend);
                    nextQueue.push(friend);
                }
            }
        }
        
        queue = nextQueue;
        currentLevel++;
    }
    
    // Step 2: Count video frequencies from people at target level
    const videoFreq = new Map<string, number>();
    
    for (const person of queue) {
        for (const video of watchedVideos[person]) {
            videoFreq.set(video, (videoFreq.get(video) || 0) + 1);
        }
    }
    
    // Step 3: Sort by frequency, then alphabetically
    const result = Array.from(videoFreq.entries())
        .sort((a, b) => {
            if (a[1] !== b[1]) {
                return a[1] - b[1]; // Sort by frequency (ascending)
            }
            return a[0].localeCompare(b[0]); // Sort alphabetically
        })
        .map(([video, _]) => video);
    
    return result;
};

```

## Solution 2: With Detailed Comments

```typescript
function watchedVideosByFriends(
    watchedVideos: string[][], 
    friends: number[][], 
    id: number, 
    level: number
): string[] {
    // Step 1: Use BFS to find all people at exactly 'level' distance from 'id'
    const visited = new Set<number>();
    visited.add(id); // Mark starting person as visited
    
    let currentLevelPeople: number[] = [id];
    let currentLevel = 0;
    
    // Traverse level by level until we reach target level
    while (currentLevel < level) {
        const nextLevelPeople: number[] = [];
        
        // For each person at current level, explore their friends
        for (const person of currentLevelPeople) {
            for (const friend of friends[person]) {
                // Only visit unvisited friends
                if (!visited.has(friend)) {
                    visited.add(friend);
                    nextLevelPeople.push(friend);
                }
            }
        }
        
        currentLevelPeople = nextLevelPeople;
        currentLevel++;
    }
    
    // Step 2: Collect all videos watched by people at target level
    // and count their frequencies
    const videoFrequency = new Map<string, number>();
    
    for (const person of currentLevelPeople) {
        for (const video of watchedVideos[person]) {
            videoFrequency.set(
                video, 
                (videoFrequency.get(video) || 0) + 1
            );
        }
    }
    
    // Step 3: Convert to array and sort
    const videos = Array.from(videoFrequency.entries());
    
    videos.sort((a, b) => {
        const [videoA, freqA] = a;
        const [videoB, freqB] = b;
        
        // Primary sort: by frequency (ascending)
        if (freqA !== freqB) {
            return freqA - freqB;
        }
        
        // Secondary sort: alphabetically (ascending)
        return videoA.localeCompare(videoB);
    });
    
    // Extract just the video names
    return videos.map(([video, _]) => video);
};
```

## Solution 3: Using Queue Class

```typescript
function watchedVideosByFriends(
    watchedVideos: string[][], 
    friends: number[][], 
    id: number, 
    level: number
): string[] {
    const visited = new Set<number>([id]);
    const queue: number[] = [id];
    
    // BFS to target level
    for (let lvl = 0; lvl < level; lvl++) {
        const size = queue.length;
        
        for (let i = 0; i < size; i++) {
            const person = queue.shift()!;
            
            for (const friend of friends[person]) {
                if (!visited.has(friend)) {
                    visited.add(friend);
                    queue.push(friend);
                }
            }
        }
    }
    
    // Count videos
    const freq = new Map<string, number>();
    for (const person of queue) {
        for (const video of watchedVideos[person]) {
            freq.set(video, (freq.get(video) || 0) + 1);
        }
    }
    
    // Sort and return
    return [...freq.entries()]
        .sort((a, b) => a[1] - b[1] || a[0].localeCompare(b[0]))
        .map(([v]) => v);
};
```

# Key Insights

- **BFS for level finding:** Natural way to find people at exact distance
- **Visited set crucial:** Prevents cycles in friend network
- **Level-by-level processing:** Use separate queue for each level
- **Frequency counting:** Map to track video occurrences
- **Two-key sorting:** First by frequency, then alphabetically

# Edge Cases

| Case | Description | Example | Notes |
|------|-------------|---------|-------|
| Level 1 | Direct friends | id=0, level=1 | Most common |
| No friends at level | Empty result | Disconnected graph | Return [] |
| Single person | Only one at level | Small network | Works fine |
| Same video multiple times | Count each occurrence | Duplicates in list | Count all |
| All same frequency | Alphabetical only | Tie-breaking | Use localeCompare |

# Common Mistakes to Avoid

1. **Not using level-by-level BFS:**
   ```typescript
   // Wrong: standard BFS visits all reachable
   while (queue.length > 0) {
       const person = queue.shift();
       // This visits ALL levels, not just target level
   }
   
   // Correct: track levels explicitly
   for (let lvl = 0; lvl < level; lvl++) {
       const nextQueue = [];
       for (const person of queue) {
           // Process current level
       }
       queue = nextQueue;
   }
   ```

2. **Forgetting to mark as visited:**
   ```typescript
   // Wrong: might revisit people
   for (const friend of friends[person]) {
       queue.push(friend);
   }
   
   // Correct: check visited first
   for (const friend of friends[person]) {
       if (!visited.has(friend)) {
           visited.add(friend);
           queue.push(friend);
       }
   }
   ```

3. **Wrong sorting logic:**
   ```typescript
   // Wrong: sorting by frequency descending
   .sort((a, b) => b[1] - a[1])
   
   // Correct: ascending frequency, then alphabetical
   .sort((a, b) => a[1] - b[1] || a[0].localeCompare(b[0]))
   ```

4. **Not handling empty level:**
   ```typescript
   // Wrong: assuming people exist at level
   for (const person of queue) {
       // queue might be empty!
   }
   
   // Correct: check if queue is empty
   if (queue.length === 0) return [];
   ```

# Performance Analysis

For n = 100 people, v = 100 videos:

| Operation | Time | Notes |
|-----------|------|-------|
| BFS | $O(n + e)$ | Visit people and edges |
| Count videos | $O(n × v)$ | Worst case all watch all |
| Sort | $O(v log v)$ | Sort unique videos |
| **Total** | **$O(n + e + v log v)$** | **Efficient** |

# Sorting Comparison

```typescript
// Method 1: Explicit if-else
.sort((a, b) => {
    if (a[1] !== b[1]) return a[1] - b[1];
    return a[0].localeCompare(b[0]);
})

// Method 2: Short-circuit OR
.sort((a, b) => a[1] - b[1] || a[0].localeCompare(b[0]))

// Both are equivalent, method 2 is more concise
```
