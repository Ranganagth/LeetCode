# Intuition

This is a **graph traversal problem** where we need to find the minimum number of buses (not stops) to reach the target. The key insight is to treat **buses as nodes** in a graph, not individual stops.

**Key observations:**
1. We want to minimize **bus transfers**, not stops visited
2. Two buses are "connected" if they share at least one stop
3. This is a **BFS problem** on the bus graph
4. Need to track which buses we can board from current stops

---

# Approach

1. **Build stop-to-buses mapping:**
   - Map each stop to all buses that visit it
   - This helps find which buses we can transfer to

2. **BFS on buses:**
   - Start with all buses that visit the source stop
   - For each bus, explore all stops it visits
   - From those stops, find new buses we can transfer to
   - Track number of buses taken (not stops)

3. **Early termination:**
   - If source equals target, return 0
   - If target is on current bus, we found the answer

---

# Complexity

- **Time complexity:** $O(N × S)$ where N is number of buses, S is total stops
- **Space complexity:** $O(N × S)$ for mappings and visited tracking

# Code

## Solution 1: BFS on Buses (Recommended)

```typescript
function numBusesToDestination(routes: number[][], source: number, target: number): number {
    // Edge case: already at target
    if (source === target) return 0;
    
    // Build stop-to-buses mapping
    const stopToBuses = new Map<number, number[]>();
    
    for (let busIdx = 0; busIdx < routes.length; busIdx++) {
        for (const stop of routes[busIdx]) {
            if (!stopToBuses.has(stop)) {
                stopToBuses.set(stop, []);
            }
            stopToBuses.get(stop)!.push(busIdx);
        }
    }
    
    // BFS: queue stores bus indices
    const queue: number[] = [];
    const visitedBuses = new Set<number>();
    const visitedStops = new Set<number>();
    
    // Start with all buses that visit the source stop
    if (stopToBuses.has(source)) {
        for (const busIdx of stopToBuses.get(source)!) {
            queue.push(busIdx);
            visitedBuses.add(busIdx);
        }
    }
    
    let busCount = 1; // We've boarded the first bus
    
    while (queue.length > 0) {
        const size = queue.length;
        
        // Process all buses at current level
        for (let i = 0; i < size; i++) {
            const busIdx = queue.shift()!;
            
            // Check all stops on this bus
            for (const stop of routes[busIdx]) {
                // Found target!
                if (stop === target) {
                    return busCount;
                }
                
                // Skip if we've already processed this stop
                if (visitedStops.has(stop)) continue;
                visitedStops.add(stop);
                
                // Find all buses at this stop and add to queue
                if (stopToBuses.has(stop)) {
                    for (const nextBus of stopToBuses.get(stop)!) {
                        if (!visitedBuses.has(nextBus)) {
                            visitedBuses.add(nextBus);
                            queue.push(nextBus);
                        }
                    }
                }
            }
        }
        
        busCount++; // Increment after processing all buses at this level
    }
    
    return -1; // Target not reachable
};

```

## Solution 2: With Detailed Comments

```typescript
function numBusesToDestination(routes: number[][], source: number, target: number): number {
    // Edge case: already at destination
    if (source === target) return 0;
    
    // Step 1: Build a mapping from each stop to all buses that visit it
    // This allows us to quickly find which buses we can transfer to
    const stopToBuses = new Map<number, number[]>();
    
    for (let busIndex = 0; busIndex < routes.length; busIndex++) {
        for (const stop of routes[busIndex]) {
            if (!stopToBuses.has(stop)) {
                stopToBuses.set(stop, []);
            }
            stopToBuses.get(stop)!.push(busIndex);
        }
    }
    
    // Step 2: BFS to find minimum number of buses
    // We do BFS on buses, not stops!
    const queue: number[] = [];
    const visitedBuses = new Set<number>();
    const visitedStops = new Set<number>();
    
    // Step 3: Initialize queue with all buses that visit source stop
    if (stopToBuses.has(source)) {
        for (const busIndex of stopToBuses.get(source)!) {
            queue.push(busIndex);
            visitedBuses.add(busIndex);
        }
    }
    
    // If no buses visit source, target is unreachable
    if (queue.length === 0) return -1;
    
    let numberOfBuses = 1; // We've boarded our first bus
    
    // Step 4: BFS traversal
    while (queue.length > 0) {
        const levelSize = queue.length;
        
        // Process all buses at current level (same number of transfers)
        for (let i = 0; i < levelSize; i++) {
            const currentBus = queue.shift()!;
            
            // Check all stops on this bus route
            for (const stop of routes[currentBus]) {
                // Check if we've reached the target
                if (stop === target) {
                    return numberOfBuses;
                }
                
                // Skip if we've already explored this stop
                if (visitedStops.has(stop)) continue;
                visitedStops.add(stop);
                
                // Find all buses at this stop (potential transfers)
                if (stopToBuses.has(stop)) {
                    for (const nextBus of stopToBuses.get(stop)!) {
                        if (!visitedBuses.has(nextBus)) {
                            visitedBuses.add(nextBus);
                            queue.push(nextBus);
                        }
                    }
                }
            }
        }
        
        // Increment bus count after processing all buses at this level
        numberOfBuses++;
    }
    
    // Target not reachable
    return -1;
};
```

## Solution 3: Optimized with Early Stop Check

```typescript
function numBusesToDestination(routes: number[][], source: number, target: number): number {
    if (source === target) return 0;
    
    const stopToBuses = new Map<number, number[]>();
    const targetBuses = new Set<number>(); // Buses that visit target
    
    for (let i = 0; i < routes.length; i++) {
        for (const stop of routes[i]) {
            if (!stopToBuses.has(stop)) {
                stopToBuses.set(stop, []);
            }
            stopToBuses.get(stop)!.push(i);
            
            if (stop === target) {
                targetBuses.add(i);
            }
        }
    }
    
    if (!stopToBuses.has(source)) return -1;
    
    const queue: number[] = [];
    const visitedBuses = new Set<number>();
    
    for (const bus of stopToBuses.get(source)!) {
        // Early check: if source bus also visits target
        if (targetBuses.has(bus)) return 1;
        
        queue.push(bus);
        visitedBuses.add(bus);
    }
    
    let buses = 1;
    
    while (queue.length > 0) {
        const size = queue.length;
        
        for (let i = 0; i < size; i++) {
            const bus = queue.shift()!;
            
            for (const stop of routes[bus]) {
                if (!stopToBuses.has(stop)) continue;
                
                for (const nextBus of stopToBuses.get(stop)!) {
                    if (visitedBuses.has(nextBus)) continue;
                    
                    if (targetBuses.has(nextBus)) {
                        return buses + 1;
                    }
                    
                    visitedBuses.add(nextBus);
                    queue.push(nextBus);
                }
            }
        }
        
        buses++;
    }
    
    return -1;
};

```

## Solution 4: Compact Version

```typescript
function numBusesToDestination(routes: number[][], source: number, target: number): number {
    if (source === target) return 0;
    
    const stopMap = new Map<number, number[]>();
    
    for (let i = 0; i < routes.length; i++) {
        for (const stop of routes[i]) {
            if (!stopMap.has(stop)) stopMap.set(stop, []);
            stopMap.get(stop)!.push(i);
        }
    }
    
    if (!stopMap.has(source)) return -1;
    
    const q: number[] = [];
    const visBus = new Set<number>();
    const visStop = new Set<number>();
    
    for (const bus of stopMap.get(source)!) {
        q.push(bus);
        visBus.add(bus);
    }
    
    let cnt = 1;
    
    while (q.length > 0) {
        const sz = q.length;
        
        for (let i = 0; i < sz; i++) {
            const bus = q.shift()!;
            
            for (const stop of routes[bus]) {
                if (stop === target) return cnt;
                if (visStop.has(stop)) continue;
                visStop.add(stop);
                
                for (const nb of stopMap.get(stop) || []) {
                    if (!visBus.has(nb)) {
                        visBus.add(nb);
                        q.push(nb);
                    }
                }
            }
        }
        cnt++;
    }
    
    return -1;
};

```

# Key Insights

- **BFS on buses, not stops:** Minimize bus transfers
- **Stop-to-buses mapping:** Quick lookup for transfers
- **Level-by-level BFS:** Each level = one more bus
- **Two visited sets:** Track both buses and stops
- **Early termination:** Return as soon as target found

---

# Why This Approach Works

**Correctness:**
1. BFS guarantees shortest path (minimum buses)
2. Level-by-level processing ensures we count buses correctly
3. Visited tracking prevents infinite loops
4. Stop-to-buses mapping finds all transfer options

**Efficiency:**
- Each bus visited at most once
- Each stop processed at most once per bus
- $O(N × S)$ where N = buses, S = total stops

# Common Mistakes to Avoid

1. **BFS on stops instead of buses:**
   ```typescript
   // Wrong: counting stops
   for (const stop of route) {
       queue.push(stop);
   }
   
   // Correct: counting buses
   for (const busIdx of stopToBuses.get(stop)) {
       queue.push(busIdx);
   }
   ```

2. **Not using level-by-level BFS:**
   ```typescript
   // Wrong: incrementing for each bus
   while (queue.length > 0) {
       const bus = queue.shift();
       busCount++;
   }
   
   // Correct: increment per level
   while (queue.length > 0) {
       const size = queue.length;
       for (let i = 0; i < size; i++) {
           // process
       }
       busCount++;
   }
   ```

3. **Not tracking visited stops:**
   ```typescript
   // Wrong: might process same stop multiple times
   for (const stop of routes[bus]) {
       // process all buses at stop
   }
   
   // Correct: skip visited stops
   if (visitedStops.has(stop)) continue;
   visitedStops.add(stop);
   ```

4. **Forgetting edge case:**
   ```typescript
   // Wrong: missing check
   function numBusesToDestination(...) {
       // start BFS
   }
   
   // Correct: check first
   if (source === target) return 0;
   ```

# Optimization Tips

1. **Pre-compute target buses:**
   ```typescript
   const targetBuses = new Set();
   // Mark buses that visit target
   // Early return if current bus in set
   ```

2. **Use array index instead of shift():**
   ```typescript
   let qIdx = 0;
   while (qIdx < queue.length) {
       const bus = queue[qIdx++];
   }
   ```
