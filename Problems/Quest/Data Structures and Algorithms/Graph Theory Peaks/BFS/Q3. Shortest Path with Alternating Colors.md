# Intuition

We need to find the shortest path from node 0 to all other nodes with the constraint that **edge colors must alternate** (red → blue → red or blue → red → blue). This is a **BFS problem with state tracking** where the state includes both the current node and the color of the last edge used.

**Key insight:** Track visited states as `(node, lastColor)` pairs to handle the alternating constraint.

---

# Approach

1. **Build adjacency lists** for red and blue edges separately

2. **BFS with state tracking:**
   - State: `(node, lastEdgeColor, distance)`
   - Start from node 0 with both red and blue edges (two initial states)
   - For each state, only traverse edges of the opposite color
   - Track visited `(node, color)` pairs to avoid cycles

3. **Track minimum distances:**
   - For each node, track the minimum distance found
   - A node can be reached via different colored edges

---

# Complexity

- **Time complexity:** $O(n + e)$ where e is total number of edges
- **Space complexity:** $O(n + e)$ for graphs and visited tracking

# Code

## Solution 1: BFS with State Tracking (Recommended)

```typescript
function shortestAlternatingPaths(n: number, redEdges: number[][], blueEdges: number[][]): number[] {
    // Build adjacency lists for red and blue edges
    const redGraph = new Map<number, number[]>();
    const blueGraph = new Map<number, number[]>();
    
    for (let i = 0; i < n; i++) {
        redGraph.set(i, []);
        blueGraph.set(i, []);
    }
    
    for (const [from, to] of redEdges) {
        redGraph.get(from)!.push(to);
    }
    
    for (const [from, to] of blueEdges) {
        blueGraph.get(from)!.push(to);
    }
    
    // Result array initialized to -1 (unreachable)
    const result = new Array(n).fill(-1);
    result[0] = 0; // Distance to node 0 is 0
    
    // BFS: [node, lastColor, distance]
    // lastColor: 0 = red, 1 = blue
    const queue: [number, number, number][] = [];
    
    // Start with both colors from node 0
    queue.push([0, 0, 0]); // Starting with red edge
    queue.push([0, 1, 0]); // Starting with blue edge
    
    // Visited: track (node, lastColor) pairs
    const visited = new Set<string>();
    visited.add('0,0');
    visited.add('0,1');
    
    while (queue.length > 0) {
        const [node, lastColor, dist] = queue.shift()!;
        
        // Choose the opposite color graph to traverse
        const nextGraph = lastColor === 0 ? blueGraph : redGraph;
        const nextColor = lastColor === 0 ? 1 : 0;
        
        for (const neighbor of nextGraph.get(node)!) {
            const stateKey = `${neighbor},${nextColor}`;
            
            if (!visited.has(stateKey)) {
                visited.add(stateKey);
                
                // Update result if this is the first time reaching this node
                // or if we found a shorter path
                if (result[neighbor] === -1) {
                    result[neighbor] = dist + 1;
                }
                
                queue.push([neighbor, nextColor, dist + 1]);
            }
        }
    }
    
    return result;
};

```

## Solution 2: With Detailed Comments

```typescript
function shortestAlternatingPaths(n: number, redEdges: number[][], blueEdges: number[][]): number[] {
    // Step 1: Build separate adjacency lists for red and blue edges
    const redGraph = new Map<number, number[]>();
    const blueGraph = new Map<number, number[]>();
    
    // Initialize empty adjacency lists
    for (let i = 0; i < n; i++) {
        redGraph.set(i, []);
        blueGraph.set(i, []);
    }
    
    // Populate red edges
    for (const [from, to] of redEdges) {
        redGraph.get(from)!.push(to);
    }
    
    // Populate blue edges
    for (const [from, to] of blueEdges) {
        blueGraph.get(from)!.push(to);
    }
    
    // Step 2: Initialize result array
    const answer = new Array(n).fill(-1);
    answer[0] = 0; // Starting node has distance 0
    
    // Step 3: BFS with state tracking
    // State: [currentNode, lastEdgeColor, distanceFromStart]
    // Color encoding: 0 = RED, 1 = BLUE
    const queue: [number, number, number][] = [];
    
    // We can start with either a red or blue edge from node 0
    // So we add both possibilities to the queue
    queue.push([0, 0, 0]); // Start with red edge
    queue.push([0, 1, 0]); // Start with blue edge
    
    // Track visited states to avoid infinite loops
    // Key format: "node,lastColor"
    const visited = new Set<string>();
    visited.add('0,0'); // Visited node 0 via red
    visited.add('0,1'); // Visited node 0 via blue
    
    // Step 4: BFS traversal
    while (queue.length > 0) {
        const [currentNode, lastColor, distance] = queue.shift()!;
        
        // Determine which graph to use next (must alternate colors)
        // If last edge was red (0), use blue graph (1)
        // If last edge was blue (1), use red graph (0)
        const nextGraph = lastColor === 0 ? blueGraph : redGraph;
        const nextColor = lastColor === 0 ? 1 : 0;
        
        // Explore all neighbors via the opposite color
        for (const neighbor of nextGraph.get(currentNode)!) {
            const stateKey = `${neighbor},${nextColor}`;
            
            // Only process if we haven't visited this state before
            if (!visited.has(stateKey)) {
                visited.add(stateKey);
                
                // Update answer if this is the first time reaching this node
                if (answer[neighbor] === -1) {
                    answer[neighbor] = distance + 1;
                }
                
                // Add to queue for further exploration
                queue.push([neighbor, nextColor, distance + 1]);
            }
        }
    }
    
    return answer;
};
```

## Solution 3: Using Enum for Colors

```typescript
function shortestAlternatingPaths(n: number, redEdges: number[][], blueEdges: number[][]): number[] {
    const RED = 0, BLUE = 1;
    
    // Build graphs
    const graphs = [new Map<number, number[]>(), new Map<number, number[]>()];
    
    for (let i = 0; i < n; i++) {
        graphs[RED].set(i, []);
        graphs[BLUE].set(i, []);
    }
    
    for (const [from, to] of redEdges) {
        graphs[RED].get(from)!.push(to);
    }
    
    for (const [from, to] of blueEdges) {
        graphs[BLUE].get(from)!.push(to);
    }
    
    const result = new Array(n).fill(-1);
    result[0] = 0;
    
    // Queue: [node, lastColor, distance]
    const queue: [number, number, number][] = [[0, RED, 0], [0, BLUE, 0]];
    const visited = new Set<string>(['0,0', '0,1']);
    
    while (queue.length > 0) {
        const [node, lastColor, dist] = queue.shift()!;
        const nextColor = 1 - lastColor; // Toggle between 0 and 1
        
        for (const neighbor of graphs[nextColor].get(node)!) {
            const key = `${neighbor},${nextColor}`;
            
            if (!visited.has(key)) {
                visited.add(key);
                if (result[neighbor] === -1) {
                    result[neighbor] = dist + 1;
                }
                queue.push([neighbor, nextColor, dist + 1]);
            }
        }
    }
    
    return result;
};
```

## Solution 4: Compact Version

```typescript
function shortestAlternatingPaths(n: number, redEdges: number[][], blueEdges: number[][]): number[] {
    const g = [new Map(), new Map()];
    
    for (let i = 0; i < n; i++) {
        g[0].set(i, []);
        g[1].set(i, []);
    }
    
    for (const [a, b] of redEdges) g[0].get(a).push(b);
    for (const [a, b] of blueEdges) g[1].get(a).push(b);
    
    const res = Array(n).fill(-1);
    res[0] = 0;
    
    const q = [[0, 0, 0], [0, 1, 0]];
    const vis = new Set(['0,0', '0,1']);
    
    for (let i = 0; i < q.length; i++) {
        const [node, color, dist] = q[i];
        const nextColor = 1 - color;
        
        for (const next of g[nextColor].get(node)) {
            const key = `${next},${nextColor}`;
            if (!vis.has(key)) {
                vis.add(key);
                if (res[next] === -1) res[next] = dist + 1;
                q.push([next, nextColor, dist + 1]);
            }
        }
    }
    
    return res;
};

```

# Visual Representation

**Alternating Path Constraint:**

```
Valid paths:
  0 --RED--> 1 --BLUE--> 2 --RED--> 3 ✓
  0 --BLUE--> 1 --RED--> 2 ✓

Invalid paths:
  0 --RED--> 1 --RED--> 2 ✗ (same color)
  0 --BLUE--> 1 --BLUE--> 2 ✗ (same color)

State tracking:
  (node, lastColor) ensures we only use opposite color next
```

---

# Key Insights

- **State = (node, color):** Must track both position and last edge color
- **Two starting states:** Can begin with either red or blue edge
- **Alternating constraint:** Only traverse opposite color edges
- **BFS for shortest path:** Level-by-level guarantees shortest distance
- **First arrival wins:** First time reaching a node gives shortest path

---

# Why State Tracking is Necessary

**Without state tracking:**
```
Path: 0 --RED--> 1 --RED--> 2
This would be allowed, violating alternating constraint
```

**With state tracking:**
```
State (1, RED) can only explore BLUE edges
State (1, BLUE) can only explore RED edges
Enforces alternating constraint
```

# Edge Cases

| Case | Description | Example | Notes |
|------|-------------|---------|-------|
| No edges | Isolated nodes | redEdges=[], blueEdges=[] | Only node 0 reachable |
| Only one color | All red or all blue | Only redEdges | Limited paths |
| Self-loops | Edge to same node | [[0,0]] | Can alternate with itself |
| Parallel edges | Multiple edges same nodes | [[0,1],[0,1]] | Both tracked |
| Unreachable nodes | Disconnected | Node 2 isolated | Return -1 |

# Common Mistakes to Avoid

1. **Not tracking color in state:**
   ```typescript
   // Wrong: only tracking node
   visited.add(node);
   
   // Correct: track (node, color) pair
   visited.add(`${node},${color}`);
   ```

2. **Not starting with both colors:**
   ```typescript
   // Wrong: only one starting state
   queue.push([0, RED, 0]);
   
   // Correct: both colors possible
   queue.push([0, RED, 0]);
   queue.push([0, BLUE, 0]);
   ```

3. **Using wrong color for next step:**
   ```typescript
   // Wrong: using same color
   const nextGraph = lastColor === 0 ? redGraph : blueGraph;
   
   // Correct: using opposite color
   const nextGraph = lastColor === 0 ? blueGraph : redGraph;
   ```

4. **Overwriting shorter paths:**
   ```typescript
   // Wrong: always updating
   result[neighbor] = dist + 1;
   
   // Correct: only update if first time
   if (result[neighbor] === -1) {
       result[neighbor] = dist + 1;
   }
   ```

# Optimization Tips

1. **Use array index instead of shift():**
   ```typescript
   let qIndex = 0;
   while (qIndex < queue.length) {
       const state = queue[qIndex++];
   }
   ```

2. **Use bit manipulation for color:**
   ```typescript
   const nextColor = color ^ 1; // Toggle between 0 and 1
   ```
