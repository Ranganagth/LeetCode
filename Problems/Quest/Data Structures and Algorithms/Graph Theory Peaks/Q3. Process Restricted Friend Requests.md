# Intuition

We need to process friend requests while ensuring that no two people who are restricted from being friends end up in the same connected component (either directly or indirectly). This is a **Union-Find** problem with constraint checking.

**Key insight:** Before unioning two people, check if merging their components would violate any restriction. If any restricted pair would end up in the same component after the union, reject the request.

---

# Approach

1. **Use Union-Find** to track friend groups (connected components)

2. **For each friend request [u, v]:**
   - Find the root of u and root of v
   - If already in same component, accept (already friends)
   - Otherwise, check all restrictions:
     - For each restriction [x, y], check if merging would put x and y in same component
     - If any violation found, reject the request
   - If no violations, accept and union u and v

3. **Violation check:**
   - After hypothetical union of u and v, x and y would be in same component if:
     - root(x) == root(u) and root(y) == root(v), OR
     - root(x) == root(v) and root(y) == root(u)

---

# Complexity

- **Time complexity:** $O(m × r × α(n))$ where m = requests, r = restrictions, α = inverse Ackermann
- **Space complexity:** $O(n)$ for Union-Find structure

# Code

## Solution 1: Union-Find with Restriction Check (Recommended)

```typescript
function friendRequests(n: number, restrictions: number[][], requests: number[][]): boolean[] {
    const uf = new UnionFind(n);
    const result: boolean[] = [];
    
    for (const [u, v] of requests) {
        const rootU = uf.find(u);
        const rootV = uf.find(v);
        
        // Already in same component (already friends)
        if (rootU === rootV) {
            result.push(true);
            continue;
        }
        
        // Check if union would violate any restriction
        let canUnion = true;
        
        for (const [x, y] of restrictions) {
            const rootX = uf.find(x);
            const rootY = uf.find(y);
            
            // Check if merging u and v would put x and y together
            if ((rootX === rootU && rootY === rootV) || 
                (rootX === rootV && rootY === rootU)) {
                canUnion = false;
                break;
            }
        }
        
        if (canUnion) {
            uf.union(u, v);
            result.push(true);
        } else {
            result.push(false);
        }
    }
    
    return result;
}

class UnionFind {
    parent: number[];
    rank: number[];
    
    constructor(size: number) {
        this.parent = Array.from({ length: size }, (_, i) => i);
        this.rank = new Array(size).fill(0);
    }
    
    find(x: number): number {
        if (this.parent[x] !== x) {
            this.parent[x] = this.find(this.parent[x]); // Path compression
        }
        return this.parent[x];
    }
    
    union(x: number, y: number): void {
        const rootX = this.find(x);
        const rootY = this.find(y);
        
        if (rootX === rootY) return;
        
        // Union by rank
        if (this.rank[rootX] < this.rank[rootY]) {
            this.parent[rootX] = rootY;
        } else if (this.rank[rootX] > this.rank[rootY]) {
            this.parent[rootY] = rootX;
        } else {
            this.parent[rootY] = rootX;
            this.rank[rootX]++;
        }
    }
};

```

## Solution 2: With Detailed Comments

```typescript
function friendRequests(n: number, restrictions: number[][], requests: number[][]): boolean[] {
    const parent = Array.from({ length: n }, (_, i) => i);
    const rank = new Array(n).fill(0);
    const result: boolean[] = [];
    
    function find(x: number): number {
        if (parent[x] !== x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    function union(x: number, y: number): void {
        const rootX = find(x);
        const rootY = find(y);
        
        if (rootX === rootY) return;
        
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
    }
    
    // Process each friend request
    for (const [u, v] of requests) {
        const rootU = find(u);
        const rootV = find(v);
        
        // Case 1: Already friends (in same component)
        if (rootU === rootV) {
            result.push(true);
            continue;
        }
        
        // Case 2: Check if union would violate restrictions
        let violatesRestriction = false;
        
        for (const [x, y] of restrictions) {
            const rootX = find(x);
            const rootY = find(y);
            
            // After union, would x and y be in same component?
            // This happens if:
            // - x is in u's component AND y is in v's component, OR
            // - x is in v's component AND y is in u's component
            if ((rootX === rootU && rootY === rootV) || 
                (rootX === rootV && rootY === rootU)) {
                violatesRestriction = true;
                break;
            }
        }
        
        // Case 3: Accept or reject based on restriction check
        if (violatesRestriction) {
            result.push(false);
        } else {
            union(u, v);
            result.push(true);
        }
    }
    
    return result;
};
```

## Solution 3: Optimized with Early Restriction Check

```typescript
function friendRequests(n: number, restrictions: number[][], requests: number[][]): boolean[] {
    const parent = Array.from({ length: n }, (_, i) => i);
    const result: boolean[] = [];
    
    function find(x: number): number {
        if (parent[x] !== x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    function canUnion(u: number, v: number): boolean {
        const rootU = find(u);
        const rootV = find(v);
        
        if (rootU === rootV) return true; // Already friends
        
        // Check each restriction
        for (const [x, y] of restrictions) {
            const rootX = find(x);
            const rootY = find(y);
            
            // Would this union violate the restriction?
            if ((rootX === rootU && rootY === rootV) || 
                (rootX === rootV && rootY === rootU)) {
                return false;
            }
        }
        
        return true;
    }
    
    for (const [u, v] of requests) {
        if (canUnion(u, v)) {
            const rootU = find(u);
            const rootV = find(v);
            
            if (rootU !== rootV) {
                parent[rootU] = rootV; // Simple union
            }
            
            result.push(true);
        } else {
            result.push(false);
        }
    }
    
    return result;
};

```

# Key Insights

- **Union-Find:** Track connected components efficiently
- **Restriction check:** Must check BEFORE performing union
- **Hypothetical union:** Check if merging would violate restrictions
- **Already friends:** If in same component, always accept
- **Transitive restriction:** Indirect connections also count

---

# Edge Cases

| Case | Description | Example | Result |
|------|-------------|---------|--------|
| Already friends | Request for existing connection | u, v in same component | true |
| Direct restriction | Restricted pair requested | [0,1] restricted, request [0,1] | false |
| Indirect restriction | Would create indirect connection | Example 1, request 1 | false |
| No restrictions | Empty restrictions array | All requests | All true |
| Self-loop | Request [u, u] | Not in constraints | N/A |

---

# Common Mistakes to Avoid

1. **Not checking before union:**
   ```typescript
   // Wrong: union first, then check
   union(u, v);
   if (violates) {
       // Too late!
   }
   
   // Correct: check first, then union
   if (!violates) {
       union(u, v);
   }
   ```

2. **Wrong violation check:**
   ```typescript
   // Wrong: only checking one direction
   if (rootX === rootU && rootY === rootV)
   
   // Correct: check both directions
   if ((rootX === rootU && rootY === rootV) || 
       (rootX === rootV && rootY === rootU))
   ```

3. **Not handling already friends:**
   ```typescript
   // Wrong: might reject valid request
   if (rootU === rootV) {
       result.push(false);
   }
   
   // Correct: already friends is valid
   if (rootU === rootV) {
       result.push(true);
       continue;
   }
   ```

4. **Forgetting path compression:**
   ```typescript
   // Wrong: slow find
   find(x) {
       while (parent[x] !== x) {
           x = parent[x];
       }
       return x;
   }
   
   // Correct: with path compression
   find(x) {
       if (parent[x] !== x) {
           parent[x] = find(parent[x]);
       }
       return parent[x];
   }
   ```

| **Total** | **$O(m × r × α(n))$** | **Acceptable** |
