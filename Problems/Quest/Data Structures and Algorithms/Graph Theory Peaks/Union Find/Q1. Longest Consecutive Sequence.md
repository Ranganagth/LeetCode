# Intuition

To find the longest consecutive sequence efficiently (in O(n)), a **hash set** can be used for constant-time lookups. The key idea:

- Insert all numbers into a set for $O(1)$ access.
- For each number, only start counting a sequence if it is the **smallest** in its sequence (i.e., `num - 1` is not in the set).
- Expand from that number upwards to find the length of the sequence.
- Keep track of the maximum sequence length found.

This approach ensures each number is$ processed at m$ost twice, maintaining O(n) complexity.

---

# Approach

1. **Insert all numbers into a set** for quick lookup.
2. **Iterate through each number:**
   - If `num - 1` is **not** in the set, then `num` is the start of a sequence.
   - Count how many consecutive numbers exist starting from `num`.
3. **Update the maximum length** during each sequence count.
4. Return the maximum length found.

---

# Implementation

```typescript
function longestConsecutive(nums: number[]): number {
    const numSet = new Set(nums);
    let maxLength = 0;

    for (const num of numSet) {
        // Only start counting if 'num' is the start of a sequence
        if (!numSet.has(num - 1)) {
            let currentNum = num;
            let currentLength = 1;

            // Count upwards
            while (numSet.has(currentNum + 1)) {
                currentNum++;
                currentLength++;
            }

            maxLength = Math.max(maxLength, currentLength);
        }
    }

    return maxLength;
};

```

# Example Walkthrough

### Example 1:
`nums = [100,4,200,1,3,2]`

- Set: `{1, 2, 3, 4, 100, 200}`
- Start with `1` (since `0` not in set):
  - Count: 1, 2, 3, 4 → sequence length = 4
- Other numbers are either part of this sequence or isolated
- Max length = 4

### Example 2:
`nums = [0,3,7,2,5,8,4,6,0,1]`

- Set: `{0,1,2,3,4,5,6,7,8}`
- Starting from `0` (since `-1` not in set):
  - Count: 0 to 8 → length = 9
- Max length = 9

---

# Summary

- Use a set for $O(1)$ lookups
- Only start counting sequences at the smallest element of each sequence
- Expand upwards to find sequence length
- Track maximum length

> This approach guarantees an $O(n)$ runtime, suitable for large input sizes.
