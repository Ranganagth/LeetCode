# Intuition

We need to find a path starting and ending at node 0 that maximizes the sum of unique node values while staying within the time limit. This is a **backtracking/DFS** problem where we explore all possible paths.

**Key insights:**
1. Must start and end at node 0
2. Can visit nodes multiple times, but count value only once
3. At most 4 edges per node limits branching factor
4. Small maxTime (≤100) and edge weights (≥10) limit path length
5. Use DFS with backtracking to explore all valid paths

---

# Approach

1. **Build adjacency list** from edges with travel times

2. **DFS with backtracking:**
   - Track current node, time used, visited nodes, and current quality
   - For each neighbor, recursively explore if time permits
   - When back at node 0, update maximum quality
   - Backtrack: unmark visited nodes when returning

3. **Optimization:**
   - Only count node value on first visit
   - Prune paths that exceed maxTime
   - Update answer only when returning to node 0

---

# Complexity

- **Time complexity:** O(4^k) where k is max path length (≈ maxTime/10)
  - At most 4 neighbors per node
  - Path length limited by time
  - In practice, much faster due to pruning
- **Space complexity:** O(n) for recursion stack and visited set

# Code

## Solution 1: DFS with Backtracking (Recommended)

```typescript
function maximalPathQuality(values: number[], edges: number[][], maxTime: number): number {
    const n = values.length;
    
    // Build adjacency list
    const graph: Map<number, [number, number][]> = new Map();
    for (let i = 0; i < n; i++) {
        graph.set(i, []);
    }
    
    for (const [u, v, time] of edges) {
        graph.get(u)!.push([v, time]);
        graph.get(v)!.push([u, time]);
    }
    
    // Track visited nodes and their visit count
    const visited = new Array(n).fill(0);
    let maxQuality = 0;
    
    function dfs(node: number, timeUsed: number, quality: number) {
        // If we're back at node 0, update max quality
        if (node === 0) {
            maxQuality = Math.max(maxQuality, quality);
        }
        
        // Try visiting each neighbor
        for (const [neighbor, travelTime] of graph.get(node)!) {
            const newTime = timeUsed + travelTime;
            
            // Prune: skip if exceeds time limit
            if (newTime > maxTime) continue;
            
            // Calculate new quality
            let newQuality = quality;
            if (visited[neighbor] === 0) {
                // First visit to this node, add its value
                newQuality += values[neighbor];
            }
            
            // Mark as visited
            visited[neighbor]++;
            
            // Recurse
            dfs(neighbor, newTime, newQuality);
            
            // Backtrack
            visited[neighbor]--;
        }
    }
    
    // Start DFS from node 0
    visited[0] = 1;
    dfs(0, 0, values[0]);
    
    return maxQuality;
};

```

function maximalPathQuality(values: number[], edges: number[][], maxTime: number): number {
    const n = values.length;
    
    // Step 1: Build adjacency list representation of graph
    const graph: Map<number, Array<[number, number]>> = new Map();
    
    for (let i = 0; i < n; i++) {
        graph.set(i, []);
    }
    
    for (const [u, v, time] of edges) {
        // Undirected graph: add edge in both directions
        graph.get(u)!.push([v, time]);
        graph.get(v)!.push([u, time]);
    }
    
    // Step 2: Track state during DFS
    // visited[i] = number of times node i has been visited in current path
    const visited = new Array(n).fill(0);
    let maxQuality = 0;
    
    // Step 3: DFS to explore all valid paths
    function dfs(currentNode: number, timeUsed: number, currentQuality: number) {
        // Check if we've returned to start node 0
        // Only update answer when we complete a valid cycle
        if (currentNode === 0) {
            maxQuality = Math.max(maxQuality, currentQuality);
        }
        
        // Explore all neighbors
        for (const [neighbor, travelTime] of graph.get(currentNode)!) {
            const newTime = timeUsed + travelTime;
            
            // Pruning: skip if this path would exceed time limit
            if (newTime > maxTime) {
                continue;
            }
            
            // Calculate quality if we visit this neighbor
            let newQuality = currentQuality;
            
            // Only add value if this is the first visit to this node
            if (visited[neighbor] === 0) {
                newQuality += values[neighbor];
            }
            
            // Mark node as visited (increment visit count)
            visited[neighbor]++;
            
            // Recursively explore from neighbor
            dfs(neighbor, newTime, newQuality);
            
            // Backtrack: unmark node (decrement visit count)
            visited[neighbor]--;
        }
    }
    
    // Step 4: Start DFS from node 0
    visited[0] = 1; // Mark starting node as visited
    dfs(0, 0, values[0]); // Start with node 0's value
    
    return maxQuality;
};

## Solution 3: Optimized with Early Pruning

```typescript
function maximalPathQuality(values: number[], edges: number[][], maxTime: number): number {
    const n = values.length;
    const graph = new Map<number, [number, number][]>();
    
    // Build graph
    for (let i = 0; i < n; i++) {
        graph.set(i, []);
    }
    for (const [u, v, time] of edges) {
        graph.get(u)!.push([v, time]);
        graph.get(v)!.push([u, time]);
    }
    
    const visited = new Array(n).fill(0);
    let maxQuality = values[0]; // At minimum, we have node 0
    
    function dfs(node: number, time: number, quality: number) {
        // Update answer when at node 0
        if (node === 0) {
            maxQuality = Math.max(maxQuality, quality);
        }
        
        // Early termination: if we can't even return to 0, stop
        // This is an optimization but not strictly necessary
        
        for (const [next, cost] of graph.get(node)!) {
            if (time + cost > maxTime) continue;
            
            const addValue = visited[next] === 0 ? values[next] : 0;
            visited[next]++;
            
            dfs(next, time + cost, quality + addValue);
            
            visited[next]--;
        }
    }
    
    visited[0] = 1;
    dfs(0, 0, values[0]);
    
    return maxQuality;
};

```

# Key Insights

- **Backtracking essential:** Need to explore all paths
- **Visit counting:** Track visits to handle multiple visits correctly
- **Quality calculation:** Only add value on first visit
- **Pruning critical:** Time limit prevents exponential explosion
- **Small branching factor:** At most 4 neighbors limits complexity
- **Must return to 0:** Only update answer when completing cycle

---

# Why This Works

**Correctness:**
1. DFS explores all possible paths from node 0
2. Backtracking ensures we try all combinations
3. Visit counting ensures values added only once
4. Time pruning ensures validity
5. Updating only at node 0 ensures complete cycles

**Efficiency:**
- Small branching factor (≤4)
- Time constraint limits depth
- Early pruning reduces search space
- In practice: O(4^10) ≈ 1M operations (manageable)

# Common Mistakes to Avoid

1. **Not using visit count:**
   ```typescript
   // Wrong: boolean visited
   const visited = new Array(n).fill(false);
   
   // Correct: count visits
   const visited = new Array(n).fill(0);
   ```

2. **Adding value multiple times:**
   ```typescript
   // Wrong: always add value
   newQuality = quality + values[neighbor];
   
   // Correct: only on first visit
   if (visited[neighbor] === 0) {
       newQuality += values[neighbor];
   }
   ```

3. **Not backtracking:**
   ```typescript
   // Wrong: no backtrack
   visited[neighbor] = true;
   dfs(neighbor, ...);
   
   // Correct: backtrack
   visited[neighbor]++;
   dfs(neighbor, ...);
   visited[neighbor]--;
   ```

4. **Updating answer at wrong time:**
   ```typescript
   // Wrong: update anywhere
   maxQuality = Math.max(maxQuality, quality);
   
   // Correct: only at node 0
   if (node === 0) {
       maxQuality = Math.max(maxQuality, quality);
   }
   ```
