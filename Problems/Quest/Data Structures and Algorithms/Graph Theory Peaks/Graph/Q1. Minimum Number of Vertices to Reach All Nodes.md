# Intuition

To reach all nodes in a directed acyclic graph (DAG), we need to start from nodes that have **no incoming edges**. These are the only nodes that cannot be reached from any other node, so they must be in our starting set.

**Key insight:** Any node with at least one incoming edge can be reached from some other node. Therefore, the smallest set of vertices from which all nodes are reachable is exactly the set of nodes with **zero in-degree** (no incoming edges).

---

# Approach

1. **Track nodes with incoming edges:**
   - Create a set to mark all nodes that have at least one incoming edge
   - Iterate through all edges and mark the destination nodes

2. **Find nodes with no incoming edges:**
   - Any node not in the "has incoming edge" set has in-degree 0
   - These are the nodes we must start from

3. **Return the result:**
   - Collect all nodes with in-degree 0

---

# Complexity

- **Time complexity:** $O(n + e)$ where e is number of edges
  - $O(e)$ to process all edges
  - $O(n)$ to check all nodes
- **Space complexity:** $O(n)$ for the set tracking incoming edges

# Code

## Solution 1: Using Set (Recommended)

```typescript
function findSmallestSetOfVertices(n: number, edges: number[][]): number[] {
    // Track all nodes that have incoming edges
    const hasIncoming = new Set<number>();
    
    // Mark all destination nodes (they have incoming edges)
    for (const [from, to] of edges) {
        hasIncoming.add(to);
    }
    
    // Nodes without incoming edges must be in our starting set
    const result: number[] = [];
    for (let i = 0; i < n; i++) {
        if (!hasIncoming.has(i)) {
            result.push(i);
        }
    }
    
    return result;
};

```

## Solution 2: Using Array (In-Degree Count)

```typescript
function findSmallestSetOfVertices(n: number, edges: number[][]): number[] {
    // Count in-degree for each node
    const inDegree = new Array(n).fill(0);
    
    // Increment in-degree for each destination node
    for (const [from, to] of edges) {
        inDegree[to]++;
    }
    
    // Collect nodes with in-degree 0
    const result: number[] = [];
    for (let i = 0; i < n; i++) {
        if (inDegree[i] === 0) {
            result.push(i);
        }
    }
    
    return result;
};

```

## Solution 3: One-Liner Approach

```typescript
function findSmallestSetOfVertices(n: number, edges: number[][]): number[] {
    const hasIncoming = new Set(edges.map(([_, to]) => to));
    return Array.from({ length: n }, (_, i) => i).filter(i => !hasIncoming.has(i));
};
```

## Solution 4: With Detailed Comments

```typescript
function findSmallestSetOfVertices(n: number, edges: number[][]): number[] {
    // Step 1: Identify all nodes that can be reached from other nodes
    // These are the destination nodes in the edges (nodes with incoming edges)
    const hasIncomingEdge = new Set<number>();
    
    for (const [from, to] of edges) {
        // 'to' has an incoming edge from 'from'
        hasIncomingEdge.add(to);
    }
    
    // Step 2: Find all nodes that have NO incoming edges
    // These nodes cannot be reached from any other node,
    // so they MUST be in our starting set
    const result: number[] = [];
    
    for (let node = 0; node < n; node++) {
        if (!hasIncomingEdge.has(node)) {
            // This node has in-degree 0
            result.push(node);
        }
    }
    
    // Step 3: Return the nodes with in-degree 0
    // From these nodes, we can reach all other nodes in the graph
    return result;
};

```

# Key Insights

- **In-degree 0 = must start here:** Nodes with no incoming edges cannot be reached from anywhere else
- **Minimal set:** Any node with incoming edges can be reached from its predecessors
- **DAG property:** No cycles means we don't need to worry about circular dependencies
- **Unique solution:** The set of nodes with in-degree 0 is unique
- **Simple solution:** Just find nodes with no incoming edges

---

# Why This Works

**Proof of correctness:**

1. **Necessity:** Nodes with in-degree 0 MUST be in the starting set
   - They have no incoming edges
   - Cannot be reached from any other node
   - Must be starting points

2. **Sufficiency:** Nodes with in-degree 0 are ENOUGH
   - Every other node has at least one incoming edge
   - Can be reached by following edges from nodes with in-degree 0
   - DAG property ensures no unreachable cycles

3. **Minimality:** This is the smallest such set
   - Removing any node with in-degree 0 makes it unreachable
   - Adding any node with in-degree > 0 is unnecessary

# Common Mistakes to Avoid

1. **Trying to use DFS/BFS:**
   ```typescript
   // Wrong: overcomplicated
   function findSmallestSetOfVertices(n: number, edges: number[][]): number[] {
       // Build graph, run DFS from each node, find minimal set...
       // This is O(n²) or worse!
   }
   
   // Correct: just find in-degree 0
   const hasIncoming = new Set(edges.map(([_, to]) => to));
   return [...Array(n).keys()].filter(i => !hasIncoming.has(i));
   ```

2. **Counting out-degree instead of in-degree:**
   ```typescript
   // Wrong: looking at outgoing edges
   const hasOutgoing = new Set(edges.map(([from, _]) => from));
   
   // Correct: looking at incoming edges
   const hasIncoming = new Set(edges.map(([_, to]) => to));
   ```

3. **Not considering all nodes:**
   ```typescript
   // Wrong: only checking nodes that appear in edges
   const result = [];
   for (const [from, to] of edges) {
       if (!hasIncoming.has(from)) result.push(from);
   }
   
   // Correct: check all nodes 0 to n-1
   for (let i = 0; i < n; i++) {
       if (!hasIncoming.has(i)) result.push(i);
   }
   ```
