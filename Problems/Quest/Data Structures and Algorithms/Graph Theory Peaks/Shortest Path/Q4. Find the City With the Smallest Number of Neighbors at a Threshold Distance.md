# Intuition

We need to find the city that can reach the **fewest number of other cities** within a given distance threshold. If there's a tie, we return the city with the **largest number** (index).

**Key observations:**
1. Need shortest paths between **all pairs** of cities
2. Graph is **undirected** (bidirectional edges)
3. Count reachable cities for each city within threshold
4. Return city with minimum count (ties broken by largest index)

**Best approach:** Use **Floyd-Warshall algorithm** to compute all-pairs shortest paths, then count reachable cities for each.

**Why Floyd-Warshall?**
- Computes shortest paths between all pairs in $O(n³)$
- Simple implementation with 3 nested loops
- Perfect for small graphs (n ≤ 100)
- Handles the "all pairs" requirement efficiently

---

# Approach

**Algorithm Steps:**

1. **Initialize distance matrix:**
   - Create n×n matrix with all distances = Infinity
   - Set diagonal to 0 (distance from city to itself)
   - Add edge weights for direct connections (both directions since bidirectional)

2. **Floyd-Warshall algorithm:**
   - For each intermediate city k
   - For each source city i
   - For each destination city j
   - Update: `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`

3. **Count reachable cities:**
   - For each city, count how many other cities are reachable within threshold
   - Track city with minimum count
   - If tie, prefer larger city number

4. **Return result:**
   - City with smallest reachable count (largest number if tie)

---

# Complexity

**Time Complexity:** $O(n³)$
- Floyd-Warshall: $O(n³)$ with three nested loops
- Counting reachable cities: $O(n²)$
- Total: $O(n³)$

**Space Complexity:** $O(n²)$
- Distance matrix: n×n array
- No additional significant space needed

**For n ≤ 100:**
- Operations: 100³ = 1,000,000 (very acceptable)
- Space: 100² = 10,000 integers (minimal)

# Code

## Solution 1: Floyd-Warshall (Clean Implementation)

```typescript
function findTheCity(n: number, edges: number[][], distanceThreshold: number): number {
    // Initialize distance matrix
    const dist: number[][] = Array.from({ length: n }, () => 
        Array(n).fill(Infinity)
    );
    
    // Distance from city to itself is 0
    for (let i = 0; i < n; i++) {
        dist[i][i] = 0;
    }
    
    // Add edges (bidirectional)
    for (const [from, to, weight] of edges) {
        dist[from][to] = weight;
        dist[to][from] = weight;
    }
    
    // Floyd-Warshall algorithm
    for (let k = 0; k < n; k++) {
        for (let i = 0; i < n; i++) {
            for (let j = 0; j < n; j++) {
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
    
    // Find city with minimum reachable cities
    let minReachable = n;
    let resultCity = 0;
    
    for (let i = 0; i < n; i++) {
        let reachableCount = 0;
        
        for (let j = 0; j < n; j++) {
            if (i !== j && dist[i][j] <= distanceThreshold) {
                reachableCount++;
            }
        }
        
        // Update result (prefer larger city number in case of tie)
        if (reachableCount <= minReachable) {
            minReachable = reachableCount;
            resultCity = i;
        }
    }
    
    return resultCity;
};

```

```typescript
function findTheCity(n: number, edges: number[][], distanceThreshold: number): number {
    // Step 1: Initialize distance matrix with infinity
    // dist[i][j] represents shortest distance from city i to city j
    const dist: number[][] = Array.from({ length: n }, () => 
        Array(n).fill(Infinity)
    );
    
    // Step 2: Set distance from each city to itself as 0
    for (let i = 0; i < n; i++) {
        dist[i][i] = 0;
    }
    
    // Step 3: Add all edges to distance matrix
    // Since edges are bidirectional, add both directions
    for (const [from, to, weight] of edges) {
        dist[from][to] = weight;
        dist[to][from] = weight; // Bidirectional
    }
    
    // Step 4: Floyd-Warshall algorithm
    // Try each city k as intermediate point
    for (let k = 0; k < n; k++) {
        // For each source city i
        for (let i = 0; i < n; i++) {
            // For each destination city j
            for (let j = 0; j < n; j++) {
                // Check if path through k is shorter
                // dist[i][j] vs dist[i][k] + dist[k][j]
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
    
    // Step 5: Count reachable cities for each city
    let minReachableCount = n; // Initialize to maximum possible
    let resultCity = 0;
    
    for (let i = 0; i < n; i++) {
        let reachableCount = 0;
        
        // Count cities reachable from city i within threshold
        for (let j = 0; j < n; j++) {
            // Don't count the city itself
            if (i !== j && dist[i][j] <= distanceThreshold) {
                reachableCount++;
            }
        }
        
        // Update result if this city has fewer reachable cities
        // Use <= to prefer larger city number in case of tie
        if (reachableCount <= minReachableCount) {
            minReachableCount = reachableCount;
            resultCity = i;
        }
    }
    
    return resultCity;
};
```

## Solution 3: Optimized with Early Break

```typescript
function findTheCity(n: number, edges: number[][], distanceThreshold: number): number {
    const INF = 1e9;
    const dist: number[][] = Array.from({ length: n }, () => 
        Array(n).fill(INF)
    );
    
    for (let i = 0; i < n; i++) {
        dist[i][i] = 0;
    }
    
    for (const [u, v, w] of edges) {
        dist[u][v] = w;
        dist[v][u] = w;
    }
    
    // Floyd-Warshall
    for (let k = 0; k < n; k++) {
        for (let i = 0; i < n; i++) {
            for (let j = 0; j < n; j++) {
                dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
            }
        }
    }
    
    let minCount = n;
    let result = 0;
    
    for (let i = 0; i < n; i++) {
        let count = 0;
        for (let j = 0; j < n; j++) {
            if (i !== j && dist[i][j] <= distanceThreshold) {
                count++;
            }
        }
        
        if (count <= minCount) {
            minCount = count;
            result = i;
        }
    }
    
    return result;
};

```

## Solution 4: Compact Version

```typescript
function findTheCity(n: number, edges: number[][], distanceThreshold: number): number {
    const d = Array.from({ length: n }, () => Array(n).fill(Infinity));
    
    for (let i = 0; i < n; i++) d[i][i] = 0;
    for (const [u, v, w] of edges) d[u][v] = d[v][u] = w;
    
    for (let k = 0; k < n; k++)
        for (let i = 0; i < n; i++)
            for (let j = 0; j < n; j++)
                d[i][j] = Math.min(d[i][j], d[i][k] + d[k][j]);
    
    let res = 0, min = n;
    for (let i = 0; i < n; i++) {
        const cnt = d[i].filter((dist, j) => i !== j && dist <= distanceThreshold).length;
        if (cnt <= min) {
            min = cnt;
            res = i;
        }
    }
    
    return res;
};

```

# Visual Representation

## Floyd-Warshall Concept

```
For each intermediate city k:
  For each pair (i, j):
    Check if going through k is shorter
    
    i ──────→ j (direct)
    vs
    i ──→ k ──→ j (through k)
    
    Update: dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

## Why Floyd-Warshall Works

```
Iteration k considers all paths using cities {0, 1, ..., k} as intermediates

k=0: Paths using only city 0
k=1: Paths using cities 0 or 1
k=2: Paths using cities 0, 1, or 2
...
k=n-1: Paths using any intermediate city (all shortest paths)
```

# Key Insights

1. **Floyd-Warshall for all-pairs:** Computes shortest paths between all city pairs efficiently
2. **Bidirectional edges:** Add both directions when building distance matrix
3. **Tie-breaking rule:** Use `<=` to prefer larger city number
4. **Distance threshold:** Only count cities within threshold distance
5. **Self-distance:** Don't count city itself (i !== j check)

# Edge Cases

| Case | Example | Output | Explanation |
|------|---------|--------|-------------|
| All cities reachable | threshold = ∞ | n-1 | Largest city number |
| No cities reachable | threshold = 0 | n-1 | All have 0, pick largest |
| Single reachable | threshold = 1 | Varies | City with fewest connections |
| Tie in count | Multiple cities | Largest | Tie-breaker rule |
| Disconnected graph | Some unreachable | Varies | Count only reachable |

# Common Mistakes to Avoid

1. **Forgetting bidirectional edges:**
   ```typescript
   // Wrong: only one direction
   dist[from][to] = weight;
   
   // Correct: both directions
   dist[from][to] = weight;
   dist[to][from] = weight;
   ```

2. **Wrong tie-breaking:**
   ```typescript
   // Wrong: uses < (prefers smaller city)
   if (count < minCount) { ... }
   
   // Correct: uses <= (prefers larger city)
   if (count <= minCount) { ... }
   ```

3. **Counting self:**
   ```typescript
   // Wrong: counts city itself
   if (dist[i][j] <= threshold) count++;
   
   // Correct: excludes self
   if (i !== j && dist[i][j] <= threshold) count++;
   ```

4. **Wrong loop order in Floyd-Warshall:**
   ```typescript
   // Wrong: k must be outermost loop
   for (let i = 0; i < n; i++)
       for (let k = 0; k < n; k++)
           for (let j = 0; j < n; j++)
   
   // Correct: k is outermost
   for (let k = 0; k < n; k++)
       for (let i = 0; i < n; i++)
           for (let j = 0; j < n; j++)
   ```
