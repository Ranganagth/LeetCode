# Intuition

This is a classic **shortest path problem** where we need to find the time for a signal to reach all nodes from a source node `k`. The answer is the **maximum** of all shortest paths (the time when the last node receives the signal).

**Key insight:** Use **Dijkstra's algorithm** to find shortest paths from source `k` to all other nodes, then return the maximum distance.

---

# Approach

1. **Build adjacency list** from the directed edges with weights

2. **Dijkstra's algorithm:**
   - Start from node `k` with distance 0
   - Use priority queue (min-heap) to always process nearest unvisited node
   - Update distances to neighbors if shorter path found
   - Track visited nodes

3. **Find maximum distance:**
   - After Dijkstra's, check if all nodes are reachable
   - Return the maximum distance (time for last node to receive signal)
   - Return -1 if any node is unreachable

---

# Complexity

- **Time complexity:** O((V + E) log V) using min-heap
  - V = number of nodes (n)
  - E = number of edges (times.length)
- **Space complexity:** $O(V + E)$ for graph and data structures

# Code

## Solution 1: Dijkstra's Algorithm with Min-Heap (Recommended)

```typescript
function networkDelayTime(times: number[][], n: number, k: number): number {
    // Build adjacency list
    const graph = new Map<number, Array<[number, number]>>();
    
    for (let i = 1; i <= n; i++) {
        graph.set(i, []);
    }
    
    for (const [u, v, w] of times) {
        graph.get(u)!.push([v, w]);
    }
    
    // Dijkstra's algorithm
    const distances = new Array(n + 1).fill(Infinity);
    distances[k] = 0;
    
    // Min-heap: [distance, node]
    const minHeap: [number, number][] = [[0, k]];
    const visited = new Set<number>();
    
    while (minHeap.length > 0) {
        // Get node with minimum distance
        minHeap.sort((a, b) => a[0] - b[0]);
        const [currentDist, node] = minHeap.shift()!;
        
        // Skip if already visited
        if (visited.has(node)) continue;
        visited.add(node);
        
        // Update distances to neighbors
        for (const [neighbor, weight] of graph.get(node)!) {
            const newDist = currentDist + weight;
            
            if (newDist < distances[neighbor]) {
                distances[neighbor] = newDist;
                minHeap.push([newDist, neighbor]);
            }
        }
    }
    
    // Find maximum distance (time for all nodes to receive signal)
    let maxTime = 0;
    for (let i = 1; i <= n; i++) {
        if (distances[i] === Infinity) {
            return -1; // Node unreachable
        }
        maxTime = Math.max(maxTime, distances[i]);
    }
    
    return maxTime;
};

```

## Solution 2: With Proper Priority Queue Implementation

```typescript
class MinHeap {
    private heap: [number, number][] = [];
    
    push(item: [number, number]) {
        this.heap.push(item);
        this.bubbleUp(this.heap.length - 1);
    }
    
    pop(): [number, number] | undefined {
        if (this.heap.length === 0) return undefined;
        if (this.heap.length === 1) return this.heap.pop();
        
        const min = this.heap[0];
        this.heap[0] = this.heap.pop()!;
        this.bubbleDown(0);
        return min;
    }
    
    isEmpty(): boolean {
        return this.heap.length === 0;
    }
    
    private bubbleUp(index: number) {
        while (index > 0) {
            const parentIndex = Math.floor((index - 1) / 2);
            if (this.heap[index][0] >= this.heap[parentIndex][0]) break;
            
            [this.heap[index], this.heap[parentIndex]] = 
                [this.heap[parentIndex], this.heap[index]];
            index = parentIndex;
        }
    }
    
    private bubbleDown(index: number) {
        while (true) {
            let minIndex = index;
            const leftChild = 2 * index + 1;
            const rightChild = 2 * index + 2;
            
            if (leftChild < this.heap.length && 
                this.heap[leftChild][0] < this.heap[minIndex][0]) {
                minIndex = leftChild;
            }
            
            if (rightChild < this.heap.length && 
                this.heap[rightChild][0] < this.heap[minIndex][0]) {
                minIndex = rightChild;
            }
            
            if (minIndex === index) break;
            
            [this.heap[index], this.heap[minIndex]] = 
                [this.heap[minIndex], this.heap[index]];
            index = minIndex;
        }
    }
}

function networkDelayTime(times: number[][], n: number, k: number): number {
    const graph = new Map<number, Array<[number, number]>>();
    
    for (let i = 1; i <= n; i++) {
        graph.set(i, []);
    }
    
    for (const [u, v, w] of times) {
        graph.get(u)!.push([v, w]);
    }
    
    const distances = new Array(n + 1).fill(Infinity);
    distances[k] = 0;
    
    const minHeap = new MinHeap();
    minHeap.push([0, k]);
    
    while (!minHeap.isEmpty()) {
        const [currentDist, node] = minHeap.pop()!;
        
        if (currentDist > distances[node]) continue;
        
        for (const [neighbor, weight] of graph.get(node)!) {
            const newDist = currentDist + weight;
            
            if (newDist < distances[neighbor]) {
                distances[neighbor] = newDist;
                minHeap.push([newDist, neighbor]);
            }
        }
    }
    
    let maxTime = 0;
    for (let i = 1; i <= n; i++) {
        if (distances[i] === Infinity) return -1;
        maxTime = Math.max(maxTime, distances[i]);
    }
    
    return maxTime;
};
```

## Solution 3: Bellman-Ford Algorithm (Alternative)

```typescript
function networkDelayTime(times: number[][], n: number, k: number): number {
    // Initialize distances
    const distances = new Array(n + 1).fill(Infinity);
    distances[k] = 0;
    
    // Relax edges n-1 times
    for (let i = 0; i < n - 1; i++) {
        for (const [u, v, w] of times) {
            if (distances[u] !== Infinity && distances[u] + w < distances[v]) {
                distances[v] = distances[u] + w;
            }
        }
    }
    
    // Find maximum distance
    let maxTime = 0;
    for (let i = 1; i <= n; i++) {
        if (distances[i] === Infinity) return -1;
        maxTime = Math.max(maxTime, distances[i]);
    }
    
    return maxTime;
};
```

## Solution 4: BFS with Distance Tracking

```typescript
function networkDelayTime(times: number[][], n: number, k: number): number {
    const graph = new Map<number, Array<[number, number]>>();
    
    for (let i = 1; i <= n; i++) {
        graph.set(i, []);
    }
    
    for (const [u, v, w] of times) {
        graph.get(u)!.push([v, w]);
    }
    
    const distances = new Array(n + 1).fill(Infinity);
    distances[k] = 0;
    
    const queue: [number, number][] = [[k, 0]]; // [node, distance]
    
    while (queue.length > 0) {
        const [node, dist] = queue.shift()!;
        
        for (const [neighbor, weight] of graph.get(node)!) {
            const newDist = dist + weight;
            
            if (newDist < distances[neighbor]) {
                distances[neighbor] = newDist;
                queue.push([neighbor, newDist]);
            }
        }
    }
    
    let maxTime = 0;
    for (let i = 1; i <= n; i++) {
        if (distances[i] === Infinity) return -1;
        maxTime = Math.max(maxTime, distances[i]);
    }
    
    return maxTime;
};
```

## Solution 5: With Detailed Comments

```typescript
function networkDelayTime(times: number[][], n: number, k: number): number {
    // Step 1: Build adjacency list representation of the graph
    // graph[node] = [[neighbor1, weight1], [neighbor2, weight2], ...]
    const graph = new Map<number, Array<[number, number]>>();
    
    // Initialize empty adjacency lists for all nodes (1 to n)
    for (let i = 1; i <= n; i++) {
        graph.set(i, []);
    }
    
    // Populate the graph with directed edges
    for (const [source, target, weight] of times) {
        graph.get(source)!.push([target, weight]);
    }
    
    // Step 2: Initialize distances array
    // distances[i] = shortest time for signal to reach node i
    const distances = new Array(n + 1).fill(Infinity);
    distances[k] = 0; // Starting node has distance 0
    
    // Step 3: Dijkstra's algorithm using min-heap
    // Heap stores [distance, node] pairs
    const minHeap: [number, number][] = [[0, k]];
    const visited = new Set<number>();
    
    while (minHeap.length > 0) {
        // Get node with minimum distance (simulate min-heap)
        minHeap.sort((a, b) => a[0] - b[0]);
        const [currentDistance, currentNode] = minHeap.shift()!;
        
        // Skip if already processed (optimization)
        if (visited.has(currentNode)) continue;
        visited.add(currentNode);
        
        // Explore all neighbors
        for (const [neighbor, edgeWeight] of graph.get(currentNode)!) {
            const newDistance = currentDistance + edgeWeight;
            
            // If we found a shorter path, update it
            if (newDistance < distances[neighbor]) {
                distances[neighbor] = newDistance;
                minHeap.push([newDistance, neighbor]);
            }
        }
    }
    
    // Step 4: Find the maximum distance (time for last node to receive signal)
    let maximumTime = 0;
    
    for (let i = 1; i <= n; i++) {
        // If any node is unreachable, return -1
        if (distances[i] === Infinity) {
            return -1;
        }
        // Track the maximum time
        maximumTime = Math.max(maximumTime, distances[i]);
    }
    
    return maximumTime;
};

```

# Key Insights

- **Dijkstra's algorithm:** Finds shortest paths from single source
- **Maximum distance:** Time when last node receives signal
- **Directed graph:** Signal flows in one direction only
- **Unreachable nodes:** Return -1 if any node can't be reached
- **Min-heap optimization:** Always process nearest unvisited node

---

# Why Dijkstra's Works

**Properties:**
1. **Greedy choice:** Always process nearest unvisited node
2. **Optimal substructure:** Shortest path to A + edge to B = shortest path to B
3. **Non-negative weights:** Ensures processed nodes have final shortest distance
4. **Completeness:** Finds shortest paths to all reachable nodes

---

# Edge Cases

| Case | Input | Output | Notes |
|------|-------|--------|-------|
| Single node | n=1, k=1 | 0 | Already received |
| Unreachable | Disconnected | -1 | Some nodes isolated |
| Direct edges | All from k | max(weights) | One hop |
| Chain | Linear path | Sum of weights | Sequential |
| Self-loop | Edge to self | Ignored | Not useful |

---

# Common Mistakes to Avoid

1. **Not checking unreachable nodes:**
   ```typescript
   // Wrong: only return max
   return Math.max(...distances);
   
   // Correct: check for Infinity
   if (distances[i] === Infinity) return -1;
   ```

2. **Using 0-indexed when nodes are 1-indexed:**
   ```typescript
   // Wrong: distances[0] to distances[n-1]
   const distances = new Array(n).fill(Infinity);
   
   // Correct: distances[1] to distances[n]
   const distances = new Array(n + 1).fill(Infinity);
   ```

3. **Not using min-heap properly:**
   ```typescript
   // Wrong: FIFO queue (BFS)
   const node = queue.shift();
   
   // Correct: min-heap (Dijkstra's)
   minHeap.sort((a, b) => a[0] - b[0]);
   const [dist, node] = minHeap.shift();
   ```

4. **Updating distance without checking:**
   ```typescript
   // Wrong: always update
   distances[neighbor] = newDist;
   
   // Correct: only if shorter
   if (newDist < distances[neighbor]) {
       distances[neighbor] = newDist;
   }
   ```

# Algorithm Comparison

**Dijkstra's vs Bellman-Ford:**

| Aspect | Dijkstra's | Bellman-Ford |
|--------|-----------|--------------|
| Time | $O((V+E) log V)$ | $O(V × E)$ |
| Negative weights | No | Yes |
| Implementation | Complex | Simple |
| Best for | Dense graphs | Negative weights |
