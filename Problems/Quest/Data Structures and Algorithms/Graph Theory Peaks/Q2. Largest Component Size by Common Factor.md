# Intuition

We need to find the largest connected component where nodes are connected if they share a common factor greater than 1. The key insight is to use **Union-Find (Disjoint Set Union)** to group numbers that share prime factors.

**Key insight:** Instead of connecting numbers directly (which would be O(n²)), we connect each number to its **prime factors**. Numbers sharing the same prime factor will be in the same component.

---

# Approach

1. **Find prime factors** for each number in `nums`

2. **Use Union-Find** to connect:
   - Each number to its prime factors
   - This indirectly connects numbers sharing prime factors

3. **Count component sizes:**
   - Group numbers by their root parent
   - Return the size of the largest group

---

# Complexity

- **Time complexity:** $O(n × √m)$ where n is array length, m is max value
  - Finding prime factors: $O(√m)$ per number
  - Union-Find operations: nearly $O(1)$ with path compression
- **Space complexity:** $O(n + p)$ where p is number of unique prime factors

# Code

## Solution 1: Union-Find with Prime Factorization (Recommended)

```typescript
function largestComponentSize(nums: number[]): number {
    const n = nums.length;
    const uf = new UnionFind(100001); // Max value is 10^5
    
    // For each number, union it with all its prime factors
    for (const num of nums) {
        const primeFactors = getPrimeFactors(num);
        
        // Union the number with each of its prime factors
        for (const prime of primeFactors) {
            uf.union(num, prime);
        }
    }
    
    // Count the size of each component
    const componentSize = new Map<number, number>();
    
    for (const num of nums) {
        const root = uf.find(num);
        componentSize.set(root, (componentSize.get(root) || 0) + 1);
    }
    
    // Return the maximum component size
    return Math.max(...componentSize.values());
}

function getPrimeFactors(num: number): number[] {
    const factors: number[] = [];
    
    // Check for factor 2
    if (num % 2 === 0) {
        factors.push(2);
        while (num % 2 === 0) {
            num /= 2;
        }
    }
    
    // Check for odd factors from 3 onwards
    for (let i = 3; i * i <= num; i += 2) {
        if (num % i === 0) {
            factors.push(i);
            while (num % i === 0) {
                num /= i;
            }
        }
    }
    
    // If num > 1, then it's a prime factor
    if (num > 1) {
        factors.push(num);
    }
    
    return factors;
}

class UnionFind {
    parent: number[];
    rank: number[];
    
    constructor(size: number) {
        this.parent = Array.from({ length: size }, (_, i) => i);
        this.rank = new Array(size).fill(0);
    }
    
    find(x: number): number {
        if (this.parent[x] !== x) {
            this.parent[x] = this.find(this.parent[x]); // Path compression
        }
        return this.parent[x];
    }
    
    union(x: number, y: number): void {
        const rootX = this.find(x);
        const rootY = this.find(y);
        
        if (rootX === rootY) return;
        
        // Union by rank
        if (this.rank[rootX] < this.rank[rootY]) {
            this.parent[rootX] = rootY;
        } else if (this.rank[rootX] > this.rank[rootY]) {
            this.parent[rootY] = rootX;
        } else {
            this.parent[rootY] = rootX;
            this.rank[rootX]++;
        }
    }
};

```

## Solution 2: Optimized with Map-based Union-Find

```typescript
function largestComponentSize(nums: number[]): number {
    const primeToNum = new Map<number, number>(); // Map prime to any number having it
    const parent = new Map<number, number>();
    
    // Initialize parent
    for (const num of nums) {
        parent.set(num, num);
    }
    
    function find(x: number): number {
        if (parent.get(x) !== x) {
            parent.set(x, find(parent.get(x)!));
        }
        return parent.get(x)!;
    }
    
    function union(x: number, y: number): void {
        const rootX = find(x);
        const rootY = find(y);
        if (rootX !== rootY) {
            parent.set(rootX, rootY);
        }
    }
    
    // Process each number
    for (const num of nums) {
        const primes = getPrimeFactors(num);
        
        for (const prime of primes) {
            if (primeToNum.has(prime)) {
                // Union with existing number that has this prime
                union(num, primeToNum.get(prime)!);
            } else {
                // First number with this prime
                primeToNum.set(prime, num);
            }
        }
    }
    
    // Count component sizes
    const componentSize = new Map<number, number>();
    
    for (const num of nums) {
        const root = find(num);
        componentSize.set(root, (componentSize.get(root) || 0) + 1);
    }
    
    return Math.max(...componentSize.values());
}

function getPrimeFactors(num: number): number[] {
    const factors: number[] = [];
    
    if (num % 2 === 0) {
        factors.push(2);
        while (num % 2 === 0) num /= 2;
    }
    
    for (let i = 3; i * i <= num; i += 2) {
        if (num % i === 0) {
            factors.push(i);
            while (num % i === 0) num /= i;
        }
    }
    
    if (num > 1) factors.push(num);
    
    return factors;
};

```

# Key Insights

- **Prime factorization:** Key to finding connections efficiently
- **Union-Find:** Perfect for tracking connected components
- **Indirect connections:** Numbers connected through shared primes
- **Path compression:** Optimizes find operations
- **Union by rank:** Keeps tree balanced

# Prime Factorization Explained

**Algorithm:**
```typescript
getPrimeFactors(12):
  12 % 2 === 0 → add 2
  12 / 2 = 6
  6 / 2 = 3
  3 % 3 === 0 → add 3
  3 / 3 = 1
  Result: [2, 3]

getPrimeFactors(35):
  35 % 2 !== 0
  35 % 3 !== 0
  35 % 5 === 0 → add 5
  35 / 5 = 7
  7 > 1 → add 7
  Result: [5, 7]
```

# Common Mistakes to Avoid

1. **Connecting numbers directly:**
   ```typescript
   // Wrong: O(n²) comparisons
   for (let i = 0; i < n; i++) {
       for (let j = i + 1; j < n; j++) {
           if (gcd(nums[i], nums[j]) > 1) {
               union(i, j);
           }
       }
   }
   
   // Correct: Connect through prime factors
   for (const prime of getPrimeFactors(num)) {
       union(num, prime);
   }
   ```

2. **Not using path compression:**
   ```typescript
   // Wrong: slow find
   find(x) {
       while (parent[x] !== x) {
           x = parent[x];
       }
       return x;
   }
   
   // Correct: with path compression
   find(x) {
       if (parent[x] !== x) {
           parent[x] = find(parent[x]);
       }
       return parent[x];
   }
   ```

3. **Including duplicate prime factors:**
   ```typescript
   // Wrong: adds 2 multiple times for 8
   while (num % 2 === 0) {
       factors.push(2);
       num /= 2;
   }
   
   // Correct: add prime only once
   if (num % 2 === 0) {
       factors.push(2);
       while (num % 2 === 0) num /= 2;
   }
   ```
