# Intuition

This is a classic **dynamic programming** problem. The key idea is: if `s` can be broken into dictionary words up to some position `i`, and the substring from `i` to `j` is also a dictionary word, then `s` can be broken up to position `j`.

We build up a boolean array where `dp[i]` represents whether the prefix `s[0..i)` can be fully segmented using words from the dictionary.

---

# Approach

1. Convert `wordDict` into a **Set** for O(1) average lookup time.
2. Create a `dp` array of size `n + 1`, where `dp[i]` means "the substring `s[0..i)` can be segmented into dictionary words".
   - `dp[0] = true` (empty string is trivially segmentable).
3. For each position `i` from `1` to `n`:
   - For each position `j` from `0` to `i - 1`:
     - If `dp[j]` is `true` and `s.substring(j, i)` exists in the word set, set `dp[i] = true` and break out of the inner loop (no need to check further).
4. Return `dp[n]`, which tells us whether the entire string `s` can be segmented.

## Optimization

- To reduce unnecessary substring checks, we can limit the inner loop `j` to only go back as far as the **maximum word length** in the dictionary, since checking substrings longer than the max word length is pointless.

---

# Complexity

- **Time complexity:** 
$$O(n \times maxWordLength)$$
where `n` is the length of `s` and `maxWordLength` is the length of the longest word in `wordDict`. Substring extraction and hash lookups are efficient.

- **Space complexity:**
$$O(n + \text{total characters in wordDict})$$
for the `dp` array and the word set.

---

# Code

```typescript
function wordBreak(s: string, wordDict: string[]): boolean {
    const wordSet = new Set(wordDict);
    const n = s.length;

    // Find the maximum word length to limit the inner loop range.
    let maxLen = 0;
    for (const word of wordDict) {
        if (word.length > maxLen) {
            maxLen = word.length;
        }
    }

    const dp = new Array<boolean>(n + 1).fill(false);
    dp[0] = true;

    for (let i = 1; i <= n; i++) {
        // Only check substrings up to maxLen characters back.
        const start = Math.max(0, i - maxLen);

        for (let j = i - 1; j >= start; j--) {
            if (dp[j] && wordSet.has(s.substring(j, i))) {
                dp[i] = true;
                break;
            }
        }
    }

    return dp[n];
};

```

# Example Walkthrough

## Example 1

```text
s = "leetcode"
wordDict = ["leet", "code"]
```

- `dp[0] = true`
- At `i = 4`: `s.substring(0, 4) = "leet"` is in the dictionary and `dp[0] = true` → `dp[4] = true`
- At `i = 8`: `s.substring(4, 8) = "code"` is in the dictionary and `dp[4] = true` → `dp[8] = true`

`dp[8] = true` → Output: `true`

## Example 2

```text
s = "catsandog"
wordDict = ["cats", "dog", "sand", "and", "cat"]
```

- `dp[0] = true`
- `dp[3] = true` (`"cat"`)
- `dp[4] = true` (`"cats"`)
- `dp[7] = true` (`"sand"` from index 3, or `"and"` from index 4)
- No valid word matches to reach `dp[9]` (`"og"` isn't in the dictionary, and no other combination works)

`dp[9] = false` → Output: `false`
