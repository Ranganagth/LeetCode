# Intuition

Since the array is repeated `k` times, directly computing the maximum subarray sum with **Kadane's algorithm** on the fully expanded array would be too slow (O(n×k)). Instead, we can leverage patterns:

1. **If k=1:** Simply find max subarray sum of the original array
2. **If total sum of array is positive:** The optimal subarray will likely span from somewhere in the first copy, through complete middle copies, to somewhere in the last copy - since each complete copy adds positive value
3. **If total sum is non-positive:** Extra copies never help, so we only need to check at most **two concatenations** to capture any cross-boundary subarray

**Key insight:** We only need to analyze the array repeated **twice** to capture all possible "wrap-around" patterns, then extrapolate for additional middle copies if the total sum is positive.

---

# Approach

1. **Compute `totalSum`** of the original array
2. **Compute `maxSingle`** = max subarray sum using Kadane's on a single copy (handles k=1 case)
3. **Compute `maxDouble`** = max subarray sum using Kadane's on the array concatenated twice (captures any cross-boundary subarray pattern)
4. **Combine results based on k:**
   - If `k == 1`: return `maxSingle`
   - If `totalSum > 0`: the best strategy extends through `(k-2)` additional full copies: `result = maxDouble + (k-2) × totalSum`
   - Otherwise: additional copies don't help: `result = maxDouble`
5. **Apply modulo** `10^9 + 7` to the final result

---

# Complexity

**Time Complexity:** O(n) - Kadane's algorithm runs once on array of size 2n (constant factor)

**Space Complexity:** O(n) - for creating the doubled array

---

# Code

```typescript
function kConcatenationMaxSum(arr: number[], k: number): number {
    const MOD = 1_000_000_007n;
    
    function kadane(array: number[]): number {
        let maxEndingHere = 0;
        let maxSoFar = 0;
        
        for (const num of array) {
            maxEndingHere = Math.max(0, maxEndingHere + num);
            maxSoFar = Math.max(maxSoFar, maxEndingHere);
        }
        
        return maxSoFar;
    }
    
    const totalSum = arr.reduce((a, b) => a + b, 0);
    const maxSingle = kadane(arr);
    
    if (k === 1) {
        return maxSingle % 1_000_000_007;
    }
    
    const doubledArr = arr.concat(arr);
    const maxDouble = kadane(doubledArr);
    
    let result: number;
    
    if (totalSum > 0) {
        result = maxDouble + (k - 2) * totalSum;
    } else {
        result = maxDouble;
    }
    
    // Use BigInt for safety with modulo, though result should fit in safe integer range
    return Number(BigInt(result) % MOD);
};

```

# Example Walkthrough

## Example 1: `arr = [1,2], k = 3`

```
totalSum = 3
maxSingle = 3 (entire array: 1+2)

doubledArr = [1,2,1,2]
maxDouble via Kadane's:
  1: maxEnd=1, maxSoFar=1
  2: maxEnd=3, maxSoFar=3
  1: maxEnd=4, maxSoFar=4
  2: maxEnd=6, maxSoFar=6
maxDouble = 6

Since totalSum(3) > 0:
result = 6 + (3-2)×3 = 6+3 = 9
```

**Output:** `9` ✓

---

## Example 2: `arr = [1,-2,1], k = 5`

```
totalSum = 1-2+1 = 0
maxSingle = 1

doubledArr = [1,-2,1,1,-2,1]
Kadane's:
  1: maxEnd=1, maxSoFar=1
  -2: maxEnd=0, maxSoFar=1
  1: maxEnd=1, maxSoFar=1
  1: maxEnd=2, maxSoFar=2
  -2: maxEnd=0, maxSoFar=2
  1: maxEnd=1, maxSoFar=2
maxDouble = 2

Since totalSum(0) is not > 0:
result = maxDouble = 2
```

**Output:** `2` ✓

---

## Example 3: `arr = [-1,-2], k = 7`

```
totalSum = -3
maxSingle = 0 (all negative, empty subarray is best)

doubledArr = [-1,-2,-1,-2]
Kadane's: all values negative, maxSoFar stays 0
maxDouble = 0

Since totalSum(-3) is not > 0:
result = maxDouble = 0
```

**Output:** `0` ✓

# Key Insights

1. **Two copies capture all patterns:** Any subarray that spans multiple repetitions either stays within 2 copies, or (if beneficial) extends through additional complete copies when `totalSum > 0`
2. **Positive total sum enables extrapolation:** When each full copy adds positive value, including more middle copies only helps, so we can mathematically add `(k-2) × totalSum`
3. **Non-positive total sum caps benefit:** If the total sum is ≤ 0, adding more copies never helps beyond what's captured in the double-array analysis
4. **BigInt for safe modulo:** Ensures correctness even though the intermediate result fits within JavaScript's safe integer range for the given constraints

This approach elegantly avoids the need to process the full `k`-times repeated array while correctly handling all edge cases!
