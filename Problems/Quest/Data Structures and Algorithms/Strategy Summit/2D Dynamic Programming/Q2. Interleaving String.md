# Intuition

This is a classic **2D dynamic programming** problem. We define `dp[i][j]` as whether the first `i+j` characters of `s3` can be formed by interleaving the first `i` characters of `s1` and first `j` characters of `s2`.

**Key insight:** At each position, `s3[i+j-1]` must match either the last character used from `s1` (position `i-1`) or from `s2` (position `j-1`), and the remaining prefix must also be a valid interleaving.

---

# Approach

1. **Early check:** If `s1.length + s2.length !== s3.length`, return `false` immediately
2. **DP recurrence:**
   - `dp[i][j] = (dp[i-1][j] && s1[i-1] === s3[i+j-1]) || (dp[i][j-1] && s2[j-1] === s3[i+j-1])`
3. **Base case:** `dp[0][0] = true` (empty strings interleave to empty string)
4. **Space optimization:** Since `dp[i][j]` only depends on the previous row and current row, we can use a **1D array** of size `s2.length + 1`

---

# Complexity

- **Time Complexity:** $O(m × n)$ where m = s1.length, n = s2.length

- **Space Complexity:** $O(n)$ using the 1D optimization (as requested in follow-up)

---

# Code

```typescript
function isInterleave(s1: string, s2: string, s3: string): boolean {
    const m = s1.length;
    const n = s2.length;
    
    if (m + n !== s3.length) return false;
    
    // dp[j] represents dp[i][j] for current row i
    const dp = new Array(n + 1).fill(false);
    dp[0] = true;
    
    // Initialize first row (i=0): only using s2 to match s3
    for (let j = 1; j <= n; j++) {
        dp[j] = dp[j - 1] && s2[j - 1] === s3[j - 1];
    }
    
    for (let i = 1; i <= m; i++) {
        // Update dp[0] for current row (i=0 column): only using s1
        dp[0] = dp[0] && s1[i - 1] === s3[i - 1];
        
        for (let j = 1; j <= n; j++) {
            const fromS1 = dp[j] && s1[i - 1] === s3[i + j - 1];
            const fromS2 = dp[j - 1] && s2[j - 1] === s3[i + j - 1];
            dp[j] = fromS1 || fromS2;
        }
    }
    
    return dp[n];
};

```

# Example Walkthrough

## Example 1: `s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"`

```
Lengths: 5+5=10, matches s3.length=10 ✓

DP builds up row by row, checking character matches from both s1 and s2.
Final dp[5] = true (valid interleaving exists)
```

**Output:** `true` ✓

## Example 3: `s1 = "", s2 = "", s3 = ""`

```
m=0, n=0, dp=[true]
Loop doesn't execute (m=0)
Return dp[0] = true
```

**Output:** `true` ✓

---

# Key Insight

By reducing the problem to **1D space** and updating in-place, we achieve $O(n)$ space complexity while maintaining $O(m×n)$ time complexity - efficient even for the maximum constraint of 100-length strings!
