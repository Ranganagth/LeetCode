# Intuition

This is the classic **"Cat and Mouse" game theory problem**, solved using **retrograde BFS** (also called backward induction / topological sort from terminal states).

Instead of trying to simulate forward from the start (which can loop forever due to possible draws), we work **backward from known winning/losing positions** and propagate results toward the initial state. This mirrors how you'd solve a game by starting from checkmate positions and working backward in chess endgame theory.

---

# Approach

## 1. Define the State Space

A game state is `(mouse position, cat position, turn)`:
- `turn = 0` → Mouse's turn
- `turn = 1` → Cat's turn

Each state maps to a result: `0 = Draw`, `1 = Mouse wins`, `2 = Cat wins`.

## 2. Identify Terminal States

- **Mouse at node 0** (the hole) → Mouse wins, regardless of turn or cat position.
- **Mouse position == Cat position** (and mouse ≠ 0, since cat can't be at hole) → Cat wins, regardless of turn.

These are the "base cases" we know for certain.

## 3. Compute Move Degrees

For each state, we track how many legal moves are available to the player whose turn it is:
- Mouse's turn: `degree = graph[mouse].length`
- Cat's turn: `degree = graph[cat].length` minus 1 if `0` is a neighbor (since cat cannot move to the hole)

## 4. Backward Propagation (BFS)

Starting from terminal states, we look at **predecessor states** — states that could transition into a known state with one move:

- If moving from predecessor state `(pm, pc, pt)` leads to a state whose winner **matches** the player whose turn it was (`pt`), then that predecessor is **immediately decided** as a win for that player (they would choose this winning move).
- Otherwise, we decrement that predecessor's `degree` (one fewer "escape route" to a good outcome). If `degree` hits `0`, it means **all possible moves lead to a loss**, so the predecessor is decided as a win for the *opponent*.

We push newly decided states into the BFS queue and continue propagating until no more updates occur.

## 5. Final Answer

Once BFS completes, the answer is simply the precomputed result for the state:
```text
(mouse = 1, cat = 2, turn = MOUSE_TURN)
```
Any state never reached during BFS remains `0` (Draw), which correctly reflects positions that can cycle forever under optimal play.

---

# Complexity

- **Time complexity:**
$$O(n^3)$$
There are `O(n²)` total states (mouse position × cat position × turn), and each state's edges are processed a constant number of times relative to graph degree, giving an overall bound proportional to `n³` in the worst case.

- **Space complexity:**
$$O(n^2)$$
For storing `color` and `degree` arrays across all `(mouse, cat, turn)` combinations.

# Code

```typescript
function catMouseGame(graph: number[][]): number {
    const n = graph.length;
    const DRAW = 0, MOUSE = 1, CAT = 2;
    const MOUSE_TURN = 0, CAT_TURN = 1;

    // color[m][c][t] = result of the game at that state
    const color: number[][][] = Array.from({ length: n }, () =>
        Array.from({ length: n }, () => [DRAW, DRAW])
    );

    // degree[m][c][t] = number of legal moves from that state
    const degree: number[][][] = Array.from({ length: n }, () =>
        Array.from({ length: n }, () => [0, 0])
    );

    for (let m = 0; m < n; m++) {
        for (let c = 0; c < n; c++) {
            degree[m][c][MOUSE_TURN] = graph[m].length;
            degree[m][c][CAT_TURN] = graph[c].length;
            if (graph[c].includes(0)) {
                degree[m][c][CAT_TURN]--;
            }
        }
    }

    const queue: [number, number, number, number][] = [];

    // Terminal states: mouse reaches hole.
    for (let c = 0; c < n; c++) {
        for (const t of [MOUSE_TURN, CAT_TURN]) {
            if (color[0][c][t] === DRAW) {
                color[0][c][t] = MOUSE;
                queue.push([0, c, t, MOUSE]);
            }
        }
    }

    // Terminal states: cat catches mouse.
    for (let m = 1; m < n; m++) {
        for (const t of [MOUSE_TURN, CAT_TURN]) {
            if (color[m][m][t] === DRAW) {
                color[m][m][t] = CAT;
                queue.push([m, m, t, CAT]);
            }
        }
    }

    const getPredecessors = (m: number, c: number, t: number): [number, number, number][] => {
        const result: [number, number, number][] = [];
        const prevTurn = 1 - t;

        if (prevTurn === MOUSE_TURN) {
            // Predecessor: mouse was at pm, moved to m. Cat stayed at c.
            for (const pm of graph[m]) {
                result.push([pm, c, MOUSE_TURN]);
            }
        } else {
            // Predecessor: cat was at pc (pc != 0), moved to c. Mouse stayed at m.
            for (const pc of graph[c]) {
                if (pc !== 0) {
                    result.push([m, pc, CAT_TURN]);
                }
            }
        }

        return result;
    };

    let head = 0;
    while (head < queue.length) {
        const [m, c, t, result] = queue[head++];

        for (const [pm, pc, pt] of getPredecessors(m, c, t)) {
            if (color[pm][pc][pt] !== DRAW) continue;

            const currentPlayer = pt === MOUSE_TURN ? MOUSE : CAT;

            if (result === currentPlayer) {
                // The player whose turn it is can force this winning move.
                color[pm][pc][pt] = result;
                queue.push([pm, pc, pt, result]);
            } else {
                // This move leads to a loss; decrement remaining options.
                degree[pm][pc][pt]--;
                if (degree[pm][pc][pt] === 0) {
                    // No good moves left; the opponent wins.
                    color[pm][pc][pt] = result;
                    queue.push([pm, pc, pt, result]);
                }
            }
        }
    }

    return color[1][2][MOUSE_TURN];
};

```

# Example Walkthrough

## Example 1

```text
graph = [[2,5],[3],[0,4,5],[1,4,5],[2,3],[0,2,3]]
```

After full backward propagation, no forced win path exists for either player from `(mouse=1, cat=2, MOUSE_TURN)` — both players can avoid losing indefinitely by cycling through positions.

Output: `0` (Draw)

## Example 2

```text
graph = [[1,3],[0],[3],[0,2]]
```

- Mouse starts at `1`, Cat starts at `2`.
- Terminal states initialize: mouse at `0` → Mouse wins; mouse==cat → Cat wins.

Tracing optimal play:
- Mouse's turn at `(1,2)`: Mouse can only move to `0` (from `graph[1] = [0]`... wait `graph[1]=[0]` here) → Mouse reaches the hole directly.

Backward propagation confirms `(1, 2, MOUSE_TURN)` resolves to **Mouse wins**, since Mouse has a direct path to the hole.

Output: `1`
