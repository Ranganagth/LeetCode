# Intuition

This problem can be transformed into a **subset sum** problem. If we split `nums` into two groups - one with `+` sign (sum = P) and one with `-` sign (sum = N), then:
- `P + N = total` (sum of all numbers)
- `P - N = target`

Solving these equations: `P = (total + target) / 2`

So we just need to **count the number of subsets** that sum to `P`. This transforms an exponential brute-force problem into a classic **0/1 knapSack counting problem**.

---

# Approach

1. **Calculate total sum** of all numbers
2. **Check feasibility:** If `(total + target)` is odd or negative, or `target` is out of range `[-total, total]`, return `0`
3. **Calculate target subset sum:** `P = (total + target) / 2`
4. **Use DP** to count subsets that sum to `P`:
   - `dp[j]` = number of ways to achieve sum `j`
   - For each number, update `dp[j] += dp[j - num]` (iterating backward to avoid reuse)

---

# Complexity

- **Time Complexity:** $O(n × sum)$ where sum ≤ 1000
- **Space Complexity:** $O(sum)$

---

# Code

```typescript
function findTargetSumWays(nums: number[], target: number): number {
    const total = nums.reduce((a, b) => a + b, 0);
    
    // Check feasibility
    if (Math.abs(target) > total || (total + target) % 2 !== 0) {
        return 0;
    }
    
    const P = (total + target) / 2;
    
    // Count subsets that sum to P
    const dp = new Array(P + 1).fill(0);
    dp[0] = 1;
    
    for (const num of nums) {
        for (let j = P; j >= num; j--) {
            dp[j] += dp[j - num];
        }
    }
    
    return dp[P];
};

```

# Example Walkthrough

## Example 1: `nums = [1,1,1,1,1], target = 3`

```
total = 5
(total + target) = 8, even ✓
P = (5+3)/2 = 4

Count subsets summing to 4:
dp = [1,0,0,0,0] initially

After processing each 1:
  Eventually dp[4] = C(5,4) = 5
  (choosing 4 out of 5 ones to be positive)
```

**Output:** `5` ✓

## Example 2: `nums = [1], target = 1`

```
total = 1
P = (1+1)/2 = 1

dp = [1,0] → after processing num=1: dp[1] += dp[0] = 1

dp[1] = 1
```

**Output:** `1` ✓

# Key Insight

This is a **beautiful reduction** from a seemingly exponential sign-assignment problem to a classic **subset-sum counting** problem, solvable via **0/1 knapsack DP** in polynomial time!
