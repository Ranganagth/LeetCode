# Intuition

At each house, we have two choices: **rob it** (and skip the previous house) or **skip it** (keeping the best amount from before). This creates a simple recurrence based on the maximum money obtainable up to each house.

---

# Approach

1. **Track two values:** `prev1` (max money up to previous house) and `prev2` (max money up to two houses back)
2. **For each house:** `curr = max(prev1, prev2 + nums[i])`
   - Either skip current house (`prev1`)
   - Or rob it, adding to the best from two houses back (`prev2 + nums[i]`)
3. **Update** and continue through the array

---

# Complexity

- **Time Complexity:** $O(n)$
- **Space Complexity:** $O(1)$

---

# Code

```typescript
function rob(nums: number[]): number {
    let prev2 = 0;
    let prev1 = 0;
    
    for (const num of nums) {
        const curr = Math.max(prev1, prev2 + num);
        prev2 = prev1;
        prev1 = curr;
    }
    
    return prev1;
};

```

---

# Example Walkthrough

## Example 1: `nums = [1,2,3,1]`

```
prev2=0, prev1=0

num=1: curr=max(0,0+1)=1 → prev2=0,prev1=1
num=2: curr=max(1,0+2)=2 → prev2=1,prev1=2
num=3: curr=max(2,1+3)=4 → prev2=2,prev1=4
num=1: curr=max(4,2+1)=4 → prev2=4,prev1=4

Return 4
```

**Output:** `4` ✓

## Example 2: `nums = [2,7,9,3,1]`

```
prev2=0, prev1=0

num=2: curr=max(0,2)=2 → prev2=0,prev1=2
num=7: curr=max(2,7)=7 → prev2=2,prev1=7
num=9: curr=max(7,2+9)=11 → prev2=7,prev1=11
num=3: curr=max(11,7+3)=11 → prev2=11,prev1=11
num=1: curr=max(11,11+1)=12 → prev2=11,prev1=12

Return 12
```

**Output:** `12` ✓

---

# Key Insight

This is a classic **linear DP** problem where each decision only depends on the previous two states, allowing an elegant **$O(1)$ space** solution instead of maintaining a full DP array.
