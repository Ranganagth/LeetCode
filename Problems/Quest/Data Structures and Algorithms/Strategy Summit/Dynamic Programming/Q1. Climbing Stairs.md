# Intuition

This is essentially a **Fibonacci sequence** problem. To reach step `n`, you must have come from either step `n-1` (taking a 1-step) or step `n-2` (taking a 2-step). So the number of ways to reach step `n` is the sum of ways to reach the two previous steps.

---

# Approach

1. **Base cases:** `ways(1) = 1`, `ways(2) = 2`
2. **Recurrence:** `ways(n) = ways(n-1) + ways(n-2)`
3. Use **iterative DP** with O(1) space by tracking only the last two values

---

# Complexity

**Time Complexity:** O(n)
**Space Complexity:** O(1)

---

# Code

```typescript
function climbStairs(n: number): number {
    if (n <= 2) return n;
    
    let prev2 = 1; // ways(1)
    let prev1 = 2; // ways(2)
    
    for (let i = 3; i <= n; i++) {
        const curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }
    
    return prev1;
};

```

# Key Insight

This is the **Fibonacci sequence** shifted by one position: `ways(n) = fib(n+1)`. The O(1) space iterative approach avoids recursion overhead and redundant recalculations that a naive recursive solution would have. 🪜
