# Intuition

We need to find two lines that, together with the x-axis, form a container holding the **maximum water**. The area is determined by the **width** between two lines and the **height** of the shorter line (since water can't rise above the shorter wall).

**Key insight:** Using a **two-pointer approach** starting from both ends, we can greedily move the pointer at the shorter line inward. This is because moving the taller line's pointer inward can only decrease or maintain the width while the height is still limited by the shorter line - so it never helps. Moving the shorter line's pointer gives a chance to find a taller line that might increase the area.

---

# Approach

1. **Initialize two pointers:** `left = 0` and `right = n-1`
2. **Calculate area** at each step: `width × min(height[left], height[right])`
3. **Move the pointer** pointing to the shorter line inward (since the shorter line is the bottleneck)
4. **Track maximum area** seen throughout the process
5. **Continue until pointers meet**

---

# Complexity

**Time Complexity:** $O(n)$ - single pass with two pointers

**Space Complexity:** $O(1)$ - only using a few variables

---

# Code

```typescript
function maxArea(height: number[]): number {
    let maxArea = 0;
    let left = 0, right = height.length - 1;

    while (left < right) {
        const h = Math.min(height[left], height[right]);
        const w = right - left;
        maxArea = Math.max(maxArea, h * w);

        if (height[left] < height[right]) {
            left++;
        } else {
            right--;
        }
    }

    return maxArea;
};

```

## Example 1: `height = [1,8,6,2,5,4,8,3,7]`

```
left=0(h=1), right=8(h=7)
  area = min(1,7) × 8 = 8
  height[left]<height[right] → left++

left=1(h=8), right=8(h=7)
  area = min(8,7) × 7 = 49 ← max so far
  height[left]>=height[right] → right--

left=1(h=8), right=7(h=3)
  area = min(8,3) × 6 = 18
  right--

left=1(h=8), right=6(h=8)
  area = min(8,8) × 5 = 40
  right-- (equal, moves right)

... continues until left meets right

Maximum area found = 49
```

**Output:** `49` ✓

# Key Insights

1. **Why move the shorter pointer:** The area is bounded by `min(height[left], height[right])`. If we move the taller pointer inward, the width decreases while the height stays the same or gets worse (still bounded by the shorter line) - so area can only decrease or stay the same. Moving the shorter pointer gives a chance for improvement.

2. **Greedy correctness:** By always discarding the shorter line, we never miss a potentially better solution because that shorter line could never contribute to a better area than what we've already calculated with it.

3. **Single pass efficiency:** This approach avoids the O(n²) brute force of checking all pairs, achieving $O(n)$ instead.

# Edge Cases

| Case | Input | Output | Explanation |
|------|-------|--------|-------------|
| Two elements | `[1,1]` | 1 | Simplest case, direct calculation |
| All same height | `[5,5,5,5]` | Depends on width | Height stays constant, width maximized |
| Increasing heights | `[1,2,3,4,5]` | Varies | Two-pointer still finds optimal |
| Zero heights | `[0,2,0]` | 0 | Container with 0 height yields 0 area |

> This two-pointer solution is the **optimal approach** for the classic "Container With Most Water" problem, achieving $O(n)$ time complexity!
