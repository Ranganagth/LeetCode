# Intuition

This is a **greedy simulation** problem. We just need to track how many $5 and $10 bills we have on hand (we never need $20 bills for change since the maximum change needed is $15, which can only be made from $5 and $10 bills).

**Key insight:** For a $20 bill, we should prefer giving one $10 + one $5 over three $5 bills, since $5 bills are more versatile (needed for both $10 and $20 payments).

---

# Approach

1. **Track counts** of $5 and $10 bills received (no need to track $20 since it's never given as change)
2. **For each bill:**
   - **$5:** Just add to our count (no change needed)
   - **$10:** Need to give back one $5. If we don't have one, return `false`
   - **$20:** Need to give back $15. Prefer one $10 + one $5 (if available), otherwise use three $5 bills. If neither works, return `false`
3. **Return `true`** if we successfully process all customers

---

# Complexity

**Time Complexity:** $O(n)$ - single pass through bills array

**Space Complexity:** $O(1)$ - only tracking two counters

---

# Code

```typescript
function lemonadeChange(bills: number[]): boolean {
    let five = 0;
    let ten = 0;
    
    for (const bill of bills) {
        if (bill === 5) {
            five++;
        } else if (bill === 10) {
            if (five === 0) return false;
            five--;
            ten++;
        } else { // bill === 20
            if (ten > 0 && five > 0) {
                ten--;
                five--;
            } else if (five >= 3) {
                five -= 3;
            } else {
                return false;
            }
        }
    }
    
    return true;
};

```

# Example Walkthrough

## Example 1: `bills = [5,5,5,10,20]`

```
Bill=5: five=1
Bill=5: five=2
Bill=5: five=3
Bill=10: five=2, ten=1 (gave one $5)
Bill=20: ten>0 && five>0? Yes → ten=0, five=1 (gave $10+$5)

All processed successfully
```

**Output:** `true`

---

## Example 2: `bills = [5,5,10,10,20]`

```
Bill=5: five=1
Bill=5: five=2
Bill=10: five=1, ten=1
Bill=10: five=0, ten=2
Bill=20: ten>0 && five>0? No (five=0)
         five>=3? No (five=0)
         Return false
```

**Output:** `false`

---

# Key Insights

- **Greedy preference matters:** Always prefer $10+$5 over three $5s when giving change for $20, since $5 bills are more flexible for future transactions
- **No need to track $20 count:** We never give $20 bills as change
- **Early termination:** Return `false` immediately when correct change can't be given
