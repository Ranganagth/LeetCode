# Intuition

The maximum distance between two prime indices is always achieved by pairing the **first prime** found in the array with the **last prime** found in the array. Any other pairing would result in a smaller or equal distance.

Since `nums[i]` is bounded by `100`, we can precompute primality for all numbers from `1` to `100` using a simple sieve, then scan the array once to find the first and last prime indices.

---

# Approach

1. **Precompute primality** for all numbers from `0` to `100` using the Sieve of Eratosthenes (or a simple trial-division check, since the range is tiny).
2. **Single pass through `nums`:**
   - Track the index of the **first** prime number encountered (`firstIndex`).
   - Track the index of the **last** prime number encountered (`lastIndex`), updating it every time a prime is found.
3. Return `lastIndex - firstIndex`.

Since primes are guaranteed to exist in the array (per constraints), we don't need to handle the "no prime found" edge case.

---

# Complexity

- **Time complexity:** 
$$O(n)$$
for scanning through `nums` once, plus $$O(1)$$ for the sieve precomputation (since values are capped at 100).

- **Space complexity:**
$$O(1)$$
since the sieve array has a fixed size of 101 regardless of input size.

# Code

```typescript
function maximumPrimeDifference(nums: number[]): number {
    const MAX_VAL = 101;
    const isPrime = new Array<boolean>(MAX_VAL).fill(true);
    isPrime[0] = false;
    isPrime[1] = false;

    for (let i = 2; i * i < MAX_VAL; i++) {
        if (isPrime[i]) {
            for (let j = i * i; j < MAX_VAL; j += i) {
                isPrime[j] = false;
            }
        }
    }

    let firstIndex = -1;
    let lastIndex = -1;

    for (let i = 0; i < nums.length; i++) {
        if (isPrime[nums[i]]) {
            if (firstIndex === -1) {
                firstIndex = i;
            }
            lastIndex = i;
        }
    }

    return lastIndex - firstIndex;
};

```

# Example Walkthrough

## Example 1

```text
nums = [4, 2, 9, 5, 3]
```

Primality check:
- `4` → not prime
- `2` → prime → `firstIndex = 1`, `lastIndex = 1`
- `9` → not prime
- `5` → prime → `lastIndex = 3`
- `3` → prime → `lastIndex = 4`

Result:

```text
lastIndex - firstIndex = 4 - 1 = 3
```

Output: `3`

## Example 2

```text
nums = [4, 8, 2, 8]
```

Primality check:
- `4` → not prime
- `8` → not prime
- `2` → prime → `firstIndex = 2`, `lastIndex = 2`
- `8` → not prime

Result:

```text
lastIndex - firstIndex = 2 - 2 = 0
```

Output: `0`
