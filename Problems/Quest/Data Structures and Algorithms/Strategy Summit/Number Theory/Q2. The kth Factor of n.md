# Intuition

The straightforward approach is to iterate through all numbers from `1` to `n`, check which are factors, and count until we reach the `k`th one. However, this takes `O(n)` time.

A smarter approach exploits the fact that factors come in **pairs**: if `i` is a factor of `n`, then `n / i` is also a factor. This means we only need to check divisors up to `√n`, then derive the larger factors from the smaller ones — reducing the time complexity to `O(√n)`.

---

# Approach

1. Iterate `i` from `1` to `√n`.
2. For each `i` where `n % i == 0`:
   - `i` is a small factor.
   - `n / i` is the corresponding large factor (its "pair").
3. Collect all small factors (`i ≤ √n`) in ascending order, and all large factors (`n / i`) in descending order (since as `i` increases, `n / i` decreases).
4. Combine: the full sorted factor list is `[small factors in ascending order] + [large factors in descending order]`, being careful not to double-count when `i == n / i` (i.e., when `n` is a perfect square).
5. Once we've identified the total count of factors, index into this conceptual combined list to find the `k`th factor directly, without building the full list explicitly.

## Implementation Detail

Rather than building two separate arrays and concatenating them (which is simple but works fine given `n ≤ 1000`), we can:
- Store small factors in a list as we find them.
- Store large factors (`n / i`) in a separate list.
- Reverse the large factors list and append it to the small factors list (skipping duplicate middle value if `n` is a perfect square).
- Return the element at index `k - 1`, or `-1` if out of bounds.

---

# Complexity

- **Time complexity:**
$$O(\sqrt{n})$$
since we only iterate up to `√n` to find all factor pairs.

- **Space complexity:**
$$(\sqrt{n})$$
for storing the small and large factor lists (at most `O(√n)` elements each).

---

# Code

```typescript
function kthFactor(n: number, k: number): number {
    const smallFactors: number[] = [];
    const largeFactors: number[] = [];

    const sqrtN = Math.floor(Math.sqrt(n));

    for (let i = 1; i <= sqrtN; i++) {
        if (n % i === 0) {
            const pair = n / i;
            smallFactors.push(i);

            if (pair !== i) {
                largeFactors.push(pair);
            }
        }
    }

    // Combine: small factors ascending + large factors descending.
    const totalFactors = smallFactors.length + largeFactors.length;

    if (k > totalFactors) {
        return -1;
    }

    if (k <= smallFactors.length) {
        return smallFactors[k - 1];
    } else {
        // Index into the reversed large factors list.
        const indexFromEnd = k - smallFactors.length - 1;
        return largeFactors[largeFactors.length - 1 - indexFromEnd];
    }
};

```

# Example Walkthrough

## Example 1

```text
n = 12, k = 3
```

Iterate `i` from `1` to `√12 ≈ 3`:

- `i = 1`: `12 % 1 == 0` → small = `[1]`, pair = `12` → large = `[12]`
- `i = 2`: `12 % 2 == 0` → small = `[1, 2]`, pair = `6` → large = `[12, 6]`
- `i = 3`: `12 % 3 == 0` → small = `[1, 2, 3]`, pair = `4` → large = `[12, 6, 4]`

Total factors: `3 + 3 = 6` (matches `[1,2,3,4,6,12]`)

Since `k = 3 ≤ smallFactors.length (3)`:

```text
Answer = smallFactors[2] = 3
```

Output: `3`

## Example 2

```text
n = 4, k = 4
```

- `i = 1`: small = `[1]`, pair = `4` → large = `[4]`
- `i = 2`: `4 % 2 == 0`, pair = `2 == i` → small = `[1, 2]` (no duplicate added to large)

Total factors: `2 + 1 = 3`

Since `k = 4 > 3` → return `-1`

Output: `-1`
