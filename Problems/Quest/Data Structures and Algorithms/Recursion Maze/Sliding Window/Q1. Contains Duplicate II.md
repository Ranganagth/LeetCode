# Intuition

We need to find two duplicate values where their indices are at most `k` apart. The key is to efficiently track recently seen values within a sliding window of size `k`.

**Key insight:** Use a hash map to store the most recent index of each value. As we iterate, check if we've seen the current value within the last `k` positions.

---

# Approach

1. **Use a hash map** to store value → most recent index

2. **Iterate through array:**
   - Check if current value exists in map
   - If yes, check if distance is ≤ k
   - Update map with current index

3. **Return result:** True if found, false otherwise

---

# Complexity

- **Time complexity:** $O(n)$ - single pass through array
- **Space complexity:** $O(min(n, k))$ - at most k+1 elements in map

---

# Code

```typescript
function containsNearbyDuplicate(nums: number[], k: number): boolean {
    const indexMap = new Map<number, number>();
    
    for (let i = 0; i < nums.length; i++) {
        const num = nums[i];
        
        // Check if we've seen this number before
        if (indexMap.has(num)) {
            const prevIndex = indexMap.get(num)!;
            
            // Check if distance is within k
            if (i - prevIndex <= k) {
                return true;
            }
        }
        
        // Update with current index
        indexMap.set(num, i);
    }
    
    return false;
};

```

# Alternative Solutions

## Solution 2: Sliding Window with Set

```typescript
function containsNearbyDuplicate(nums: number[], k: number): boolean {
    const window = new Set<number>();
    
    for (let i = 0; i < nums.length; i++) {
        // Check if current number is in the window
        if (window.has(nums[i])) {
            return true;
        }
        
        // Add current number to window
        window.add(nums[i]);
        
        // Maintain window size of k
        if (window.size > k) {
            window.delete(nums[i - k]);
        }
    }
    
    return false;
};

```

## Solution 3: Optimized with Early Window Check

```typescript
function containsNearbyDuplicate(nums: number[], k: number): boolean {
    if (k === 0) return false;
    
    const seen = new Map<number, number>();
    
    for (let i = 0; i < nums.length; i++) {
        if (seen.has(nums[i]) && i - seen.get(nums[i])! <= k) {
            return true;
        }
        seen.set(nums[i], i);
    }
    
    return false;
};

```

# Key Insights

- **Hash map tracks last seen index:** Efficient O(1) lookup
- **Update on every iteration:** Always store most recent index
- **Distance check:** `i - prevIndex <= k` ensures constraint
- **Early return:** Stop as soon as duplicate found within range

# Edge Cases

| Case | Input | k | Output | Notes |
|------|-------|---|--------|-------|
| No duplicates | [1,2,3,4] | 3 | false | All unique |
| k = 0 | [1,1] | 0 | false | Adjacent not allowed |
| Exact distance | [1,2,1] | 2 | true | Distance exactly k |
| Multiple duplicates | [1,1,1] | 1 | true | First pair found |
| Large k | [1,2,1] | 100 | true | k larger than array |
| Single element | [1] | 1 | false | No pairs possible |

# Common Mistakes to Avoid

1. **Not updating index:**
   ```typescript
   // Wrong: don't update if distance > k
   if (i - prevIndex <= k) {
       return true;
   }
   // Missing: indexMap.set(num, i);
   
   // Correct: always update
   indexMap.set(num, i);
   ```

2. **Wrong distance calculation:**
   ```typescript
   // Wrong: absolute value not needed (i is always larger)
   if (Math.abs(i - prevIndex) <= k)
   
   // Correct: i is always > prevIndex
   if (i - prevIndex <= k)
   ```

3. **Off-by-one in window size:**
   ```typescript
   // Wrong: window size should be k, not k+1
   if (window.size > k + 1)
   
   // Correct:
   if (window.size > k)
   ```
