# Intuition

We want to find the longest substring where we can make all characters the same by changing at most `k` characters.

**Key insight:** For a window to be valid, the number of characters we need to change = `window_size - count_of_most_frequent_character`. This must be ≤ k.

Use a **sliding window** approach: expand the window while valid, shrink when invalid.

---

# Approach

1. **Sliding window with two pointers:**
   - `left`: start of window
   - `right`: end of window

2. **Track character frequencies** in current window

3. **Track max frequency** of any character in current window

4. **Window validity check:**
   - Characters to change = `(right - left + 1) - maxFreq`
   - If this > k, window is invalid, shrink from left

5. **Track maximum valid window size**

---

# Complexity

- **Time complexity:** $O(n)$ - each character visited at most twice
- **Space complexity:** $O(26) = O(1)$ - fixed size frequency array

---

# Code

```typescript
function characterReplacement(s: string, k: number): number {
    const n = s.length;
    const count = new Array(26).fill(0);
    let left = 0;
    let maxFreq = 0;
    let maxLength = 0;
    
    for (let right = 0; right < n; right++) {
        // Add current character to window
        const charIndex = s.charCodeAt(right) - 'A'.charCodeAt(0);
        count[charIndex]++;
        
        // Update max frequency in current window
        maxFreq = Math.max(maxFreq, count[charIndex]);
        
        // Calculate characters to replace in current window
        const windowSize = right - left + 1;
        const charsToReplace = windowSize - maxFreq;
        
        // If we need to replace more than k characters, shrink window
        if (charsToReplace > k) {
            count[s.charCodeAt(left) - 'A'.charCodeAt(0)]--;
            left++;
        }
        
        // Update max length
        maxLength = Math.max(maxLength, right - left + 1);
    }
    
    return maxLength;
};

```

## Solution 2: Optimized (No Need to Update maxFreq on Shrink)

```typescript
function characterReplacement(s: string, k: number): number {
    const count = new Array(26).fill(0);
    let left = 0;
    let maxFreq = 0;
    let maxLength = 0;
    
    for (let right = 0; right < n; right++) {
        const idx = s.charCodeAt(right) - 65; // 'A' = 65
        count[idx]++;
        maxFreq = Math.max(maxFreq, count[idx]);
        
        // Window size - max frequency > k means invalid
        while (right - left + 1 - maxFreq > k) {
            count[s.charCodeAt(left) - 65]--;
            left++;
        }
        
        maxLength = Math.max(maxLength, right - left + 1);
    }
    
    return maxLength;
};

```

## Solution 3: With Map for Clarity

```typescript
function characterReplacement(s: string, k: number): number {
    const freq = new Map<string, number>();
    let left = 0;
    let maxFreq = 0;
    let result = 0;
    
    for (let right = 0; right < s.length; right++) {
        const char = s[right];
        freq.set(char, (freq.get(char) || 0) + 1);
        maxFreq = Math.max(maxFreq, freq.get(char)!);
        
        // Check if current window is valid
        const windowSize = right - left + 1;
        if (windowSize - maxFreq > k) {
            // Shrink window
            const leftChar = s[left];
            freq.set(leftChar, freq.get(leftChar)! - 1);
            left++;
        }
        
        result = Math.max(result, right - left + 1);
    }
    
    return result;
};

```

# Key Insights

- **Window validity:** `windowSize - maxFreq ≤ k`
- **maxFreq optimization:** We don't need to recalculate maxFreq when shrinking (it only matters for the largest window)
- **Greedy expansion:** Always try to expand, only shrink when necessary
- **Character replacement:** We replace the less frequent characters to match the most frequent one

---

# Why maxFreq Doesn't Need to Decrease

**Important optimization:**

When we shrink the window, we don't need to recalculate `maxFreq` because:
- We're looking for the **maximum** window size
- If `maxFreq` decreases, the window size also decreases
- We only update `maxLength` when we find a larger valid window
- A smaller `maxFreq` won't give us a larger window than we've already found

This keeps the solution $O(n)$ instead of $O(26n)$.

# Common Mistakes to Avoid

1. **Recalculating maxFreq unnecessarily:**
   ```typescript
   // Wrong: O(26n) - recalculating max every time
   maxFreq = Math.max(...count);
   
   // Correct: O(n) - only update when adding
   maxFreq = Math.max(maxFreq, count[charIndex]);
   ```

2. **Wrong window validity check:**
   ```typescript
   // Wrong: checking if we can replace k characters
   if (count[mostFrequent] + k >= windowSize)
   
   // Correct: checking if we need to replace ≤ k characters
   if (windowSize - maxFreq <= k)
   ```

3. **Not shrinking properly:**
   ```typescript
   // Wrong: shrinking too much
   while (windowSize - maxFreq > k) {
       left++;
       // Need to update count!
   }
   
   // Correct: update count when shrinking
   if (windowSize - maxFreq > k) {
       count[s[left]]--;
       left++;
   }
   ```
