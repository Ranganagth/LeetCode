# Intuition

The key insight is that if a substring `[l, r]` contains at least one of each character (a, b, c), then **all substrings starting at `l` and ending at or after `r`** also satisfy the condition.

Instead of counting all valid substrings directly, we use a **sliding window** approach: for each valid left boundary `l`, we count how many right boundaries make valid substrings.

---

# Approach

1. **Sliding window with two pointers:**
   - `r` (right): expands the window
   - `l` (left): contracts the window when valid

2. **Track character counts** in current window

3. **When window is valid** (has all a, b, c):
   - All substrings from `l` to any position from `r` to end are valid
   - Count = `n - r` (all possible endings)
   - Shrink window from left and repeat

4. **Sum all counts**

---

# Complexity

- **Time complexity:** $O(n)$ - each character visited at most twice (once by r, once by l)
- **Space complexity:** $O(1)$ - fixed size count object

---

# Code Explanation

```typescript
function numberOfSubstrings(s: string): number {
    let count = { a: 0, b: 0, c: 0 };
    let l = 0, result = 0, n = s.length;

    for (let r = 0; r < n; r++) {
        // Expand window: add character at r
        count[s[r] as keyof typeof count]++;

        // While window contains all three characters
        while (count['a'] > 0 && count['b'] > 0 && count['c'] > 0) {
            // All substrings from l to r, r+1, ..., n-1 are valid
            // That's (n - r) substrings
            result += n - r;
            
            // Shrink window from left
            count[s[l] as keyof typeof count]--;
            l++;
        }
    }

    return result;
};

```

# Key Insights

- **Counting trick:** When window `[l, r]` is valid, all extensions to the right are also valid
- **Efficient counting:** `n - r` gives count of all valid endings
- **Sliding window:** Each character processed at most twice (expand and contract)
- **Greedy shrinking:** Shrink as much as possible to count all valid left boundaries

---

# Why This Works

**Mathematical reasoning:**

For a valid window `[l, r]`:
- Substring `s[l...r]` is valid
- Substring `s[l...r+1]` is valid (if r+1 exists)
- Substring `s[l...r+2]` is valid (if r+2 exists)
- ...
- Substring `s[l...n-1]` is valid

Total count = `n - r` substrings

By shrinking from left and recounting, we cover all possible valid left boundaries.

# Common Mistakes to Avoid

1. **Counting individual substrings:**
   ```typescript
   // Wrong: O(n²) - checking each substring
   for (let i = 0; i < n; i++) {
       for (let j = i; j < n; j++) {
           if (hasAllThree(s.substring(i, j+1))) count++;
       }
   }
   
   // Correct: O(n) - use sliding window
   ```

2. **Not using n - r:**
   ```typescript
   // Wrong: only counting current substring
   if (hasAll) result++;
   
   // Correct: count all extensions
   result += n - r;
   ```

3. **Breaking after first valid window:**
   ```typescript
   // Wrong: stops too early
   if (hasAll) return n - r;
   
   // Correct: continue shrinking
   while (hasAll) {
       result += n - r;
       shrink();
   }
   ```

# Alternative Approach (Less Efficient)

**Brute force - O(n²):**
```typescript
function numberOfSubstrings(s: string): number {
    let count = 0;
    const n = s.length;
    
    for (let i = 0; i < n; i++) {
        const seen = new Set<string>();
        for (let j = i; j < n; j++) {
            seen.add(s[j]);
            if (seen.size === 3) {
                count += n - j; // All extensions are valid
                break;
            }
        }
    }
    
    return count;
};

```
