# Intuition

To create the shortest palindrome by adding characters to the front, we need to find the **longest palindromic prefix** of the string. Then, we add the reverse of the remaining suffix to the front.

**Key insight:** Find the longest prefix of `s` that is also a palindrome. The characters after this prefix need to be reversed and prepended.

---

# Approach

## Optimal Solution: KMP Algorithm

1. **Create a new string:** `s + "#" + reverse(s)`
   - The `#` separator prevents overlap

2. **Use KMP failure function** to find the longest prefix of `s` that matches a suffix of `reverse(s)`

3. **This tells us the longest palindromic prefix** of the original string

4. **Add the reverse of the remaining part** to the front

---

# Complexity

- **Time complexity:** $O(n)$ - KMP algorithm
- **Space complexity:** $O(n)$ - for the combined string and KMP table

---

# Code

## Solution 1: KMP Algorithm (Optimal)

```typescript
function shortestPalindrome(s: string): string {
    if (s.length === 0) return s;
    
    const rev = s.split('').reverse().join('');
    
    // Create pattern: s + "#" + reverse(s)
    const combined = s + "#" + rev;
    
    // Build KMP failure function
    const lps = buildLPS(combined);
    
    // lps[combined.length - 1] gives length of longest palindromic prefix
    const longestPalindromePrefix = lps[combined.length - 1];
    
    // Add reverse of remaining suffix to front
    const suffix = s.substring(longestPalindromePrefix);
    const prefix = suffix.split('').reverse().join('');
    
    return prefix + s;
}

function buildLPS(pattern: string): number[] {
    const n = pattern.length;
    const lps = new Array(n).fill(0);
    let len = 0; // Length of previous longest prefix suffix
    let i = 1;
    
    while (i < n) {
        if (pattern[i] === pattern[len]) {
            len++;
            lps[i] = len;
            i++;
        } else {
            if (len !== 0) {
                len = lps[len - 1];
            } else {
                lps[i] = 0;
                i++;
            }
        }
    }
    
    return lps;
};

```

## Solution 2: Two Pointers (Simpler but Less Efficient)

```typescript
function shortestPalindrome(s: string): string {
    if (s.length === 0) return s;
    
    // Find longest palindromic prefix
    let end = s.length - 1;
    
    for (let i = s.length - 1; i >= 0; i--) {
        if (isPalindrome(s, 0, i)) {
            end = i;
            break;
        }
    }
    
    // Add reverse of remaining part to front
    const suffix = s.substring(end + 1);
    const prefix = suffix.split('').reverse().join('');
    
    return prefix + s;
}

function isPalindrome(s: string, left: number, right: number): boolean {
    while (left < right) {
        if (s[left] !== s[right]) {
            return false;
        }
        left++;
        right--;
    }
    return true;
};

```

## Solution 3: Recursive Approach

```typescript
function shortestPalindrome(s: string): string {
    if (s.length === 0) return s;
    
    const n = s.length;
    const rev = s.split('').reverse().join('');
    
    // Find longest palindromic prefix
    for (let i = 0; i < n; i++) {
        // Check if s matches with rev starting from position i
        if (s.substring(0, n - i) === rev.substring(i)) {
            // Found the longest palindromic prefix
            return rev.substring(0, i) + s;
        }
    }
    
    return rev + s;
};

```

# Key Insights

- **KMP optimization:** Uses failure function to find longest palindromic prefix in $O(n)$
- **String matching:** The combined string trick allows us to use KMP
- **Minimal addition:** We only add what's necessary (reverse of non-palindromic suffix)
- **Separator importance:** The "#" prevents false matches between s and reverse(s)

---

# Why KMP Works

**The trick:**

1. Create: `s + "#" + reverse(s)`
2. KMP finds longest prefix of this string that's also a suffix
3. This prefix length tells us how much of `s` matches with the end of `reverse(s)`
4. This matching part is exactly the longest palindromic prefix of `s`

**Example:**
```
s = "aacecaaa"
rev = "aaacecaa"
combined = "aacecaaa#aaacecaa"

KMP finds that "aacecaa" (length 7) is both:
- A prefix of combined
- A suffix of combined

This means first 7 chars of s form a palindrome!
```

# Edge Cases

| Case | Input | Output | Notes |
|------|-------|--------|-------|
| Empty | "" | "" | No change needed |
| Single char | "a" | "a" | Already palindrome |
| Already palindrome | "aba" | "aba" | No addition needed |
| No palindrome | "abc" | "cbabc" | Add "cb" to front |
| All same | "aaaa" | "aaaa" | Already palindrome |

# Common Mistakes to Avoid

1. **Not using separator in KMP:**
   ```typescript
   // Wrong: can cause false matches
   combined = s + rev;
   
   // Correct: separator prevents overlap
   combined = s + "#" + rev;
   ```

2. **Wrong substring extraction:**
   ```typescript
   // Wrong: using wrong index
   suffix = s.substring(lps[n]);
   
   // Correct: use lps of combined string
   suffix = s.substring(lps[combined.length - 1]);
   ```

3. **Not reversing the suffix:**
   ```typescript
   // Wrong: adding suffix directly
   return suffix + s;
   
   // Correct: reverse the suffix
   return suffix.split('').reverse().join('') + s;
   ```
