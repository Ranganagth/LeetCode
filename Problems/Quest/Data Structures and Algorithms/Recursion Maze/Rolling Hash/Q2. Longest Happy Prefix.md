# Intuition

This is a classic application of the **KMP (Knuth-Morris-Pratt) failure function**. The longest happy prefix is exactly what the KMP algorithm's LPS (Longest Proper Prefix which is also Suffix) array computes.

**Key insight:** The last value in the LPS array gives us the length of the longest proper prefix that is also a suffix.

---

# Approach

1. **Build KMP failure function (LPS array):**
   - `lps[i]` = length of longest proper prefix of `s[0...i]` that is also a suffix

2. **The answer is `lps[n-1]`:**
   - This gives the length of the longest happy prefix

3. **Return the substring** of that length from the beginning

---

# Complexity

- **Time complexity:** $O(n)$ - KMP algorithm
- **Space complexity:** $O(n)$ - LPS array

---

# Code

## Solution 1: KMP Algorithm (Optimal)

```typescript
function longestPrefix(s: string): string {
    const n = s.length;
    
    // Build LPS (Longest Proper Prefix which is also Suffix) array
    const lps = new Array(n).fill(0);
    let len = 0; // Length of previous longest prefix suffix
    let i = 1;
    
    while (i < n) {
        if (s[i] === s[len]) {
            len++;
            lps[i] = len;
            i++;
        } else {
            if (len !== 0) {
                // Try shorter prefix
                len = lps[len - 1];
            } else {
                lps[i] = 0;
                i++;
            }
        }
    }
    
    // lps[n-1] gives length of longest happy prefix
    const happyPrefixLength = lps[n - 1];
    
    return s.substring(0, happyPrefixLength);
};

```

## Solution 2: With Detailed Comments

```typescript
function longestPrefix(s: string): string {
    const n = s.length;
    
    // LPS[i] = length of longest proper prefix of s[0..i] 
    // which is also a suffix of s[0..i]
    const lps = new Array(n).fill(0);
    
    // len = length of the previous longest prefix suffix
    let len = 0;
    
    // lps[0] is always 0 (a single character has no proper prefix)
    // Start from i = 1
    let i = 1;
    
    while (i < n) {
        if (s[i] === s[len]) {
            // Characters match, extend the current prefix
            len++;
            lps[i] = len;
            i++;
        } else {
            // Mismatch after len matches
            if (len !== 0) {
                // Try with shorter prefix
                // Don't increment i, we'll compare s[i] with s[len] again
                len = lps[len - 1];
            } else {
                // No prefix found
                lps[i] = 0;
                i++;
            }
        }
    }
    
    // The last element of lps gives us the longest happy prefix length
    return s.substring(0, lps[n - 1]);
};

```

## Solution 3: Alternative Implementation

```typescript
function longestPrefix(s: string): string {
    const n = s.length;
    const lps = buildLPS(s);
    
    // Return substring of length lps[n-1]
    return lps[n - 1] > 0 ? s.substring(0, lps[n - 1]) : "";
}

function buildLPS(pattern: string): number[] {
    const n = pattern.length;
    const lps = new Array(n).fill(0);
    
    for (let i = 1, len = 0; i < n; ) {
        if (pattern[i] === pattern[len]) {
            lps[i++] = ++len;
        } else if (len > 0) {
            len = lps[len - 1];
        } else {
            lps[i++] = 0;
        }
    }
    
    return lps;
};

```

```
lps[2] = 1: "aba" -> "a" matches (prefix "a" = suffix "a")
lps[3] = 2: "abab" -> "ab" matches
lps[4] = 3: "ababa" -> "aba" matches
lps[5] = 4: "ababab" -> "abab" matches
```

# Key Insights

- **KMP failure function:** Designed exactly for this problem
- **Proper prefix:** Excludes the string itself
- **Overlapping allowed:** Prefix and suffix can overlap
- **Efficient:** $O(n)$ time, no nested loops needed
- **Last value matters:** `lps[n-1]` gives the answer

---

# Why KMP Works

**The algorithm:**

1. At each position `i`, we try to extend the current matching prefix
2. If characters match, we increment the length
3. If they don't match, we fall back to a shorter prefix using `lps[len-1]`
4. This fallback is the key optimization that makes it $O(n)$

**Example of fallback:**
```
s = "aabaaa"
At i=5, we have len=2 (matched "aa")
s[5]='a', s[2]='b' -> mismatch
Fall back: len = lps[1] = 1
Now compare s[5]='a' with s[1]='a' -> match!
```

# Edge Cases

| Case | Input | Output | Notes |
|------|-------|--------|-------|
| Single char | "a" | "" | No proper prefix |
| Two same | "aa" | "a" | "a" is both prefix and suffix |
| All same | "aaaa" | "aaa" | Almost entire string |
| No match | "abcd" | "" | No happy prefix |
| Repeating pattern | "abcabc" | "abc" | Full pattern repeats |

# Common Mistakes to Avoid

1. **Including the string itself:**
   ```typescript
   // Wrong: returning entire string
   if (lps[n-1] === n) return s;
   
   // Correct: proper prefix excludes itself
   // lps[n-1] will never equal n
   ```

2. **Not handling fallback correctly:**
   ```typescript
   // Wrong: not using lps for fallback
   if (s[i] !== s[len]) {
       len = 0;
   }
   
   // Correct: use lps[len-1] for fallback
   if (len !== 0) {
       len = lps[len - 1];
   }
   ```

3. **Incrementing i when falling back:**
   ```typescript
   // Wrong: incrementing i during fallback
   len = lps[len - 1];
   i++;
   
   // Correct: don't increment i, retry with shorter prefix
   len = lps[len - 1];
   // i stays the same
   ```

# Alternative: Rolling Hash

```typescript
function longestPrefix(s: string): string {
    const n = s.length;
    const MOD = 1e9 + 7;
    const BASE = 26;
    
    let prefixHash = 0, suffixHash = 0;
    let power = 1;
    let maxLen = 0;
    
    for (let i = 0; i < n - 1; i++) {
        // Add to prefix hash
        prefixHash = (prefixHash * BASE + (s.charCodeAt(i) - 97)) % MOD;
        
        // Add to suffix hash
        suffixHash = (suffixHash + (s.charCodeAt(n - 1 - i) - 97) * power) % MOD;
        power = (power * BASE) % MOD;
        
        // Check if hashes match
        if (prefixHash === suffixHash) {
            maxLen = i + 1;
        }
    }
    
    return s.substring(0, maxLen);
};

```
