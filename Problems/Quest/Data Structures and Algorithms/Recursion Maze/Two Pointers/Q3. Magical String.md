# Intuition

The magical string is self-generating: the string itself describes the lengths of consecutive groups of 1's and 2's.

**Key insight:** We need to build the string iteratively, where:
- The string starts with "122"
- Each position in the string tells us how many of the next character to add
- Characters alternate between 1 and 2

---

# Approach

1. **Initialize:** Start with "122" (base case)

2. **Two pointers:**
   - `i`: points to current position in string (tells us the count)
   - Current position in building: where we add new characters

3. **Alternate characters:** Switch between adding 1's and 2's

4. **Build until length n:** Keep generating until we have at least n characters

5. **Count 1's:** Count occurrences of '1' in first n characters

---

# Complexity

- **Time complexity:** O(n) - generate n characters
- **Space complexity:** O(n) - store the magical string

# Code

## Solution 1: Array Building

```typescript
function magicalString(n: number): number {
    if (n === 0) return 0;
    if (n <= 3) return 1;
    
    // Start with base string "122"
    const s: number[] = [1, 2, 2];
    
    // Pointer to read the count from
    let i = 2;
    
    // Current character to add (alternates between 1 and 2)
    let num = 1;
    
    // Build string until we have at least n characters
    while (s.length < n) {
        // s[i] tells us how many times to add 'num'
        const count = s[i];
        
        // Add 'num' count times
        for (let j = 0; j < count; j++) {
            s.push(num);
        }
        
        // Alternate between 1 and 2
        num = num === 1 ? 2 : 1;
        
        // Move to next position
        i++;
    }
    
    // Count 1's in first n positions
    let ones = 0;
    for (let j = 0; j < n; j++) {
        if (s[j] === 1) {
            ones++;
        }
    }
    
    return ones;
};

```

## Solution 2: Optimized with Direct Counting

```typescript
function magicalString(n: number): number {
    if (n === 0) return 0;
    if (n <= 3) return 1;
    
    const s: number[] = [1, 2, 2];
    let countOnes = 1; // Already have one '1' in "122"
    
    let i = 2; // Index to read count from
    let num = 1; // Current number to add
    
    while (s.length < n) {
        const count = s[i];
        
        // Add 'num' count times
        for (let j = 0; j < count && s.length < n; j++) {
            s.push(num);
            if (num === 1) {
                countOnes++;
            }
        }
        
        // Alternate number
        num = 3 - num; // Toggle between 1 and 2
        i++;
    }
    
    return countOnes;
};

```

## Solution 3: With Detailed Comments

```typescript
function magicalString(n: number): number {
    // Edge cases
    if (n === 0) return 0;
    if (n === 1) return 1;
    if (n === 2) return 1;
    if (n === 3) return 1;
    
    // Initialize magical string with "122"
    const magicStr: number[] = [1, 2, 2];
    
    // Pointer to read the count (how many of current number to add)
    let readIndex = 2;
    
    // Current number to add (alternates between 1 and 2)
    let currentNum = 1;
    
    // Count of 1's so far (we have one '1' in initial "122")
    let onesCount = 1;
    
    // Build the magical string until we have at least n characters
    while (magicStr.length < n) {
        // Read how many times to add currentNum
        const timesToAdd = magicStr[readIndex];
        
        // Add currentNum 'timesToAdd' times
        for (let i = 0; i < timesToAdd; i++) {
            // Only add if we haven't reached n yet
            if (magicStr.length < n) {
                magicStr.push(currentNum);
                
                // Count if it's a 1
                if (currentNum === 1) {
                    onesCount++;
                }
            }
        }
        
        // Alternate between 1 and 2
        currentNum = currentNum === 1 ? 2 : 1;
        
        // Move to next position to read count
        readIndex++;
    }
    
    return onesCount;
};

```

## Solution 4: String-based (Less Efficient)

```typescript
function magicalString(n: number): number {
    if (n === 0) return 0;
    if (n <= 3) return 1;
    
    let s = "122";
    let i = 2;
    let num = 1;
    
    while (s.length < n) {
        const count = parseInt(s[i]);
        s += num.toString().repeat(count);
        num = num === 1 ? 2 : 1;
        i++;
    }
    
    // Count 1's in first n characters
    let ones = 0;
    for (let j = 0; j < n; j++) {
        if (s[j] === '1') ones++;
    }
    
    return ones;
};

```

# Common Mistakes to Avoid

1. **Not handling base cases:**
   ```typescript
   // Must handle n <= 3 specially
   if (n <= 3) return 1;
   ```

2. **Wrong alternation:**
   ```typescript
   // Wrong: not alternating properly
   num = num + 1;
   
   // Correct: toggle between 1 and 2
   num = num === 1 ? 2 : 1;
   // or
   num = 3 - num;
   ```

3. **Reading from wrong position:**
   ```typescript
   // Must start reading from index 2, not 0
   let i = 2;
   ```

4. **Counting after exceeding n:**
   ```typescript
   // Wrong: might count beyond n
   for (let j = 0; j < count; j++) {
       s.push(num);
   }
   
   // Correct: check length
   for (let j = 0; j < count && s.length < n; j++) {
       s.push(num);
   }
   ```
