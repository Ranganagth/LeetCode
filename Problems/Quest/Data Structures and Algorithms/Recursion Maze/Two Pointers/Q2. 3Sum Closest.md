# Intuition

This problem is similar to the classic 3Sum problem, but instead of finding triplets that sum to zero, we need to find the triplet whose sum is closest to the target.

**Key insight:** Sort the array first, then use a combination of fixed pointer + two-pointer technique to efficiently find the closest sum.

---

# Approach

1. **Sort the array** to enable two-pointer technique

2. **Fix first element** and use two pointers for the remaining two:
   - Iterate through array with index `i`
   - Use `left = i + 1` and `right = n - 1`

3. **Calculate sum** and track closest:
   - If sum equals target, return immediately (can't get closer)
   - If sum is closer to target than current best, update
   - Move pointers based on whether sum is less than or greater than target

4. **Return** the closest sum found

---

# Complexity

- **Time complexity:** O(n²) - O(n log n) for sorting + O(n²) for nested loops
- **Space complexity:** O(1) or O(log n) depending on sorting algorithm

# Code

## Solution 1: Two Pointers (Optimal)

```typescript
function threeSumClosest(nums: number[], target: number): number {
    const n = nums.length;
    
    // Sort array to enable two-pointer technique
    nums.sort((a, b) => a - b);
    
    let closestSum = nums[0] + nums[1] + nums[2];
    
    // Fix first element
    for (let i = 0; i < n - 2; i++) {
        let left = i + 1;
        let right = n - 1;
        
        // Two pointers for remaining two elements
        while (left < right) {
            const currentSum = nums[i] + nums[left] + nums[right];
            
            // If exact match, return immediately
            if (currentSum === target) {
                return currentSum;
            }
            
            // Update closest sum if current is closer
            if (Math.abs(currentSum - target) < Math.abs(closestSum - target)) {
                closestSum = currentSum;
            }
            
            // Move pointers based on comparison with target
            if (currentSum < target) {
                left++;
            } else {
                right--;
            }
        }
    }
    
    return closestSum;
};

```

## Solution 2: With Detailed Comments

```typescript
function threeSumClosest(nums: number[], target: number): number {
    const n = nums.length;
    
    // Step 1: Sort the array
    // This allows us to use two-pointer technique efficiently
    nums.sort((a, b) => a - b);
    
    // Initialize with first possible triplet sum
    let closestSum = nums[0] + nums[1] + nums[2];
    let minDiff = Math.abs(closestSum - target);
    
    // Step 2: Fix the first element and find best pair for remaining two
    for (let i = 0; i < n - 2; i++) {
        // Skip duplicates for optimization (optional)
        if (i > 0 && nums[i] === nums[i - 1]) continue;
        
        // Two pointers for the remaining array
        let left = i + 1;
        let right = n - 1;
        
        while (left < right) {
            const currentSum = nums[i] + nums[left] + nums[right];
            const currentDiff = Math.abs(currentSum - target);
            
            // Perfect match - can't get closer
            if (currentSum === target) {
                return currentSum;
            }
            
            // Update closest sum if this is better
            if (currentDiff < minDiff) {
                closestSum = currentSum;
                minDiff = currentDiff;
            }
            
            // Move pointers to try to get closer to target
            if (currentSum < target) {
                // Sum too small, need larger values
                left++;
            } else {
                // Sum too large, need smaller values
                right--;
            }
        }
    }
    
    return closestSum;
};

```

## Solution 3: With Early Termination Optimization

```typescript
function threeSumClosest(nums: number[], target: number): number {
    nums.sort((a, b) => a - b);
    const n = nums.length;
    let closestSum = nums[0] + nums[1] + nums[2];
    
    for (let i = 0; i < n - 2; i++) {
        // Skip duplicates
        if (i > 0 && nums[i] === nums[i - 1]) continue;
        
        let left = i + 1;
        let right = n - 1;
        
        while (left < right) {
            const sum = nums[i] + nums[left] + nums[right];
            
            // Early return if exact match
            if (sum === target) return sum;
            
            // Update closest
            if (Math.abs(sum - target) < Math.abs(closestSum - target)) {
                closestSum = sum;
            }
            
            if (sum < target) {
                left++;
                // Skip duplicates
                while (left < right && nums[left] === nums[left - 1]) left++;
            } else {
                right--;
                // Skip duplicates
                while (left < right && nums[right] === nums[right + 1]) right--;
            }
        }
    }
    
    return closestSum;
};

```

## Solution 4: Brute Force (For Comparison)

```typescript
function threeSumClosest(nums: number[], target: number): number {
    const n = nums.length;
    let closestSum = Infinity;
    let minDiff = Infinity;
    
    // Try all possible triplets
    for (let i = 0; i < n - 2; i++) {
        for (let j = i + 1; j < n - 1; j++) {
            for (let k = j + 1; k < n; k++) {
                const sum = nums[i] + nums[j] + nums[k];
                const diff = Math.abs(sum - target);
                
                if (diff < minDiff) {
                    minDiff = diff;
                    closestSum = sum;
                }
                
                // Early return if exact match
                if (sum === target) return sum;
            }
        }
    }
    
    return closestSum;
};

```

## Example 1:

**Input:** `nums = [-1,2,1,-4], target = 1`

**Step-by-step:**

```

nums = [-4, -1, 1, 2]

Step 2: Initialize
closestSum = -4 + (-1) + 1 = -4

Step 3: Fix i=0 (nums[0] = -4)
left = 1, right = 3

Iteration 1:
sum = -4 + (-1) + 2 = -3
|-3 - 1| = 4 < |-4 - 1| = 5
closestSum = -3
sum < target, left++

Iteration 2:
left = 2, right = 3
sum = -4 + 1 + 2 = -1
|-1 - 1| = 2 < 4
closestSum = -1
sum < target, left++

left >= right, exit inner loop

Step 4: Fix i=1 (nums[1] = -1)
left = 2, right = 3

Iteration 1:
sum = -1 + 1 + 2 = 2
|2 - 1| = 1 < 2
closestSum = 2
sum > target, right--

left >= right, exit inner loop

Step 5: Fix i=2 (nums[2] = 1)
left = 3, right = 3
left >= right, skip

Final: closestSum = 2
```

**Output:** `2`

# Key Insights

- **Sorting enables efficiency:** Two-pointer technique only works on sorted arrays
- **Greedy pointer movement:** Move pointers based on whether sum is too large or too small
- **Early termination:** If exact match found, return immediately
- **Distance tracking:** Use absolute difference to measure closeness

# Common Mistakes to Avoid

1. **Not sorting first:** Two-pointer technique requires sorted array

2. **Wrong pointer movement:**
   ```typescript
   // Wrong: always moving left
   if (sum !== target) left++;
   
   // Correct: move based on comparison
   if (sum < target) left++;
   else right--;
   ```

3. **Not handling exact match:**
   ```typescript
   // Should return immediately when sum === target
   if (sum === target) return sum;
   ```

4. **Wrong distance calculation:**
   ```typescript
   // Wrong: not using absolute value
   if (sum - target < closestSum - target)
   
   // Correct: use absolute difference
   if (Math.abs(sum - target) < Math.abs(closestSum - target))
   ```

2. **Early termination:** Return when exact match found
3. **Pruning:** Skip if current element makes impossible sums
