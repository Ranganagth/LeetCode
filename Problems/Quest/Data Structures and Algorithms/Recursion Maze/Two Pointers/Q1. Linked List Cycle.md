# Intuition

The classic **Floyd's Cycle Detection Algorithm** (also known as the "tortoise and hare" algorithm) is the optimal solution. 

**Key insight:** If there's a cycle, a fast pointer moving 2 steps at a time will eventually meet a slow pointer moving 1 step at a time inside the cycle.

---

# Approach

## Solution: Two Pointers (Floyd's Algorithm)

1. **Initialize two pointers:** Both start at head
   - `slow`: moves 1 step at a time
   - `fast`: moves 2 steps at a time

2. **Move pointers:** 
   - Advance slow by 1 node
   - Advance fast by 2 nodes

3. **Check for meeting:**
   - If `slow === fast`, there's a cycle
   - If `fast` or `fast.next` becomes null, no cycle

4. **Return result**

**Why this works:** In a cycle, the fast pointer will eventually "lap" the slow pointer and they'll meet.

---

# Complexity

- **Time complexity:** O(n) - in worst case, visit each node once or twice
- **Space complexity:** O(1) - only using two pointers

# Code Analysis


## Solution 1: Floyd's Algorithm

```typescript
function hasCycle(head: ListNode | null): boolean {
    if (!head || !head.next) return false;

    let slow: ListNode | null = head;
    let fast: ListNode | null = head;

    while (fast && fast.next) {
        slow = slow!.next;
        fast = fast.next.next;

        if (slow === fast) {
            return true;
        }
    }

    return false;
};

```

## Solution 2: With Detailed Comments

```typescript
function hasCycle(head: ListNode | null): boolean {
    // Edge case: empty list or single node without cycle
    if (!head || !head.next) {
        return false;
    }

    // Initialize two pointers
    let slow: ListNode | null = head;
    let fast: ListNode | null = head;

    // Move pointers until fast reaches end or they meet
    while (fast && fast.next) {
        // Move slow pointer one step
        slow = slow!.next;
        
        // Move fast pointer two steps
        fast = fast.next.next;

        // If pointers meet, there's a cycle
        if (slow === fast) {
            return true;
        }
    }

    // Fast pointer reached end, no cycle
    return false;
};

```

function hasCycle(head: ListNode | null): boolean {
    if (!head) return false;

    let slow = head;
    let fast = head.next; // Start fast one step ahead

    }

    return false;

## Solution 4: Using Set (O(n) Space - Not Optimal)

```typescript
function hasCycle(head: ListNode | null): boolean {
    const visited = new Set<ListNode>();
    let current = head;

    while (current) {
        // If we've seen this node before, there's a cycle
        if (visited.has(current)) {
            return true;
        }
        
        visited.add(current);
        current = current.next;
    }

    return false;
};

```

function hasCycle(head: ListNode | null): boolean {

        // Mark visited nodes
        if ((current as any).visited) {
            return true;
        }
        
        (current as any).visited = true;
        current = current.next;
    }

    return false;

# Example Walkthrough

## Example 1:

**Input:** `head = [3,2,0,-4], pos = 1` (cycle exists)

**Visual:**
```
3 → 2 → 0 → -4
    ↑__________|
```

**Execution:**

```
Initial: slow = 3, fast = 3

Step 1:
slow = 2 (moved 1 step)
fast = 0 (moved 2 steps)
slow ≠ fast

Step 2:
slow = 0 (moved 1 step)
fast = 2 (moved 2 steps: -4 → 2)
slow ≠ fast

Step 3:
slow = -4 (moved 1 step)
fast = -4 (moved 2 steps: 0 → -4)
slow === fast

Return true
```

**Output:** `true`

# Key Insights

- **Speed difference:** Fast moves twice as fast as slow
- **Meeting guarantee:** If cycle exists, they will meet
- **Meeting point:** Not necessarily at cycle start
- **No cycle:** Fast reaches null
- **Constant space:** Only two pointers needed

---

# Why Floyd's Algorithm Works

**Mathematical proof:**

1. **If no cycle:** Fast pointer reaches end → return false

2. **If cycle exists:**
   - Let's say slow enters cycle when fast is already k nodes ahead
   - Each iteration, fast gains 1 node on slow (moves 2 vs 1)
   - In a cycle of length C, they'll meet in at most C iterations
   - Meeting is guaranteed because the distance closes by 1 each step

**Example:**
```
Cycle length = 4
Slow at position 0, Fast at position 2

Step 1: Slow at 1, Fast at 0 (gap = 3)
Step 2: Slow at 2, Fast at 2 (gap = 0, MEET!)
```

# Edge Cases

| Case | Input | Output | Notes |
|------|-------|--------|-------|
| Empty list | null | false | No nodes |
| Single node | [1], pos=-1 | false | No cycle possible |
| Single node cycle | [1], pos=0 | true | Points to itself |
| Two nodes cycle | [1,2], pos=0 | true | Cycle at start |
| Large cycle | 10000 nodes | true/false | Efficient O(n) |
| Cycle at end | [1,2,3], pos=2 | true | Last node cycles |

# Common Mistakes to Avoid

1. **Not checking fast.next:**
   ```typescript
   // Wrong: can cause null pointer error
   while (fast) {
       fast = fast.next.next; // Error if fast.next is null
   }
   
   // Correct:
   while (fast && fast.next) {
       fast = fast.next.next;
   }
   ```

2. **Checking equality before moving:**
   ```typescript
   // Wrong: misses detection
   if (slow === fast) return true;
   slow = slow.next;
   fast = fast.next.next;
   
   // Correct: move first, then check
   slow = slow.next;
   fast = fast.next.next;
   if (slow === fast) return true;
   ```

3. **Starting both at head.next:**
   ```typescript
   // Can miss single-node cycles
   let slow = head.next;
   let fast = head.next;
   ```

# Follow-up: Finding Cycle Start

If you need to find where the cycle begins:

```typescript
function detectCycle(head: ListNode | null): ListNode | null {
    if (!head || !head.next) return null;

    let slow = head;
    let fast = head;

    // Find meeting point
    while (fast && fast.next) {
        slow = slow.next!;
        fast = fast.next.next;
        
        if (slow === fast) {
            // Cycle detected, find start
            slow = head;
            while (slow !== fast) {
                slow = slow.next!;
                fast = fast.next!;
            }
            return slow; // Cycle start
        }
    }

    return null; // No cycle
};

```
