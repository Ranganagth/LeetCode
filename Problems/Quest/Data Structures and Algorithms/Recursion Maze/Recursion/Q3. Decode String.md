# Intuition

We need to decode a string with nested patterns like `k[encoded_string]`. The key challenge is handling **nested brackets** - we need to decode from the innermost brackets outward.

**Key insight:** Use a **stack** to handle nested structures. When we encounter `]`, we pop from the stack to get the string to repeat and the count, then push the repeated string back.

---

# Approach

1. **Use a stack** to track:
   - Current string being built
   - Repeat counts for nested patterns

2. **Iterate through the string:**
   - **Digit:** Build the number (could be multi-digit like "100")
   - **'[':** Push current string and count to stack, reset for new level
   - **']':** Pop from stack, repeat current string, append to previous level
   - **Letter:** Add to current string

3. **Return the final decoded string**

---

# Complexity

- **Time complexity:** $O(n × k)$ where n is string length, k is max repeat count
- **Space complexity:** $O(n)$ for the stack

---

# Code

## Solution 1: Stack-based (Recommended)

```typescript
function decodeString(s: string): string {
    const stack: string[] = [];
    let currentString = '';
    let currentNum = 0;
    
    for (const char of s) {
        if (char >= '0' && char <= '9') {
            // Build the number (could be multi-digit)
            currentNum = currentNum * 10 + parseInt(char);
        } else if (char === '[') {
            // Push current state to stack and reset
            stack.push(currentString);
            stack.push(currentNum.toString());
            currentString = '';
            currentNum = 0;
        } else if (char === ']') {
            // Pop count and previous string
            const num = parseInt(stack.pop()!);
            const prevString = stack.pop()!;
            
            // Repeat current string and append to previous
            currentString = prevString + currentString.repeat(num);
        } else {
            // Regular letter
            currentString += char;
        }
    }
    
    return currentString;
};

```

## Solution 2: Two Stacks (More Explicit)

```typescript
function decodeString(s: string): string {
    const countStack: number[] = [];
    const stringStack: string[] = [];
    let currentString = '';
    let currentNum = 0;
    
    for (const char of s) {
        if (char >= '0' && char <= '9') {
            currentNum = currentNum * 10 + parseInt(char);
        } else if (char === '[') {
            // Save current state
            countStack.push(currentNum);
            stringStack.push(currentString);
            
            // Reset for new level
            currentNum = 0;
            currentString = '';
        } else if (char === ']') {
            // Decode current level
            const repeatCount = countStack.pop()!;
            const prevString = stringStack.pop()!;
            
            // Build repeated string
            currentString = prevString + currentString.repeat(repeatCount);
        } else {
            // Letter
            currentString += char;
        }
    }
    
    return currentString;
};

```

## Solution 3: Recursive Approach

```typescript
function decodeString(s: string): string {
    let index = 0;
    
    function decode(): string {
        let result = '';
        let num = 0;
        
        while (index < s.length) {
            const char = s[index];
            
            if (char >= '0' && char <= '9') {
                num = num * 10 + parseInt(char);
                index++;
            } else if (char === '[') {
                index++; // Skip '['
                const decoded = decode();
                result += decoded.repeat(num);
                num = 0;
            } else if (char === ']') {
                index++; // Skip ']'
                return result;
            } else {
                result += char;
                index++;
            }
        }
        
        return result;
    }
    
    return decode();
};

```

## Solution 4: With Detailed Comments

```typescript
function decodeString(s: string): string {
    const stack: string[] = [];
    let currentString = '';
    let currentNum = 0;
    
    for (let i = 0; i < s.length; i++) {
        const char = s[i];
        
        if (char >= '0' && char <= '9') {
            // Build multi-digit number
            // e.g., "100" -> 1, 10, 100
            currentNum = currentNum * 10 + parseInt(char);
        } else if (char === '[') {
            // Start of encoded section
            // Save current state before going deeper
            stack.push(currentString);
            stack.push(currentNum.toString());
            
            // Reset for the new nested level
            currentString = '';
            currentNum = 0;
        } else if (char === ']') {
            // End of encoded section
            // Pop the repeat count
            const repeatCount = parseInt(stack.pop()!);
            
            // Pop the string before this encoded section
            const prevString = stack.pop()!;
            
            // Repeat current string and append to previous
            currentString = prevString + currentString.repeat(repeatCount);
        } else {
            // Regular letter, add to current string
            currentString += char;
        }
    }
    
    return currentString;
};

```

# Example Walkthrough

## Example 1: `s = "3[a]2[bc]"`

```
Initial: stack=[], currentString='', currentNum=0

i=0, char='3':
  currentNum = 3
  
i=1, char='[':
  stack.push('') // currentString
  stack.push('3') // currentNum
  stack = ['', '3']
  currentString = '', currentNum = 0

i=2, char='a':
  currentString = 'a'

i=3, char=']':
  num = stack.pop() = 3
  prevString = stack.pop() = ''
  currentString = '' + 'a'.repeat(3) = 'aaa'
  stack = []

i=4, char='2':
  currentNum = 2

i=5, char='[':
  stack.push('aaa')
  stack.push('2')
  stack = ['aaa', '2']
  currentString = '', currentNum = 0

i=6, char='b':
  currentString = 'b'

i=7, char='c':
  currentString = 'bc'

i=8, char=']':
  num = stack.pop() = 2
  prevString = stack.pop() = 'aaa'
  currentString = 'aaa' + 'bc'.repeat(2) = 'aaabcbc'
  stack = []

Result: "aaabcbc"
```

**Output:** `"aaabcbc"`

# Key Insights

- **Stack for nesting:** Handles nested brackets naturally
- **Multi-digit numbers:** Build number digit by digit
- **State preservation:** Stack saves previous context
- **String concatenation:** Build result incrementally
- **LIFO property:** Last opened bracket is first closed

---

# Edge Cases

| Case | Input | Output | Notes |
|------|-------|--------|-------|
| No encoding | "abc" | "abc" | No brackets |
| Single level | "3[a]" | "aaa" | Simple repeat |
| Nested | "2[a2[b]]" | "abbabb" | Two levels |
| Multiple sections | "2[a]3[b]" | "aabbb" | Sequential |
| Large number | "100[a]" | "aaa...a" | Multi-digit |
| Mixed | "2[abc]3[cd]ef" | "abcabccdcdcdef" | With suffix |

# Common Mistakes to Avoid

1. **Not handling multi-digit numbers:**
   ```typescript
   // Wrong: only handles single digit
   if (char >= '0' && char <= '9') {
       currentNum = parseInt(char);
   }
   
   // Correct: build multi-digit number
   currentNum = currentNum * 10 + parseInt(char);
   ```

2. **Wrong stack operations:**
   ```typescript
   // Wrong: pushing in wrong order
   stack.push(currentNum.toString());
   stack.push(currentString);
   
   // Correct: string first, then number
   stack.push(currentString);
   stack.push(currentNum.toString());
   ```

3. **Not resetting after '[':**
   ```typescript
   // Wrong: not resetting
   if (char === '[') {
       stack.push(currentString);
   }
   
   // Correct: reset for new level
   currentString = '';
   currentNum = 0;
   ```

4. **Incorrect repeat logic:**
   ```typescript
   // Wrong: not appending to previous
   currentString = currentString.repeat(num);
   
   // Correct: append to previous string
   currentString = prevString + currentString.repeat(num);
   ```
