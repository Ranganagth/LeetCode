# Intuition

We need to find the k-th bit in the n-th string without actually building the entire string (which could be up to 2^20 - 1 characters long).

**Key insight:** The string has a recursive structure:
- `Sn = Sn-1 + "1" + reverse(invert(Sn-1))`
- Length of `Sn` = 2^n - 1
- The middle element is always "1"

We can use **recursion** to find the k-th bit by determining which part of the structure it falls into.

---

# Approach

1. **Base case:** If `n = 1`, return "0"

2. **Calculate length:** `len = 2^n - 1`

3. **Find middle position:** `mid = (len + 1) / 2`

4. **Determine which part k falls into:**
   - If `k < mid`: k is in the left part (Sn-1), recurse
   - If `k == mid`: return "1" (middle element)
   - If `k > mid`: k is in the right part (reversed and inverted Sn-1)
     - Map k to corresponding position in Sn-1
     - Recurse and invert the result

---

# Complexity

- **Time complexity:** $O(n)$ - at most n recursive calls
- **Space complexity:** $O(n)$ - recursion call stack

---

# Code

## Solution 1: Recursive (Optimal)

```typescript
function findKthBit(n: number, k: number): string {
    // Base case: S1 = "0"
    if (n === 1) {
        return "0";
    }
    
    // Length of Sn = 2^n - 1
    const length = (1 << n) - 1; // 2^n - 1
    const mid = Math.floor(length / 2) + 1; // Middle position (1-indexed)
    
    if (k === mid) {
        // Middle element is always "1"
        return "1";
    } else if (k < mid) {
        // k is in the left part (Sn-1)
        return findKthBit(n - 1, k);
    } else {
        // k is in the right part (reverse(invert(Sn-1)))
        // Map k to corresponding position in Sn-1
        const mirrorPos = length - k + 1;
        
        // Get the bit from Sn-1 and invert it
        const bit = findKthBit(n - 1, mirrorPos);
        return bit === "0" ? "1" : "0";
    }
};

```

## Solution 2: Iterative Approach

```typescript
function findKthBit(n: number, k: number): string {
    let invert = false;
    
    while (n > 1) {
        const length = (1 << n) - 1;
        const mid = (length >> 1) + 1;
        
        if (k === mid) {
            return invert ? "0" : "1";
        } else if (k > mid) {
            // Map to left side
            k = length - k + 1;
            invert = !invert;
        }
        
        n--;
    }
    
    // Base case: S1 = "0"
    return invert ? "1" : "0";
};

```

## Solution 3: With Detailed Comments

```typescript
function findKthBit(n: number, k: number): string {
    // Base case: S1 = "0"
    if (n === 1) return "0";
    
    // Calculate length of Sn
    // Sn has length 2^n - 1
    const len = (1 << n) - 1; // Bit shift for 2^n
    
    // Find middle position (1-indexed)
    // For S3 = "0111001" (length 7), mid = 4
    const mid = (len + 1) >> 1; // Equivalent to Math.floor((len + 1) / 2)
    
    if (k === mid) {
        // The middle bit is always "1"
        return "1";
    } else if (k < mid) {
        // k is in the left part, which is Sn-1
        // Recurse with n-1
        return findKthBit(n - 1, k);
    } else {
        // k is in the right part: reverse(invert(Sn-1))
        
        // Find the mirror position in the original Sn-1
        // If k is at position 6 in S3 (length 7), mirror is at position 2
        // Formula: mirrorPos = len - k + 1
        const mirrorPos = len - k + 1;
        
        // Get the bit at mirror position in Sn-1
        const originalBit = findKthBit(n - 1, mirrorPos);
        
        // Invert the bit (0 -> 1, 1 -> 0)
        return originalBit === "0" ? "1" : "0";
    }
};

```

# Key Insights

- **Recursive structure:** Each Sn is built from Sn-1
- **Middle is always "1":** The concatenation adds "1" in the middle
- **Mirror property:** Right part is reverse(invert(left part))
- **No need to build string:** Use recursion to navigate structure
- **Efficient:** $O(n)$ time instead of $O(2^n)$ to build entire string

---

# Pattern Recognition

**Length pattern:**
```
S1: length = 1 = 2^1 - 1
S2: length = 3 = 2^2 - 1
S3: length = 7 = 2^3 - 1
S4: length = 15 = 2^4 - 1
Sn: length = 2^n - 1
```

**Structure pattern:**
```
Sn = [ Sn-1 ] + [1] + [ reverse(invert(Sn-1)) ]
     └─ left ─┘ mid └────── right ──────────┘
```

# Common Mistakes to Avoid

1. **Building entire string:**
   ```typescript
   // Wrong: $O(2^n)$ time and space
   function buildString(n) {
       if (n === 1) return "0";
       const prev = buildString(n - 1);
       return prev + "1" + reverse(invert(prev));
   }
   
   // Correct: $O(n)$ recursive navigation
   ```

2. **Wrong mirror calculation:**
   ```typescript
   // Wrong: incorrect mirror position
   const mirrorPos = k - mid;
   
   // Correct: mirror from end
   const mirrorPos = length - k + 1;
   ```

3. **Forgetting to invert:**
   ```typescript
   // Wrong: not inverting right part
   if (k > mid) {
       return findKthBit(n - 1, mirrorPos);
   }
   
   // Correct: invert the result
   const bit = findKthBit(n - 1, mirrorPos);
   return bit === "0" ? "1" : "0";
   ```

4. **Off-by-one in middle:**
   ```typescript
   // Wrong: 0-indexed middle
   const mid = length / 2;
   
   // Correct: 1-indexed middle
   const mid = (length + 1) / 2;
   ```
