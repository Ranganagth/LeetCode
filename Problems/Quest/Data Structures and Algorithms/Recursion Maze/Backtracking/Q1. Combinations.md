# Intuition

We need to generate all possible combinations of `k` numbers from `[1, n]`. This is a classic **backtracking** problem where we build combinations incrementally and explore all valid paths.

**Key insight:** Use backtracking to choose numbers one at a time, ensuring we don't pick the same number twice and maintain ascending order to avoid duplicates.

---

# Approach

1. **Use backtracking** to build combinations:
   - Start from a given number
   - Add it to current combination
   - Recursively explore remaining choices
   - Backtrack by removing the last added number

2. **Pruning optimization:**
   - If remaining slots > remaining numbers, stop early
   - Only explore numbers that can lead to valid combinations

3. **Base case:**
   - When combination size equals `k`, add to results

---

# Complexity

- **Time complexity:** $O(C(n,k) × k)$ where C(n,k) is the binomial coefficient
- **Space complexity:** $O(k)$ for recursion depth and current combination

---

# Code

## Solution 1: Backtracking (Recommended)

```typescript
function combine(n: number, k: number): number[][] {
    const result: number[][] = [];
    const current: number[] = [];
    
    function backtrack(start: number) {
        // Base case: combination is complete
        if (current.length === k) {
            result.push([...current]);
            return;
        }
        
        // Try each number from start to n
        for (let i = start; i <= n; i++) {
            // Add current number
            current.push(i);
            
            // Recurse with next number
            backtrack(i + 1);
            
            // Backtrack: remove current number
            current.pop();
        }
    }
    
    backtrack(1);
    return result;
};

```

## Solution 2: With Pruning Optimization

```typescript
function combine(n: number, k: number): number[][] {
    const result: number[][] = [];
    const current: number[] = [];
    
    function backtrack(start: number) {
        // Base case
        if (current.length === k) {
            result.push([...current]);
            return;
        }
        
        // Calculate how many more numbers we need
        const need = k - current.length;
        
        // Pruning: only iterate if enough numbers remain
        // We need 'need' more numbers, so we must have at least 'need' numbers left
        // Last valid start position: n - need + 1
        for (let i = start; i <= n - need + 1; i++) {
            current.push(i);
            backtrack(i + 1);
            current.pop();
        }
    }
    
    backtrack(1);
    return result;
};

```

## Solution 3: Iterative Approach

```typescript
function combine(n: number, k: number): number[][] {
    const result: number[][] = [];
    const combination: number[] = [];
    
    // Initialize with first k numbers
    for (let i = 1; i <= k; i++) {
        combination.push(i);
    }
    
    while (true) {
        // Add current combination
        result.push([...combination]);
        
        // Find the rightmost element that can be incremented
        let i = k - 1;
        while (i >= 0 && combination[i] === n - k + i + 1) {
            i--;
        }
        
        // If no element can be incremented, we're done
        if (i < 0) break;
        
        // Increment this element
        combination[i]++;
        
        // Set all elements after it to consecutive numbers
        for (let j = i + 1; j < k; j++) {
            combination[j] = combination[j - 1] + 1;
        }
    }
    
    return result;
};

```

## Solution 4: With Detailed Comments

```typescript
function combine(n: number, k: number): number[][] {
    const result: number[][] = [];
    const current: number[] = [];
    
    function backtrack(start: number) {
        // If we've selected k numbers, we have a valid combination
        if (current.length === k) {
            // Make a copy and add to results
            result.push([...current]);
            return;
        }
        
        // Calculate remaining slots to fill
        const remaining = k - current.length;
        
        // Try each number from start to n
        // Optimization: stop when not enough numbers left
        // If we need 'remaining' more numbers, we need at least 'remaining' numbers available
        // So the last valid starting point is n - remaining + 1
        for (let i = start; i <= n - remaining + 1; i++) {
            // Choose: add current number to combination
            current.push(i);
            
            // Explore: recurse with next number as new start
            // We use i+1 to avoid duplicates and maintain ascending order
            backtrack(i + 1);
            
            // Unchoose: backtrack by removing the number
            current.pop();
        }
    }
    
    backtrack(1);
    return result;
};

```

# Key Insights

- **Backtracking pattern:** Choose → Explore → Unchoose
- **Avoid duplicates:** Start from `i+1` in recursion
- **Pruning optimization:** Stop when not enough numbers remain
- **Ascending order:** Naturally maintained by starting from `start`
- **Deep copy:** Must copy array when adding to results

---

# Pruning Optimization Explained

**Without pruning:**
```typescript
for (let i = start; i <= n; i++)
```

**With pruning:**
```typescript
const need = k - current.length;
for (let i = start; i <= n - need + 1; i++)
```

**Example:** n=4, k=3, current=[1]
- Need 2 more numbers
- Last valid start: 4 - 2 + 1 = 3
- No point trying i=4 (can't get 2 more numbers)

# Common Mistakes to Avoid

1. **Not copying the array:**
   ```typescript
   // Wrong: all results point to same array
   result.push(current);
   
   // Correct: create a copy
   result.push([...current]);
   ```

2. **Wrong start index:**
   ```typescript
   // Wrong: allows duplicates like [1,1]
   backtrack(start);
   
   // Correct: start from next number
   backtrack(i + 1);
   ```

3. **Not backtracking:**
   ```typescript
   // Wrong: doesn't remove element
   current.push(i);
   backtrack(i + 1);
   
   // Correct: backtrack
   current.push(i);
   backtrack(i + 1);
   current.pop();
   ```

4. **Wrong pruning condition:**
   ```typescript
   // Wrong: off by one
   for (let i = start; i <= n - need; i++)
   
   // Correct: need + 1
   for (let i = start; i <= n - need + 1; i++)
   ```

# Mathematical Background

**Binomial coefficient:**
```
C(n,k) = n! / (k! × (n-k)!)

Examples:
C(4,2) = 4!/(2!×2!) = 24/4 = 6
C(5,3) = 5!/(3!×2!) = 120/12 = 10
```
