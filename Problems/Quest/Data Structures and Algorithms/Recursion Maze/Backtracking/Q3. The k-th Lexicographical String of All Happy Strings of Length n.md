# Intuition

We need to generate the k-th lexicographically ordered "happy string" of length n, where no two adjacent characters are the same. This is a **backtracking** problem where we build strings character by character, ensuring each new character differs from the previous one.

**Key insight:** Use backtracking to generate happy strings in lexicographical order. Stop when we find the k-th string or determine it doesn't exist.

---

# Approach

1. **Use backtracking** to build happy strings:
   - Try characters 'a', 'b', 'c' in order (ensures lexicographical order)
   - Skip characters that match the previous character
   - When length reaches n, increment counter

2. **Early termination:**
   - Stop as soon as we find the k-th string
   - No need to generate all strings

3. **Count optimization:**
   - Total happy strings of length n = 3 × 2^(n-1)
   - If k exceeds this, return empty string immediately

---

# Complexity

- **Time complexity:** $O(k)$ in best case, $O(3 × 2^n)$ in worst case
- **Space complexity:** $O(n)$ for recursion depth and current string

# Code

## Solution 1: Backtracking (Recommended)

```typescript
function getHappyString(n: number, k: number): string {
    const chars = ['a', 'b', 'c'];
    let count = 0;
    let result = '';
    
    function backtrack(current: string) {
        // Base case: we have a complete happy string
        if (current.length === n) {
            count++;
            if (count === k) {
                result = current;
                return true; // Signal to stop
            }
            return false;
        }
        
        // Try each character
        for (const char of chars) {
            // Skip if same as previous character
            if (current.length > 0 && current[current.length - 1] === char) {
                continue;
            }
            
            // Add character and recurse
            if (backtrack(current + char)) {
                return true; // Found k-th string, stop
            }
        }
        
        return false;
    }
    
    backtrack('');
    return result;
};

```

## Solution 3: Collecting All Results

```typescript
function getHappyString(n: number, k: number): string {
    const chars = ['a', 'b', 'c'];
    const results: string[] = [];
    
    function backtrack(current: string) {
        if (current.length === n) {
            results.push(current);
            return;
        }
        
        for (const char of chars) {
            if (current.length > 0 && current[current.length - 1] === char) {
                continue;
            }
            
            backtrack(current + char);
        }
    }
    
    backtrack('');
    
    // Return k-th string (1-indexed)
    return k <= results.length ? results[k - 1] : '';
};

```

## Solution 4: With Detailed Comments

```typescript
function getHappyString(n: number, k: number): string {
    const chars = ['a', 'b', 'c'];
    let count = 0; // Counter for happy strings found
    let result = ''; // Store the k-th happy string
    
    function backtrack(current: string): boolean {
        // Base case: we've built a complete happy string of length n
        if (current.length === n) {
            count++;
            
            // Check if this is the k-th string
            if (count === k) {
                result = current;
                return true; // Signal to stop searching
            }
            
            return false; // Continue searching
        }
        
        // Try each character in lexicographical order
        for (const char of chars) {
            // Happy string constraint: no adjacent characters can be the same
            if (current.length > 0 && current[current.length - 1] === char) {
                continue; // Skip this character
            }
            
            // Choose: add character to current string
            // Explore: recurse with new string
            if (backtrack(current + char)) {
                return true; // Found k-th string, propagate stop signal
            }
            // Unchoose: implicit (string is immutable)
        }
        
        return false; // Haven't found k-th string yet
    }
    
    backtrack('');
    return result;
};

```

# Key Insights

- **Lexicographical order:** Trying 'a', 'b', 'c' in order ensures this
- **Happy constraint:** Skip character if it matches previous
- **Early termination:** Stop as soon as k-th string is found
- **Count formula:** Total = 3 × 2^(n-1)
  - First position: 3 choices
  - Each subsequent position: 2 choices (exclude previous char)

---

# Mathematical Analysis

**Total happy strings of length n:**

```
Position 1: 3 choices (a, b, c)
Position 2: 2 choices (exclude previous)
Position 3: 2 choices (exclude previous)
...
Position n: 2 choices (exclude previous)

Total = 3 × 2 × 2 × ... × 2 = 3 × 2^(n-1)

Examples:
n=1: 3 × 2^0 = 3
n=2: 3 × 2^1 = 6
n=3: 3 × 2^2 = 12
n=4: 3 × 2^3 = 24
```

# Common Mistakes to Avoid

1. **Not checking adjacent characters:**
   ```typescript
   // Wrong: allows "aa"
   for (const char of chars) {
       backtrack(current + char);
   }
   
   // Correct: skip if same as previous
   if (current.length > 0 && current[current.length - 1] === char) {
       continue;
   }
   ```

2. **Not stopping after finding k-th:**
   ```typescript
   // Wrong: continues generating all strings
   if (count === k) {
       result = current;
   }
   
   // Correct: return true to stop
   if (count === k) {
       result = current;
       return true;
   }
   ```

3. **Wrong lexicographical order:**
   ```typescript
   // Wrong: random order
   const chars = ['c', 'a', 'b'];
   
   // Correct: alphabetical order
   const chars = ['a', 'b', 'c'];
   ```

4. **Off-by-one in k:**
   ```typescript
   // Wrong: 0-indexed
   return results[k];
   
   // Correct: k is 1-indexed
   return results[k - 1];
   ```

# Optimization: Direct Calculation

For advanced solution, we can calculate the k-th string directly without backtracking:

```typescript
function getHappyString(n: number, k: number): string {
    const total = 3 * Math.pow(2, n - 1);
    if (k > total) return '';
    
    const chars = ['a', 'b', 'c'];
    let result = '';
    k--; // Convert to 0-indexed
    
    // First character
    const firstCharIndex = Math.floor(k / Math.pow(2, n - 1));
    result += chars[firstCharIndex];
    k %= Math.pow(2, n - 1);
    
    // Remaining characters
    for (let i = 1; i < n; i++) {
        const options = chars.filter(c => c !== result[i - 1]);
        const optionIndex = Math.floor(k / Math.pow(2, n - 1 - i));
        result += options[optionIndex];
        k %= Math.pow(2, n - 1 - i);
    }
    
    return result;
};

```
