# Intuition

We need to split a string of digits into exactly 4 parts, where each part represents a valid IP segment (0-255, no leading zeros except "0" itself). This is a classic **backtracking** problem where we try different ways to partition the string.

**Key insight:** Use backtracking to place 3 dots in the string, creating 4 segments. Validate each segment as we build the IP address.

---

# Approach

1. **Use backtracking** to build IP addresses:
   - Try placing dots at different positions
   - Validate each segment (0-255, no leading zeros)
   - When we have 4 segments and used all digits, we have a valid IP

2. **Validation rules:**
   - Segment length: 1-3 digits
   - Value: 0-255
   - No leading zeros (except "0" itself)

3. **Pruning:**
   - Stop early if remaining digits can't form valid segments
   - Each segment needs 1-3 digits

---

# Complexity

- **Time complexity:** $O(1)$ - at most $3^4 = 81$ combinations to try
- **Space complexity:** $O(1)$ - constant recursion depth (max 4)

# Code

## Solution 1: Backtracking (Recommended)

```typescript
function restoreIpAddresses(s: string): string[] {
    const result: string[] = [];
    const n = s.length;
    
    // Early termination: IP needs 4-12 digits
    if (n < 4 || n > 12) return result;
    
    function backtrack(start: number, segments: string[]) {
        // Base case: we have 4 segments
        if (segments.length === 4) {
            // Check if we've used all digits
            if (start === n) {
                result.push(segments.join('.'));
            }
            return;
        }
        
        // Try segments of length 1, 2, and 3
        for (let len = 1; len <= 3; len++) {
            // Check if we have enough digits left
            if (start + len > n) break;
            
            // Extract segment
            const segment = s.substring(start, start + len);
            
            // Validate segment
            if (isValid(segment)) {
                // Choose: add segment
                segments.push(segment);
                
                // Explore: recurse
                backtrack(start + len, segments);
                
                // Unchoose: backtrack
                segments.pop();
            }
        }
    }
    
    function isValid(segment: string): boolean {
        // No leading zeros (except "0" itself)
        if (segment.length > 1 && segment[0] === '0') {
            return false;
        }
        
        // Check range 0-255
        const num = parseInt(segment);
        return num >= 0 && num <= 255;
    }
    
    backtrack(0, []);
    return result;
};

```

## Solution 2: Iterative with 3 Nested Loops

```typescript
function restoreIpAddresses(s: string): string[] {
    const result: string[] = [];
    const n = s.length;
    
    if (n < 4 || n > 12) return result;
    
    // Try all possible positions for 3 dots
    for (let i = 1; i < 4 && i < n; i++) {
        for (let j = i + 1; j < i + 4 && j < n; j++) {
            for (let k = j + 1; k < j + 4 && k < n; k++) {
                // Split into 4 segments
                const seg1 = s.substring(0, i);
                const seg2 = s.substring(i, j);
                const seg3 = s.substring(j, k);
                const seg4 = s.substring(k);
                
                // Validate all segments
                if (isValid(seg1) && isValid(seg2) && 
                    isValid(seg3) && isValid(seg4)) {
                    result.push(`${seg1}.${seg2}.${seg3}.${seg4}`);
                }
            }
        }
    }
    
    return result;
    
    function isValid(segment: string): boolean {
        if (segment.length === 0 || segment.length > 3) return false;
        if (segment.length > 1 && segment[0] === '0') return false;
        const num = parseInt(segment);
        return num >= 0 && num <= 255;
    }
};

```

## Solution 3: With Pruning Optimization

```typescript
function restoreIpAddresses(s: string): string[] {
    const result: string[] = [];
    const n = s.length;
    
    if (n < 4 || n > 12) return result;
    
    function backtrack(start: number, segments: string[]) {
        // Base case
        if (segments.length === 4) {
            if (start === n) {
                result.push(segments.join('.'));
            }
            return;
        }
        
        // Pruning: check if remaining digits can form valid segments
        const remaining = 4 - segments.length;
        const digitsLeft = n - start;
        
        // Each segment needs 1-3 digits
        if (digitsLeft < remaining || digitsLeft > remaining * 3) {
            return;
        }
        
        // Try segments of length 1, 2, and 3
        for (let len = 1; len <= 3 && start + len <= n; len++) {
            const segment = s.substring(start, start + len);
            
            if (isValid(segment)) {
                segments.push(segment);
                backtrack(start + len, segments);
                segments.pop();
            }
        }
    }
    
    function isValid(segment: string): boolean {
        if (segment.length > 1 && segment[0] === '0') return false;
        const num = parseInt(segment);
        return num >= 0 && num <= 255;
    }
    
    backtrack(0, []);
    return result;
};

```

# Key Insights

- **Exactly 4 segments:** IP address has fixed structure
- **Segment constraints:** 0-255, no leading zeros
- **Backtracking pattern:** Try different partitions
- **Early termination:** String length must be 4-12
- **Validation critical:** Check each segment before recursing

| Case | Input | Output | Notes |
|------|-------|--------|-------|

| Leading zeros | "010010" | ["0.10.0.10","0.100.1.0"] | No "01" segments |

| Too long | "1234567890123" | [] | Max 12 digits |

# Common Mistakes to Avoid

1. **Not checking leading zeros:**
   ```typescript
   // Wrong: allows "01"
   if (num >= 0 && num <= 255) return true;
   
   // Correct: check leading zeros
   if (segment.length > 1 && segment[0] === '0') return false;
   ```

2. **Wrong segment count:**
   ```typescript
   // Wrong: might have < 4 segments
   if (start === n) result.push(segments.join('.'));
   
   // Correct: ensure exactly 4 segments
   if (segments.length === 4 && start === n)
   ```

3. **Not validating range:**
   ```typescript
   // Wrong: doesn't check 255 limit
   if (segment.length <= 3) return true;
   
   // Correct: check value
   return num >= 0 && num <= 255;
   ```

4. **Forgetting to backtrack:**
   ```typescript
   // Wrong: doesn't remove segment
   segments.push(segment);
   backtrack(start + len, segments);
   
   // Correct: backtrack
   segments.push(segment);
   backtrack(start + len, segments);
   segments.pop();
   ```

# Performance Analysis

For string length n ≤ 12:

| Approach | Time | Space | Notes |
|----------|------|-------|-------|
| Backtracking | $O(1)$ | $O(1)$ | Max $3^4 = 81$ combinations |
| 3 Nested Loops | $O(1)$ | $O(1)$ | Fixed iterations |
| With Pruning | $O(1)$ | $O(1)$ | Faster in practice |

**Maximum combinations:** 3 × 3 × 3 = 27 (each of 3 dots has 3 positions)
